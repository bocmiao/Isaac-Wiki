# Challenge guide sources and regeneration

`challenge-guides.json` contains separately authored practical advice for all 45 official challenges. It does not define new probability tables or numerical game rules. The game rules, characters, goals and unlocks remain in the reviewed `docs/strategy/challenges.md` table and its `docs/.vitepress/theme/data/challenges.json` lookup, generated by `scripts/generate-tool-data.py`.

`scripts/generate-challenge-pages.py` joins those rules to the advice and the pinned `data/achievement-source.json` conditions. It creates `docs/challenges/1.md` through `45.md` and the searchable catalog. Reward #29 / #30 must use the post-Afterbirth version branch: Kidney Stone (#232) for Onan's Streak and Blank Rune (#233) for The Guardian. Do not match the first number in the older combined source condition. Challenge-open achievements and challenge-complete rewards remain separate links.

Mode articles are authored in `docs/modes/`; their card metadata is in `docs/.vitepress/theme/data/catalog/modes.json`. Difficulty IDs are verified against IsaacDocs commit `e05b1fd90e33608a7a7a8dcb70a89cef908cc41a`. Numbered challenge IDs are 1–45, not the four Difficulty values. Older XML-derived third-party lists are not authoritative for changed Repentance+ rules; they contain discrepancies such as Scat Man's removed E. Coli and cannot be blindly merged.

Rule sources: [Challenges](https://bindingofisaacrebirth.wiki.gg/wiki/Challenges), the challenge-specific pages linked from the generated articles, [Greed Mode](https://bindingofisaacrebirth.wiki.gg/wiki/Greed_Mode), [Daily Challenges](https://bindingofisaacrebirth.wiki.gg/wiki/Daily_Challenges), [Victory Lap](https://bindingofisaacrebirth.wiki.gg/wiki/Victory_Lap), [RERUN](https://bindingofisaacrebirth.wiki.gg/wiki/RERUN), [Seeds](https://bindingofisaacrebirth.wiki.gg/wiki/Seeds) and [Co-op](https://bindingofisaacrebirth.wiki.gg/wiki/Co-op), as reviewed in existing repository guides. Conditions derived from wiki.gg retain **CC BY-SA 4.0** and the attribution in `achievement-source.README.md`; original tactical recommendations are identified as suggestions, never as required item combinations. No game installation or real run was used to validate the tactics.

After changing reviewed rules, regenerate the tool lookup first; after changing tactics or challenge rewards:

```sh
python3 scripts/generate-challenge-pages.py
python3 scripts/generate-save-progress-data.py <IsaacScript checkout>
BASE=/Isaac-Wiki/ npm run build
npm test
python3 scripts/check-built-links.py
```

Commit authored data, generated challenge pages, local lookup and the standalone HTML download together. The offline local tool includes each challenge's strategy and canonical online page link, without adding network requests or save-file writes.
