# 各模式能解锁什么与失败排查

<VersionBadge checked="2026-10" />

先在[全成就](/achievements/)查清目标条件，再选模式。例如：挑战奖励要进 Challenges 拿奖杯，困难标记要选 Hard，店主要靠贪婪捐款机解锁。打赢一局不一定同时完成这些目标。

## 按模式对照

| 局类型 | 普通解锁 / 标记 | 专属目标 | 核对入口 |
| --- | --- | --- | --- |
| 随机普通 Normal | 可推进符合条件的普通解锁与目标普通标记 | 正常主线、探索和累计条件 | [普通模式](/modes/normal) |
| 随机困难 Hard | 同目标同时满足普通完成，补困难红标记 | 困难限定奖励 | [困难模式](/modes/hard) |
| 贪婪 Greed | 对应角色普通贪婪条件与标记 | 贪婪捐款机里程碑 | [贪婪](/modes/greed) |
| 极贪 Greedier | 同角色普通贪婪与极贪条件，红边标记 | 要打完金色二阶段；捐款另算 | [极贪](/modes/greedier) |
| 官方编号挑战 | 不用于普通角色标记或其他普通成就 | 当前挑战终点奖杯的奖励 | [45 个挑战](/challenges/) |
| 正式每日 Daily Run | 不用于普通角色标记或其他普通成就 | 参与、总胜利、连胜分别计；在线每日另有奖励 | [每日挑战](/modes/daily) |
| 每日 Practice | 不增加正式每日计数 | 练当天内容 | [练习方式](/modes/practice) |
| 手动指定普通种子 | 禁用普通成就 | 复盘地图与道具 | [种子局](/modes/seeded) |
| 特殊 / 彩蛋种子 | 按所启用的效果逐项判断 | 一种效果禁成就，就不当成正常解锁局 | [完整种子表](/strategy/seeds) |
| 离线胜利圈 | 不用于其他普通成就、普通标记与正常连胜 | 一、二、三圈专属奖励 | [胜利圈](/modes/victory-lap) |
| RERUN | 不用于普通成就和角色标记 | 延续道具搭配娱乐与练习 | [重跑](/modes/rerun) |

以上“可推进”仍要求本局没有其他禁成就因素，并满足指定角色、终点、难度及存档前置。联机还需检查加入资格；自定义挑战和模组奖励另按作者定义，不归入官方 45 项。

## 打完却没得到奖励，按这六步查

1. **核对条件原文。** 去[全成就索引](/achievements/)查编号，确认要求的角色、普通 / 里角色、Boss、困难 / 极贪、单局或累计。打过普通撒但不等于超级撒但；??? 角色与 ??? Boss 也不同。
2. **核对所开的局。** 看是正常局、编号挑战、正式每日、Practice、种子、胜利圈还是 RERUN。能用某个道具不代表本局可以解锁它；每日按全解锁处理也不会替普通存档开放所有内容。
3. **核对结束动作。** 编号挑战和正式每日要碰到终点奖杯。极贪第一阶段结束还没通关；胜利圈要按羔羊与圈数条件完成。
4. **核对参与身份。** 官方在线解锁要求从开局参与，中途加入不能直接当作全程完成。本地宝宝、Remote Play 和官方在线不是同一种身份，也不满足同一组在线成就。
5. **核对记录的含义。** 菜单已开放的挑战不等于已完成；道具已解锁不等于收藏页已拿过；完成普通标记不等于完成困难标记。
6. **核对存档栏与保存。** 一、二、三号存档独立。正常退出游戏后读最新永久进度文件；日期备份、另一栏存档或本局 gamestate 不能替代当前永久进度。见[本地读取方法](/tools/local-progress)。

## 三组最容易混淆的进度

### 挑战开放与完成

前置成就让挑战出现在 Challenges 菜单，进入后还要按规则通关拿奖杯。例如开放 #25 Have a Heart 与完成后获得两种胶囊是不同步骤：[挑战 #25](/challenges/25) · [奖励成就 #228](/achievements/ids-201-300#achievement-228)。

### 通关、捐款与收集

用阿撒泻勒打通普通贪婪解锁莉莉丝；向贪婪捐款机累计投 500 枚开放极贪。这是两种条件。通关后的剩余钱要真正投进机器才推进捐款，商店普通捐款机另记。

道具奖励开放后仍需实际取得，才能推进对应收藏记录。本地工具能读取普通道具的收藏记录，不能判断每张卡牌、每个饰品或胶囊是否拿过。[34 个角色贪婪奖励](/modes/greed-rewards) · [捐款进度](/tools/donations)。

### 每日参与、胜利与连胜

参加 31 次、赢 7 次、连赢 5 次分别对应 #325、#354、#336。失败可计参与，不计获胜；不参加某一天不自动断连胜，参加并失败则断。Practice 的胜利不能补回正式失败。#640 还要求正式在线每日，离线每日与远程同屏不替代。[详细教程](/achievements/special#daily)。

## 下一局怎么安排

普通标记与普通探索成就，选择新开的随机正常局；要红标记就用对应困难 / 极贪。挑战与每日专属奖励进各自正式入口。缺捐款就规划终点留钱，缺收藏则先确认已开放，再去正确来源寻找。

练习时可用种子或控制台熟悉操作，再回符合条件的正式局完成。模组与控制台的具体开关、版本限制见[模组专题](/topics/mods)和[控制台专题](/topics/debug-console)。
