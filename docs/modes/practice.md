# 练习局与控制台训练

<EntryHeader en="Practice / Debug Console" category="练习方式" icon="wrench" />
<VersionBadge checked="2026-10" />

想重打失败的地图，用种子局；想试道具组合或练指定敌人，用控制台；想重打当天每日，用 Practice。三种方式的进度规则不同，见下表。

## 三种训练怎么选

| 训练方式 | 适合做什么 | 进度 |
| --- | --- | --- |
| 每日 Practice | 重复当天角色、地图和终点 | 不增加正式每日参与、胜利或连胜 |
| 手动种子局 | 复盘自己失败的地图 | 不解锁普通成就 |
| 控制台局 | 搭建道具组合、跳到练习场景 | 不把命令生成的结果当正常解锁教程 |

## 开启控制台

Windows Steam 忏悔+ 按[控制台开启教程](/topics/debug-console)找到正确配置文件，关闭游戏后修改，再进入练习局。开不了时先核对版本、配置路径和启用状态，不把其他版本的目录直接照搬。

打开后用[命令生成器](/tools/console-generator)按名称或真实道具 ID 生成命令，完整语法与适用版本见[命令手册](/topics/debug-console-commands)。生成后先读命令用途；跳关和生成实体不会替你完成路线前置。

## 怎样安排有效训练

一次只练一个动作：某个 Boss 的脚踩、某段弹幕、某种近战攻击或某件自伤道具。保留角色平时的移速和射程，先不用无限伤害秒掉目标，否则很难观察自己究竟哪里躲错。

熟悉动作后减少额外防护，最后回正常随机局验证。练母亲、祸兽等路线时，除了 Boss 本身也要练刀片、照片和上行准备；直接跳到终局不能替代路线知识。

## 回到解锁局前

正式每日必须关闭模组和控制台并重启；普通解锁则检查当前局的种子、模式、存档与控制台限制。不要把练习胜利误填成正式每日或挑战完成，清单记录以真实奖杯和成就为准。
