# 重跑 RERUN

<EntryHeader en="RERUN" category="通关后延续" icon="dice" />
<VersionBadge checked="2026-10" />

RERUN 是解锁后的菜单延续玩法：一局胜利后，用上一局的角色和道具搭配再开新的地图。它适合继续玩已有组合，不是用强道具搭配补普通完成标记的工具。

## 如何解锁与进入

先完成 [#337 RERUN](/achievements/ids-301-400#achievement-337)：正常局打羔羊后接受胜利圈，再连续完成三圈，在结束提示中继续。初始正常局不计作第一圈。[胜利圈流程](/modes/victory-lap)。

解锁后，在符合条件的胜利局结束后使用菜单的 **RERUN** 选项，而不是按键盘 R。新局开始时检查实际血量、消耗品和保留下来的能力，不按上一局最后一刻的 HUD 直接估算生存。

## 新局怎么打

地图重新生成，继承道具搭配让早期清房通常更轻松，但房间位置不能照上一局走。重新建立路线计划，少捡会破坏当前稳定攻击的未知组合。

如果前一局依赖有限复活、特定血量状态或临时效果，开局先确认它们仍可用。延续已有组合是娱乐与练习，不意味着不用走位或没有资源风险。

## 能解锁什么

RERUN 不用于解锁普通成就和角色完成标记，也不是继续累加胜利圈奖励。需要推存档进度时，返回新游戏开一场符合条件的随机正常局。

## 三个容易混淆的名字

| 名称 | 行为 | 用途 |
| --- | --- | --- |
| RERUN 菜单 | 胜利后延续已有角色和道具搭配，开新地图 | 继续玩组合，禁普通解锁 |
| 长按键盘 R | 放弃当前局、重新开始 | 不继承这局道具，不增加胜利圈 |
| R键（R Key）道具 | 在当前局使用道具回到开局 | 具体保留与进度规则见道具页 |

[R键（R Key）](/items/c636)的规则不能用来解释 RERUN；控制台的重启命令也是另外一种操作。
