# 自定义挑战与模组局

<EntryHeader en="Custom Challenges / Modded Runs" category="特殊开局" icon="wrench" />
<VersionBadge checked="2026-10" />

自定义挑战由模组作者定义角色、道具、终点与额外规则。它的规则和奖励由模组决定，与官方 #1–45 分开。

## 怎么进入

在 Steam 创意工坊订阅兼容的模组，按作者说明启用并重启。在 **Challenges** 菜单用 <KeyCap>Tab</KeyCap> 切换到自定义挑战列表，再选模组提供的条目。单纯的界面、说明或贴图模组未必带挑战，订阅后没有新挑战并不一定是安装失败。

模组要求的 DLC、Repentance / Repentance+ 版本与前置库必须分别检查。查找和选择实用模组见[创意工坊专题](/topics/mods)。

## 规则与奖励看哪里

终点、房间生成、特殊角色和脚本效果都可能由模组改变，优先看该模组的说明与更新记录。普通挑战攻略只能帮助理解基础战斗，不能替作者定义数值。

自定义挑战完成不等于完成官方挑战，不会替代官方奖励的条件。作者自己的进度与奖励按模组设计记录；普通模组局是否能解锁本体成就，另按当前存档和控制台等条件判断，见[模组与成就说明](/topics/mods)。

## 怎么排查与练习

第一次体验只启用该挑战需要的模组与前置，避免多套角色、地图或道具脚本同时改规则。进入后先确认角色、攻击和目标，做一层测试；若异常，记录游戏版本、模组列表和报错，再按作者说明排查。

想练本体 Boss 或道具组合，可直接用[种子局](/modes/seeded)或[控制台练习](/modes/practice)，不必安装一个复杂挑战来实现简单训练。

## 与联机的关系

官方在线要求关闭模组，因此不能假设自定义挑战可以通过官方在线房间游玩。本地合作是否支持，要看模组作者；Remote Play 只是把本地画面传给朋友，不会自动修复合作兼容问题。
