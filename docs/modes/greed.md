# 贪婪模式

<EntryHeader en="Greed" category="基础难度" icon="coin" />
<VersionBadge checked="2026-10" />

贪婪模式把逐房探索改成固定竞技场刷波、拿钱购物。它属于胎衣及后续 DLC 的内容，Windows Steam 忏悔+ 中可在选角色界面选择 **Greed**；本页不把未经核实的主线击杀次数当作额外开放条件。

## 七层与一层的流程

地下室 → 洞穴 → 深处 → 子宫 → 阴间 → 商店层 → 究极贪婪层。前五层有免费银框宝箱房与需要钥匙的金框宝箱房，商店层没有这两间宝箱房，最后一层直接打战斗房与终点。[七层独立详解](/strategy/floors#greed-floors)。

1. 看免费道具、金框宝箱房和商店，确认本层缺输出还是缺血。
2. 按竞技场按钮，打 **8 个普通波**，清完剩余怪后门开。
3. 再按按钮，打 **2 个 Boss 波**。必需波清完，出口开放。
4. 可选的第 11 波是噩梦波，打完出现恶魔 / 天使房；血量不足可以跳过。
5. 购物、补血、决定剩余资金，再下楼。

## 按钮、硬币与充能

倒计时到或当前波清完会出下一波，清怪慢就可能多波叠在一起。中途踩尖刺按钮可暂停刷波，一般付半颗心；游魂与里游魂改为下一波少一枚硬币。暂停后仍要杀掉场上的怪，见[按钮详细例外](/strategy/greed#波次与按钮)。

硬币在每波**开始**时生成，不是越快清怪奖励越多。普通波每波 2 枚，两个 Boss 波各 4 枚；另有无红心伤害的波次奖励，完整规则见[硬币来源](/strategy/greed#硬币从哪来)。

每波给主动充能，“本房间有效”的效果留在竞技场就可跨波保留，但离房会结束。莉莉丝的朋友盒、犹大的彼列之书因此很好用；波次并不等于所有“进新房”道具都会触发。

## 发育与终局打法

首层先解决清怪速度，否则敌人堆积会快速消耗血量。钱优先用于能立刻改善战斗的道具，再留钥匙与治疗预算。后几层逐步建立防御，波次清完后再从安全区域收钱，不为一枚硬币站在攻击线上。

究极贪婪会利用部分地面硬币回血，留意造币类攻击的副作用。进最后一层前把主动充满，打法见[究极贪婪](/strategy/bosses-2)。

## 奖励与捐款

[34 个角色的贪婪 / 极贪奖励表](/modes/greed-rewards)列出每个角色的具体解锁、道具页与成就条件。想同时补两种通关奖励，开放极贪后可直接用对应角色打极贪。

通关得到该角色不带红边的贪婪标记。Boss 后剩余硬币可投进贪婪捐款机；里程碑包括 **500 枚开放极贪、879 枚让游魂开局带圣斗篷、1000 枚解锁店主**。这是贪婪捐款机，不是商店里的普通捐款机。

卡住概率按角色累计分开计算，轮换角色有助于捐款。来源表有省略的区间，本工具不会补造概率。[捐款规则与里程碑](/strategy/greed#贪婪捐款机) · [捐款进度工具](/tools/donations)。
