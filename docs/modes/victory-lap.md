# 胜利圈

<EntryHeader en="Victory Lap" category="通关后延续" icon="map" />
<VersionBadge checked="2026-10" />

正常局打败羔羊后，可以接受继续跑一圈的提示，带着部分已有构筑回到开局重新走楼层。这里的“胜利圈”与菜单上的正常连胜数字不是同一件事。

## 怎么开启与计数

正常局妈妈时拿底片，走阴间 → 暗室，击败羔羊后选择 **Victory Lap**。最初这场正常局不算已完成的一圈：接受后再一路打到羔羊，才完成第一圈。

要继续累计圈数，每圈仍需到暗室击败羔羊并选择继续。改走宝箱层或虚空的终点不替代羔羊的圈数条件。

## 继承与规则

圈与圈之间可能失去道具，不要假设第一局的飞行、免伤或输出永久存在。每圈开局重新看血量与攻击，再检查路线道具；妈妈时确保拿到底片。

第三圈起会变成游魂，不能再用前两圈的换血策略。继承的构筑虽然强，但失去道具、角色变化和不熟悉的组合仍可导致失败。[游魂常规操作](/characters/lost)。

## 怎么打更稳

第一局先建立可靠攻击、回血与防护，能稳定打羔羊后再接受继续。每次重开一圈时检查哪些关键能力丢了，缺防护就少打无收益支路；不要用已经失去的飞行去穿坑。

接近第三圈前把操作转成游魂思路：优先无伤与安全站位，不赌持续自伤构筑。主动、卡牌和跟班能帮助补防御，但不能假设普通角色的圣斗篷开局强化一定按原样继承。

## 奖励与成就限制

| 完成圈数 | 奖励成就 |
| --- | --- |
| 1 圈 | [#321](/achievements/ids-301-400#achievement-321) |
| 2 圈 | [#360 Butter!](/achievements/ids-301-400#achievement-360) |
| 3 圈并按结束提示继续 | [#337 RERUN](/achievements/ids-301-400#achievement-337) |

离线胜利圈只做圈数相关奖励，不能刷普通角色标记、其他普通成就或正常连胜。按 R 重新开局会丢掉当前局与圈数，不是开始下一圈。

需要普通标记或其他普通解锁时，优先新开随机正常局。联机还需确认自己从开局参与，并检查当前局的成就资格，见[模式解锁排查](/modes/unlock-rules)和[联机专题](/topics/coop)。
