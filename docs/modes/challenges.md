# 编号挑战模式

<EntryHeader en="Challenges" category="特殊开局" icon="trophy" />
<VersionBadge checked="2026-10" />

官方编号挑战共有 **45 个**，每个指定角色、开局规则和终点。它们与地图里的挑战房、每天更新的 Daily Run、模组自定义挑战分别是不同的内容。

## 从哪里选、哪些默认开放

从游戏的 **Challenges** 菜单按编号选择。默认开放 #1–3、#12–18、#36，共 11 个；其余 34 个要先在可解锁的正常局做前置。#45 DELETE THIS 在列表里没有文字，最后那条空白项就是入口。

[45 个独立攻略与搜索](/challenges/)可按编号、名称、角色、奖励与规则查。每篇都有开放条件的成就教程，注意“开放挑战”与“完成挑战奖励”是不同成就。

## 什么算通关、能解锁什么

到指定终点打败目标后**碰到奖杯**，才完成这一挑战并获得对应奖励。挑战里不刷普通角色完成标记，也不用于解锁其他普通成就。失败可以重试，但不能把打过开局 Boss 当作打完所有目标；#31 Backasswards 就还需要反向回到地下室 I。

## 通用限制与发育

大多数挑战没有宝箱房，商店、Boss 奖励、交易房和诅咒房承担主要补强。#1 没有商店；宝箱房例外在各挑战开局表注明。#26 I RULE! 是困难难度，其余为普通难度加挑战规则。

蒙眼意味着不能发射普通泪弹，必须围绕跟班、主动或特殊攻击发育；一般泪弹提升未必解决当前输出。挑战指定开局优先于角色普通开局，以撒不会因为存档解锁了六面骰就在所有挑战里带着它。

挑战没有捐款机，且排除一些换角色、复活和重开道具；完整排除列表、重置与联机注意事项见[挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 推荐顺序

刚开档可以先做 Computer Savvy、The Host、It's in the Cards 等默认开放且有实用奖励的挑战。打过妈妈以后，把 #32 Aprils Fool 纳入计划，完成后抹大拉开局带体力回满胶囊。

需要高级终点或里角色的挑战，等相应路线和角色开放后再做。不要为赶 #34 Ultra Hard 等高压挑战打断基础角色发育；奖励最终都要完成，顺序按当前可进入和自己的操作熟练度安排。[完整推荐顺序](/strategy/challenges#先做哪些)。

## 如何记录

[挑战进度清单](/tools/challenges)支持勾选、导入与导出；[本地存档对照](/tools/local-progress)可以读 Windows Steam 忏悔+ 的实际挑战完成记录。清单勾选代表拿到奖杯，不是菜单项已经解锁。
