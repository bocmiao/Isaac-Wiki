# 困难模式

<EntryHeader en="Hard" category="基础难度" icon="skull" />
<VersionBadge checked="2026-10" />

困难模式仍走正常主线，角色、路线与道具系统都在；区别是房间战斗与资源压力更大。准备冲白金神时，主线完成标记应优先在困难模式做。

## 怎么进入

新游戏选角色时选择 **Hard**。主线未开放的路线仍需先做前置，选择困难不会跳过心脏、底片、母亲路线等开放条件。HUD 会显示困难标识，开局先检查一次。

## 与普通模式有什么区别

| 项目 | 困难模式的影响 | 实际取舍 |
| --- | --- | --- |
| 房间与敌人 | 更容易遇到难处理的布局、精英及资源压力 | 进门先找退路，优先清高威胁目标 |
| 商店 | 忏悔起，在已解锁的商店等级中随机 | 有钱也不保证每层都出现满级商店 |
| 献血机等资源交换 | 部分收益或支付门槛不同 | 不照普通模式经验估算收益 |
| 完成标记 | 对应目标获得困难红标记 | 同时覆盖该目标普通完成 |

商店、乞丐、机器等已核对的具体差异见[机制详解](/strategy/mechanics)。本页不把旧版敌人速度或心掉率传闻写成忏悔+ 的统一数值。

## 前期与中期打法

前两层先建立安全清房能力，不为等“神装”放弃当前有效的提升。精英攻击和狭窄房间很容易造成额外失误，尽量保持侧向移动，不沿敌人的攻击轴线后退。

中期把魂心、防护和伤害当作共同预算：交易提高输出但会减少容错，必须看是否能立即减少受伤。商店可能降级，别把全部补强希望押到下一层商店。遇到回血或护盾，先判断能否解决当前角色真正的生存限制。

## 路线与终局准备

开局明确本局目标，母亲、祸兽、死寂、超级撒但各有路线条件。终点前充好主动，保留关键卡牌，确保角色机制与当前道具不会自伤。[十二格与奖励](/strategy/character-roster#marks) · [路线规划](/tools/routes)。

困难不是要求全程无伤，也不是禁止回血；已经受伤时仍可继续完成该局的目标。需要无伤、限时或特定限制的成就，则另按对应条件判断。

## 奖励与极贪的关系

主线困难目标会满足同目标普通条件，并补红标记。贪婪那一格是另一套玩法：在忏悔+ 中，**普通贪婪不带红边，极贪带红边**。要求全部困难标记的奖励还需要[极贪](/modes/greedier)，不能只把主线 Hard 全打完。
