# 种子局与特殊种子

<EntryHeader en="Seeded Run / Easter Eggs" category="特殊开局" icon="dice" />
<VersionBadge checked="2026-10" />

种子决定一局的主要随机结果。手动指定种子适合复现地图、练 Boss 或分享构筑；特殊种子则是控制视觉、移动、敌人等规则的彩蛋效果。

## 怎么进入

选角色时打开种子输入框，PC 键盘常用 <KeyCap>Tab</KeyCap>，输入游戏认可的代码再开局。当前种子可在暂停界面抄下，输入与彩蛋菜单说明见[完整种子教程](/strategy/seeds)。手柄按键不在本页从键盘映射猜测。

## 普通指定种子与特殊种子

| 类型 | 用途 | 成就 |
| --- | --- | --- |
| 手动输入一局的普通种子 | 复现主要地图与道具随机结果 | 禁用普通成就 |
| 特殊 / 彩蛋种子 | 改变某些规则或表现 | 按具体效果判断，不能一概而论 |
| 游戏自行生成随机种子 | 正常推进存档 | 没有其他限制时可解锁 |

多种彩蛋可以组合，但有互斥与路线冲突。只要其中一种禁用成就，本局就按禁成就处理。完整效果、代码与成就列见[特殊种子表](/strategy/seeds)。

## 为什么同一种子结果不一样

要比较游戏版本、DLC、角色、模组与存档解锁。种子并不保证不同版本或不同条件下每个细节完全一致，也不是“输入别人神种就能复制整套操作结果”。拿到关键道具的时机、重置与操作顺序仍可能改变后续结果。

## 如何用来练习

记下自己失败那局的种子，使用同角色、同版本重新开，先练最常受伤的房间或 Boss。已知地图后可以减少探索压力，专注走位；熟悉后回随机局验证自己能否应对新布局。

试特殊种子前先检查限制是否会卡住路线。例如部分不返房或和平规则与特定终点不兼容，已知例外见[注意事项](/strategy/seeds#注意事项)，不要把彩蛋效果当作解锁捷径。
