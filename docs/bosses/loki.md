# 洛基

<VersionBadge checked="2026-10" />

十字与环状泪弹、传送和召唤交替；Lokii 是另外的双本体 Boss。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 十字 / 环状弹幕 | 本体射击前摇 | 离开对齐轴线，弹幕展开后再调整射线 |
| 召唤 | 额外敌人出现 | 先清阻挡走位的目标 |
| 传送 | 消失后在另一位置出现 | 重新判断两者相对位置，不照旧方向一直冲 |

## 站位与打法

留在能向侧面躲的区域；出现额外本体或召唤物后先观察交叉攻击。

## 容易受伤的地方

只盯本体，退路被召唤物和弹幕堵住。Lokii 的两个半身不是 Loki 的一个普通精英配色。

## 不要混淆

[Lokii（双半身洛基）](/bosses/lokii)。不同 Boss 的击杀记录不互相替代。
