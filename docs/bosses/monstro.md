# 萌死戳

<VersionBadge checked="2026-10" />

小跳调整位置，抬头吐散弹，大跳暂时离开画面。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 小跳 | 身体反复跃起 | 横向跟随移动，留出落点距离 |
| 喷吐 | 抬头张嘴 | 往侧面移动，让散弹先展开再穿空隙 |
| 大跳 | 跳出屏幕 | 离开原站位，看影子与落地后的弹幕 |

## 安全站位与打法

看到吐弹前摇就侧移；大跳时离开原站位，等落地再回到能射击的位置。

## 最容易受伤的地方

只顾打本体而站在落点，或迎着散弹向前追。

精英与变体可能改变速度、弹幕或召唤；进入战斗先看实际外观和攻击，不能只靠名称套用一个节奏。
