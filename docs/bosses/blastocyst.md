# 囊胚

<VersionBadge checked="2026-10" />

跳跃、吐弹与多层分裂会逐步增加场上目标。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 跳跃 | 本体跃起 | 先让开落点 |
| 分裂 | 大体散成小体 | 集中完成一个分支，减少同时吐弹的目标 |

## 站位与打法

先离开落点，再集中清一个分裂分支；小体阶段仍需留弹幕空隙。

## 容易受伤的地方

平均打残所有目标，让多个分支一起变成一群小体。
