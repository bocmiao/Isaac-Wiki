# 小拉里

<VersionBadge checked="2026-10" />

多段身体在房间移动，粪便会改变通道。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 身体移动 | 多段蛇身转弯 | 不要横穿身体，沿外侧走道输出 |
| 排便 | 通道被粪便缩窄 | 先打通退路，再追击；别把自己堵在角落 |

## 安全站位与打法

留在开阔通道，从侧面射击；身体接近时先退到另一条路线。

## 最容易受伤的地方

把自己夹在粪便和墙角之间，或为了追尾巴横穿身体。

精英与变体可能改变速度、弹幕或召唤；进入战斗先看实际外观和攻击，不能只靠名称套用一个节奏。
