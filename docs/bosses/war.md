# 战争骑士

<VersionBadge checked="2026-10" />

骑乘时可冲锋与放炸弹，后段追逐会持续压迫走位。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 冲锋 | 骑乘本体加速 | 横向让路 |
| 炸弹 | 地面出现引线 | 先离开爆炸区域 |
| 下马追逐 | 本体形态变化 | 利用开阔通道边退边打 |

## 安全站位与打法

冲锋横向躲，炸弹位置单独观察；下马后沿开阔路线边退边射击。

## 最容易受伤的地方

沿冲锋轴退到墙边，或下马后停在炸弹旁。

精英与变体可能改变速度、弹幕或召唤；进入战斗先看实际外观和攻击，不能只靠名称套用一个节奏。
