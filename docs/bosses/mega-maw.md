# 巨口

<VersionBadge checked="2026-10" />

吐出的火焰 / 弹幕有展开和移动过程。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 火焰弹 | 嘴部吐出火焰 | 先拉开距离看展开轨迹，再走空隙 |
| 火圈与其他吐弹 | 大范围展开的攻击 | 不要贴脸，留足左右移动空间 |
| 召唤 | 额外敌人出现 | 先打靠近的敌人，不让小怪和火焰一起到达 |

## 站位与打法

远离本体给弹幕展开留空间，观察走向后从空隙穿过。

## 容易受伤的地方

站得太近，直到火焰展开才开始找出口。
