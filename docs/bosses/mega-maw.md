# 巨口

<VersionBadge checked="2026-10" />

吐出的火焰 / 弹幕有展开和移动过程。

## 招式与观察

吐出的火焰 / 弹幕有展开和移动过程。

## 安全站位与打法

远离本体给弹幕展开留空间，观察走向后从空隙穿过。

## 最容易受伤的地方

站得太近，直到火焰展开才开始找出口。

精英与变体可能改变速度、弹幕或召唤；进入战斗先看实际外观和攻击，不能只靠名称套用一个节奏。
