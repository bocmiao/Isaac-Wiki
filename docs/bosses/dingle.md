# 小便便

<VersionBadge checked="2026-10" />

吹口哨、吐弹和连续滑行有不同前摇。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 吹口哨 / 吐弹 | 表情和嘴部前摇 | 观察吐弹方向，绕侧边清小怪 |
| 连续滑行 | 身体蓄力 | 横向闪开，连续冲刺未结束前别贴回去 |
| 喘气停顿 | 冲刺结束后疲惫 | 利用停顿输出，但预留下一次侧移空间 |

## 站位与打法

滑行开始后侧向让路，不在它冲刺方向直退；喘气时集中输出。

## 容易受伤的地方

只躲开第一段滑行，立刻贴近，忽略连续冲刺。
