# 胖蛆

<VersionBadge checked="2026-10" />

看到角色后可直线冲锋，也会产生小怪。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 直线冲锋 | 身体面向并加速 | 离开冲锋轴线，从侧面输出 |
| 召唤小蛆 | 尾部或身体生成小怪 | 清掉脚边小怪再瞄准本体 |
| 吞炸弹 | 冲锋路径上放置炸弹 | 可作为辅助打法；先确保自己有逃离爆炸的空间 |

## 站位与打法

从冲锋轴线侧移；清小怪后再输出，炸弹可作为可选打法。

## 容易受伤的地方

站在窄通道正中与它对射，没有横移空间。
