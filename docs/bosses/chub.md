# 胖蛆

<VersionBadge checked="2026-10" />

看到角色后可直线冲锋，也会产生小怪。

## 招式与观察

看到角色后可直线冲锋，也会产生小怪。

## 安全站位与打法

从冲锋轴线侧移；清小怪后再输出，炸弹可作为可选打法。

## 最容易受伤的地方

站在窄通道正中与它对射，没有横移空间。

精英与变体可能改变速度、弹幕或召唤；进入战斗先看实际外观和攻击，不能只靠名称套用一个节奏。
