# Reap Creep

<VersionBadge checked="2026-10" />

沿墙活动，吐弹和激光按本体所在方位压迫场地。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 沿墙换位 | 本体爬向另一面墙 | 重新判断正前方和输出角度 |
| 吐弹 / 激光 | 本体攻击前摇 | 提前选侧移方向，避开攻击线 |

## 安全站位与打法

本体换墙后重新判断攻击方向；离墙和攻击轴稍远，给弹幕展开空间。

## 最容易受伤的地方

只记一个安全角落，本体换位后仍停在原处。

精英与变体可能改变速度、弹幕或召唤；进入战斗先看实际外观和攻击，不能只靠名称套用一个节奏。
