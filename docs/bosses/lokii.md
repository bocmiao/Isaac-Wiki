# Lokii（双半身洛基）

<VersionBadge checked="2026-10" />

两个半身分别行动和射击，会形成交叉弹幕。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 双本体吐弹 | 两侧都能起手 | 先看交叉区域，避开同时对齐 |
| 传送与召唤 | 位置或敌人数改变 | 重新安排退路，集中清掉一个本体 |

## 站位与打法

同时看两侧，优先击败一个半身减少压力；射线穿过弹幕空隙而非追着本体走。

## 容易受伤的地方

只打左侧却退进右侧弹幕；把 Loki 的单本体击杀当成 Lokii 击杀。

## 不要混淆

[洛基](/bosses/loki)。不同 Boss 的击杀记录不互相替代。
