# 浮肿

<VersionBadge checked="2026-10" />

正下方和两侧的激光、跳跃与漂浮眼球共同限制走位。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 横向 / 下方激光 | 角色与本体对齐 | 优先在本体上方找输出角度 |
| 跳跃 | 本体离地 | 重新判断落地位置，不把上一次安全角度当永久安全 |
| 眼球与地面危害 | 移动眼球或危险地面出现 | 同时看眼球和可站区域，别贴眼球绕圈 |

## 安全站位与打法

优先在上方寻找安全输出角度；跳跃后重新判断位置，不贴着眼球走。

## 最容易受伤的地方

站在正下方对射，或只躲本体却撞上眼球。

精英与变体可能改变速度、弹幕或召唤；进入战斗先看实际外观和攻击，不能只靠名称套用一个节奏。
