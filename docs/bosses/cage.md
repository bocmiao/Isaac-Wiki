# 牢笼

<VersionBadge checked="2026-10" />

跳跃与滚动会改变本体位置和安全区域。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 滚动 | 蜷缩并开始滚行 | 让开滚动路线，不跟着追 |
| 跳跃 | 跃起后准备落地 | 离开落点，并观察落地后的危险 |
| 吐出或召唤 | 本体停顿并张嘴 | 清靠近威胁，再利用停顿输出 |

## 站位与打法

先让开移动路线，等本体停下再输出；看清落地后的地面危险。

## 容易受伤的地方

为了维持输出跟着滚动方向追，撞进本体路径。
