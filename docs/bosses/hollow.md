# 空心虫

<VersionBadge checked="2026-10" />

多段身体沿路径运动，多个身体可能交叉。

## 招式与观察

多段身体沿路径运动，多个身体可能交叉。

## 安全站位与打法

从身体路径之外射击，先确认转向再穿过空隙。

## 最容易受伤的地方

追着尾部进入身体下一次转向的位置。

精英与变体可能改变速度、弹幕或召唤；进入战斗先看实际外观和攻击，不能只靠名称套用一个节奏。
