# 恶鬼

<VersionBadge checked="2026-10" />

先处理小幽灵，再对付沿上方移动的主本体与激光。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 小幽灵阶段 | 本体仍有保护，小幽灵在场 | 先处理可受伤的小幽灵 |
| 本体吐弹 | 上方本体张嘴 | 先留弹幕展开距离，不向上顶 |
| 激光 | 本体正对攻击线蓄势 | 在发射前离开正前方，不要等激光出现再穿线 |

## 站位与打法

第一段清召唤物；本体阶段避开正前方攻击线，贴边也要保留退路。

## 容易受伤的地方

把它当作普通追逐怪一直向上顶，或激光前没有观察站位。
