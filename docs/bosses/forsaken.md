# The Forsaken

<VersionBadge checked="2026-10" />

隐身换位、召唤与激光波影响安全角度。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 隐身换位 | 消失与重新显形 | 先观察新位置，不冲向旧位置 |
| 召唤 | 敌人出现 | 先清近处威胁 |
| 激光波 | 开始发射 | 提前选空隙方向，别直穿激光线 |

## 安全站位与打法

本体消失时先清堵路的小怪；重新出现后观察激光展开方向，继续移动。

## 最容易受伤的地方

只盯本体站桩，等攻击出现才找退路。

精英与变体可能改变速度、弹幕或召唤；进入战斗先看实际外观和攻击，不能只靠名称套用一个节奏。
