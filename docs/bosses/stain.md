# The Stain

<VersionBadge checked="2026-10" />

钻地、触手与大范围弹幕交替。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 钻地 | 本体消失 | 移动并观察重新出现的位置 |
| 触手 / 弹幕 | 露头后攻击 | 离近处威胁远一些，弹幕展开后找空隙 |

## 站位与打法

钻地时保持移动，露头后先确认触手和弹幕方向；不追进角落。

## 容易受伤的地方

看不见本体就停下，被露头和触手夹击。
