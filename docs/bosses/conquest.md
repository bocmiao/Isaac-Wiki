# 征服骑士

<VersionBadge checked="2026-10" />

冲锋与分身、泪弹和圣光会改变攻击位置。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 冲锋 / 分身 | 多条冲锋路径形成 | 避开横穿路径，不追着其中一个影像 |
| 圣光 / 泪弹 | 地面或空中攻击展开 | 同时看落点和弹幕，先躲再输出 |

## 安全站位与打法

看清冲锋路径与地面落点，留侧移空间；分身出现后不要只盯原本体。

## 最容易受伤的地方

把场上的影像全当装饰，或站在圣光落点。

精英与变体可能改变速度、弹幕或召唤；进入战斗先看实际外观和攻击，不能只靠名称套用一个节奏。
