# 咕噜妈妈

<VersionBadge checked="2026-10" />

上方本体吐弹、呕吐与地面尖刺交替。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 地面尖刺 | 地面出现变化 | 移向还安全的位置，别长期守一块地面 |
| 吐弹 / 呕吐 | 上方本体张嘴 | 留出弹幕展开距离并同时观察地面 |

## 站位与打法

同时看地面与弹幕；安全地面变少时先找下一块能站的地方，不贴上方本体。

## 容易受伤的地方

只顾躲空中的弹丸，停在升起的尖刺上。
