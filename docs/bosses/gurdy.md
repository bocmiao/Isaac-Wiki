# 咕噜大

<VersionBadge checked="2026-10" />

本体较固定，能从不同方向吐弹并召唤敌人。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 前方 / 两侧吐弹 | 不同位置露出攻击口 | 保持远距离的侧移空间，别贴本体 |
| 苍蝇、吐弹小怪、疖子 | 小怪或固定炮台出现 | 优先打靠近或封路目标，清出路线后回打本体 |

## 站位与打法

留在有侧移空间的位置；召唤物靠近时先清掉，再回来打本体。

## 容易受伤的地方

贴着本体射击，让两侧攻击和小怪同时封路。
