# 咕噜

<VersionBadge checked="2026-10" />

多个本体移动和冲锋，地面痕迹限制路线。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 冲锋 | 本体转向并加速 | 同时观察其他本体，横向避开冲锋轴 |
| 移动与地面痕迹 | 走过位置出现危险地面 | 走干净的通道，集中打掉一只减少交叉威胁 |

## 站位与打法

优先集中伤害清掉一只；移动时同时看其他本体与地面。

## 容易受伤的地方

绕圈只盯目标，撞上另一只或它留下的地面伤害。
