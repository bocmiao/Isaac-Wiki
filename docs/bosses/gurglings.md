# 咕噜

<VersionBadge checked="2026-10" />

多个本体移动和冲锋，地面痕迹限制路线。

## 招式与观察

多个本体移动和冲锋，地面痕迹限制路线。

## 安全站位与打法

优先集中伤害清掉一只；移动时同时看其他本体与地面。

## 最容易受伤的地方

绕圈只盯目标，撞上另一只或它留下的地面伤害。

精英与变体可能改变速度、弹幕或召唤；进入战斗先看实际外观和攻击，不能只靠名称套用一个节奏。
