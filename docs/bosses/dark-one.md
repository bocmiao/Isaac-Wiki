# 黑暗之主

<VersionBadge checked="2026-10" />

变暗、环状弹幕、冲锋与激光交替。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 冲锋 | 本体加速 | 横向避让 |
| 环状弹幕 | 环圈向外展开 | 保持距离，找空隙 |
| 激光 / 变暗 | 本体蓄力或视野降低 | 提前换角度，别在正前方停下 |

## 安全站位与打法

离开冲锋轴和激光线；视野变暗时减少追击，给转向留下空间。

## 最容易受伤的地方

房间变暗后靠记忆一直直跑。

精英与变体可能改变速度、弹幕或召唤；进入战斗先看实际外观和攻击，不能只靠名称套用一个节奏。
