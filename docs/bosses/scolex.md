# Scolex

<VersionBadge checked="2026-10" />

潜地与吐弹交替，身体不同部位的受伤能力不同。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 潜地 / 跳出 | 本体消失后露出 | 保持移动，确认露出部位再射击 |
| 吐弹 | 头部露出并攻击 | 侧移避开弹丸及落点 |

## 安全站位与打法

看它露出的部位，尽量对可伤部位输出；潜地时调整位置，不贴着落点追。

## 最容易受伤的地方

一直打保护部位却不看血条。

精英与变体可能改变速度、弹幕或召唤；进入战斗先看实际外观和攻击，不能只靠名称套用一个节奏。
