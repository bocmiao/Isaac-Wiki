# 绷带人

<VersionBadge checked="2026-10" />

头部与召唤物会分散威胁，本体还会继续行动。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 抛头与蜘蛛 | 头部离开本体 | 先清贴身威胁，别让头和蜘蛛围住退路 |
| 泪弹 | 本体射击动作 | 侧移避弹，保持能处理召唤物的射线 |
| 恢复召唤物 | 战场数量再次增加 | 输出不足时优先整理场面，避免只追本体 |

## 站位与打法

输出不足时先清威胁近的召唤物，不让战场越拖越乱。

## 容易受伤的地方

全程只追本体，忽略会靠近的头与蜘蛛。
