# 绷带人

<VersionBadge checked="2026-10" />

## 招式与观察

头部与召唤物会分散威胁，本体还会继续行动。

## 安全站位与打法

输出不足时先清威胁近的召唤物，不让战场越拖越乱。

## 最容易受伤的地方

全程只追本体，忽略会靠近的头与蜘蛛。

精英与变体可能改变速度、弹幕或召唤；进入战斗先看实际外观和攻击，不能只靠名称套用一个节奏。
