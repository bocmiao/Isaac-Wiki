# 饥荒骑士

<VersionBadge checked="2026-10" />

骑乘时冲锋与召唤，后段头部继续吐弹。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 冲锋 | 开始沿轴线冲刺 | 横向让开，不沿同一直线后退 |
| 召唤 | 小怪出现 | 先清堵路目标 |
| 头部射击 | 只剩头部 | 重新拉开距离，看吐弹方向 |

## 安全站位与打法

冲锋侧向躲，先清近处随从；本体变化后调整距离观察新弹道。

## 最容易受伤的地方

下马或身体变化后以为已经结束。

精英与变体可能改变速度、弹幕或召唤；进入战斗先看实际外观和攻击，不能只靠名称套用一个节奏。
