# 死亡骑士

<VersionBadge checked="2026-10" />

镰刀、减速与后续骑士敌人影响移动节奏。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 镰刀 | 场上出现镰刀 | 先让开移动路径，清能处理的威胁 |
| 沙漏减速 | 角色移动节奏变慢 | 提前离开攻击线，减少贴身输出 |
| 后续召唤 | 阶段或随从变化 | 先清阻挡退路的目标 |

## 安全站位与打法

先处理靠近的镰刀与随从；速度降低时提早躲避，不按原来移速估算。

## 最容易受伤的地方

减速后仍贴着本体追，或忽略独立移动的敌人。

精英与变体可能改变速度、弹幕或召唤；进入战斗先看实际外观和攻击，不能只靠名称套用一个节奏。
