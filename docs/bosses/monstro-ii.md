# 萌死戳二世

<VersionBadge checked="2026-10" />

跳跃、召唤与横向激光交替。

## 招式与观察

跳跃、召唤与横向激光交替。

## 安全站位与打法

避免与它长时间保持同一水平线；激光前侧移到上下方。

## 最容易受伤的地方

沿着它面对的方向跑，或把它当成只吐弹的第一章版本。

精英与变体可能改变速度、弹幕或召唤；进入战斗先看实际外观和攻击，不能只靠名称套用一个节奏。
