# 萌死戳二世

<VersionBadge checked="2026-10" />

跳跃、召唤与横向激光交替。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 横向激光 | 和本体处在同一水平线 | 预先移到上方或下方，别沿水平线后退 |
| 跳跃 | 本体离地 | 离开落点，落地后重新确认激光轴 |
| 召唤 | 小怪进入场地 | 优先清脚边威胁，避免侧移方向被堵 |

## 站位与打法

避免与它长时间保持同一水平线；激光前侧移到上下方。

## 容易受伤的地方

沿着它面对的方向跑，或把它当成只吐弹的第一章版本。
