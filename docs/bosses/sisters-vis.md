# 维斯姐妹

<VersionBadge checked="2026-10" />

双本体的滚动和攻击可能同时封路，战斗会因一方死亡改变。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 滚动 | 两者缩起并移动 | 看两条路径，避开交汇位置 |
| 一方倒下 | 剩余本体动作改变 | 先重新拉开距离，再继续输出 |

## 站位与打法

在两者路径外侧移动，优先打掉一只；阶段变化后先观察剩余本体节奏。

## 容易受伤的地方

夹在两个本体中间，或击败一只后以为余下的一样慢。
