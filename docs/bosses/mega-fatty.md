# 超级胖胖

<VersionBadge checked="2026-10" />

大跳、小跳和其他招式节奏不同。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 高跳 / 低跳 | 身体弹起高度与节奏不同 | 离开落点，不能把所有跳跃按同一时机躲 |
| 吸入与呕吐 | 吸气后转为吐出攻击 | 看吸入结束的转折，别朝本体顶 |
| 其他近身攻击 | 身体周围出现影响 | 保持距离，停顿时再输出 |

## 站位与打法

看跳跃前摇与落点，持续移动但不要绕进角落；停顿时输出。

## 容易受伤的地方

把所有跳跃都按同一速度躲，或跳完立即贴身。
