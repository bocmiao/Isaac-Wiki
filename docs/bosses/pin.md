# 针头

<VersionBadge checked="2026-10" />

潜地后跳出，落点附近有泪弹。

## 招式与观察

潜地后跳出，落点附近有泪弹。

## 安全站位与打法

看影子和跳出方向，持续横移；在它显露身体时输出。

## 最容易受伤的地方

站在原地等它出现，或在刚落地时冲到它下面。

精英与变体可能改变速度、弹幕或召唤；进入战斗先看实际外观和攻击，不能只靠名称套用一个节奏。
