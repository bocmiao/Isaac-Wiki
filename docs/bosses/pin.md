# 针头

<VersionBadge checked="2026-10" />

潜地后跳出，落点附近有泪弹。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 潜地跳出 | 身体消失、地面位置变化 | 保持横移，露头时射击，不守原地 |
| 爆炸弹 | 头部露出并吐出弹丸 | 避开弹丸落点，不与爆炸位置重合 |

## 站位与打法

看影子和跳出方向，持续横移；在它显露身体时输出。

## 容易受伤的地方

站在原地等它出现，或在刚落地时冲到它下面。
