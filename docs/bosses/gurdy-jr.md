# 小咕噜大

<VersionBadge checked="2026-10" />

滑行冲锋、吐弹与召唤交替，近身冲撞是主要威胁。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 滑行 | 蓄力后向前冲 | 往垂直于冲刺的方向躲，不直退到墙角 |
| 吐弹 | 喷射前摇 | 保留距离，穿过展开后的空隙 |
| 召唤 | 小怪出场 | 先清最近威胁，避免冲锋和小怪同时封路 |

## 安全站位与打法

以横向闪避冲刺，留足距离；墙角附近先找下一条退路。

## 最容易受伤的地方

沿冲刺方向一直后退，最终被墙挡住。

精英与变体可能改变速度、弹幕或召唤；进入战斗先看实际外观和攻击，不能只靠名称套用一个节奏。
