# 敌手

<VersionBadge checked="2026-10" />

激光与其他攻击会按当前位置造成威胁。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 激光 | 头部蓄力、脸朝攻击方向 | 提前侧移并继续走，不停下对射 |
| 召唤蜘蛛 | 小怪出现 | 清最近威胁，再调整本体角度 |
| 变暗 / 跳起 | 视野或本体位置变化 | 提高观察落点的优先级，不盲追 |

## 站位与打法

留意脸部前摇，激光即将发出时侧移；持续调整角度。

## 容易受伤的地方

完全停下对射，等激光已出现才开始换位置。
