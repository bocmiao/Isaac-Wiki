# 敌手

<VersionBadge checked="2026-10" />

激光与其他攻击会按当前位置造成威胁。

## 招式与观察

激光与其他攻击会按当前位置造成威胁。

## 安全站位与打法

留意脸部前摇，激光即将发出时侧移；持续调整角度。

## 最容易受伤的地方

完全停下对射，等激光已出现才开始换位置。

精英与变体可能改变速度、弹幕或召唤；进入战斗先看实际外观和攻击，不能只靠名称套用一个节奏。
