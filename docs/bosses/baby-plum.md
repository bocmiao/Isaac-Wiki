# 糖梅宝宝

<VersionBadge checked="2026-10" />

旋转射击、弹圈和大范围弹幕需要分别观察。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 旋转射击 | 本体旋转 | 留展开距离，不贴着追 |
| 弹圈 | 成圈的泪弹出现 | 先观察空隙，再穿圈 |
| 大范围弹幕 | 发射方向持续变化 | 移动躲弹，别只盯本体 |

## 安全站位与打法

保持距离看弹幕展开，再从空隙移动；要拿逃离解锁时先停手并防止随从误伤。

## 最容易受伤的地方

想解锁糖梅溜溜笛却让被动跟班或爆炸持续伤害本体。

精英与变体可能改变速度、弹幕或召唤；进入战斗先看实际外观和攻击，不能只靠名称套用一个节奏。

## 特殊奖励怎么取

要解锁糖梅溜溜笛，在允许解锁的随机正常局让糖梅宝宝自行离开，不要击杀。停止攻击并躲避，留意跟班、火焰、毒和爆炸等误伤；逃离奖励与直接打死的结算不同。 对应[成就 #410](/achievements/ids-401-500#achievement-410)。
