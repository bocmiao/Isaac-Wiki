# 瘘管

<VersionBadge checked="2026-10" />

大块分裂成小块，数量会逐渐增加。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 分裂 | 大块被打散 | 集中清完一个分支，减少同时存在的小块 |
| 碎块移动 | 多个目标向不同方向扩散 | 优先留下开阔走道，不平均打残全部碎块 |

## 站位与打法

优先把一个分支打完，减少同时活动的碎块；保持开阔走道。

## 容易受伤的地方

平均攻击所有碎块，导致场上同时出现大量小目标。
