# 瘘管

<VersionBadge checked="2026-10" />

大块分裂成小块，数量会逐渐增加。

## 招式与观察

大块分裂成小块，数量会逐渐增加。

## 安全站位与打法

优先把一个分支打完，减少同时活动的碎块；保持开阔走道。

## 最容易受伤的地方

平均攻击所有碎块，导致场上同时出现大量小目标。

精英与变体可能改变速度、弹幕或召唤；进入战斗先看实际外观和攻击，不能只靠名称套用一个节奏。
