# 瘟疫骑士

<VersionBadge checked="2026-10" />

爆炸弹和召唤物会同时影响站位，失去头部后仍会攻击。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 爆炸弹 | 吐出抛物线弹丸 | 先让开落点，别贴着落点继续射击 |
| 召唤 | 额外敌人出现 | 先清堵路威胁 |
| 后段 | 头部消失 | 不要停手，继续按本体动作躲避 |

## 安全站位与打法

避开爆炸落点和危险地面，先清贴身随从；头部变化后继续观察。

## 最容易受伤的地方

只躲弹丸，停在爆炸或危险地面的落点。

精英与变体可能改变速度、弹幕或召唤；进入战斗先看实际外观和攻击，不能只靠名称套用一个节奏。
