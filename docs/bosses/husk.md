# The Husk

<VersionBadge checked="2026-10" />

移动、召唤与成簇吐弹并存，是苍蝇公爵相关变体。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 召唤 | 随从出现 | 先打靠近且封路的敌人 |
| 吐弹 / 弹簇 | 本体攻击动作 | 拉开距离看展开方向，侧移避弹 |

## 站位与打法

先清靠近的召唤物，离本体稍远看弹簇展开；不用苍蝇公爵只召唤的节奏套它。

## 容易受伤的地方

只盯苍蝇，忘记本体也会直接射击。
