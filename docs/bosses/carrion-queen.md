# 腐肉女王

<VersionBadge checked="2026-10" />

多段身体冲锋并留下危险地面，正面输出可能受限。

## 招式、前摇与应对

| 招式 | 看什么 | 怎么躲 |
| --- | --- | --- |
| 冲锋 | 本体朝一条轴线移动 | 侧移，别正面硬顶 |
| 排便 | 地面危险增加 | 尽早保留干净通道，必要时先处理障碍 |
| 后段受伤窗口 | 尾部或后方暴露 | 从可命中的角度射击，确认血条下降 |

## 站位与打法

从侧后方观察能受伤的位置；先留干净走道，避免红色大便堵住唯一退路。

## 容易受伤的地方

迎着头部打却不看血条，或退到危险地面。
