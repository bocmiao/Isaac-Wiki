# #41 Pica Run

<EntryHeader en="Challenge #41" category="编号挑战 · 需要解锁" icon="trophy" />

<VersionBadge checked="2026-10" />

底座变成饰品，发育核心是挑选、吞下和叠加有用饰品。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [以撒](/characters/isaac) |
| 终点 | 以撒（Boss） |
| 宝箱房 | 有常规宝箱房 |
| 商店 | 可生成，受本挑战的替换与价格规则影响 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 所有道具换成随机饰品；妈妈的盒子（Mom's Box）、弹珠袋（Marbles）、妈妈的钱包（Mom's Purse），弹珠袋每次受伤都触发；有宝箱房 |

挑战按上表的固定开局玩。蒙眼时不能发射普通泪弹，主要靠跟班、主动或特殊攻击。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：妈妈的心脏累计 11 次，并已解锁弹珠袋。[逐步解锁教程](/achievements/ids-501-600#achievement-512)。

**完成奖励**：冰块（Ice Cube）。[奖励成就 #522 的条件](/achievements/ids-501-600#achievement-522)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

多用妈妈的盒子生成饰品，先保留能稳定增加输出、资源或生存的效果。妈妈的钱包提供容量，但不需要把每件饰品都留下，先看当下短板。

## 中期拿什么道具

弹珠袋在本挑战每次受伤都会触发吞饰品，能把当前饰品保留下来；仍不要为吞掉低价值饰品反复扣血。找到好饰品后再评估受伤成本，注意妈妈的盒子对持有饰品的强化。

## 路线与终点打法

打完子宫 II 的心脏 / 它活着，走光柱到教堂，击败以撒。

走教堂打以撒，终点前整理好真正参与战斗的饰品。稳住普通泪弹与护盾来源，不要到了 Boss 战才通过挨打临时尝试吞下新饰品。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

不能按正常局的品质底座来选道具搭配；商店、Boss 奖励等也受替换规则影响。
