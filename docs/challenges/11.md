# #11 Glass Cannon

<EntryHeader en="Challenge #11" category="编号挑战 · 需要解锁" icon="trophy" />

<VersionBadge checked="2026-10" />

史诗胎儿博士输出很强，但只有一颗红心容器且会误炸自己。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [犹大](/characters/judas) |
| 终点 | 撒但 |
| 宝箱房 | 不生成常规宝箱房 |
| 商店 | 可生成，特殊替换规则见下文 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 只有 1 红心；史诗胎儿博士（Epic Fetus）、洛基的角（Loki's Horns） |

挑战指定的开局优先于角色普通局的开局。蒙眼时不能发射普通泪弹；跟班、可用主动与特殊攻击另看各挑战规则。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：完成 The Family Man，击败 Lokii，并已解锁犹大和「它活着」。[逐步解锁教程](/achievements/ids-101-200#achievement-164)。

**完成奖励**：规则卡（Rules Card）。[奖励成就 #99 的条件](/achievements/ids-001-100#achievement-99)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

准星放在离自己较远的敌人身上，发射后留意角色位置。先补魂心、黑心、容器或爆炸免疫，不要觉得一开始伤害够高就可以舍弃防御。

## 中期发育与道具取舍

洛基的角可能增加攻击方向，靠墙和小房间尤其要小心。主要提升生存和稳定性；当场能改善清房的商店防护比继续堆过量伤害更实用。

## 路线与终点打法

打完子宫 II 的心脏 / 它活着，走向下的入口到阴间，击败撒但。

撒但每段都留出自己的安全区域，等脚下阴影出现后先走开再定位准星。用远程轰炸处理水蛭，避免把爆炸落点引到自己移动的路线。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

挑战名称叫 Glass Cannon，但开局攻击道具是史诗胎儿博士，不是玻璃大炮主动道具。
