# #28 PRIDE DAY!

<EntryHeader en="Challenge #28" category="编号挑战 · 需要解锁" icon="trophy" />

<VersionBadge checked="2026-10" />

泪弹效果与轨迹持续改变，不能依赖一种固定的手感。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [以撒](/characters/isaac) |
| 终点 | 妈妈的心脏 |
| 宝箱房 | 不生成常规宝箱房 |
| 商店 | 可生成，受本挑战的替换与价格规则影响 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 3美元纸币（3 Dollar Bill）、彩虹宝宝（Rainbow Baby）、饰品彩虹虫（Rainbow Worm），彩虹虫不能丢弃或替换 |

挑战按上表的固定开局玩。蒙眼时不能发射普通泪弹，主要靠跟班、主动或特殊攻击。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：击败妈妈。[逐步解锁教程](/achievements/ids-201-300#achievement-272)。

**完成奖励**：八面骰（D8）。[奖励成就 #231 的条件](/achievements/ids-201-300#achievement-231)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

射击时观察当前弹道，先保持稍远的距离。出现爆炸或短射程效果时及时调整，不要把上一秒的安全距离沿用到下一种泪弹。

## 中期拿什么道具

优先拿稳定防御、血量和跟班，减少对随机泪弹的依赖。彩虹虫不能直接丢掉或替换，想带别的饰品要借助额外容量或吞饰品效果。

## 路线与终点打法

地下室 → 洞穴 → 深处 → 子宫 II 的妈妈的心脏 / 它活着。

心脏弹幕阶段集中躲避，效果变短时等安全窗口再靠近。彩虹宝宝可以补伤害，但不会消除自身泪弹的轨迹变化。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

不要因为大多数随机效果有利就持续贴脸，火焰意志等效果仍可能造成自伤。
