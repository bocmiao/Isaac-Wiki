# #14 It's in the Cards

<EntryHeader en="Challenge #14" category="编号挑战 · 默认开放" icon="trophy" />

<VersionBadge checked="2026-10" />

大量抽牌提供资源和战斗机会，胜负仍取决于是否把牌用在合适的房间。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [以撒](/characters/isaac) |
| 终点 | 妈妈 |
| 宝箱房 | 不生成常规宝箱房 |
| 商店 | 可生成，特殊替换规则见下文 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 9伏特、蓄电池（The Battery）、卡牌盒（Deck of Cards）、新手牌组（Starter Deck）、2 张随机塔罗牌 |

挑战指定的开局优先于角色普通局的开局。蒙眼时不能发射普通泪弹；跟班、可用主动与特殊攻击另看各挑战规则。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：默认开放。默认开放，可直接选择。

**完成奖励**：超级食肉男孩死忠粉（SMB Super Fan）。[奖励成就 #63 的条件](/achievements/ids-001-100#achievement-63)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

及时使用卡牌盒，让9伏特和蓄电池参与充能循环。资源牌在不会浪费拾取物的位置用，传送牌先保留一张作应急，再用另一格放攻击或保命牌。

## 中期发育与道具取舍

卡牌只是补充发育，Boss 奖励、商店和交易仍要改善泪弹输出。遇到改变血量、传送或重置效果的牌，先看说明再用，不要把未知牌全部带进终点战一次按完。

## 路线与终点打法

地下室 → 洞穴 → 深处 II 的妈妈。终点就在妈妈战，不需要继续打子宫。

妈妈战前准备保命或直接伤害牌，进场后按攻击窗口使用。留意传送牌会让你离开战斗房，打完不要把终点奖杯当成普通掉落跳过。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

新手牌组提供两格卡牌容量，但持有两张强牌并不会自动触发它们。
