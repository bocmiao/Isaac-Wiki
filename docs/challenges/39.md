# #39 Isaac's Awakening

<EntryHeader en="Challenge #39" category="编号挑战 · 需要解锁" icon="trophy" />

<VersionBadge checked="2026-10" />

用英灵剑代替普通泪弹，走替代路线打母亲；盾牌与近战距离都需要管理。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [以撒](/characters/isaac) |
| 终点 | 母亲 |
| 宝箱房 | 通常不生成；#39 下水道 II 的刀片房例外 |
| 商店 | 可生成，特殊替换规则见下文 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 英灵剑（Spirit Sword）、三位一体盾、妈妈的手镯（Mom's Bracelet）；不发射泪弹，改为挥剑 |

挑战指定的开局优先于角色普通局的开局。蒙眼时不能发射普通泪弹；跟班、可用主动与特殊攻击另看各挑战规则。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：击败母亲。[逐步解锁教程](/achievements/ids-501-600#achievement-510)。

**完成奖励**：英灵剑。[奖励成就 #520 的条件](/achievements/ids-501-600#achievement-520)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

用挥剑和蓄力攻击清怪，举盾朝向主要弹幕来源。进入下水道、矿洞、陵墓不需要正常门票，但仍须完成刀片流程；下水道 II 的刀片宝箱房是特殊保留的例外。

## 中期发育与道具取舍

取得菜刀碎片1、2，经过陵墓妈妈与后续路线进入尸宫。不要在其他层反复寻找常规宝箱房，补强主要靠 Boss、商店和交易；妈妈的手镯可处理障碍与辅助攻击。

## 路线与终点打法

走下水道 / 水潭 → 矿洞 / 灰坑 → 陵墓 / 炼狱 → 尸宫 II，完成路线需要的刀片流程，击败母亲。

尸宫的 Rotgut 和母亲都需要把躲避放在近身挥剑之前。母亲战朝向弹幕举盾，安全时用蓄力斩抓窗口；影之书等无敌能力能帮助处理难躲的阶段。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

免费进替代路线不等于自动拿齐刀片；忘做镜面或矿洞流程仍会卡住母亲路线。
