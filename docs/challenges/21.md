每层地图都很大，但同一章的两层仍分别存在，不能按普通迷宫层少走一层的思路。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [以撒](/characters/isaac) |
| 终点 | 妈妈的心脏 |
| 宝箱房 | 有常规宝箱房 |
| 商店 | 可生成，受本挑战的替换与价格规则影响 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 每层都是 XL 大小（XL 层：平常由同一章两层合并成的加大层），但这里同一章的两层不合并；有宝箱房 |

挑战指定的开局优先于角色普通局的开局。蒙眼时不能发射普通泪弹；跟班、可用主动与特殊攻击另看各挑战规则。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：击败妈妈。[逐步解锁教程](/achievements/ids-201-300#achievement-265)。

**完成奖励**：金心（Gold Heart）。[奖励成就 #224 的条件](/achievements/ids-201-300#achievement-224)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

在大地图中先找宝箱房和 Boss，清过的死路在地图上记住，少做没有收益的往返。找到地图、指南针或蓝地图时，导航价值比正常局更高。

## 中期发育与道具取舍

房间多意味着可积累主动充能和资源，也意味着更多受伤机会。需要补强时再探索支路，构筑能稳定清房后，把重点转到终点方向；留钥匙给后续宝箱房。

## 路线与终点打法

地下室 → 洞穴 → 深处 → 子宫 II 的妈妈的心脏 / 它活着。

到子宫后不再为了遍历地图清光所有房间，先确认 Boss 方位和血量。心脏战按正常节奏，避免因为跑图时间长而急着贴脸结束。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

这是每层加大，不是把整章合成一层；误以为已经跳过第二层会低估剩余路程。
