# #36 Scat Man

<EntryHeader en="Challenge #36" category="编号挑战 · 默认开放" icon="trophy" />

<VersionBadge checked="2026-10" />

蒙眼，用破坏大便生成的大便跟班清房，不能靠普通泪弹启动。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [以撒](/characters/isaac) |
| 终点 | 妈妈 |
| 宝箱房 | 不生成常规宝箱房 |
| 商店 | 可生成，受本挑战的替换与价格规则影响 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 4 红心；蒙眼；大便（The Poop）、粪臭素（Skatole）、龌龊之心（Dirty Mind）等大便主题道具，饰品神秘糖果（Mysterious Candy）；忏悔+ 起不再带大肠杆菌 |

挑战按上表的固定开局玩。蒙眼时不能发射普通泪弹，主要靠跟班、主动或特殊攻击。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：默认开放，可直接从 Challenges 菜单选择。

**完成奖励**：龌龊之心。[奖励成就 #517 的条件](/achievements/ids-501-600#achievement-517)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

使用大便制造可破坏的障碍，再用霹雳大腿踩碎来生成跟班。留意房间已有的大便和神秘糖果产生的大便，把它们转化为实际输出。

## 中期拿什么道具

优先补跟班强化、充能、移速和防护。龌龊之心让破坏大便有战斗价值，别清完一房才想起生成跟班；跟班减少后，在下个危险房前准备好补充手段。

## 路线与终点打法

地下室 → 洞穴 → 深处 II 的妈妈。终点就在妈妈战，不需要继续打子宫。

妈妈战先维持跟班数量，处理小怪并躲脚，别在中心只顾踩大便。能找到额外攻击主动或远程跟班时，它们可填补大便跟班消耗后的空档。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

忏悔+ 不再带大肠杆菌，不要按旧视频把撞敌人变大便作为开局主要操作。
