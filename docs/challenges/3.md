# #3 Head Trauma

<EntryHeader en="Challenge #3" category="编号挑战 · 默认开放" icon="trophy" />

<VersionBadge checked="2026-10" />

豆奶的大量低伤泪弹绕着角色转，需要把敌人放进泪弹的环带。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [以撒](/characters/isaac) |
| 终点 | 妈妈 |
| 宝箱房 | 不生成常规宝箱房 |
| 商店 | 可生成，受本挑战的替换与价格规则影响 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 小小星球（Tiny Planet）、豆奶（Soy Milk）、小石头（The Small Rock）、铁块（Iron Bar） |

挑战指定的开局优先于角色普通局的开局。蒙眼时不能发射普通泪弹；跟班、可用主动与特殊攻击另看各挑战规则。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：默认开放，可直接从 Challenges 菜单选择。

**完成奖励**：马骑符文（Ehwaz）。[奖励成就 #91 的条件](/achievements/ids-001-100#achievement-91)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

找开阔位置持续射击，再横向移动让环绕泪弹扫过敌人。不要只盯住射击方向的正前方；进门先给泪弹一点展开空间。

## 中期发育与道具取舍

优先提升伤害和生存，利用铁块的控制效果维持距离。没有宝箱房，要把 Boss 奖励、商店和交易作为主要发育渠道；遇到会改变轨迹的道具，先判断自己是否还能稳定命中。

## 路线与终点打法

地下室 → 洞穴 → 深处 II 的妈妈。终点就在妈妈战，不需要继续打子宫。

妈妈房留在中外圈，让环形泪弹覆盖门口和小怪；脚踩下时向空白区域移动，不要为了让泪弹贴上去站在阴影里。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

大量泪弹看起来很热闹，但单颗伤害低，开局打不快并不表示射击键没起作用。
