# #34 Ultra Hard

<EntryHeader en="Challenge #34" category="编号挑战 · 需要解锁" icon="trophy" />

<VersionBadge checked="2026-10" />

四种诅咒、精英敌人与不掉心同时存在，最重要的是建立不会依赖掉心的续航。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [以撒](/characters/isaac) |
| 终点 | 超级撒但 |
| 宝箱房 | 有；#39 的路线特例另见正文 |
| 商店 | 可生成，特殊替换规则见下文 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 4 个去不掉的诅咒；能变精英的敌人全是精英；Boss 战尽量变成双 Boss；不掉任何心；钥匙碎片1、2；有宝箱房 |

挑战指定的开局优先于角色普通局的开局。蒙眼时不能发射普通泪弹；跟班、可用主动与特殊攻击另看各挑战规则。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：击败超级撒但，并已解锁底片。[逐步解锁教程](/achievements/ids-201-300#achievement-280)。

**完成奖励**：参孙开局带小孩的心脏。[奖励成就 #334 的条件](/achievements/ids-301-400#achievement-334)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

迷宫、致盲、迷失、混乱无法按普通方式解除，先辨认攻击是否能安全清房。没有直接治疗或防护时少进危险房；宝箱房存在，但问号底座不能先看效果再选。

## 中期发育与道具取舍

优先找胎盘、吸血鬼之魅、水蛭、撒但圣经等直接回血或加心的能力。床、彩虹大便和直接给血的效果可以帮助续航；只在地上生成心的道具与卡牌不能解决缺血。

## 路线与终点打法

妈妈时拿底片，心脏后走阴间到暗室，用开局的两块钥匙碎片开超级撒但门。

妈妈时拿底片，走阴间、暗室，到超级撒但。进入终局前应有可靠回血或足够防护，召唤阶段先清危险精英；不要为了速度用残血硬闯。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

不掉心包括常见红心、魂心等地面拾取，教皇牌和查德宝宝不能按正常局当续航；拿到强攻击也仍需解决血量。
