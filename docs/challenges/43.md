# #43 Cantripped!

<EntryHeader en="Challenge #43" category="编号挑战 · 需要解锁" icon="trophy" />

<VersionBadge checked="2026-10" />

里该隐通过特殊道具卡发育，不能照普通合成宝袋配方走。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [里该隐](/characters/tainted-cain) |
| 终点 | 妈妈 |
| 宝箱房 | 不生成常规宝箱房 |
| 商店 | 可生成，特殊替换规则见下文 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 道具以特殊「道具卡」形式使用，卡牌和胶囊也被替换；道具卡可提供道具能力或主动效果；Boss 掉落换成新手牌组 |

挑战指定的开局优先于角色普通局的开局。蒙眼时不能发射普通泪弹；跟班、可用主动与特殊攻击另看各挑战规则。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：已解锁里该隐。[逐步解锁教程](/achievements/ids-501-600#achievement-514)。

**完成奖励**：VIII-正义？（VIII - Justice?）。[奖励成就 #532 的条件](/achievements/ids-501-600#achievement-532)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

先看拾到的道具卡是什么，再选择使用地点。道具卡可能提供道具能力或主动效果，伤害、治疗和传送要分开安排，别在空房间浪费攻击效果。

## 中期发育与道具取舍

以本层实际得到的能力清房，过层后重新确认手里的卡与构筑，不把一张卡当作普通永久底座估值。Boss 奖励被替换为新手牌组，要继续从道具卡中寻找战斗和生存手段。

## 路线与终点打法

地下室 → 洞穴 → 深处 II 的妈妈。终点就在妈妈战，不需要继续打子宫。

目标只到妈妈。把有用的攻击和保命卡留给终点，先使用能改善当前战斗的效果，再保持安全走位；传送类效果可能让你离开 Boss 房，使用前看清楚。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

普通里该隐的配方查询和合成预算不能直接应用于这个挑战；道具卡也不只是随机主动按钮。
