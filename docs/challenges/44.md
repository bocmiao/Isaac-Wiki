# #44 Red Redemption

<EntryHeader en="Challenge #44" category="编号挑战 · 需要解锁" icon="trophy" />

<VersionBadge checked="2026-10" />

地图要靠红钥匙自己开，过度开房会召来 Dark Esau，必须边探索边规划路线。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [里雅各](/characters/tainted-jacob) |
| 终点 | 母亲 |
| 宝箱房 | 有常规宝箱房 |
| 商店 | 可生成，受本挑战的替换与价格规则影响 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 爸爸的钥匙、红钥匙（Red Key）；起始房不连任何房间，要用红钥匙开路，用满 20 次会出现 Dark Esau；有宝箱房 |

挑战指定的开局优先于角色普通局的开局。蒙眼时不能发射普通泪弹；跟班、可用主动与特殊攻击另看各挑战规则。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：已解锁里雅各。[逐步解锁教程](/achievements/ids-501-600#achievement-515)。

**完成奖励**：IX-隐者？（IX - The Hermit?）。[奖励成就 #533 的条件](/achievements/ids-501-600#achievement-533)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

起始房没有相邻房间，先用红钥匙建立路线。连续开房前看小地图边界与已开的格子，少造重复死路；红钥匙和爸爸的钥匙承担不同功能，不要按错主动位。

## 中期发育与道具取舍

用满 20 次红钥匙会引出 Dark Esau，探索数量要纳入风险预算。出现后保持侧移、利用冲撞间隔继续开路；在危险房不要站着慢慢研究墙面，先清怪再开。

## 路线与终点打法

沿本挑战各层的 Boss 与出口推进，最终到尸宫 II 打母亲。红房间地图按挑战自身流程处理，不直接套用正常局分支的门票与开门条件。

终点是母亲，沿本挑战生成的楼层出口推进到尸宫。进入终局前保证输出、防护和操作空间；Dark Esau 的威胁与 Boss 弹幕要同时管理。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

红房间多不代表都值得清，盲目把每面墙都开完会更快触发额外追击，并消耗操作时间。
