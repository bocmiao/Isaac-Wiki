# #25 Have a Heart

<EntryHeader en="Challenge #25" category="编号挑战 · 需要解锁" icon="trophy" />

<VersionBadge checked="2026-10" />

只有一颗已填红心，很多空容器；普通红心掉落被替换，必须靠直接回血。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [以撒](/characters/isaac) |
| 终点 | 妈妈的心脏 |
| 宝箱房 | 有常规宝箱房 |
| 商店 | 可生成，受本挑战的替换与价格规则影响 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 1 红心 + 11 个空红心容器；吸血鬼之魅（Charm of the Vampire）；原本掉红心改为掉硬币；有宝箱房 |

挑战按上表的固定开局玩。蒙眼时不能发射普通泪弹，主要靠跟班、主动或特殊攻击。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：击败妈妈。[逐步解锁教程](/achievements/ids-201-300#achievement-269)。

**完成奖励**：两种胶囊：放-松（Re-Lax）、？？？。[奖励成就 #228 的条件](/achievements/ids-201-300#achievement-228)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

前几层先让吸血鬼之魅通过击杀逐步回血，避免缺血时连续进诅咒房或献祭。先清安全的普通怪，利用已有空容器承接直接治疗。

## 中期拿什么道具

美味的心、胎盘及直接治疗的效果更实用，普通掉红心的道具不能按正常局估值。优先让当前血量健康，再拿伤害；11 个空容器不代表你能扛 11 次攻击。

## 路线与终点打法

地下室 → 洞穴 → 深处 → 子宫 II 的妈妈的心脏 / 它活着。

进入心脏战前应先用可用的治疗补好血，战斗中不要指望临时刷出红心救急。先清眼睛，保持外围走位，输出够用就稳打。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

把空容器误当成实际血量，或拿只生成红心的工具当治疗，都会高估生存能力。
