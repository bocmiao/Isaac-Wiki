# #31 Backasswards

<EntryHeader en="Challenge #31" category="编号挑战 · 需要解锁" icon="trophy" />

<VersionBadge checked="2026-10" />

从超级撒但开打，再倒着上楼；每层都会失去道具和红心容器。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [以撒](/characters/isaac) |
| 终点 | 地下室 I |
| 宝箱房 | 不生成常规宝箱房 |
| 商店 | 可生成，受本挑战的替换与价格规则影响 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 从超级撒但战开始倒着往上打；开局 8–10 个随机道具；每往上一层失去 1 个道具和 1 个红心容器 |

挑战指定的开局优先于角色普通局的开局。蒙眼时不能发射普通泪弹；跟班、可用主动与特殊攻击另看各挑战规则。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：击败超级撒但，并已解锁底片。[逐步解锁教程](/achievements/ids-201-300#achievement-277)。

**完成奖励**：拉撒路开局带贫血（Anemic）。[奖励成就 #331 的条件](/achievements/ids-301-400#achievement-331)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

开局先看随机构筑能否打过超级撒但，辨认主输出、保命和会自伤的组合。遇到操作不熟的攻击形式先了解效果，第一场就是终局战，不能等后面慢慢发育。

## 中期发育与道具取舍

每次上楼后重新检查血量、飞行与输出，原来依赖的道具可能已经被移除。圣饼、直接治疗、可靠跟班等生存能力很有价值；不要照原路线随意站在坑上或继续硬换血。

## 路线与终点打法

开局先打超级撒但，随后沿反向楼层出口上行，最终到地下室 I。

超级撒但是开局考验，真正完成目标是回到地下室 I 并领取终点奖杯。沿上行出口推进，后期构筑变弱时少打无必要的支路，把血量留给必须经过的房间。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

嗝屁猫会改变红心容器，容易破坏倒着上楼的血量预算；不要见到复活道具就无条件拿。
