# #42 Hot Potato

<EntryHeader en="Challenge #42" category="编号挑战 · 需要解锁" icon="trophy" />

<VersionBadge checked="2026-10" />

里遗骸的骨头定时爆炸，要把身体当作会爆的投掷物，同时保护灵魂。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [里遗骸](/characters/tainted-forgotten) |
| 终点 | 撒但 |
| 宝箱房 | 不生成常规宝箱房 |
| 商店 | 可生成，受本挑战的替换与价格规则影响 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 3 魂心；蒙眼，每 2.5 秒爆炸一次，进新房间或拿道具时重置计时 |

挑战指定的开局优先于角色普通局的开局。蒙眼时不能发射普通泪弹；跟班、可用主动与特殊攻击另看各挑战规则。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：已解锁里遗骸。[逐步解锁教程](/achievements/ids-501-600#achievement-513)。

**完成奖励**：VII-战车？（VII - The Chariot?）。[奖励成就 #531 的条件](/achievements/ids-501-600#achievement-531)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

先练把骨头扔向敌人，再让灵魂远离爆炸位置。进新房和拿道具会重置计时，清房操作要重新开始计算，不能接着上一房的节奏猜。

## 中期发育与道具取舍

3 魂心的容错不高，优先补魂心、防护和容易操作的额外输出。不要只追着骨头跑，先判断周围敌人与爆炸范围；地形拥挤时留足回收骨头的退路。

## 路线与终点打法

打完子宫 II 的心脏 / 它活着，走向下的入口到阴间，击败撒但。

撒但战把骨头投到可以命中的位置，灵魂在安全区躲激光与脚。Boss 移动时重新摆骨头，别为了捡回它冲进脚下阴影或水蛭群。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

定时爆炸不是普通里遗骸近战手感；没留灵魂位置就反复拿起骨头容易连续受伤。
