# #5 The Tank

<EntryHeader en="Challenge #5" category="编号挑战 · 需要解锁" icon="trophy" />

<VersionBadge checked="2026-10" />

血厚但移速很慢，主要问题是躲不过连续攻击。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [抹大拉](/characters/magdalene) |
| 终点 | 妈妈 |
| 宝箱房 | 不生成常规宝箱房 |
| 商店 | 可生成，特殊替换规则见下文 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 耻辱假面（Infamy）、桶装猪油（Bucket of Lard）、霹雳大腿（Thunder Thighs）、美味的心（Yum Heart） |

挑战指定的开局优先于角色普通局的开局。蒙眼时不能发射普通泪弹；跟班、可用主动与特殊攻击另看各挑战规则。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：同时拥有 7 个或以上红心容器。[逐步解锁教程](/achievements/ids-101-200#achievement-158)。

**完成奖励**：诸神符文（Ansuz）。[奖励成就 #93 的条件](/achievements/ids-001-100#achievement-93)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

先找能提高移速的 Boss 奖励或商店道具。用霹雳大腿踩碎有价值的石头，但接近蘑菇、炸弹石等障碍时留意破坏后的效果。

## 中期发育与道具取舍

美味的心充好就及时回血，别满充能带着伤血连续清房。耻辱假面的格挡不可靠，仍应从房间外侧慢慢清怪，优先解决追人的敌人。

## 路线与终点打法

地下室 → 洞穴 → 深处 II 的妈妈。终点就在妈妈战，不需要继续打子宫。

妈妈战尽量少穿过房间中心，提早离开脚下阴影。每次只处理一个方向的威胁，缺血时利用美味的心，避免被小怪和脚同时夹住。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

容器多不等于当前血量多；低移速下不要把大量红心全换成恶魔道具。
