# #33 Pokey Mans

<EntryHeader en="Challenge #33" category="编号挑战 · 需要解锁" icon="trophy" />

<VersionBadge checked="2026-10" />

友好球召唤随机友军，友军阵亡后才能很快续上下一只。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [以撒](/characters/isaac) |
| 终点 | 以撒（Boss） |
| 宝箱房 | 不生成常规宝箱房 |
| 商店 | 可生成，受本挑战的替换与价格规则影响 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 友好球（Friendly Ball）、妈妈的眼影（Mom's Eyeshadow）；友好球每次使用放出一只随机怪物，怪物死后友好球立刻充满 |

挑战指定的开局优先于角色普通局的开局。蒙眼时不能发射普通泪弹；跟班、可用主动与特殊攻击另看各挑战规则。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：妈妈的心脏累计 11 次。[逐步解锁教程](/achievements/ids-201-300#achievement-279)。

**完成奖励**：充能钥匙（Charged Key）。[奖励成就 #333 的条件](/achievements/ids-301-400#achievement-333)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

进战斗房先放出友军，让它分担仇恨，自己用普通泪弹补伤害。召唤结果不稳定，不适合把所有战斗都交给友军后原地等。

## 中期发育与道具取舍

优先把自身伤害、射速和血量发展到能独立清房。友军死亡会让球充满，看到主动充好就补下一只；妈妈的眼影可帮助控场，但不要把魅惑当作全程免伤。

## 路线与终点打法

打完子宫 II 的心脏 / 它活着，走光柱到教堂，击败以撒。

教堂以撒战开场召唤，再保持自己的射击与圣光躲避。友军更换期间仍要持续输出，别为了等待随机强怪而耗尽生存资源。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

友好球在本挑战中的特殊召唤、充能规则不同于普通局，不能只按普通主动说明操作。
