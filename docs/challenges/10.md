# #10 Cursed!

<EntryHeader en="Challenge #10" category="编号挑战 · 需要解锁" icon="trophy" />

<VersionBadge checked="2026-10" />

普通门带刺，来回走动本身就会消耗血量。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [抹大拉](/characters/magdalene) |
| 终点 | 妈妈 |
| 宝箱房 | 有常规宝箱房 |
| 商店 | 可生成，受本挑战的替换与价格规则影响 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 每层都有专属的 Curse of the Cursed；美味的心、生肝（Raw Liver）、指南针（The Compass）、藏宝图（Treasure Map）、蓝地图（Blue Map）、饰品小孩的心脏（Child's Heart）；有宝箱房 |

挑战指定的开局优先于角色普通局的开局。蒙眼时不能发射普通泪弹；跟班、可用主动与特殊攻击另看各挑战规则。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：同时拥有 7 个或以上红心容器。[逐步解锁教程](/achievements/ids-101-200#achievement-163)。

**完成奖励**：信用卡（Credit Card）。[奖励成就 #98 的条件](/achievements/ids-001-100#achievement-98)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

利用开局的地图、指南针和蓝地图规划短路线，先判断宝箱房和 Boss 的方向。美味的心用于抵消过门消耗，避免为了没把握的支路反复穿同一扇门。

## 中期发育与道具取舍

扁锉可去掉门刺，胎盘、吸血鬼之魅等直接回血也很有价值。每次偏离主路前，比较能得到什么和至少要穿几次门；飞行不能解决这个挑战的门刺扣血。

## 路线与终点打法

地下室 → 洞穴 → 深处 II 的妈妈。终点就在妈妈战，不需要继续打子宫。

终点是妈妈，不必把血量预算延长到子宫。进 Boss 房前补好红心，把主动回血留给仍有缺血的时候；妈妈战按常规远程打法处理。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

进入已经清过的房间仍可能要付过门血量，清完怪不代表门就变安全了。
