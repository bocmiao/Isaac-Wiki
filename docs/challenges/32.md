地图位置、道具外观和血量会骗人，所有 Boss 都换成 The Bloat。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [以撒](/characters/isaac) |
| 终点 | 妈妈的心脏 |
| 宝箱房 | 有常规宝箱房 |
| 商店 | 可生成，受本挑战的替换与价格规则影响 |
| 难度 | 普通（挑战自带的特殊限制另算） |

挑战按上表的固定开局玩。蒙眼时不能发射普通泪弹，主要靠跟班、主动或特殊攻击。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：击败妈妈。[逐步解锁教程](/achievements/ids-201-300#achievement-278)。

**完成奖励**：抹大拉开局带体力回满胶囊。[奖励成就 #332 的条件](/achievements/ids-301-400#achievement-332)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

用已经清过的房间推断自己的实际位置，不要只看小地图上的角色标记。拿道具后看实际攻击与属性变化；主动、卡牌和胶囊效果随机，使用前给自己留退路。

## 中期拿什么道具

忏悔+ 此挑战禁用游戏内道具说明，更需要依赖实际表现判断道具搭配。恶魔交易的显示不可靠，想稳过时倾向保血和天使房；找到追踪或容易绕过障碍的输出可减轻战斗负担。

## 路线与终点打法

地下室 → 洞穴 → 深处 → 子宫 II 的妈妈的心脏 / 它活着。

The Bloat 的硫磺火朝两侧与下方打，优先站在上方或安全斜角。它移动、跳起或生成血液时重新找位置，不要站在正下方贪输出；终点仍按心脏所在阶段领取奖杯。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

随机效果可能有利也可能危险，不能把某种主动的正常说明当作这里必定发生的结果。
