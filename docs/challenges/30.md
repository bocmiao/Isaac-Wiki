# #30 The Guardian

<EntryHeader en="Challenge #30" category="编号挑战 · 需要解锁" icon="trophy" />

<VersionBadge checked="2026-10" />

真正需要保护的是跟着受气包走的心脏；角色自己躲开，不代表这一击安全。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [以撒](/characters/isaac) |
| 终点 | 妈妈的心脏 |
| 宝箱房 | 不生成常规宝箱房 |
| 商店 | 可生成，受本挑战的替换与价格规则影响 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 蒙眼；圣杯（Holy Grail）、以撒的心脏（Isaac's Heart）、受气包（Punching Bag）、命运之矛（Spear of Destiny）；以撒的心脏跟着受气包走 |

挑战按上表的固定开局玩。蒙眼时不能发射普通泪弹，主要靠跟班、主动或特殊攻击。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：击败妈妈。[逐步解锁教程](/achievements/ids-201-300#achievement-274)。

**完成奖励**：空白符文（Blank Rune）。[奖励成就 #233 的条件](/achievements/ids-201-300#achievement-233)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

进房先找到受气包和心脏的位置，利用命运之矛处理正在接近它们的怪。圣杯提供飞行，可以越过障碍去拦截，但不要只围着自己的安全区域绕。

## 中期拿什么道具

优先补清场、跟班和防护，尽量在敌人碰到心脏前杀掉。角色位置可帮助拦攻击，却不能固定受气包的移动，看到它走进危险区就要及时转移火力。

## 路线与终点打法

地下室 → 洞穴 → 深处 → 子宫 II 的妈妈的心脏 / 它活着。

心脏战先处理眼睛和新增小怪，时刻看受气包正在靠近哪一侧弹幕。不要只盯中央 Boss 的血条，保护目标比追求一次贴矛伤害更重要。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

普通以撒的心脏打法不能直接照搬：这个挑战中心脏跟随受气包，不是始终跟着玩家。
