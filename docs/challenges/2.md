# #2 High Brow

<EntryHeader en="Challenge #2" category="编号挑战 · 默认开放" icon="trophy" />

<VersionBadge checked="2026-10" />

小号把泪弹射程压得很短，不能照普通以撒的远距离打法。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [以撒](/characters/isaac) |
| 终点 | 妈妈 |
| 宝箱房 | 不生成常规宝箱房 |
| 商店 | 可生成，受本挑战的替换与价格规则影响 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 小号（Number One）、大肠杆菌（E. Coli）、屁股炸弹（Butt Bombs）、冲水！（Flush!）、饰品石化大便（Petrified Poop） |

挑战指定的开局优先于角色普通局的开局。蒙眼时不能发射普通泪弹；跟班、可用主动与特殊攻击另看各挑战规则。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：默认开放，可直接从 Challenges 菜单选择。

**完成奖励**：收获符文（Jera）。[奖励成就 #90 的条件](/achievements/ids-001-100#achievement-90)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

先清掉入口附近的怪，再从侧面接近剩余敌人。利用冲水！处理一群可被转换的普通敌人；把大便打碎，发挥石化大便的资源收益。

## 中期发育与道具取舍

射程提升能直接改善安全距离，伤害和射速其次。没有宝箱房，主要靠 Boss 奖励与交易补强；屁股炸弹的清场效果可以用于被围住时脱困。

## 路线与终点打法

地下室 → 洞穴 → 深处 II 的妈妈。终点就在妈妈战，不需要继续打子宫。

妈妈露出门口部位时靠近打一小段，再退到空处躲脚。冲水！不能替代终点 Boss 战，进场前应当有足够的泪弹输出和血量。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

大肠杆菌的接触效果不等于接触免伤，不要主动撞怪换大便。
