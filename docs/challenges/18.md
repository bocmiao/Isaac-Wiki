# #18 The Host

<EntryHeader en="Challenge #18" category="编号挑战 · 默认开放" icon="trophy" />

<VersionBadge checked="2026-10" />

靠普通射击产生蓝苍蝇，属于开局比较容易成形的挑战。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [以撒](/characters/isaac) |
| 终点 | 妈妈 |
| 宝箱房 | 不生成常规宝箱房 |
| 商店 | 可生成，特殊替换规则见下文 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 虫群复击（The Mulligan）、蜘蛛宝宝（Spiderbaby）、饰品血虱（Tick） |

挑战指定的开局优先于角色普通局的开局。蒙眼时不能发射普通泪弹；跟班、可用主动与特殊攻击另看各挑战规则。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：默认开放。默认开放，可直接选择。

**完成奖励**：科技0.5（Tech.5）。[奖励成就 #104 的条件](/achievements/ids-101-200#achievement-104)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

持续射击并保持距离，让虫群复击产生的蓝苍蝇补伤害。血虱能帮助处理耐打目标，但蜘蛛宝宝只在受伤时补输出，不要为了生蜘蛛主动挨打。

## 中期发育与道具取舍

优先提高普通射击的稳定性与防御，伤害提升也有利于蓝苍蝇输出。血虱不容易直接换下，捡新饰品前先确认它能不能替代，不必为饰品槽浪费资源。

## 路线与终点打法

地下室 → 洞穴 → 深处 II 的妈妈。终点就在妈妈战，不需要继续打子宫。

妈妈战保持射击积累蓝苍蝇，先清小怪再转火门口目标。看到脚下阴影即移动，受伤产生的蜘蛛只当作补救。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

这个挑战有受伤触发道具，但它们不会返还受伤消耗的血。
