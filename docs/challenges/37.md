# #37 Bloody Mary

<EntryHeader en="Challenge #37" category="编号挑战 · 需要解锁" icon="trophy" />

<VersionBadge checked="2026-10" />

血誓在换层时抽走红心换增益，伯大尼又不能把魂心当外层血量。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [伯大尼](/characters/bethany) |
| 终点 | 撒但 |
| 宝箱房 | 不生成常规宝箱房 |
| 商店 | 可生成，特殊替换规则见下文 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 4 红心 + 4 点魂心充能；彼列之书、血袋（Blood Bag）、贫血、血誓（Blood Oath）、饰品小孩的心脏 |

挑战指定的开局优先于角色普通局的开局。蒙眼时不能发射普通泪弹；跟班、可用主动与特殊攻击另看各挑战规则。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：已解锁伯大尼、血袋和「它活着」。[逐步解锁教程](/achievements/ids-501-600#achievement-508)。

**完成奖励**：巴风特之印（Sigil of Baphomet）。[奖励成就 #518 的条件](/achievements/ids-501-600#achievement-518)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

先了解血誓会在新层消耗红心，上一层别为了满红心就浪费全部资源。保留能在下一层使用的治疗，魂心主要转为伯大尼的主动充能，不是蓝色防护层。

## 中期发育与道具取舍

用彼列之书和血誓的增益尽快清怪，贫血的液体仅是辅助。血袋与后续容器、直接治疗、护盾可以改善生存；下楼前确认红心预算，不靠魂心图标判断能挨几下。

## 路线与终点打法

打完子宫 II 的心脏 / 它活着，走向下的入口到阴间，击败撒但。

终点撒但。进 Boss 房前补好实际红心、备好彼列之书的使用机会，脚阶段把躲踩放在首位；别因为换层增益高就忽略自己可能只剩很少血。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

挑战开局不是普通伯大尼的美德之书构筑，不能假设能按普通开局自动积累美德灵火。
