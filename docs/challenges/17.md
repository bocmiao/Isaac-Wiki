# #17 Waka Waka

<EntryHeader en="Challenge #17" category="编号挑战 · 默认开放" icon="trophy" />

<VersionBadge checked="2026-10" />

悬停泪弹配合引力会吸引敌人，需要把弹团当成陷阱来摆。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [以撒](/characters/isaac) |
| 终点 | 妈妈 |
| 宝箱房 | 不生成常规宝箱房 |
| 商店 | 可生成，特殊替换规则见下文 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 反重力（Anti-Gravity）、怪异磁铁（Strange Attractor） |

挑战指定的开局优先于角色普通局的开局。蒙眼时不能发射普通泪弹；跟班、可用主动与特殊攻击另看各挑战规则。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：默认开放。默认开放，可直接选择。

**完成奖励**：死神之触（Death's Touch）。[奖励成就 #103 的条件](/achievements/ids-101-200#achievement-103)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

在空处按住射击形成弹团，再移到旁边释放，让敌人朝弹团移动。不要让弹团长时间堆在自己的撤退路线，尤其不要把追人怪吸到角色脚下。

## 中期发育与道具取舍

伤害和射速能提升弹团清怪能力，移速和防护让你更容易脱离引力中心。优先建立稳定的摆弹节奏，再接受会改变轨迹或产生爆炸的组合。

## 路线与终点打法

地下室 → 洞穴 → 深处 II 的妈妈。终点就在妈妈战，不需要继续打子宫。

妈妈房把弹团放在门口目标前方，自己留在侧面躲脚和小怪。不要在房间中心长时间蓄积泪弹，免得多个敌人同时靠过来。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

怪异磁铁会影响敌人运动；不能按普通局经验假设它们一直沿原路线追你。
