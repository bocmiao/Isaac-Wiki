# #29 Onan's Streak

<EntryHeader en="Challenge #29" category="编号挑战 · 需要解锁" icon="trophy" />

<VersionBadge checked="2026-10" />

打空泪弹会扣血，必须从持续乱射改成确认能命中的攻击。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [犹大](/characters/judas) |
| 终点 | 以撒（Boss） |
| 宝箱房 | 有常规宝箱房 |
| 商店 | 可生成，受本挑战的替换与价格规则影响 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 只有 1 红心；彼列之书（The Book of Belial）、巧克力牛奶（Chocolate Milk）；泪弹打空就扣血；有宝箱房 |

挑战指定的开局优先于角色普通局的开局。蒙眼时不能发射普通泪弹；跟班、可用主动与特殊攻击另看各挑战规则。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：已解锁犹大和「它活着」。[逐步解锁教程](/achievements/ids-201-300#achievement-273)。

**完成奖励**：肾结石（Kidney Stone）。[奖励成就 #232 的条件](/achievements/ids-201-300#achievement-232)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

用巧克力牛奶蓄力，等敌人走进清楚的射线再松开。清完最后一个敌人就停止出手，别把多余泪弹朝空房间发出去。

## 中期发育与道具取舍

追踪效果能降低失误风险，稳定伤害让你减少出手次数；跟班与攻击主动可以补输出。不要盲目拿分裂、多方向或复杂弹道道具，它们可能让命中管理更难。

## 路线与终点打法

打完子宫 II 的心脏 / 它活着，走光柱到教堂，击败以撒。

教堂以撒战在可受伤阶段找对齐窗口打一发，Boss 转阶段和消失时立即停手。彼列之书进场使用，血量不足时优先稳住而不是用密集低蓄力弹赌命中。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

这个挑战惩罚的是无效射击，伤害高并不能自动抵消空枪代价。
