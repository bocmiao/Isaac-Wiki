# #20 Purist

<EntryHeader en="Challenge #20" category="编号挑战 · 需要解锁" icon="trophy" />

<VersionBadge checked="2026-10" />

普通以撒没有开局强化，也没有宝箱房，发育比正常局更依赖 Boss 和交易。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [以撒](/characters/isaac) |
| 终点 | 妈妈的心脏 |
| 宝箱房 | 不生成常规宝箱房 |
| 商店 | 可生成，特殊替换规则见下文 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 没有开局道具 |

挑战指定的开局优先于角色普通局的开局。蒙眼时不能发射普通泪弹；跟班、可用主动与特殊攻击另看各挑战规则。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：击败妈妈。[逐步解锁教程](/achievements/ids-101-200#achievement-166)。

**完成奖励**：桦木符文（Berkano）。[奖励成就 #95 的条件](/achievements/ids-001-100#achievement-95)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

先按基础泪弹稳过前两层，炸弹和钥匙用于能提供实际收益的隐藏房、箱子与商店。不要在地图上反复寻找不会生成的宝箱房。

## 中期发育与道具取舍

Boss 奖励优先解决伤害、射速和血量中的短板，保护红心争取交易房。不要把所有血量都交给恶魔交易；终点是子宫 II，足够过心脏的构筑就可以收尾。

## 路线与终点打法

地下室 → 洞穴 → 深处 → 子宫 II 的妈妈的心脏 / 它活着。

心脏战先处理两侧眼睛，再维持距离绕开弹幕。主动道具进场前充满，缺伤害时也不要站着硬换血。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

Purist 不是禁用一切后续道具；没有开局道具和宝箱房不意味着必须裸装通关。
