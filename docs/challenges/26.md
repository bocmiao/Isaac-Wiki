# #26 I RULE!

<EntryHeader en="Challenge #26" category="编号挑战 · 需要解锁" icon="trophy" />

<VersionBadge checked="2026-10" />

这是困难难度挑战，妈妈的菜刀输出强，但近距离蓄力与出刀需要练习。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [以撒](/characters/isaac) |
| 终点 | 超级撒但 |
| 宝箱房 | 不生成常规宝箱房 |
| 商店 | 可生成，特殊替换规则见下文 |
| 难度 | 困难 |
| 开局 / 特殊规则 | 唯一不是普通难度的挑战；回旋镖、钥匙碎片1（Key Piece 1）、钥匙碎片2（Key Piece 2）、梯子（The Ladder）、妈妈的菜刀（Mom's Knife）、三位一体盾（Trinity Shield） |

挑战指定的开局优先于角色普通局的开局。蒙眼时不能发射普通泪弹；跟班、可用主动与特殊攻击另看各挑战规则。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：击败超级撒但，并已解锁底片。[逐步解锁教程](/achievements/ids-201-300#achievement-270)。

**完成奖励**：筹码（Poker Chip）。[奖励成就 #229 的条件](/achievements/ids-201-300#achievement-229)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

先练菜刀伸出的距离，把敌人放在刀锋范围内，角色不要贴上去。回旋镖帮助控制普通怪，三位一体盾按朝向拦弹，不能挡住所有方向的攻击。

## 中期发育与道具取舍

钥匙碎片已经齐全，重点转向保命和可控伤害。妈妈战拿底片，走阴间到暗室；不要为多拿一件未知道具，把能通关的血量全部换掉。

## 路线与终点打法

妈妈时拿底片，心脏后走阴间到暗室，用开局的两块钥匙碎片开超级撒但门。

在暗室用两块钥匙开启超级撒但门。分波清掉召唤物，举盾方向对准主要弹幕来源；躲避阶段可以放弃蓄力，安全后再用菜刀抓攻击窗口。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

本挑战不能按其他挑战的普通难度估计伤害风险；钥匙齐了也仍要走对终点路线。
