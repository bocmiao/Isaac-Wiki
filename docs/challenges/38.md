# #38 Baptism by Fire

<VersionBadge checked="2026-10" />

蒙眼，用灵魂之瓮的喷火和充能循环清房，不能用普通泪弹补空档。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [伯大尼](/characters/bethany) |
| 终点 | 以撒（Boss） |
| 宝箱房 | 不生成常规宝箱房 |
| 商店 | 可生成，特殊替换规则见下文 |

挑战指定的开局优先于角色普通局的开局。蒙眼时不能发射普通泪弹；跟班、可用主动与特殊攻击另看各挑战规则。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：用伯大尼击败撒但、妈妈的心脏累计 11 次，并已解锁抹大拉的信仰。[逐步解锁教程](/achievements/ids-501-600#achievement-509)。

**完成奖励**：炼狱恶鬼（Purgatory）。[奖励成就 #519 的条件](/achievements/ids-501-600#achievement-519)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

把火焰对准敌群，杀怪获取后续续航，不要在没有目标时持续消耗瓮的资源。走位与喷火方向分开考虑，优先烧掉会冲到面前的敌人。

## 中期发育与道具取舍

书包让你保留灵魂之瓮和嗝屁猫的爪子；后者消耗红心容器提供魂心，而伯大尼把魂心用于充能，所以使用前先算能留下多少红心容器。抹大拉的信仰有助于补容器，但永恒之心要保到下一层。

## 路线与终点打法

打完子宫 II 的心脏 / 它活着，走光柱到教堂，击败以撒。

从教堂入口到以撒终点。进场前留足喷火资源与红心，先躲圣光再调整火焰方向；缺少充能时用已取得的跟班或备用攻击能力补上。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

嗝屁猫的爪子不是免费充能，反复使用会消耗红心容器；不要把全部容器转走。
