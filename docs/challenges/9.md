# #9 Demo Man

<EntryHeader en="Challenge #9" category="编号挑战 · 需要解锁" icon="trophy" />

<VersionBadge checked="2026-10" />

胎儿博士提供可持续发射的炸弹，关键是安全距离和起爆时机。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [以撒](/characters/isaac) |
| 终点 | 妈妈的心脏 |
| 宝箱房 | 不生成常规宝箱房 |
| 商店 | 可生成，特殊替换规则见下文 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 胎儿博士（Dr. Fetus）、起爆器（Remote Detonator）、饰品火柴棍（Match Stick） |

挑战指定的开局优先于角色普通局的开局。蒙眼时不能发射普通泪弹；跟班、可用主动与特殊攻击另看各挑战规则。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：妈妈的心脏累计 9 次。[逐步解锁教程](/achievements/ids-101-200#achievement-162)。

**完成奖励**：混沌卡（Chaos Card）。[奖励成就 #97 的条件](/achievements/ids-001-100#achievement-97)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

先练发射、后退、起爆的节奏，避免炸弹被墙反弹回身边。无限攻击炸弹能搜索隐藏房，也能破坏障碍收集资源，不必把找房成本按普通炸弹库存计算。

## 中期发育与道具取舍

纵火狂或寄居骷髅帽能解决主要自伤风险。弹速改善炸弹投射距离；起爆器适合把炸弹留在敌人附近再引爆，主动位换掉它前要确认自己能掌握自然爆炸时机。

## 路线与终点打法

地下室 → 洞穴 → 深处 → 子宫 II 的妈妈的心脏 / 它活着。

心脏战先炸掉眼睛，再向中央投弹并保持退路。Boss 无敌时不要浪费一串炸弹，留到可受伤阶段一起起爆。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

爆炸免疫也不免疫敌人的接触伤害和弹幕，不能拿到免疫就完全停止走位。
