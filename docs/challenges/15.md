# #15 Slow Roll

<EntryHeader en="Challenge #15" category="编号挑战 · 默认开放" icon="trophy" />

<VersionBadge checked="2026-10" />

泪弹很强但出手慢，镜像轨迹让空枪后的补救也慢。

## 开局与规则

| 项目 | 内容 |
| --- | --- |
| 指定角色 | [以撒](/characters/isaac) |
| 终点 | 妈妈 |
| 宝箱房 | 不生成常规宝箱房 |
| 商店 | 可生成，特殊替换规则见下文 |
| 难度 | 普通（挑战自带的特殊限制另算） |
| 开局 / 特殊规则 | 丘比特之箭（Cupid's Arrow）、我的镜像、巨人独眼（Polyphemus） |

挑战指定的开局优先于角色普通局的开局。蒙眼时不能发射普通泪弹；跟班、可用主动与特殊攻击另看各挑战规则。[查看挑战通用规则](/strategy/challenges#挑战模式是什么)。

## 开放条件与完成奖励

**开放条件**：默认开放。默认开放，可直接选择。

**完成奖励**：被吞下的硬币（Swallowed Penny）。[奖励成就 #101 的条件](/achievements/ids-101-200#achievement-101)。

“挑战已开放”与“挑战已完成”是两个进度。达成前置只是让它出现在菜单里；本局到达终点并碰到奖杯，才领取完成奖励。编号挑战不用于刷普通角色标记或其他普通成就。

## 前期怎么打

先确定敌人的运动方向再射击，横向移动让穿透泪弹扫过一排敌人。不要原地等下一发，把射击间隔用来躲追击和弹幕。

## 中期发育与道具取舍

优先改善射速和生存，也可以用跟班补出手间隙。贯穿能力适合处理成群目标，狭窄房间则先退到入口一侧，避免同时应对多个方向。

## 路线与终点打法

地下室 → 洞穴 → 深处 II 的妈妈。终点就在妈妈战，不需要继续打子宫。

妈妈战对门口出现的部位射击，脚落下前先移动，不要为了攒下一发站在阴影里。高伤泪弹有利于迅速清小怪，先把走位空间打出来。

打完后领取终点奖杯，再回菜单检查完成状态。[主线路线与前置](/guide/unlocks/endings) · [终局 Boss 打法](/strategy/bosses) · [母亲与其他终局打法](/strategy/bosses-2)。

## 最容易失败的地方

持续按住射击不代表输出连续；巨人独眼的低射速需要主动管理攻击间隔。
