# 贪婪 · 究极贪婪（Ultra Greed）

<EntryHeader en="Ultra Greed" category="贪婪模式" icon="coin" />

<VersionBadge checked="2026-10" />

这是贪婪 / 极贪模式的**第 7 层**，使用模式自己的楼层顺序，不能套用普通主线同名楼层的终点与伤害规则。

## 房间与发育

第七层依次经过起始房、小头目房与究极贪婪 Boss 房。极贪模式还有金色第二阶段。

经过前置房进入终局；极贪还有究极贪婪金色第二阶段。

## 下楼前

赢后用贪婪捐款机，不把开场的钱全部当作已成功捐入。

## 前六层的波次与模式规则

普通贪婪为8 普通波 + 2 Boss 波 + 1 可选噩梦波，极贪为 9 + 2 + 1；可选噩梦波开交易房，不能用普通主线“整层保护红心”那套概率直接计算。通常清场或计时会推动波次；怪没打完就叠波，需用按钮及时止损。贪婪模式变体随解锁可能改变外观与敌人，不改变七层的整体顺序。

贪婪捐款累计 500 解锁极贪、1000 解锁店主；卡住概率、角色累计和里程碑查[捐款进度工具](/tools/donations)。普通商店捐款机是另一套进度，不混用。
