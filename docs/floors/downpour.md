# 下水道 {#downpour}

<EntryHeader en="Downpour" category="母亲路线" icon="map" />

<VersionBadge checked="2026-10" />

## 位置与特点

替代第一章，由地下室 I / II Boss 旁的钥匙门进入。水面、反射与更复杂的弹幕要求观察完整房间，不要只看离自己最近的敌人。

## I 层打法

先取有效道具与补给，熟悉替代敌人的攻击后再多探索。I 层不做镜面刀片流程，要继续到 II。

## II 层刀片 1

找到白火与镜子，触碰白火进入临时游魂形态，然后穿镜子到镜面世界，在镜面宝箱房拿刀片 1，再穿镜子回来。临时游魂不等于天然有无限保命；圣斗篷是否可用要看相应开局强化，未解锁时尤其谨慎。镜面 Boss 是可选额外奖励，母亲路线不要求击败它。不要打碎镜子后才想返回。完成后用两颗炸弹开矿洞路线门。
## 本章共通规则

前置是死寂累计击败 3 次的[秘密出口（407）](/achievements/ids-401-500#achievement-407)。替代章节有自己的敌人、布局与门票，宝箱房常有可见 / 问号二选一；它们不是只换背景。入口规则见[替代章节入口房](/rooms/secret-exit)。

::: tip 一次走通 Mother
地下室阶段留 **1 钥匙** → 下水道 / 污水渠 **II 拿刀片 1** → 留 **2 炸弹**开矿洞门 → 矿洞 / 灰坑 **II 拿刀片 2** → 留能承担 **2 心伤害**的生命开陵墓门 → 陵墓 / 炼狱 **II 刀片开肉门、打加强心脏** → 尸宫 I → 尸宫 II 母亲。

可以跳过部分替代路线的 I 层，但**两段 II 层的刀片步骤不能漏**。从地下室 I 转入对应下水道 I，地下室 II 转入对应下水道 II；别因为只剩 II 层就误以为已经来不及拿第一块刀片。
:::
