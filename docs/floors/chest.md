# 宝箱 {#chest}

<EntryHeader en="Chest" category="终局与上行" icon="map" />

<VersionBadge checked="2026-10" />

## 进入

教堂以撒后携带全家福进入大箱子。这里是一个完整楼层，不是前三章金门宝箱房。

## 奖励与终点

起点有四个金箱子，可以开出道具，先保留足够钥匙。后续房间也是高强度战斗，终点 Boss 为 ???；可另走金门挑战超级撒但。

## 打法

先整理开场道具与联动再探索，有效果不明的道具就查名称。钥匙不足时先用有效提升打几间房获取资源，不要以为抵达宝箱层就能自动拿走四件。超级撒但金门需要两块钥匙碎片或相应开门手段，普通钥匙不行。
