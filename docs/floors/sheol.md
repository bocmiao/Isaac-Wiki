# 阴间 {#sheol}

<EntryHeader en="Sheol" category="终局与上行" icon="map" />

<VersionBadge checked="2026-10" />

## 进入

它活着后选活板门；前期也可能经恶魔房出口进入。只有一层，终点撒但，没有常规宝箱房与商店让你重新发育。

## 打法与路线

普通房依靠已成型组合清场，珍惜心与主动充能。撒但是多阶段战，别把开场小头目打完误当胜利。累计击败撒但 5 次解锁底片；本局带底片时，撒但后的大箱子可通暗室。没有正确照片，大箱子通常结束本局，不能进入后再回来改走教堂。
