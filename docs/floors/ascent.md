# 上行 {#ascent}

<EntryHeader en="Ascent" category="终局与上行" icon="map" />

<VersionBadge checked="2026-10" />

## 前置

已击败母亲，开放深处 II 起点的奇怪的门。去妈妈前炸本层带记号的骷髅拿愚者等传送；妈妈后取全家福或底片，传送回起点，用照片开门，照片会被消耗。

## 特殊陵墓 II

奇怪的门后有自己的地图与发育房，终点不再是普通加强妈妈，而是爸爸的便条。拿便条会开始倒着上行，不能再按 Mother 路线去找肉门。

## 上行怎么走

从之前楼层的 Boss 房附近进入，往初始房走，踩光柱继续上一层，直到地下室 I，再进家。路径按本局经过的楼层倒序处理，I / II、变体与跳层会影响实际经过哪些层；不是新开一遍普通主线，敌人也有变化。上行的普通伤害按整心处理，即使回到地下室也一样。

## 能补什么

先前宝箱房 / Boss 房留下的底座可以成为回访资源，适合把无用道具留着、上行再判断；但不是所有清房奖励和箱子都无限重发。提前把饰品留在宝箱房或 Boss 房，上行会转换成红钥匙碎片，带到家解锁对应里角色。该流程支持“下行跳宝箱房争取星象房，上行再拿”的规划，但不要在血量不够时硬赌。
