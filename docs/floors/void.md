# 虚空 {#void}

<EntryHeader en="The Void" category="终局与上行" icon="map" />

<VersionBadge checked="2026-10" />

## 前置与入口

先击败过死寂。符合条件的终局 Boss 后可能出现虚空传送门；忏悔+ 对部分 Boss 的出口有变化，具体见[虚空入口表](/guide/unlocks/endings#精神错乱与虚空)。不是每个 Boss 后必开，也不能把显示的概率当成下一次保底。

## 地图与奖励

大型混合楼层，有多个 Boss 房，其中一个是精神错乱，其他是随机 Boss，可用于继续取得奖励。此处不再按“找最远 Boss 就一定是本层终点”的普通地图经验判断。

## 打法与选择

想稳健通关就先提升生命与防御，再决定是否进入；进了通常不能返回原路线。想找精神错乱，可用其 Boss 房需要容纳 2×2 区域、不与已有房间重叠的特征排除候选，但不是看图标直接确定。精神错乱的形态变化和突发攻击另看[打法](/strategy/bosses-2#精神错乱-delirium)。
