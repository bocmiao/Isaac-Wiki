# 尸宫 {#corpse}

<EntryHeader en="Corpse" category="母亲路线" icon="map" />

<VersionBadge checked="2026-10" />

## 进入与规则

陵墓 / 炼狱 II 完整刀片开启肉门并击败加强心脏后的母亲路线。尸体、腐败主题敌人和较危险地形要求保持距离；没有普通前三章那样的常规宝箱房、商店补给，普通伤害按整心阶段处理。

## I 层打法

用已有输出稳定清房，主动要及时用于难房，避免攒满电一路掉血。不能再依赖下一层商店补齐组合；先检查地图中的可恢复资源，再打本层 Boss。

## II 层终点

母亲，攻略见[Mother 打法](/strategy/bosses-2#母亲-mother)。第一次击败解锁雅各和以扫及[奇怪的门（635）](/achievements/ids-601-641#achievement-635)。忏悔+ 击败后会提供虚空入口；旧版本不要按这个出口规划本局一定续打精神错乱。
## 本章共通规则

前置是死寂累计击败 3 次的[秘密出口（407）](/achievements/ids-401-500#achievement-407)。替代章节有自己的敌人、布局与门票，宝箱房常有可见 / 问号二选一；它们不是只换背景。入口规则见[替代章节入口房](/rooms/secret-exit)。

::: tip 一次走通 Mother
地下室阶段留 **1 钥匙** → 下水道 / 污水渠 **II 拿刀片 1** → 留 **2 炸弹**开矿洞门 → 矿洞 / 灰坑 **II 拿刀片 2** → 留能承担 **2 心伤害**的生命开陵墓门 → 陵墓 / 炼狱 **II 刀片开肉门、打加强心脏** → 尸宫 I → 尸宫 II 母亲。

可以跳过部分替代路线的 I 层，但**两段 II 层的刀片步骤不能漏**。从地下室 I 转入对应下水道 I，地下室 II 转入对应下水道 II；别因为只剩 II 层就误以为已经来不及拿第一块刀片。
:::
