# 联机专题

<VersionBadge checked="2026-10" />

::: tip 速览
- **PC 在线联机要装 Repentance+**：免费，但要先拥有前面全部 DLC（[基本情况](#在线联机的基本情况)）
- **最多 4 人，所有模式都能在线玩**，模组必须全部关掉（[基本情况](#在线联机的基本情况)）
- **必须从开局就在队里**，中途加入的人这一局解锁不了东西（[成就和解锁](#成就和解锁)）
- **硬币、炸弹、钥匙全队共用**，花之前说一声（[共用规则](#角色、道具和复活规则)）
- **死了别急着退**：清掉 Boss 房全员复活，在线还能喂复活机（[复活](#角色、道具和复活规则)）
:::

本页讲 PC 上的在线联机和本地联机；主机版的在线联机要等 2026 年 11 月 19 日，见[主机专题](/topics/console)。

## 在线联机的基本情况

| 项目 | 说明 |
| --- | --- |
| 上线时间 | 2024 年 11 月 18 日随 Repentance+ 在 Steam 推出，官方发布时把它叫作 Beta |
| 需要什么 | 本体加胎衣、胎衣+、忏悔，再免费领取 Repentance+，见[版本与 DLC 怎么买](/guide/start/versions) |
| 人数 | 最多 4 人 |
| 能玩的模式 | 普通、困难、贪婪模式、极贪模式、挑战、每日挑战（Daily Run）、种子局 |
| 模组 | 必须全部关掉，并重启游戏，见[配置与模组](/topics/mods) |

::: warning 在线联机还是 Beta
在线联机可能不稳定，偶尔会损坏存档。
:::

## 怎么开房间、匹配和邀请好友

在线有三种组队方式：

| 方式 | 说明 |
| --- | --- |
| 好友房间（Friend Match） | 和 Steam 好友一起玩。房间会显示在好友房间列表里，可以设密码 |
| 公开房间（Public Match） | 自己开房，或在列表里找陌生人的房。开房和找房时都能设筛选条件 |
| 快速匹配（Quick Match） | 随机和一组在线玩家组队，最省事 |

每日挑战也能在线玩，同样分公开房间和好友房间，还有单独的组队排行榜。

几个容易踩的坑：

- 大家的游戏版本要一致，不然进不了好友房间。
- 队员可以投票踢人。被踢的人不能再进同一个好友房间。
- 已经开始的每日挑战，不能中途加入。

## 成就和解锁

- 单人能拿到的解锁，在线都能拿。
- 中途加入的人，这一局不能解锁，界面上会有图标提示。他会在下一层开始时进场，游戏会按进度补给他几件道具。
- 在线局按全队里解锁最少的那个人的存档来算（据英文 wiki 记载）。队友没解锁的东西，这一局大家都见不到。
- Repentance+ 加了在线成就。
- 还没拿到白金神（Dead God，全成就）的人，以后也要把在线成就拿到。已经拿到白金神的人不受影响。

## 角色、道具和复活规则

从忏悔开始，联机的队友可以用完整的角色，不再只是联机宝宝。下面的规则本地和在线都适用：

| 规则 | 内容 |
| --- | --- |
| 共用 | 硬币、炸弹、钥匙 |
| 各自独立 | 血量、道具、饰品、卡牌和胶囊 |
| Boss 掉落 | 每多一个玩家，多掉一个道具 |
| 打 Boss | 所有人对 Boss 的伤害都降低 20% |
| 死了以后 | 变成小幽灵，见下方 |
| 复活 | 清掉 Boss 房后，所有死去的玩家都会复活 |

变成小幽灵以后：

- **不能**：捡道具、用主动道具。敌人也不会追你。
- **能**：飞；捡硬币、炸弹、钥匙；踩地上的按钮；射伤害很低的眼泪。

在线还多了复活机（Revive Machine）：

- **位置**：普通和困难模式里，在每层初始房间上方门的左边；贪婪模式里在每层的商店。
- **用法**：撞一下花 1 枚硬币，机器上的数字从 10 往下减，减到 0 就复活一个人。
- **越来越贵**：每复活一次，下一次复活要多花 2 枚硬币。
- **复活谁**：死了好几个人时，由投币的人选。
- **别白撞**：没人死的时候把它撞满，不会复活任何人，计数还会重来，钱就白花了。

## 本地联机和在线联机的区别

本地联机：开新局后，只要 1P 还没离开初始房间，其他人按开始键就能加入，在屏幕上方的小轮盘里选一个已解锁的角色，或者随机。1P 离开初始房间后再加入，就只能当联机宝宝（co-op baby）。

| | 本地（同屏） | 在线 |
| --- | --- | --- |
| 怎么组队 | 同一台机器，在初始房间加入 | 好友房间、公开房间或快速匹配 |
| 中途加入 | 只能当联机宝宝 | 可以，下一层开始时进场 |
| 成就 | 所有角色都拿完成标记（打败某个 Boss 后在角色上记下的标记），不管出了多少力 | 从开局就在的人才能解锁 |
| 复活 | 清掉 Boss 房 | 清掉 Boss 房，或喂复活机 |
| 交流 | 当面说 | 表情轮盘、文字聊天 |

在线时想重开，要所有人一起按住 <KeyCap>R</KeyCap>。

::: tip 另一种在线玩法：远程同乐
Steam 版还可以用 Steam 的远程同乐（Remote Play Together）功能，把本地联机搬到网上玩。
:::

::: info PC 的跨平台联机
2026 年 4 月的 1.9.7.16 更新，加入了 Steam 和 Epic 之间的跨平台联机。按当时的公告，它默认关闭，要手动改 options.ini 里的 EosCrossplay 才能打开。新手可以先不管。
:::

## 新手联机建议

1. 第一次先开好友房间，和认识的人玩，方便商量。
2. 人到齐再开局。中途进来的人，这局解锁不了东西。
3. 钱、炸弹、钥匙是共用的。谁买商店道具、钥匙开哪个门，花之前说一声。
4. Boss 道具一人一个，别抢。本地联机时，Boss 房原本的那个道具被拿走后，多掉的道具才会出现。
5. 死了别急着退。幽灵还能捡硬币、踩按钮，打完 Boss 就复活。在线时队友也可以喂复活机。
6. 角色搭配：
   - 英文 wiki 认为，雅各和以扫（Jacob & Esau）除了刷成就或自找挑战，基本没理由拿来联机。
   - 游魂（The Lost）挨一两下就死，但联机时每层都能复活，这个弱点小了很多。
   - 抹大拉（Magdalene）用主动道具美味的心（Yum Heart）时，会给其他队友各回半颗心。
7. 想发表情，键盘按左 <KeyCap>Alt</KeyCap>，手柄按下右摇杆。网络延迟大的话，游戏里可以手动调输入延迟。
