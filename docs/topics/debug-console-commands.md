# 调试控制台：命令大全与编号

<VersionBadge checked="2026-10" />

::: tip 速览
- **四种编号别混**：`c` 道具、`t` 饰品、`p` 胶囊效果、`k` 卡牌 / 符文（[四种编号](#ids)）
- **尖括号里的参数换成实际值**，不要原样输入尖括号
- **`debug 编号` 是开关**，同号再输一次即关闭，编号不能相加（[debug](#debug)）
- **宏里的 debug 也是切换**，之前开过的可能被宏关掉（[内置 macro](#macros)）
- 本页查命令和编号；还没开启先看[开启与关闭](/topics/debug-console)，逐条练习见[练习示例与排错](/topics/debug-console-practice)
:::

本页收录原版命令，也包括「未列出命令」（游戏 `help` 列表里不显示，但能用的命令）和旧版命令，不含模组扩展的命令。示例以忏悔 / 忏悔+ 为主；只在某些版本能用的命令，在那一行注明版本。

## 先分清四种编号 {#ids}

`giveitem` 用的带前缀编号、`spawn` 用的实体编号、`restart` 用的角色编号、`goto` 用的房间布局编号，是几套互不相干的编号。

| 操作 | 写法 | 含义 |
| --- | --- | --- |
| 给收藏道具（主动 / 被动） | `giveitem c105` | 给 D6。`c` 代表 collectible（道具），道具编号和卡牌编号是两回事 |
| 给饰品 | `giveitem t15` | 给编号 15 的饰品 |
| 给胶囊效果 | `giveitem p0` | 按胶囊**效果**编号给胶囊，不是按本局胶囊外观颜色编号 |
| 给卡牌 / 符文 / 口袋物品 | `giveitem k1` | 按卡牌编号给，符文等也用这套编号 |
| 生成地上实体 | `spawn 5.100.1` | `类型.变体.子类型`：生成悲伤洋葱道具底座，不是直接装备 |
| 换角色开新局 | `restart 0` | 角色编号 0 是以撒，不是道具 0 |

`g` 是 `giveitem` 的缩写，`r` 是 `remove` 的缩写。

- 也可以用英文名称，如 `g Brimstone`。但名称相近时可能给错东西，要准确复现时用编号。
- 前缀是英文缩写 `c` / `t` / `p` / `k`，不要按拼音首字母猜。

查编号：[CollectibleType](https://wofsauge.github.io/IsaacDocs/rep/enums/CollectibleType.html)、[TrinketType](https://wofsauge.github.io/IsaacDocs/rep/enums/TrinketType.html)、[Card](https://wofsauge.github.io/IsaacDocs/rep/enums/Card.html)、[PillEffect](https://wofsauge.github.io/IsaacDocs/rep/enums/PillEffect.html)、[EntityType](https://wofsauge.github.io/IsaacDocs/rep/enums/EntityType.html)、[PickupVariant](https://wofsauge.github.io/IsaacDocs/rep/enums/PickupVariant.html)。模组新增内容用它自己的编号与名称。

## 道具、实体与资源 {#items}

| 命令 / 示例 | 用途与边界 |
| --- | --- |
| `giveitem c1` / `g c1` | 直接给角色悲伤洋葱（The Sad Onion）。也能给饰品、卡牌、胶囊，或用英文名称。给主动或口袋道具时，可能顶掉你原来那一格的东西 |
| `remove c1` / `r c1` | 移除道具。已经发生的回血、消耗、变身等效果不一定会撤销 |
| `remove *` | 身上每种道具和饰品各移除一个。同一道具有好几个时不会一次清空，也不会还原到开局状态 |
| `combo 0.3` | 从编号 0 的宝箱房道具池随机给 3 件；语法是 `池编号.数量`，不是道具编号 |
| `spawn 5.100.1` | 在房间中央生成悲伤洋葱底座。完整格式是 `类型.变体.子类型.冠军编号`，后面几段可以省略；也可以写实体英文名称 |
| `gridspawn 1000` / `gridspawn 1000 28` | 随机位置或指定网格位置生成网格实体，此例为石头。网格实体和敌人 / 掉落物的 spawn 编号不同 |
| `listcollectibles` | 输出持有的收藏道具及各自数量，便于比较组合 |
| `costumetest 3` | 添加 3 个随机外观，不给对应道具；无参数时随机数量 |
| `restock` | 未列出命令：让所有商店重新补货，不会给钱 |
| `metro c1` | 忏悔起：指定节拍器（Metronome）下次变成的道具，不是直接获得道具 |
| `delirious Monstro` | 忏悔+：指定主动道具精神错乱（Delirious）下次召唤的 Boss，也可以写 Boss ID。忏悔（非 +）里的 `delirious 1` 编号对应关系不同，据记载不起作用 |

常用池编号：`0` 宝箱房、`1` 商店、`2` Boss、`3` 恶魔、`4` 天使。完整池表见 [ItemPoolType](https://wofsauge.github.io/IsaacDocs/rep/enums/ItemPoolType.html)。池编号和道具品质（道具 0～4 级的强度评级）无关。

生成无效实体可能闪退。不要照抄 `spawn coplayer`：据记载它会让游戏崩溃，还可能损坏存档。要测多角色，用 `addplayer`（见[多角色](#multiplayer)），并先弄清控制器怎么分配。

## 楼层、房间与对局 {#runs}

| 命令 / 示例 | 用途与边界 |
| --- | --- |
| `stage 1` | 到地下室 I。数字后面加字母选变体，见下方[楼层编号](#stages)。它会直接换楼层，不能用来撤销操作 |
| `goto d.10` | 进入当前层的普通房布局 10。同一编号在不同楼层是不同的房间 |
| `goto s.boss.1010` | 进入指定类型、指定布局的特殊房，格式 `s.类型.布局编号`。楼层文件里的特殊房用 `x.类型.编号`，如练习页的祸兽示例 |
| `goto 6 6 0` | 按 X、Y 坐标和维度去一个已存在的房间，维度编号见 [Dimension](https://wofsauge.github.io/IsaacDocs/rep/enums/Dimension.html)。坐标上没有房间时，不会凭空造一个 |
| `reseed` | 重新生成当前楼层的布局和楼层种子，不是重开整局 |
| `restart` / `restart 0` | 从头开新局，可指定角色。会替换掉当前这局；不会回到上一房间，也不会永久解锁这个角色 |
| `seed T1MM AY48` | 用指定种子开始新局。手动输入种子的局不能正常解锁成就 |
| `challenge 20` | 开始指定编号的挑战（随机种子），`challenge 0` 开不带挑战的局。编号要在当前版本里存在，见[挑战攻略](/strategy/challenges) |
| `curse 2` | 设置本层诅咒。参数是数值，见下方[诅咒参数](#curses)；多个诅咒把数值相加，不能写诅咒名称。胎衣+ 里据记载不起作用 |
| `clearseeds` | 清除本局的[彩蛋种子](/strategy/seeds)（带特殊效果的种子）效果。手动输入种子的局，清完也还是不能解锁 |
| `rewind` | 忏悔起，未列出：效果类似发光沙漏（Glowing Hourglass），回到上一房间，并回退当前房间的状态。不是回滚整个存档 |
| `forceroom s.boss.1010` | 忏悔起，未列出：提高指定房间的生成权重，再用 `reseed` 测试。门、难度等条件仍可能让它不出现 |
| `testbosspool` | 忏悔起，未列出：输出当前楼层的 Boss 池和各自权重，权重 `10000` 表示 100% |
| `time` | 输出按游戏帧计算的本局时间 |

### 诅咒参数 {#curses}

`curse` 的参数是下表的数值，要同时加多个诅咒就把数值相加：

| 数值 | 诅咒 |
| --- | --- |
| `1` | 黑暗 |
| `2` | 迷宫（XL，本层和下一层合成一个大层） |
| `4` | 迷失 |
| `8` | 未知 |
| `16` | 诅咒（Cursed，特殊尖刺门） |
| `32` | 迷途（Maze） |
| `64` | 致盲 |

`curse 65` 表示黑暗与致盲，`curse 0` 表示不设置诅咒。完整枚举见 [LevelCurse](https://wofsauge.github.io/IsaacDocs/rep/enums/LevelCurse.html)。用 `curse` 加上迷宫诅咒，本层不会因此重新生成为 XL 布局。要重新生成楼层，见上表的 `reseed`。

### 楼层编号 {#stages}

| 数字 | 默认楼层 | 加后缀 |
| --- | --- | --- |
| `1` / `2` | 地下室 I / II | `a` 地窖、`b` 燃烧地下室、`c` 下水道、`d` 水牢 |
| `3` / `4` | 洞穴 I / II | `a` 地下墓穴、`b` 淹水洞穴、`c` 矿井、`d` 灰坑 |
| `5` / `6` | 深牢 I / II | `a` 坟场、`b` 黑暗深牢、`c` 陵墓、`d` 地狱 |
| `7` / `8` | 子宫 I / II | `a` 血宫、`b` 伤痕子宫；`c` 尸宫 I / II |
| `9` | 蓝子宫 / ???（死寂所在层） | 不是大教堂 |
| `10` | 阴间 | `10a` 大教堂 |
| `11` | 暗室 | `11a` 宝箱层 |
| `12` | 虚空 | 忏悔主线终局区域之一 |
| `13` | 家 | 忏悔起；进入家不等于立刻开始祸兽战 |

- 后缀要接在数字后面，例如 `7c` 是尸宫 I，`8c` 是尸宫 II。
- 以上是普通模式的楼层编号。贪婪模式的楼层对应关系是另一套，不能照搬。
- 输入不存在的楼层（例如 14、15）可能崩溃，不要乱试编号。
- 完整底层编号见 [LevelStage](https://wofsauge.github.io/IsaacDocs/rep/enums/LevelStage.html) 与 [StageType](https://wofsauge.github.io/IsaacDocs/rep/enums/StageType.html)。

## debug：显示信息与练习开关 {#debug}

输入 `debug 编号` 打开对应功能，再输一次同一编号就关闭。要开多个功能就分别输入，不能把编号相加。记下自己开了哪些，免得把练习时的伤害当成角色的正常强度。

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| `1` | 标出实体位置 | 看实体坐标基点 |
| `2` | 显示网格 cost | 寻路 / 碰撞调试用，不会显示全地图 |
| `3` | 无限生命 | 受伤不扣血。某些特殊死亡和剧情机制不一定挡得住 |
| `4` | 高伤害 | 伤害 +40，适合快速清杂兵 |
| `5` | 房间信息 | 在画面下方显示房间资料 |
| `6` | 命中判定球 | 忏悔起：用红圈显示实体的伤害判定范围。胎衣+ 里这个编号叫 Textual Map，据记载没有可见效果 |
| `7` | 伤害数字 | 显示实体受到的原始伤害数值，包括玩家伤害 |
| `8` | 无限主动充能 | 反复测试主动效果 |
| `9` | 高幸运 | 幸运 +50，便于观察按概率触发的效果 |
| `10` | 快速杀敌 | 敌人持续快速受伤；练走位时不要开 |
| `11` | 网格编号 / 坐标 | 查 `gridspawn` 位置参数 |
| `12` | 玩家道具信息 | 忏悔起：显示身上的道具和临时道具效果 |
| `13` | 网格碰撞点 | 忏悔起：显示实体与墙 / 障碍的碰撞点 |
| `14` | Lua 内存曲线 | 忏悔+：调试模组内存 |

## 输出、画面与模组开发 {#development}

| 命令 / 示例 | 用途与边界 |
| --- | --- |
| `clear` | 清控制台输出，不撤销之前执行的命令 |
| `copy 3` | 将最近 3 条命令复制到剪贴板；不是复制存档 |
| `repeat 3` | 把上一条命令再额外执行 3 次，最多 10000 次。上一条如果是生成实体，次数多了很快会卡 |
| `macro 名称` / `m 名称` | 执行游戏预置的一组命令，不是自动录制自己的宏；列表见下节 |
| `clearcache` | 清精灵缓存，可重新载入改过的精灵资源；不是删存档 |
| `reloadshaders` | 重载着色器，未必有可见变化 |
| `reloadfx` | 忏悔起：重载楼层覆盖特效 |
| `reloadwisps` | 忏悔起，未列出：重载美德之书（Book of Virtues）的魂火和无底坑（Abyss）的蝗虫 |
| `playsfx 1` / `playsfx 1 0.5` | 播放指定 ID 的音效，第二个参数是音调 |
| `cutscene 1` | 播放指定过场动画。播放过不等于正常打出了这个结局 |
| `lua print("Hello World!")` / `l print("Hello World!")` | 直接执行一行 Lua。这个只打印文字的例子用来确认命令能用 |
| `luamem` | 输出 Lua 内存使用 |
| `luamod 模组文件夹名` | 重跑模组的 `main.lua`。参数是文件夹名，不一定和工坊标题相同。它不是完整的卸载重装，可能重复注册回调 |
| `luarun 路径` | 执行指定 Lua 文件，相对路径从游戏安装目录算起。运行前先看懂代码做什么 |

### 内置 macro 名称 {#macros}

宏会一次执行跳层、发道具和 debug 开关等多条命令。**宏里的 debug 也是切换，不是强制打开**：之前开过同一个开关，运行宏反而会把它关掉。想清楚掌握练习配置，逐条输入比反复运行宏更容易核对。

| 名称 | 用途 |
| --- | --- |
| `mom` | 到深牢 II，给圣经（The Bible）、卡牌 IV-皇帝（IV - The Emperor），开无限生命、高伤害等 |
| `momh` | 子宫 II，类似妈妈之心练习配置 |
| `hush` | 到死寂层，给皇帝卡和来自多个道具池的随机道具 |
| `bigchest` | 到大教堂，给全家福（The Polaroid）、底片（The Negative）和大量道具，并开战斗类开关 |
| `hud` | 添加多种道具、饰品与胶囊，测试 HUD / 持有物显示 |
| `fc` | 添加恐惧相关道具与无限生命、充能、高幸运配置 |
| `ms` | 到超级撒旦房布局，可用的布局取决于所在楼层 |
| `mss` | 到超级撒旦布局，给输出道具，开无限生命、高伤害 |
| `ug` / `ugg` | 当年测究极贪婪用的宏，**不是正常进入贪婪模式**：都会传送到宝箱层，并去 ID 6000 的 Boss 房。忏悔前没有 6000 号房间，加载会失败；忏悔起 6000 号房间已存在，就会直接把你传进去。`ugg` 另外给 2 个悲伤洋葱、2 个撕碎的照片、变异蜘蛛、五芒星、一美元、烟火盛宴，并开无限生命 |
| `qk` | 大量移动 / 地图 / 资源道具，加无限生命、充能与快速杀敌 |
| `beast` | 忏悔后续更新加入：到家，进祸兽战斗布局，给随机道具 |

## 多角色与旧网络测试命令 {#multiplayer}

这些都是**未列出命令**，不是在线联机的设置方法。

| 命令 / 示例 | 用途 |
| --- | --- |
| `giveitem2 c105` / `g2 c105` | 忏悔起：给次角色（如以扫）道具 |
| `remove2 c1` / `r2 c1` | 忏悔起：从次角色移除道具 |
| `addplayer 1` / `addplayer 6 1` | 忏悔起：增加一个玩家，可指定角色和控制器 ID。按默认的控制器分配，新玩家不一定能单独操作 |
| `netdelay 2` | 忏悔的旧网络测试命令：调整网络延迟参数，并不能降低实际的网络延迟 |
| `netstart <SteamID1> <SteamID2>` | 忏悔的旧实验联机入口。所有人都要用 `--networktest` 参数启动游戏，填数字 Steam ID，也可以在存档目录的 `steamids.txt` 里设别名。可能不稳定，代替不了忏悔+ 的正式邀请 |

Steam ID 不是昵称。想在忏悔+正常和朋友玩，请用[联机专题](/topics/coop)，不要为它复制旧测试参数。

## 永久进度与已移除命令 {#legacy}

| 命令 | 用途 / 状态 |
| --- | --- |
| `eggs` | 在菜单里解锁全部彩蛋种子，会改变菜单里能选的内容。想先了解单局效果，看[种子攻略](/strategy/seeds) |
| `achievement 编号` / `achievement 名称` / `achievement *` | **胎衣+ 旧命令**：解锁指定成就或全部成就，会写入永久进度和 Steam 成就，`remove`、`rewind` 都撤销不了。忏悔里没有这条命令，也不推荐用来练习 |
| `prof` / `profstop` | 旧的性能分析命令，已移除 |
| `macro sg` | 胎衣+ 的旧宏，有崩溃记录，忏悔已移除。不要尝试 |
