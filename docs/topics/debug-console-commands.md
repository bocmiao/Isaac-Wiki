# 调试控制台：命令大全与编号

<VersionBadge checked="2026-10" />

::: tip 速览
- **四种编号别混**：`c` 道具、`t` 饰品、`p` 胶囊效果、`k` 卡牌 / 符文（[四种编号](#ids)）
- **尖括号里的参数换成实际值**，不要原样输入尖括号
- **`debug 编号` 是开关**，同号再输一次即关闭，编号不能相加（[debug](#debug)）
- **宏里的 debug 也是切换**，之前开过的可能被宏关掉（[内置 macro](#macros)）
- 本页查命令和编号；还没开启先看[开启与关闭](/topics/debug-console)，逐条练习见[练习示例与排错](/topics/debug-console-practice)
:::

下表覆盖公开文档列出的原版命令、未列出命令及旧版命令，不含所有模组扩展；示例以忏悔 / 忏悔+ 为主，额外版本限制写在对应行。

## 先分清四种编号 {#ids}

`giveitem` 的编号前缀、实体编号、角色编号与房间布局编号是不同系统。

| 操作 | 写法 | 含义 |
| --- | --- | --- |
| 给收藏道具（主动 / 被动） | `giveitem c105` | 给 D6；`c` 是 collectible，道具编号不是卡牌编号 |
| 给饰品 | `giveitem t15` | 给编号 15 的饰品 |
| 给胶囊效果 | `giveitem p0` | 按胶囊**效果**编号给胶囊，不是按本局胶囊外观颜色编号 |
| 给卡牌 / 符文 / 口袋物品 | `giveitem k1` | 按卡牌编号给物品；符文等也在此编号表内 |
| 生成地上实体 | `spawn 5.100.1` | `类型.变体.子类型`：生成悲伤洋葱道具底座，不是直接装备 |
| 换角色开新局 | `restart 0` | 角色编号 0 是以撒，不是道具 0 |

`g` 是 `giveitem` 的缩写，`r` 是 `remove` 的缩写。也可用英文名称，如 `g Brimstone`；相似名称可能匹配到意外目标，需要准确复现时用编号。示例采用文档的 `c` / `t` / `p` / `k`，不要凭拼音首字母猜前缀。

查编号：[CollectibleType](https://wofsauge.github.io/IsaacDocs/rep/enums/CollectibleType.html)、[TrinketType](https://wofsauge.github.io/IsaacDocs/rep/enums/TrinketType.html)、[Card](https://wofsauge.github.io/IsaacDocs/rep/enums/Card.html)、[PillEffect](https://wofsauge.github.io/IsaacDocs/rep/enums/PillEffect.html)、[EntityType](https://wofsauge.github.io/IsaacDocs/rep/enums/EntityType.html)、[PickupVariant](https://wofsauge.github.io/IsaacDocs/rep/enums/PickupVariant.html)。模组新增内容用它自己的编号与名称。

## 道具、实体与资源 {#items}

| 命令 / 示例 | 用途与边界 |
| --- | --- |
| `giveitem c1` / `g c1` | 直接给角色悲伤洋葱；也支持饰品、卡牌、胶囊与英文名称。主动、口袋道具涉及槽位，注意替换 |
| `remove c1` / `r c1` | 移除道具；不保证撤销已经发生的回血、消耗、变身或其他历史效果 |
| `remove *` | 从所有持有道具与饰品中各移除一份；多份堆叠不代表一次清空，也不是还原初始状态 |
| `combo 0.3` | 从编号 0 的宝箱房道具池随机给 3 件；语法是 `池编号.数量`，不是道具编号 |
| `spawn 5.100.1` | 在房间中央生成悲伤洋葱底座；完整格式 `类型.变体.子类型.冠军编号`，后部可按需求省略，也支持实体英文名称 |
| `gridspawn 1000` / `gridspawn 1000 28` | 随机位置或指定网格位置生成网格实体，此例为石头。网格实体和敌人 / 掉落物的 spawn 编号不同 |
| `listcollectibles` | 输出持有的收藏道具及各自数量，便于比较组合 |
| `costumetest 3` | 添加 3 个随机外观，不给对应道具；无参数时随机数量 |
| `restock` | 补货所有商店；属未列出命令，不是直接加钱 |
| `metro c1` | 忏悔起：指定节拍器（Metronome）下次选中的道具，不是直接获得道具 |
| `delirious Monstro` | 忏悔+：指定 Delirious 主动下次选中的 Boss，也接受 Boss ID。忏悔旧版的 `delirious 1` 映射和忏悔+不同，公开文档标注旧版命令不工作 |

常用池编号：`0` 宝箱房、`1` 商店、`2` Boss、`3` 恶魔、`4` 天使。完整池表见 [ItemPoolType](https://wofsauge.github.io/IsaacDocs/rep/enums/ItemPoolType.html)，编号不等于道具品质。

无效实体可能导致闪退；不要照抄 `spawn coplayer`，公开文档记录它会崩溃，且可能损坏存档。要测多角色请用文档支持的 `addplayer` 并了解控制器分配。

## 楼层、房间与对局 {#runs}

| 命令 / 示例 | 用途与边界 |
| --- | --- |
| `stage 1` | 到地下室 I；数字后缀选择变体，完整速查见下表。会改变楼层，不是撤销操作 |
| `goto d.10` | 进入当前层可用的普通房布局 10；同一编号在不同楼层并非同一房间 |
| `goto s.boss.1010` | 进入指定特殊房类型与布局；`s.类型.布局编号`。`x.类型.编号` 用于楼层文件内特殊房，如祸兽示例 |
| `goto 6 6 0` | 按 X、Y、维度到已存在的房间；维度编号见 [Dimension](https://wofsauge.github.io/IsaacDocs/rep/enums/Dimension.html)。不存在时不能凭坐标创造房间 |
| `reseed` | 给当前楼层重新生成布局与楼层种子；不等于重开整局 |
| `restart` / `restart 0` | 从头开新局；可指定角色。会替换当前局，不是返回上一房间，也不会永久解锁该角色 |
| `seed T1MM AY48` | 用指定种子开始新局；手动普通种子不能正常刷解锁 |
| `challenge 20` | 以指定挑战编号开始随机种子新局；`challenge 0` 开无挑战局。编号需在当前版本存在，见[挑战攻略](/strategy/challenges) |
| `curse 2` | 设诅咒位掩码；多个诅咒用数值相加，不是输入诅咒名称。胎衣+文档标为不工作 |
| `clearseeds` | 清除本局彩蛋种子效果；不是把手动普通种子局变回可解锁局 |
| `rewind` | 忏悔起，未列出：类似发光沙漏，回到上一房间并回退当前房状态；不是完整存档回滚 |
| `forceroom s.boss.1010` | 忏悔起，未列出：提高指定房间生成权重，再用 `reseed` 测试；门、难度等条件仍可能让它不出现 |
| `testbosspool` | 忏悔起，未列出：输出当前楼层 Boss 池与权重，文档中 `10000` 对应 100% |
| `time` | 输出按游戏帧计算的本局时间 |

### 诅咒参数 {#curses}

`curse` 使用位掩码，多个诅咒把数值相加：

| 数值 | 诅咒 |
| --- | --- |
| `1` | 黑暗 |
| `2` | 迷宫（XL） |
| `4` | 迷失 |
| `8` | 未知 |
| `16` | 诅咒（Cursed，特殊尖刺门） |
| `32` | 迷途（Maze） |
| `64` | 致盲 |

`curse 65` 表示黑暗与致盲，`curse 0` 表示不设置诅咒。完整枚举见 [LevelCurse](https://wofsauge.github.io/IsaacDocs/rep/enums/LevelCurse.html)。修改标记不应当作已经重新生成 XL 布局；需要重建楼层另看 `reseed` 的作用。

### 楼层编号 {#stages}

| 数字 | 默认楼层 | 常用变体 / 后缀 |
| --- | --- | --- |
| `1` / `2` | 地下室 I / II | `a` 地窖、`b` 燃烧地下室、`c` 下水道、`d` 水牢 |
| `3` / `4` | 洞穴 I / II | `a` 地下墓穴、`b` 淹水洞穴、`c` 矿井、`d` 灰坑 |
| `5` / `6` | 深牢 I / II | `a` 坟场、`b` 黑暗深牢、`c` 陵墓、`d` 地狱 |
| `7` / `8` | 子宫 I / II | `a` 血宫、`b` 伤痕子宫；`c` 尸宫 I / II |
| `9` | 蓝子宫 / ???（死寂所在层） | 不是大教堂 |
| `10` | 阴间 | `10a` 大教堂 |
| `11` | 暗室 | `11a` 宝箱层 |
| `12` | 虚空 | 忏悔主线终局区域之一 |
| `13` | 家 | 忏悔起；进入家不等于立刻开始祸兽战 |

- 楼层数字与后缀要配合使用；`7c` 为尸宫 I，`8c` 为尸宫 II。
- 以上是普通模式的关卡编号；贪婪模式按另一套楼层对应关系，不能照搬。
- 无效楼层（例如 14、15）可能崩溃，不靠随机编号找入口。
- 完整底层编号见 [LevelStage](https://wofsauge.github.io/IsaacDocs/rep/enums/LevelStage.html) 与 [StageType](https://wofsauge.github.io/IsaacDocs/rep/enums/StageType.html)。

## debug：显示信息与练习开关 {#debug}

输入 `debug 编号` 切换对应功能，再输同一编号关闭。编号不是可相加的位掩码。记录自己开启的项目，免得把练习伤害当成正常角色强度。

| 编号 | 功能 | 版本 / 练习用途 |
| --- | --- | --- |
| `1` | 标出实体位置 | 看实体坐标基点 |
| `2` | 显示网格 cost | 路径 / 碰撞调试，不是直接显示全地图 |
| `3` | 无限生命 | 受伤不扣血；不保证所有特殊死亡与剧情机制都被阻止 |
| `4` | 高伤害 | 伤害增加 40，适合快速清杂兵 |
| `5` | 房间信息 | 在画面下方显示房间资料 |
| `6` | 命中判定球 | 忏悔显示实体伤害判定红圈；胎衣+旧称 Textual Map，公开文档记为无可见效果 |
| `7` | 伤害数字 | 显示实体受到的原始伤害数值，包括玩家伤害 |
| `8` | 无限主动充能 | 反复测试主动效果 |
| `9` | 高幸运 | 幸运增加 50，便于观察概率触发 |
| `10` | 快速杀敌 | 敌人持续快速受伤；练走位时不要开 |
| `11` | 网格编号 / 坐标 | 查 `gridspawn` 位置参数 |
| `12` | 玩家道具信息 | 忏悔起；持有道具与临时道具效果 |
| `13` | 网格碰撞点 | 忏悔起；显示实体与墙 / 障碍的碰撞点 |
| `14` | Lua 内存曲线 | 忏悔+；模组内存调试 |

## 输出、画面与模组开发 {#development}

| 命令 / 示例 | 用途与边界 |
| --- | --- |
| `clear` | 清控制台输出，不撤销之前执行的命令 |
| `copy 3` | 将最近 3 条命令复制到剪贴板；不是复制存档 |
| `repeat 3` | 把上一条命令额外执行 3 次，文档上限 10000；上一条若生成大量实体，可能很快卡顿 |
| `macro 名称` / `m 名称` | 执行游戏预置的一组命令，不是自动录制自己的宏；列表见下节 |
| `clearcache` | 清精灵缓存，可重新载入改过的精灵资源；不是删存档 |
| `reloadshaders` | 重载着色器，未必有可见变化 |
| `reloadfx` | 忏悔起：重载楼层覆盖特效 |
| `reloadwisps` | 忏悔起，未列出：重载美德之书魂火与无底坑蝗虫 |
| `playsfx 1` / `playsfx 1 0.5` | 播放音效 ID；第二参数为音调 |
| `cutscene 1` | 播放指定过场，不能当成已正常打通对应结局的证明 |
| `lua print("Hello World!")` / `l print("Hello World!")` | 直接执行一行 Lua；只打印文字的例子用于验证入口 |
| `luamem` | 输出 Lua 内存使用 |
| `luamod 模组文件夹名` | 重跑模组 `main.lua`；名称是文件夹名，不一定是工坊标题。不是完整卸载重装，可能重复注册回调 |
| `luarun 路径` | 执行指定 Lua 文件；相对路径基于游戏安装目录。运行前读清代码作用 |

### 内置 macro 名称 {#macros}

宏会组合跳层、发道具和 debug 开关。**debug 是切换而非强制置为开启**，之前开过同一开关时，宏可能反而把它关掉。想明确控制练习配置，逐条输入比重复运行宏容易核对。

| 名称 | 用途 |
| --- | --- |
| `mom` | 深牢 II，圣经、皇帝卡、无限生命与高伤害相关配置 |
| `momh` | 子宫 II，类似妈妈之心练习配置 |
| `hush` | 到死寂层，给皇帝卡与多池随机道具 |
| `bigchest` | 大教堂、全家福（The Polaroid）与底片（The Negative），加大量道具和战斗开关 |
| `hud` | 添加多种道具、饰品与胶囊，测试 HUD / 持有物显示 |
| `fc` | 添加恐惧相关道具与无限生命、充能、高幸运配置 |
| `ms` | 到超级撒旦房布局；可用布局取决于楼层 |
| `mss` | 超级撒旦布局，加输出道具与无限生命、高伤害 |
| `ug` / `ugg` | 旧开发贪婪测试宏；跳宝箱层并请求 Boss 布局 6000，**不是正常进入贪婪模式**。旧版布局不存在，忏悔布局已改用 |
| `qk` | 大量移动 / 地图 / 资源道具，加无限生命、充能与快速杀敌 |
| `beast` | 忏悔后续更新加入：到家、祸兽战斗布局并发随机道具 |

## 多角色与旧网络测试命令 {#multiplayer}

这些是公开文档中的**未列出命令**，不是新手在线联机设置教程。

| 命令 / 示例 | 用途与版本范围 |
| --- | --- |
| `giveitem2 c105` / `g2 c105` | 忏悔起：给次角色（如以扫）道具 |
| `remove2 c1` / `r2 c1` | 忏悔起：从次角色移除道具 |
| `addplayer 1` / `addplayer 6 1` | 忏悔起：增加玩家，可指定角色类型与控制器 ID。默认控制器分配不保证形成正常独立操作 |
| `netdelay 2` | 忏悔旧网络测试：调整网络延迟参数，不是降低实际互联网延迟的万能指令 |
| `netstart <SteamID1> <SteamID2>` | 忏悔旧实验联机入口，文档要求参与者以 `--networktest` 启动并使用数字 Steam ID；也支持存档目录 `steamids.txt` 的别名表。可能不稳定，不替代忏悔+官方邀请流程 |

Steam ID 不是昵称。想在忏悔+正常和朋友玩，请用[联机专题](/topics/coop)，不要为它复制旧测试参数。

## 永久进度与已移除命令 {#legacy}

| 命令 | 用途 / 状态 |
| --- | --- |
| `eggs` | 解锁菜单中的全部彩蛋种子，改变可用菜单内容；想观察单局效果应先看[种子攻略](/strategy/seeds) |
| `achievement 编号` / `achievement 名称` / `achievement *` | **胎衣+旧版**：指定或批量解锁成就，会写入永久进度及 Steam 成就，不能靠 `remove` 或 `rewind` 撤销。忏悔不提供此旧命令，不作为本站练习方案 |
| `prof` / `profstop` | 旧性能分析命令，公开文档标为已移除 |
| `macro sg` | 胎衣+旧宏有崩溃记录，忏悔已移除；不要尝试 |
