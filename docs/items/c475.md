# 计划C

<EntryHeader en="Plan C" category="主动道具" icon="dice" code="c475" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 对所有敌人造成9,999,999点伤害
- 注意： 在3秒后击杀角色
- 精神错乱与母亲为10到12秒

::: details 忏悔版的效果差异
以下为忏悔基础说明；上方为忏悔+说明。

- 对所有敌人造成9,999,999点伤害
- 注意： 在3秒后击杀角色
:::

## 解锁与获取

- **解锁条件**：用拉撒路击败究极贪婪加强版。 [详细教程：成就 305](/achievements/ids-301-400#achievement-305)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：诅咒房、恶魔乞丐、恶魔房、贪婪诅咒房、贪婪商店、红箱子、商店、究极隐藏房。忏悔+ 的来源可能有调整。
