# 祭坛

<EntryHeader en="Sacrificial Altar" category="主动道具" icon="dice" code="c536" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 献祭最多2个跟班并生成同样数量的恶魔房道具
- 硬币： 将蓝蜘蛛/蓝苍蝇变成硬币

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 类型 | 主动道具 |
| 游戏内 ID | 536 |
| 基础充能方式 | 无需常规清房充能 |

## 解锁与获取

- **解锁条件**：累计完成 50 次恶魔交易。 [详细教程：成就 383](/achievements/ids-301-400#achievement-383)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：诅咒房、恶魔房、贪婪诅咒房、贪婪恶魔房。忏悔+ 的来源可能有调整。
