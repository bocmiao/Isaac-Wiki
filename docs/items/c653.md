# 驱魔护符

<EntryHeader en="Vade Retro" category="主动道具" icon="dice" code="c653" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 持有时, 非幽灵的敌人在死亡时生成小的红色幽灵
- 使用时, 引爆所有红色幽灵
- 使用时, 也会击杀所有血量低于50%的幽灵类敌人(包括头目)

## 解锁与获取

- **解锁条件**：用伯大尼击败究极贪婪加强版。 [详细教程：成就 424](/achievements/ids-401-500#achievement-424)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：天使房、贪婪天使房。忏悔+ 的来源可能有调整。
