# 玄奇驴皮

<EntryHeader en="Magic Skin" category="主动道具" icon="dice" code="c642" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 生成当前房间道具池的1个道具
- 将1心之容器/1骨心/2魂心变为1碎心
- 注意： 若角色不再持有, 则有概率将后续道具替换(1次使用后33%, 2次后50%, 3次后100%)
- 若玄奇驴皮在本层道具底座上, 则降低概率

## 解锁与获取

- **解锁条件**：用雅各与以扫击败母亲。 [详细教程：成就 472](/achievements/ids-401-500#achievement-472)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：诅咒房、贪婪诅咒房、红箱子、商店。忏悔+ 的来源可能有调整。
