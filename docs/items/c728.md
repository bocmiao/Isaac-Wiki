# 格罗

<EntryHeader en="Gello" category="主动道具" icon="dice" code="c728" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 在当前房间中, 角色会迸出恶魔跟班
- 恶魔向最近的敌人发射, 模仿角色属性和泪弹效果
- 伤害： 其泪弹造成75%角色伤害

## 解锁与获取

- **解锁条件**：用里莉莉丝击败精神错乱。 [详细教程：成就 595](/achievements/ids-501-600#achievement-595)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：恶魔房、贪婪恶魔房、贪婪宝箱房、宝箱房、究极隐藏房。忏悔+ 的来源可能有调整。
