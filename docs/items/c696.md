# 救恩

<EntryHeader en="Salvation" category="被动道具" icon="crown" code="c696" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 角色周围环绕光环
- 站在光环中过久的敌人受到十字光柱攻击
- 受伤时, 在本层中提升光环的大小

## 解锁与获取

- **解锁条件**：用里拉撒路击败祸兽。 [详细教程：成就 499](/achievements/ids-401-500#achievement-499)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：天使房、贪婪天使房。忏悔+ 的来源可能有调整。
