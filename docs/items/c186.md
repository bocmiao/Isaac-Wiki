# 血之权利

<EntryHeader en="Blood Rights" category="主动道具" icon="dice" code="c186" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 对所有敌人造成40点伤害
- 射速： 当前房间中射速修正+0.48
- 注意： 对角色造成1心伤害
- 在房间中首次使用后, 改为造成半心伤害
- 红心容器： 优先消耗红心

::: details 忏悔版的效果差异
以下为忏悔基础说明；上方为忏悔+说明。

- 对所有敌人造成40点伤害
- 注意： 对角色造成1心伤害
- 在房间中首次使用后, 改为造成半心伤害
- 红心容器： 优先消耗红心
:::

## 解锁与获取

- **解锁条件**：用参孙击败撒但。 [详细教程：成就 56](/achievements/ids-001-100#achievement-56)。
