# 纯洁

<EntryHeader en="Purity" category="被动道具" icon="crown" code="c407" />

<VersionBadge checked="2026-10" />

## 效果与数值

- ↑ 根据光环颜色对角色属性进行增强
- 受伤时, 移除光环, 在下个房间获得新的光环
- 黄色 = ↑ 移速+0.5
- 蓝色 = ↑ 射速修正+2
- 红色 = ↑ 伤害+4
- 橙色 = ↑ 射程+3

## 解锁与获取

- **解锁条件**：用抹大拉击败死寂。 [详细教程：成就 180](/achievements/ids-101-200#achievement-180)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：天使房、贪婪天使房、贪婪宝箱房、宝箱房。忏悔+ 的来源可能有调整。
