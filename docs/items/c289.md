# 红蜡烛

<EntryHeader en="Red Candle" category="主动道具" icon="dice" code="c289" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 投掷红火
- 火焰可造成接触伤害, 阻挡弹幕, 在造成或阻挡4次伤害后或10秒后消失

## 解锁与获取

- **解锁条件**：向普通捐款机累计捐 400 枚硬币。 [详细教程：成就 137](/achievements/ids-101-200#achievement-137)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：贪婪商店、商店、究极隐藏房。忏悔+ 的来源可能有调整。
