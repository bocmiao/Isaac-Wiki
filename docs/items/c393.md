# 蛇蝎之吻

<EntryHeader en="Serpent&#x27;s Kiss" category="被动道具" icon="crown" code="c393" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 中毒： 15%概率发射有毒泪弹
- 中毒： 使接触的敌人中毒
- 黑心： 因接触而中毒的敌人死亡时, 20%概率掉落黑心

## 解锁与获取

- **解锁条件**：用莉莉丝击败撒但。 [详细教程：成就 220](/achievements/ids-201-300#achievement-220)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：贪婪宝箱房、宝箱房。忏悔+ 的来源可能有调整。
