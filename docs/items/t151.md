# 扁锉

<EntryHeader en="Flat File" category="饰品" icon="key" code="t151" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 尖刺全部缩回, 不造成伤害
- 也影响诅咒房的门, 刺箱子和任何尖刺障碍物

| 项目 | 内容 |

## 解锁与获取

可从饰品掉落中取得，也可留意箱子、机器和生成饰品的道具。

无需成就解锁。
