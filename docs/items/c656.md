# 达摩克里斯之剑（悬剑形态）

<EntryHeader en="Damocles" category="跟班" icon="face" code="c656" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 在角色头上悬着剑, 并使底座道具翻倍
- 有价格或箱子中的道具不翻倍
- 注意： 受伤后, 剑每帧有极低概率立即击杀角色
- 无敌效果可以避免死亡

## 解锁与获取

- **解锁条件**：用雅各与以扫击败羔羊。 [详细教程：成就 432](/achievements/ids-401-500#achievement-432)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

使用主动版[达摩克里斯之剑](/items/c577)后形成的悬剑状态，不是额外掉落的常规跟班。
