# 嗜血小宠

<EntryHeader en="Blood Puppy" category="跟班" icon="face" code="c565" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 追击敌人
- 击杀15个敌人后, 会造成更多伤害, 每击杀10个敌人掉落半红心, 但也会尝试对角色造成伤害
- 击杀40个敌人后, 会造成更多伤害, 掉落整红心, 可以摧毁石头
- 对其造成足够多伤害可使其回到第一阶段

## 解锁与获取

- **解锁条件**：用莉莉丝击败母亲。 [详细教程：成就 462](/achievements/ids-401-500#achievement-462)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：诅咒房、贪婪诅咒房、贪婪宝箱房、红箱子、宝箱房、究极隐藏房。忏悔+ 的来源可能有调整。
