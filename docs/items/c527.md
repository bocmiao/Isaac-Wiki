# 自我先生！

<EntryHeader en="Mr. ME!" category="主动道具" icon="dice" code="c527" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 几秒内显示可移动光标, 随后生成幽灵, 根据光标位置:
- 打开门或箱子
- 带回物品
- 50%概率在商店/恶魔房偷东西
- 攻击敌人直到目标死亡
- 炸开墙/石头/天使雕像/店主/机器/乞丐
- 按下压力板

## 解锁与获取

- **解锁条件**：累计打开 20 个上锁箱子。 [详细教程：成就 371](/achievements/ids-301-400#achievement-371)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：夹娃娃机、贪婪商店、钥匙大师、商店、木箱子。忏悔+ 的来源可能有调整。
