## 已核对的组合

- **[光明之冠](/items/c415) + [神圣屏障](/items/c313)**：屏障挡下的那一下不会让冠冕熄灭。
- **[达摩克里斯之剑](/items/c577) + [神圣屏障](/items/c313)**：被屏障挡下的伤害不算受伤，不会开始掉剑的判定。剑真的落下时，屏障挡不住。
- **[嗝屁猫](/items/c81) + [神圣屏障](/items/c313)**：屏障能减少复活后立刻再死的风险；不保证复活时无敌，也不弥补特殊角色复活限制。。
- **[巴比伦大淫妇](/items/c122) + [神圣屏障](/items/c313)**：能在低红心打法中增加容错；是否触发低红心效果看实际生命机制。。
