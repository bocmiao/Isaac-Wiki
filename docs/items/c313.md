# 神圣屏障

<EntryHeader en="Holy Mantle" category="被动道具" icon="crown" code="c313" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 阻挡每个房间第一次受到的伤害

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 类型 | 被动道具 |
| 游戏内 ID | 313 |

## 解锁与获取

**可能出现的地方（忏悔版）**：天使房、贪婪天使房、宝箱房。忏悔+ 的来源可能有调整。

无需成就解锁。

## 可以搭配的道具

- **[光明之冠](/items/c415) + [神圣屏障](/items/c313)**：屏障挡下的那一下不会让冠冕熄灭。
- **[达摩克里斯之剑](/items/c577) + [神圣屏障](/items/c313)**：被屏障挡下的伤害不算受伤，不会开始掉剑的判定。剑真的落下时，屏障挡不住。
- **[嗝屁猫](/items/c81) + [神圣屏障](/items/c313)**：复活后，神圣屏障能挡本房间一次伤害，给你重新拉开距离的机会。
- **[巴比伦大淫妇](/items/c122) + [神圣屏障](/items/c313)**：低红心激活巴比伦大淫妇后，神圣屏障可以挡一次伤害，减少刚进房就丢血的危险。
