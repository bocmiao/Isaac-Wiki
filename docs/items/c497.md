# 迷彩内裤

<EntryHeader en="Camo Undies" category="被动道具" icon="crown" code="c497" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 混乱： 进入房间时, 使所有敌人混乱并使角色伪装, 直到角色开始发射
- ↑ 移速： 伪装时移速+0.5
- 解除伪装时, 对角色周围造成伤害, 并获得非常短暂的射速和伤害提升
