# 血田

<EntryHeader en="Akeldama" category="被动道具" icon="crown" code="c641" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 在有敌人的房间中, 在角色身后产生一串泪弹
- 泪弹造成3.5点伤害

## 解锁与获取

- **解锁条件**：用犹大击败母亲。 [详细教程：成就 446](/achievements/ids-401-500#achievement-446)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。
