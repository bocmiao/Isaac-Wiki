# 血色羁绊

<EntryHeader en="Sanguine Bond" category="被动道具" icon="crown" code="c692" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 在恶魔房中生成地刺
- 在地刺上受伤可获得:
- 35%: 无
- 33%: ↑ 伤害+0.5
- 15%: 6硬币
- 10%: 2黑心
- 5%: 随机恶魔房道具
- 2%: 利维坦套装

## 解锁与获取

- **解锁条件**：用里犹大击败祸兽。 [详细教程：成就 494](/achievements/ids-401-500#achievement-494)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：诅咒房、恶魔房、贪婪诅咒房、贪婪恶魔房、贪婪商店、究极隐藏房。忏悔+ 的来源可能有调整。
