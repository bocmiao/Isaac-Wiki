# 念力

<EntryHeader en="Telekinesis" category="主动道具" icon="dice" code="c522" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 使靠近角色的敌人弹幕停滞3秒, 结束后弹幕会被抛开
- 效果期间推开靠近的敌人

## 解锁与获取

- **解锁条件**：完成洞穴章节且不受伤。 [详细教程：成就 365](/achievements/ids-301-400#achievement-365)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：贪婪宝箱房、宝箱房。忏悔+ 的来源可能有调整。
