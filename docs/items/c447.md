## 效果与数值

- 每连续发射4秒时, 生成一朵便便云
- 10秒内尺寸不断变大
- 尺寸越大伤害越低
- 可通过射击便便云使其移动

::: details 忏悔版的效果差异
以下为忏悔基础说明；上方为忏悔+说明。

- 每连续发射7.5秒时, 生成一朵便便云
- 便便云每秒造成5次1×角色伤害
- 便便云持续15秒, 可通过射击便便云使其移动
:::
