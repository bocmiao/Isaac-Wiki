# 搬家盒

<EntryHeader en="Moving Box" category="主动道具" icon="dice" code="c523" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 使用时, 储存当前房间中最多10掉落物
- 再次使用将储存物放回地上
- 允许角色在房间之间搬东西

## 解锁与获取

- **解锁条件**：在暗室使用潘多拉魔盒。 [详细教程：成就 366](/achievements/ids-301-400#achievement-366)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：商店。忏悔+ 的来源可能有调整。
