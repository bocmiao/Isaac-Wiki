# 超级喷射

<EntryHeader en="Mega Blast" category="主动道具" icon="dice" code="c441" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 发射超级撒但血激光柱15秒
- 激光在房间和层之间持续存在

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 类型 | 主动道具 |
| 游戏内 ID | 441 |
| 基础充能方式 | 12 格常规充能 |

## 解锁与获取

- **解锁条件**：全部 17 个表角色分别击败超级撒但；忏悔起不包含里角色。 [详细教程：成就 276](/achievements/ids-201-300#achievement-276)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：恶魔房、贪婪恶魔房。忏悔+ 的来源可能有调整。
