# 店主的胯袋

<EntryHeader en="Keeper&#x27;s Sack" category="被动道具" icon="crown" code="c716" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 拾起时, 生成3硬币和1钥匙
- [商店](/rooms/shop) 每花费3硬币获得其一:
- ↑ 移速+0.03
- ↑ 伤害+0.5
- ↑ 射程+0.25

## 解锁与获取

- **解锁条件**：用店主击败母亲。 [详细教程：成就 464](/achievements/ids-401-500#achievement-464)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：贪婪隐藏房、贪婪宝箱房、隐藏房、商店。忏悔+ 的来源可能有调整。
