# 暗仪刺刀

<EntryHeader en="Dark Arts" category="主动道具" icon="dice" code="c705" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 1秒内(发射前)获得:
- ↑ 移速+1
- 角色可穿过敌人/弹幕并使其静止
- 效果结束时, 伤害静止的敌人, 移除静止的弹幕, 在角色位置产生冲击
- 穿过的敌人/弹幕越多, 伤害和冲击越强

## 解锁与获取

- **解锁条件**：用里犹大击败精神错乱。 [详细教程：成就 587](/achievements/ids-501-600#achievement-587)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：恶魔房、贪婪恶魔房、究极隐藏房。忏悔+ 的来源可能有调整。
