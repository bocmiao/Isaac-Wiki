# 火星

<EntryHeader en="Mars" category="被动道具" icon="crown" code="c593" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 双击移动键使角色冲锋
- 伤害： 冲锋时角色无敌, 造成4×角色伤害+8的伤害
- 3秒冷却
- 燃烧： 撞击时在角色周围生成火圈

::: details 忏悔版的效果差异
以下为忏悔基础说明；上方为忏悔+说明。

- 双击移动键使角色冲锋
- 伤害： 冲锋时角色无敌, 造成4×角色伤害+8的伤害
- 3秒冷却
:::
