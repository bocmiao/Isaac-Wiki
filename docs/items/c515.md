# 神秘礼物

<EntryHeader en="Mystery Gift" category="主动道具" icon="dice" code="c515" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 根据当前房间的道具池生成1个随机道具
- 概率生成煤块/大便

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 类型 | 主动道具 |
| 游戏内 ID | 515 |
| 基础充能方式 | 无需常规清房充能 |

## 解锁与获取

- **解锁条件**：累计破坏 500 个石头。 [详细教程：成就 350](/achievements/ids-301-400#achievement-350)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：夹娃娃机、贪婪商店、贪婪宝箱房、商店。忏悔+ 的来源可能有调整。
