# 双胞胎

<EntryHeader en="The Twins" category="饰品" icon="key" code="t183" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 每个房间有50%概率复制1个跟班
- 若角色没有跟班, 则获得波比兄弟或玛姬姐妹

## 解锁与获取

- **解锁条件**：用里莉莉丝分别击败以撒、小蓝人、撒但、羔羊，四项齐全。 [详细教程：成就 570](/achievements/ids-501-600#achievement-570)。
可从饰品掉落中取得，也可留意箱子、机器和生成饰品的道具。
