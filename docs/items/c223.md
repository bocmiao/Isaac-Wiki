# 纵火狂

<EntryHeader en="Pyromaniac" category="被动道具" icon="crown" code="c223" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 炸弹： +5炸弹
- 免疫爆炸和火焰
- 恢复红心： 受到爆炸时治疗半红心

## 解锁与获取

**可能出现的地方（忏悔版）**：贪婪宝箱房、宝箱房。忏悔+ 的来源可能有调整。

无需成就解锁。

## 可以搭配的道具

- **[吐根酊](/items/c149) + [纵火狂](/items/c223)**：降低近距离自爆的风险；有红心容器时才能利用红心回复。
- **[胎儿博士](/items/c52) + [纵火狂](/items/c223)**：能更安全地利用炸弹泪弹清房和开口，不能因此忽略其他伤害。
