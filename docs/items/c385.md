# 乞丐宝

<EntryHeader en="Bumbo" category="跟班" icon="face" code="c385" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 硬币： 捡起附近的硬币
- 捡起6, 12, 24硬币时升级
- 2级: 清理房间后, 概率生成掉落物或道具
- 3级: 发射泪弹, 击中时概率生成硬币
- 4级: 追击敌人, 每秒造成37.5点接触伤害
- 4级: 继续捡硬币, 能生成掉落物或道具
