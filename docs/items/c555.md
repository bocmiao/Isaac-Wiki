# 金剃刀片

<EntryHeader en="Golden Razor" category="主动道具" icon="dice" code="c555" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 硬币： 拾起时+5硬币
- 花费5硬币, 并在当前房间中获得:
- ↑ 伤害+1.2

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 类型 | 主动道具 |
| 游戏内 ID | 555 |
| 基础充能方式 | 无需常规清房充能 |

## 解锁与获取

- **解锁条件**：同局先持有 99 枚硬币，再把它们全部花光。 [详细教程：成就 583](/achievements/ids-501-600#achievement-583)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：贪婪宝箱房、宝箱房。忏悔+ 的来源可能有调整。
