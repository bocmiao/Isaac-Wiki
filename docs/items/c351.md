# 超级豆子

<EntryHeader en="Mega Bean" category="主动道具" icon="dice" code="c351" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 石化： 使房间中所有敌人石化并造成100点伤害
- 中毒： 造成5点伤害并使附近敌人中毒
- 可打开隐藏房并粉碎岩石

::: details 忏悔版的效果差异
以下为忏悔基础说明；上方为忏悔+说明。

- 石化： 使房间中所有敌人石化
- 中毒： 造成5点伤害并使附近敌人中毒
- 向角色移动方向发出岩石波
- 岩石波可打开隐藏房和粉碎石头
:::
