## 效果与数值

- 石化： 使房间中所有敌人石化并造成100点伤害
- 中毒： 造成5点伤害并使附近敌人中毒
- 可打开隐藏房并粉碎岩石

::: details 忏悔版的效果差异

- 岩石波可打开隐藏房和粉碎石头
