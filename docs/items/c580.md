# 红钥匙

<EntryHeader en="Red Key" category="主动道具" icon="dice" code="c580" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 在常规房间旁产生门形轮廓指示的红色房间
- 红色房间可以是特殊房间
- [错误房](/rooms/error) 进入13×13地图范围外的房间时, 将角色传送至错误房

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 类型 | 主动道具 |
| 游戏内 ID | 580 |
| 基础充能方式 | 4 格常规充能 |

## 解锁与获取

- **解锁条件**：打开家里妈妈卧室的箱子。 [详细教程：成就 415](/achievements/ids-401-500#achievement-415)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：诅咒房、钥匙大师、妈妈的箱子、红箱子、隐藏房、究极隐藏房。忏悔+ 的来源可能有调整。
