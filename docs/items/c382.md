# 友好球

<EntryHeader en="Friendly Ball" category="主动道具" icon="dice" code="c382" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 可以扔向敌人将其捕捉
- 友好： 成功捕捉后，下一次使用则会生成相同的友好敌人
- 靠近捕捉后的球会立即将道具充能

## 解锁与获取

**可能出现的地方（忏悔版）**：夹娃娃机、贪婪宝箱房、宝箱房。忏悔+ 的来源可能有调整。

无需成就解锁。
