# 游戏掌机

<EntryHeader en="The Gamekid" category="主动道具" icon="dice" code="c93" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 在6.5秒内获得:
- 无敌
- 角色无法发射, 但每秒造成40点接触伤害
- 半红心： 每击杀2个敌人治疗半红心
- 恐惧： 使房间中的所有敌人恐惧

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 类型 | 主动道具 |
| 游戏内 ID | 93 |
| 基础充能方式 | 4 格常规充能 |

## 解锁与获取

- **解锁条件**：累计进入 10 个赌博房。 [详细教程：成就 26](/achievements/ids-001-100#achievement-26)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：夹娃娃机、贪婪宝箱房、宝箱房。忏悔+ 的来源可能有调整。
