# 尖头钥匙

<EntryHeader en="Sharp Key" category="主动道具" icon="dice" code="c623" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 钥匙： +5钥匙
- 向角色发射方向投掷角色的1钥匙
- 投掷的钥匙可造成伤害, 摧毁障碍物或开门
- 被钥匙击杀的敌人有概率掉落箱子里的物品, 包括道具
