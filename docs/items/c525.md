# 麻风病

<EntryHeader en="Leprosy" category="跟班" icon="face" code="c525" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 受伤时, 生成1个阻挡弹幕的环绕物
- 最多有3个环绕物
- 每秒造成30点接触伤害
- 环绕物受伤过多后被摧毁

## 解锁与获取

- **解锁条件**：完成深处章节且不受伤。 [详细教程：成就 368](/achievements/ids-301-400#achievement-368)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：贪婪宝箱房、宝箱房。忏悔+ 的来源可能有调整。
