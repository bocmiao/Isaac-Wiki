# 十二面骰

<EntryHeader en="D12" category="主动道具" icon="dice" code="c386" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 将障碍物重置为其他随机类型的障碍物(大便/罐子/TNT/红大便/石头等)
- 小概率重置为按钮/击杀按钮/暗门/活板门

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 类型 | 主动道具 |
| 游戏内 ID | 386 |
| 基础充能方式 | 3 格常规充能 |

## 解锁与获取

- **解锁条件**：用该隐击败死寂。 [详细教程：成就 181](/achievements/ids-101-200#achievement-181)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：夹娃娃机、贪婪商店、宝箱房。忏悔+ 的来源可能有调整。
