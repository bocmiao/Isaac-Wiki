# 灵魂枷锁

<EntryHeader en="Spirit Shackles" category="被动道具" icon="crown" code="c674" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 承受致命伤害时, 将角色变为幽灵并被锁链束缚在尸体上, 留有半心继续战斗
- 幽灵存活10秒后, 角色重生
- 必须通过拾起魂心充能

## 解锁与获取

- **解锁条件**：用遗骸击败祸兽。 [详细教程：成就 469](/achievements/ids-401-500#achievement-469)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：贪婪隐藏房、贪婪商店、隐藏房。忏悔+ 的来源可能有调整。
