# 0-愚者？

<EntryHeader en="0 - The Fool?" category="卡牌 / 符文" icon="card" code="k56" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 将角色的所有心(留半心)和掉落物掉在地上
- 若数量充足, 可作为25美分和[轰！](/items/c19) 轰! 等道具生成
