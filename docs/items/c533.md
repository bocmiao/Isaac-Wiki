# 三圣颂

<EntryHeader en="Trisagion" category="被动道具" icon="crown" code="c533" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 角色的泪弹由穿刺光束弹取代
- 每秒造成15次33%角色伤害

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 类型 | 被动道具 |
| 游戏内 ID | 533 |

## 解锁与获取

- **解锁条件**：累计取得 25 件天使房道具。 [详细教程：成就 380](/achievements/ids-301-400#achievement-380)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：天使房、贪婪天使房。忏悔+ 的来源可能有调整。

## 可以搭配的道具

- **[英灵剑](/items/c579) + [三圣颂](/items/c533)**：剑气换成三圣颂光波，伤害更高。
