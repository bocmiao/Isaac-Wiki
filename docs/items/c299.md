# 金牛座

<EntryHeader en="Taurus" category="被动道具" icon="crown" code="c299" />

<VersionBadge checked="2026-10" />

## 效果与数值

- ↓ 移速-0.3
- ↑ 移速： 在有敌人的房间中, 移速缓慢增加
- 移速达到2时, 角色无敌并造成接触伤害, 持续5秒
- 随后, 在当前房间中失去金牛座移速加成
