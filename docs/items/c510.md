# 精神错乱

<EntryHeader en="Delirious" category="主动道具" icon="dice" code="c510" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 生成1个友好的精神错乱版的头目
- 切换房间持续存在
- 注意： 一次只能激活1个头目
- 生成的头目血量会随时间流失

::: details 忏悔版的效果差异
以下为忏悔基础说明；上方为忏悔+说明。

- 友好： 当前房间中生成1个友好的精神错乱版的头目
:::

## 解锁与获取

- **解锁条件**：击败精神错乱。 [详细教程：成就 338](/achievements/ids-301-400#achievement-338)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：天使房。忏悔+ 的来源可能有调整。
