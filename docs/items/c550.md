# 铲子碎片

<EntryHeader en="Broken Shovel" category="主动道具" icon="dice" code="c550" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 妈腿会持续攻击角色
- 使用后, 在当前房间中(或头目车轮战1波次)妈腿攻击停止
- 注意： (试着带着它通过头目车轮战!)
