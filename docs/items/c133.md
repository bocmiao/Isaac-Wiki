# 嗝屁猫的爪子

<EntryHeader en="Guppy&#x27;s Paw" category="主动道具" icon="dice" code="c133" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 魂心： 将1心之容器转换为3魂心

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 类型 | 主动道具 |
| 游戏内 ID | 133 |
| 基础充能方式 | 无需常规清房充能 |

## 解锁与获取

**可能出现的地方（忏悔版）**：诅咒房、恶魔房、贪婪诅咒房、贪婪恶魔房、红箱子。忏悔+ 的来源可能有调整。

无需成就解锁。

## 可以搭配的道具

- **[嗝屁猫的爪子](/items/c133) + [嗝屁猫](/items/c81)**：复活后可用爪子把一颗红心容器换成 3 颗魂心。两件都属于嗝屁猫变身组件，但还需要第三种组件。
- **[嗝屁猫](/items/c81) + [嗝屁猫的爪子](/items/c133) + [嗝屁猫的尾巴](/items/c134)**：取得这三种不同组件可推进嗝屁猫变身；这是一组示例，不是唯一三件配方。
