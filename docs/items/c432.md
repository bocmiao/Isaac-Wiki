# 闪光炸弹

<EntryHeader en="Glitter Bombs" category="被动道具" icon="crown" code="c432" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 炸弹： +5炸弹
- 角色的炸弹爆炸时, 63%概率生成1随机掉落物, 15%概率魅惑炸到的敌人
- 当前楼层每次生成掉落物后, 生成概率降低1%
