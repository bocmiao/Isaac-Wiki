# 稻草人

<EntryHeader en="Strawman" category="跟班" icon="face" code="c667" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 炸弹： +1炸弹
- [店主](/characters/keeper) 生成店主作为第二个角色
- 店主死亡时生成蓝蜘蛛并永久移除稻草人及其拾起的道具
- 恶魔房概率： 店主活着时恶魔交易花费硬币
- 注意： 店主也能拾起剧情道具

## 解锁与获取

- **解锁条件**：用里店主击败祸兽。 [详细教程：成就 503](/achievements/ids-501-600#achievement-503)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：贪婪隐藏房、贪婪商店、隐藏房。忏悔+ 的来源可能有调整。
