# 伯列恒之星

<EntryHeader en="Star of Bethlehem" category="跟班" icon="face" code="c651" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 从本层初始房间向[Boss 房](/rooms/boss) 头目房缓慢移动
- 角色领先则移动加快, 角色落后则移动减慢
- 站在光环中获得:
- ↑ 射速修正×2.5
- ↑ 伤害修正×1.2
- 追踪泪弹
- 50%概率忽略伤害
