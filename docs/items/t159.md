# 镀金钥匙

<EntryHeader en="Gilded Key" category="饰品" icon="key" code="t159" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 钥匙： 首次拾起时+1钥匙
- 金箱子： 所有新生成的箱子(除了旧箱子和大箱子)由金箱子取代
- 金箱子可能含有额外的卡牌/胶囊/饰品

## 解锁与获取

- **解锁条件**：用里该隐分别击败以撒、小蓝人、撒但、羔羊，四项齐全。 [详细教程：成就 552](/achievements/ids-501-600#achievement-552)。
可从饰品掉落中取得，也可留意箱子、机器和生成饰品的道具。
