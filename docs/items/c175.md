# 爸爸的钥匙

<EntryHeader en="Dad&#x27;s Key" category="主动道具" icon="dice" code="c175" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 打开房间中所有的门, 包括[隐藏房](/rooms/secret) [超级隐藏房](/rooms/supersecret) 隐藏房, [挑战房](/rooms/challenge) [Boss Rush](/rooms/boss-rush) 挑战房和超级撒旦的门

## 解锁与获取

- **解锁条件**：同局从天使获得两块钥匙碎片。 [详细教程：成就 58](/achievements/ids-001-100#achievement-58)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：贪婪宝箱房、钥匙大师、旧箱子、宝箱房。忏悔+ 的来源可能有调整。
