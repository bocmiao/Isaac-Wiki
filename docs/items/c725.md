# 大肠激躁症

<EntryHeader en="IBS" category="被动道具" icon="crown" code="c725" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 造成足够伤害使角色闪红色
- 闪红时松开发射键, 触发其一:
- 投掷1个随机大便
- 产生增益水迹
- 放毒屁
- 生成5个激活的炸弹

## 解锁与获取

- **解锁条件**：用里小蓝人击败精神错乱。 [详细教程：成就 588](/achievements/ids-501-600#achievement-588)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：贪婪宝箱房、宝箱房。忏悔+ 的来源可能有调整。
