# 亡者之书

<EntryHeader en="Book of the Dead" category="主动道具" icon="dice" code="c545" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 友好： 当前房间中每击杀1个敌人, 生成1个骨头环绕物/友好的骷髅仔
- 最多生成8个

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 类型 | 主动道具 |
| 游戏内 ID | 545 |
| 基础充能方式 | 6 格常规充能 |

## 解锁与获取

- **解锁条件**：用遗骸击败精神错乱。 [详细教程：成就 401](/achievements/ids-401-500#achievement-401)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：恶魔房、贪婪恶魔房、贪婪宝箱房、图书馆、宝箱房。忏悔+ 的来源可能有调整。
