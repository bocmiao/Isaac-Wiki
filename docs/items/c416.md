# 深口袋

<EntryHeader en="Deep Pockets" category="被动道具" icon="crown" code="c416" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 硬币： 若清理房间没有奖励, 则生成1-3硬币
- 硬币： 提高硬币上限至999

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 类型 | 被动道具 |

## 解锁与获取

- **解锁条件**：用店主击败小蓝人（Boss）。 [详细教程：成就 238](/achievements/ids-201-300#achievement-238)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：贪婪商店、贪婪宝箱房、商店。忏悔+ 的来源可能有调整。
