# 巴比伦大淫妇

<EntryHeader en="Whore of Babylon" category="被动道具" icon="crown" code="c122" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 当不多于半红心时:
- ↑ 移速+0.3
- ↑ 伤害+1.5

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 类型 | 被动道具 |
| 游戏内 ID | 122 |

## 解锁与获取

**可能出现的地方（忏悔版）**：恶魔乞丐、恶魔房、贪婪恶魔房、究极隐藏房。忏悔+ 的来源可能有调整。

无需成就解锁。

## 可以搭配的道具

- **[巴比伦大淫妇](/items/c122) + [神圣屏障](/items/c313)**：低红心激活巴比伦大淫妇后，神圣屏障可以挡一次伤害，减少刚进房就丢血的危险。
