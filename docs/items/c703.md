# 小以扫

<EntryHeader en="Esau Jr." category="主动道具" icon="dice" code="c703" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 在当前角色和小以扫之间切换
- 小以扫拥有3黑心, 伤害+2, 飞行, 首次使用时获得与主角色等量的随机道具
- 两个角色道具和血量独立
- 注意： 任意角色死亡, 游戏结束

## 解锁与获取

- **解锁条件**：用里雅各击败祸兽。 [详细教程：成就 507](/achievements/ids-501-600#achievement-507)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：贪婪隐藏房、贪婪商店、贪婪宝箱房、隐藏房、宝箱房、究极隐藏房。忏悔+ 的来源可能有调整。
