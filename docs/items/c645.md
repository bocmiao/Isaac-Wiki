# 小畸胎瘤

<EntryHeader en="Tinytoma" category="跟班" icon="face" code="c645" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 阻挡弹幕的大型环绕物
- 每秒造成3.5点接触伤害
- 受击3次时, 分裂为更小的畸胎瘤
- 小畸胎瘤被摧毁时产生蓝蜘蛛
- 被完全摧毁时, 5秒后重生

## 解锁与获取

- **解锁条件**：用拉撒路击败母亲。 [详细教程：成就 456](/achievements/ids-401-500#achievement-456)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：里店主商店、贪婪宝箱房、宝箱房。忏悔+ 的来源可能有调整。
