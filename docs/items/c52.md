# 胎儿博士

<EntryHeader en="Dr. Fetus" category="被动道具" icon="crown" code="c52" />

<VersionBadge checked="2026-10" />

## 效果与数值

- ↓ 射速修正×0.4
- 炸弹： 角色的泪弹由炸弹取代
- 伤害： 该炸弹造成10×角色伤害
- 若结果超过60, 则改为5×+30

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 类型 | 被动道具 |
| 游戏内 ID | 52 |

## 解锁与获取

- **解锁条件**：累计击败妈妈的心脏 / 它活着 9 次。 [详细教程：成就 11](/achievements/ids-001-100#achievement-11)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：贪婪宝箱房、宝箱房。忏悔+ 的来源可能有调整。

## 可以搭配的道具

- **[胎儿博士](/items/c52) + [纵火狂](/items/c223)**：能更安全地利用炸弹泪弹清房和开口，不能因此忽略其他伤害。
