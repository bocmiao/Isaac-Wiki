# 所罗门魔典

<EntryHeader en="Lemegeton" category="主动道具" icon="dice" code="c712" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 生成1个环绕物, 获得随机道具的效果
- 该道具有25%概率来自当前房间的道具池, 75%概率来自随机道具池

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 类型 | 主动道具 |
| 游戏内 ID | 712 |
| 基础充能方式 | 6 格常规充能 |

## 解锁与获取

- **解锁条件**：用里伯大尼击败精神错乱。 [详细教程：成就 599](/achievements/ids-501-600#achievement-599)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：恶魔房、贪婪恶魔房、图书馆。忏悔+ 的来源可能有调整。
