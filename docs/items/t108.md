# 核桃

<EntryHeader en="Walnut" category="饰品" icon="key" code="t108" />

## 效果与数值

- 受到爆炸后, 33%概率摧毁该饰品并生成1随机心, 1硬币：随机硬币, 1钥匙：随机钥匙和1饰品：随机饰品
- 不必要受伤
