# 弥达斯之触

<EntryHeader en="Midas&#x27; Touch" category="被动道具" icon="crown" code="c202" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 石化： 接触敌人时使其石化并变成金块
- 角色根据持有硬币量造成接触伤害
- 硬币： 击杀金敌人会生成硬币
- 角色生成的大便为金大便的概率更高
