# 残损铁镐

<EntryHeader en="Notched Axe" category="主动道具" icon="dice" code="c147" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 使用时, 角色持拿铁镐
- 持拿时, 允许角色打碎当前房间中接触的石头, 隐藏房入口, 并对敌人造成伤害
- 命中时, 降低铁镐的充能
- 进入新层时, 铁镐完全充能
