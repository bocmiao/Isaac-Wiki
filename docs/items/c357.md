# 朋友盒

<EntryHeader en="Box of Friends" category="主动道具" icon="dice" code="c357" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 在当前房间复制所有跟班
- [恶魔宝宝](/items/c113) 若没有跟班, 则在当前房间获得1个恶魔宝宝

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 类型 | 主动道具 |
| 游戏内 ID | 357 |
| 基础充能方式 | 3 格常规充能 |

## 解锁与获取

- **解锁条件**：用莉莉丝击败究极贪婪。 [详细教程：成就 203](/achievements/ids-201-300#achievement-203)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：夹娃娃机、贪婪宝箱房、商店。忏悔+ 的来源可能有调整。

## 可以搭配的道具

- **[朋友盒](/items/c357) + [蓄电池](/items/c63)**：提前存好充能后，可在同房间多次使用朋友盒；离房后的复制按主动机制处理。
