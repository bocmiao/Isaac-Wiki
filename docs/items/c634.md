# 炼狱恶鬼

<EntryHeader en="Purgatory" category="被动道具" icon="crown" code="c634" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 在有敌人的房间中的地面生成红色裂缝
- 走过裂缝时会召唤追踪爆炸幽灵

## 解锁与获取

- **解锁条件**：完成挑战 #38 Baptism by Fire。 [详细教程：成就 519](/achievements/ids-501-600#achievement-519)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：天使房、恶魔房、贪婪天使房、贪婪恶魔房。忏悔+ 的来源可能有调整。
