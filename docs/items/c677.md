# 灵魂出窍

<EntryHeader en="Astral Projection" category="被动道具" icon="crown" code="c677" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 在有敌人的房间中首次受伤时, 获得:
- 灵体泪弹
- 飞行
- 抵消下次伤害
- 时间暂停2秒
- 2秒内大幅提升移速和射速

| 项目 | 内容 |
| --- | --- |
| 类型 | 被动道具 |
| 游戏内 ID | 677 |

## 解锁与获取

- **解锁条件**：用拉撒路击败祸兽。 [详细教程：成就 457](/achievements/ids-401-500#achievement-457)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：贪婪隐藏房、贪婪宝箱房、隐藏房、宝箱房。忏悔+ 的来源可能有调整。
