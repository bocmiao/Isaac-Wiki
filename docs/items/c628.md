# 死亡证明

<EntryHeader en="Death Certificate" category="主动道具" icon="dice" code="c628" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 将角色传送至含有所有游戏道具的一层
- 拾起1个道具后回到之前的房间

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 类型 | 主动道具 |
| 游戏内 ID | 628 |
| 基础充能方式 | 无需常规清房充能 |

## 解锁与获取

- **解锁条件**：34 个表 / 里角色完成全部困难标记，贪婪格为极贪。 [详细教程：成就 636](/achievements/ids-601-641#achievement-636)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：贪婪隐藏房、隐藏房。忏悔+ 的来源可能有调整。
