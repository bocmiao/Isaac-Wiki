# 扁桃体

<EntryHeader en="Tonsil" category="饰品" icon="key" code="t97" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 受伤6-12次后, 获得阻挡弹幕的跟班
- 最多2个跟班, 之后该饰品消失

::: details 忏悔版的效果差异

- 生成2个跟班后消失
:::
