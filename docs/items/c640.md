# 灵魂之瓮

<EntryHeader en="Urn of Souls" category="主动道具" icon="dice" code="c640" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 喷射火焰
- 击杀1个敌人, 瓮增加1格充能

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 类型 | 主动道具 |
| 游戏内 ID | 640 |
| 基础充能方式 | 无需常规清房充能 |

## 解锁与获取

- **解锁条件**：用伯大尼击败撒但。 [详细教程：成就 418](/achievements/ids-401-500#achievement-418)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：天使房、贪婪天使房。忏悔+ 的来源可能有调整。
