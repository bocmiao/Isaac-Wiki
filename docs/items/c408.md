# 祭祀之刃

<EntryHeader en="Athame" category="被动道具" icon="crown" code="c408" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 25%概率在被击杀敌人周围生成黑色硫磺火圈
- 黑圈2秒内造成30×角色伤害
- 幸运： 每点幸运+2.5%概率

## 解锁与获取

- **解锁条件**：用夏娃击败死寂。 [详细教程：成就 184](/achievements/ids-101-200#achievement-184)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：诅咒房、恶魔房、贪婪诅咒房、贪婪恶魔房。忏悔+ 的来源可能有调整。
