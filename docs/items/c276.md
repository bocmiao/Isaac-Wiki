# 以撒的心脏

<EntryHeader en="Isaac&#x27;s Heart" category="跟班" icon="face" code="c276" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 角色无敌
- 生成跟随角色的心脏
- 角色发射时心脏蓄力, 停止发射时释放散射泪弹
- 注意： 心脏受伤时, 角色也会受伤

## 解锁与获取

- **解锁条件**：用游魂击败以撒（Boss）。 [详细教程：成就 129](/achievements/ids-101-200#achievement-129)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：宝箱房、究极隐藏房。忏悔+ 的来源可能有调整。
