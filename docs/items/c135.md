# 献血袋

<EntryHeader en="IV Bag" category="主动道具" icon="dice" code="c135" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 硬币： 对角色造成半红心伤害并生成1-2硬币
- 红心容器： 优先消耗红心

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 类型 | 主动道具 |
| 游戏内 ID | 135 |
| 基础充能方式 | 无需常规清房充能 |

## 解锁与获取

**可能出现的地方（忏悔版）**：究极隐藏房。忏悔+ 的来源可能有调整。

无需成就解锁。

## 可以搭配的道具

- **[小猪存钱罐](/items/c227) + [献血袋](/items/c135)**：用献血袋付红心换钱时，储蓄罐也可以因受伤掉币；先准备能补回红心的手段。
