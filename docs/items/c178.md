# 圣水

<EntryHeader en="Holy Water" category="跟班" icon="face" code="c178" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 投掷： 向角色发射方向投掷自身
- 击中敌人时, 造成7点伤害并破碎
- 石化： 留下的水迹能石化敌人并造成伤害
