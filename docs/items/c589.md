# 月亮

<EntryHeader en="Luna" category="被动道具" icon="crown" code="c589" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 每层额外增加1个隐藏房和超级隐藏房
- 每层揭示1个隐藏房
- 隐藏房内有光束, 接触时在本层获得:
- ↑ 射速修正+0.5
- ↑ 射速： 每层首个光柱额外+0.5射速修正
- 半魂心： 1半魂心
