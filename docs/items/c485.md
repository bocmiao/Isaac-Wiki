# 被掰弯的硬币

<EntryHeader en="Crooked Penny" category="主动道具" icon="dice" code="c485" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 50%概率使房间中所有道具, 掉落物和箱子翻倍
- 50%概率将上述内容移除并生成1硬币

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 类型 | 主动道具 |
| 游戏内 ID | 485 |
| 基础充能方式 | 4 格常规充能 |

## 解锁与获取

- **解锁条件**：用店主击败精神错乱。 [详细教程：成就 294](/achievements/ids-201-300#achievement-294)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：普通乞丐、贪婪商店、商店、宝箱房。忏悔+ 的来源可能有调整。
