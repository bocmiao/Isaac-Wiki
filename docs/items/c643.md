# 终末天启

<EntryHeader en="Revelation" category="被动道具" icon="crown" code="c643" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 飞行
- 蓄力： 可蓄力发射高伤害圣光柱
- 不会取代角色的泪弹

::: details 忏悔版的效果差异
以下为忏悔基础说明；上方为忏悔+说明。

- 魂心： +2魂心
- 飞行
- 蓄力： 可蓄力发射高伤害圣光柱
- 不会取代角色的泪弹
:::

## 解锁与获取

- **解锁条件**：用伯大尼击败母亲。 [详细教程：成就 470](/achievements/ids-401-500#achievement-470)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：天使房、贪婪天使房。忏悔+ 的来源可能有调整。

## 可以搭配的道具

- **[终末天启](/items/c643) + [天使棱镜](/items/c528)**：激光打到棱镜，分成 4 道。
