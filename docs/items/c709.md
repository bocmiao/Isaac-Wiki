# 背摔！

<EntryHeader en="Suplex!" category="主动道具" icon="dice" code="c709" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 角色向移动方向冲刺
- 冲到敌人或头目时将其举起并摔在地上
- 根据角色体型造成摔伤并产生岩石波
- 冲刺和摔击时角色无敌

## 解锁与获取

- **解锁条件**：用雅各与以扫击败精神错乱。 [详细教程：成就 437](/achievements/ids-401-500#achievement-437)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：夹娃娃机、贪婪宝箱房、宝箱房。忏悔+ 的来源可能有调整。
