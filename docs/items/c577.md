# 达摩克里斯之剑

<EntryHeader en="Damocles" category="主动道具" icon="dice" code="c577" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 在角色头上悬着剑, 并使底座道具翻倍
- 有价格或箱子中的道具不翻倍
- 注意： 受伤后, 剑每帧有极低概率立即击杀角色
- 无敌效果可以避免死亡

| 项目 | 内容 |

| 游戏内 ID | 577 |

## 解锁与获取

- **解锁条件**：用雅各与以扫击败羔羊。 [详细教程：成就 432](/achievements/ids-401-500#achievement-432)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：恶魔房、贪婪恶魔房。忏悔+ 的来源可能有调整。

## 可以搭配的道具

- **[达摩克里斯之剑](/items/c577) + [神圣屏障](/items/c313)**：被屏障挡下的伤害不算受伤，不会开始掉剑的判定。剑真的落下时，屏障挡不住。
