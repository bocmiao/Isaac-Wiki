# 骨刺

<EntryHeader en="Bone Spurs" category="被动道具" icon="crown" code="c683" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 敌人死亡时生成骨片
- 骨片可阻挡弹幕并造成接触伤害

## 解锁与获取

- **解锁条件**：用遗骸击败母亲。 [详细教程：成就 468](/achievements/ids-401-500#achievement-468)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：贪婪宝箱房、宝箱房。忏悔+ 的来源可能有调整。
