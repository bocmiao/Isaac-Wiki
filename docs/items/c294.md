# 棉豆

<EntryHeader en="Butter Bean" category="主动道具" icon="dice" code="c294" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 击退附近的敌人和弹幕
- 将敌人击退到障碍物上会造成10点伤害

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 类型 | 主动道具 |
| 游戏内 ID | 294 |
| 基础充能方式 | 90 格常规充能 |

## 解锁与获取

- **解锁条件**：累计破坏 100 个大便。 [详细教程：成就 145](/achievements/ids-101-200#achievement-145)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：普通乞丐、宝箱房。忏悔+ 的来源可能有调整。
