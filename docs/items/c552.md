# 妈妈的铲子

<EntryHeader en="Mom&#x27;s Shovel" category="主动道具" icon="dice" code="c552" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 生成通往下一层的活板门
- [夹层](/rooms/crawlspace) 在有装饰(草/碎石/纸/宝石等)的地板上使用时, 改为生成暗门
- 注意： 在"暗室"的土丘上使用铲子

## 解锁与获取

铲子任务中两部分合成后的完整铲子，暗室土堆解锁遗骸需要它。永久解锁与本局任务获取是不同事项，参见[坟墓房](/rooms/grave)。
