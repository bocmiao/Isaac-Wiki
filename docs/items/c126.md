# 剃刀片

<EntryHeader en="Razor Blade" category="主动道具" icon="dice" code="c126" />

<VersionBadge checked="2026-10" />

## 效果与数值

- ↑ 伤害： 在当前房间中伤害+1.2
- 注意： 对角色造成1心伤害
- 在房间中首次使用后, 改为造成半心伤害
- 红心容器： 优先消耗红心

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 类型 | 主动道具 |
| 游戏内 ID | 126 |
| 基础充能方式 | 无需常规清房充能 |

## 解锁与获取

- **解锁条件**：用夏娃击败撒但。 [详细教程：成就 44](/achievements/ids-001-100#achievement-44)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：诅咒房、恶魔乞丐、贪婪诅咒房、贪婪宝箱房、宝箱房。忏悔+ 的来源可能有调整。
