# 妈妈的菜刀

<EntryHeader en="Mom&#x27;s Knife" category="被动道具" icon="crown" code="c114" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 角色的泪弹由可投掷的菜刀取代
- 伤害： 持拿时菜刀造成2×角色伤害, 蓄力1/3时为上限6×
- 继续蓄力只会增加投掷距离
- 返回角色时, 伤害降至2×

## 解锁与获取

- **解锁条件**：用以撒击败撒但。 [详细教程：成就 43](/achievements/ids-001-100#achievement-43)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：恶魔房、贪婪恶魔房、贪婪宝箱房、妈妈的箱子、旧箱子、宝箱房。忏悔+ 的来源可能有调整。

## 可以搭配的道具

- **[硫磺火](/items/c118) + [妈妈的菜刀](/items/c114)**：菜刀优先，不吃硫磺火的射速惩罚。扔出菜刀后再射出一小串菜刀，忏悔起每把造成 2 倍伤害。
- **[英灵剑](/items/c579) + [妈妈的菜刀](/items/c114)**：蓄力旋转攻击时把剑扔出去一小段，边飞边转。
