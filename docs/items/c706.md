# 无底坑

<EntryHeader en="Abyss" category="主动道具" icon="dice" code="c706" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 消耗房间中所有底座道具并对应生成蝗虫跟班
- 一些道具会生成特殊蝗虫
- 伤害： 蝗虫造成1×角色伤害, 并根据道具品质修正:
- 品质 0 - 0.5×
- 品质 1 - 0.75×
- 品质 2 - 1.0×
- 品质 3 - 1.5×
- 品质 4 - 2.0×

::: details 忏悔版的效果差异
以下为忏悔基础说明；上方为忏悔+说明。

- 消耗房间中所有底座道具并对应生成蝗虫跟班
- 蝗虫造成2×-3×角色伤害
- 一些道具会生成特殊蝗虫
:::

## 解锁与获取

- **解锁条件**：用里亚玻伦击败精神错乱。 [详细教程：成就 597](/achievements/ids-501-600#achievement-597)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：恶魔房、贪婪恶魔房、究极隐藏房。忏悔+ 的来源可能有调整。
