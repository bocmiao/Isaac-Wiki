# 迷失游魂

<EntryHeader en="Lost Soul" category="跟班" icon="face" code="c612" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 受伤时死亡, 会在下一层重生
- 如果存活时带到下一层, 可能生成:
- 魂心： 3魂心
- 永恒之心： 2永恒之心
- [宝箱房](/rooms/treasure) 1个宝箱房道具
- [天使房](/rooms/angel) 1个天使房道具

## 解锁与获取

- **解锁条件**：用游魂击败母亲。 [详细教程：成就 460](/achievements/ids-401-500#achievement-460)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：里店主商店、贪婪隐藏房、贪婪宝箱房、隐藏房、宝箱房。忏悔+ 的来源可能有调整。
