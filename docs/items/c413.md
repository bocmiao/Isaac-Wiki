# 圣灵受胎

<EntryHeader en="Immaculate Conception" category="被动道具" icon="crown" code="c413" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 魂心： 每拾起15次心, 永久获得1个天使跟班并生成1魂心
- 最多产生5个跟班

## 解锁与获取

- **解锁条件**：用莉莉丝完成 Boss Rush。 [详细教程：成就 222](/achievements/ids-201-300#achievement-222)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：天使房、贪婪天使房。忏悔+ 的来源可能有调整。
