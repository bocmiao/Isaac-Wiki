# 鸟肥笼

<EntryHeader en="Bird Cage" category="跟班" icon="face" code="c610" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 角色在房间中首次受伤时, 跃向敌人
- 造成45点伤害并释放岩石波
- 之后追击敌人, 每秒造成6.5点接触伤害

## 解锁与获取

- **解锁条件**：用夏娃击败母亲。 [详细教程：成就 450](/achievements/ids-401-500#achievement-450)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：里店主商店、贪婪宝箱房、宝箱房。忏悔+ 的来源可能有调整。
