<EntryHeader en="Forget Me Now" category="主动道具" icon="dice" code="c127" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 重置整层

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 类型 | 主动道具 |
| 游戏内 ID | 127 |
| 基础充能方式 | 无需常规清房充能 |

## 解锁与获取

- **解锁条件**：用小蓝人击败撒但。 [详细教程：成就 48](/achievements/ids-001-100#achievement-48)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：恶魔乞丐、恶魔房、贪婪隐藏房、隐藏房、宝箱房。忏悔+ 的来源可能有调整。
