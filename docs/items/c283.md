# 一百面骰

<EntryHeader en="D100" category="主动道具" icon="dice" code="c283" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 复制房间中的1掉落物
- 重置角色的移速, 射速, 伤害, 射程和被动道具
- 重置房间中的所有底座道具, 掉落物和石头
- 重新开始当前房间, 重生所有敌人并降级

## 解锁与获取

- **解锁条件**：用游魂完成 Boss Rush。 [详细教程：成就 133](/achievements/ids-101-200#achievement-133)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：夹娃娃机、贪婪商店、宝箱房。忏悔+ 的来源可能有调整。
