# 超级蘑菇

<EntryHeader en="Mega Mush" category="主动道具" icon="dice" code="c625" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 角色巨化并获得:
- ↑ 伤害修正×4
- ↑ 射程+2
- ↓ 射速-1.9
- 无敌
- 能踩碎障碍物和敌人
- 持续30秒, 能在房间之间和层之间持续

## 解锁与获取

- **解锁条件**：17 个表角色完成全部困难标记，贪婪格为极贪。 [详细教程：成就 547](/achievements/ids-501-600#achievement-547)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：贪婪隐藏房、贪婪宝箱房、隐藏房、宝箱房。忏悔+ 的来源可能有调整。
