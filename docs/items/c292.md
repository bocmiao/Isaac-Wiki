# 撒但圣经

<EntryHeader en="Satanic Bible" category="主动道具" icon="dice" code="c292" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 黑心： +1黑心
- [恶魔房](/rooms/devil) 在头目战斗前使用, 头目房道具会变成恶魔交易
- 购买恶魔交易与在恶魔房后果相同
- 不影响虚空层的底座道具

## 解锁与获取

- **解锁条件**：用阿撒泻勒击败以撒（Boss）。 [详细教程：成就 126](/achievements/ids-101-200#achievement-126)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：恶魔房、贪婪恶魔房、图书馆、宝箱房。忏悔+ 的来源可能有调整。
