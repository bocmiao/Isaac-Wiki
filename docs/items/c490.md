# 伊甸的灵魂

<EntryHeader en="Eden&#x27;s Soul" category="主动道具" icon="dice" code="c490" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 根据当前房间的道具池生成2个随机道具
- 起始无充能

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 类型 | 主动道具 |
| 游戏内 ID | 490 |
| 基础充能方式 | 12 格常规充能 |

## 解锁与获取

- **解锁条件**：用伊甸击败精神错乱。 [详细教程：成就 289](/achievements/ids-201-300#achievement-289)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：天使房、贪婪天使房。忏悔+ 的来源可能有调整。
