# 合成宝袋

<EntryHeader en="Bag of Crafting" category="主动道具" icon="dice" code="c710" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 收集最多8个掉落物, 不能再拿出
- 集满时使用可将掉落物合成为道具
- 道具品质取决于掉落物品质

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 类型 | 主动道具 |
| 游戏内 ID | 710 |
| 基础充能方式 | 无需常规清房充能 |

## 解锁与获取

- **解锁条件**：用里该隐击败精神错乱。 [详细教程：成就 586](/achievements/ids-501-600#achievement-586)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：贪婪宝箱房、宝箱房。忏悔+ 的来源可能有调整。
