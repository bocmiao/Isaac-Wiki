# 虱子

<EntryHeader en="Louse" category="饰品" icon="key" code="t70" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 在有敌人的房间里每30秒生成1只蓝蜘蛛
- 清理房间后生成1只蓝蜘蛛

::: details 忏悔版的效果差异
以下为忏悔基础说明；上方为忏悔+说明。

- 在有敌人的房间中, 时不时生成1只蓝蜘蛛
:::
