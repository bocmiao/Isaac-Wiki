# 剪刀

<EntryHeader en="Scissors" category="主动道具" icon="dice" code="c325" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 当前房间中将角色的头变为不动的跟班
- 独立控制角色身体, 向发射方向抛射泪弹

## 解锁与获取

- **解锁条件**：累计死亡 100 次。 [详细教程：成就 30](/achievements/ids-001-100#achievement-30)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：贪婪宝箱房、宝箱房。忏悔+ 的来源可能有调整。
