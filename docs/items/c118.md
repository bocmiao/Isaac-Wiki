# 硫磺火

<EntryHeader en="Brimstone" category="被动道具" icon="crown" code="c118" />

<VersionBadge checked="2026-10" />

## 效果与数值

- ↓ 射速修正×0.33
- 蓄力： 角色的泪弹由可蓄力的鲜血激光取代
- 伤害： 在0.63秒内造成9×角色伤害

## 解锁与获取

**可能出现的地方（忏悔版）**：恶魔房、贪婪恶魔房、究极隐藏房。忏悔+ 的来源可能有调整。

无需成就解锁。

## 可以搭配的道具

- **[硫磺火](/items/c118) + [妈妈的菜刀](/items/c114)**：菜刀优先，不吃硫磺火的射速惩罚。扔出菜刀后再射出一小串菜刀，忏悔起每把造成 2 倍伤害。
- **[硫磺火](/items/c118) + [内眼](/items/c2)**：一次射 3 道激光。内眼虽然降射速，总输出仍比配完美视力（20/20，2 道激光）提升更多。
- **[硫磺火](/items/c118) + [弯勺魔术](/items/c3)**：激光可随追踪修正弯向敌人，仍需要保持与目标距离。
- **[完美视力](/items/c245) + [硫磺火](/items/c118)**：一次蓄力可发出多束激光，扩大攻击覆盖；是否同时命中要看角度。
