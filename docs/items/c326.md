# 生命之息

<EntryHeader en="Breath of Life" category="主动道具" icon="dice" code="c326" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 按住使用键时消耗充能条
- 充能条为空时角色暂时无敌
- 无敌时, 角色接触到敌人会召唤光柱
- 如果阻挡伤害时机完美, 则发射4向圣光并获得短暂护盾
- 注意： 按住过久会对角色造成伤害
