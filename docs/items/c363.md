# 宣誓守护者

<EntryHeader en="Sworn Protector" category="跟班" icon="face" code="c363" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 环绕物
- 每秒造成105点接触伤害
- 吸引并阻挡弹幕
- 在1个房间中阻挡10颗弹幕时, 生成1永恒之心

## 解锁与获取

- **解锁条件**：用游魂击败死寂。 [详细教程：成就 189](/achievements/ids-101-200#achievement-189)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：天使房、里店主商店、贪婪天使房。忏悔+ 的来源可能有调整。
