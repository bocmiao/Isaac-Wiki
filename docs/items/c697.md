# 消失的胞胎

<EntryHeader en="Vanishing Twin" category="跟班" icon="face" code="c697" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 进入头目房时, 生成头目的复制体
- 击败复制体可额外生成1个道具
- 复制体更慢, 血量只有75%

## 解锁与获取

- **解锁条件**：用雅各与以扫击败死寂。 [详细教程：成就 435](/achievements/ids-401-500#achievement-435)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：诅咒房、隐藏房。忏悔+ 的来源可能有调整。
