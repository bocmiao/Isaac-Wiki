# 剖腹产

<EntryHeader en="C Section" category="被动道具" icon="crown" code="c678" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 蓄力： 角色的泪弹由蓄力攻击取代, 发射追踪灵体胎儿
- 伤害： 胎儿每秒造成2.8×角色伤害

## 解锁与获取

- **解锁条件**：用莉莉丝击败祸兽。 [详细教程：成就 463](/achievements/ids-401-500#achievement-463)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：贪婪宝箱房、宝箱房、究极隐藏房。忏悔+ 的来源可能有调整。
