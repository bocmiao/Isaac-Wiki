## 使用与取舍

先看当前缺输出、生存还是资源，再判断本条目的效果。箭头、倍率与触发条件要一起读；已有泪弹替换、爆炸、自伤等组合时，先核对效果如何叠加，再决定是否交易或重置掉现有奖励。

## 已核对的组合

- **[嗝屁猫的爪子](/items/c133) + [嗝屁猫](/items/c81)**：每次复活后把那个容器换成 3 魂心，相当于血量变成 3 倍。两件都算嗝屁猫变身（Guppy）的组件，都在恶魔房道具池。
- **[嗝屁猫](/items/c81) + [嗝屁猫的爪子](/items/c133) + [嗝屁猫的尾巴](/items/c134)**：取得这三种不同组件可推进嗝屁猫变身；这是一组示例，不是唯一三件配方。。
- **[嗝屁猫](/items/c81) + [神圣屏障](/items/c313)**：屏障能减少复活后立刻再死的风险；不保证复活时无敌，也不弥补特殊角色复活限制。。
