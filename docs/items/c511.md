# 愤怒苍蝇

<EntryHeader en="Angry Fly" category="跟班" icon="face" code="c511" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 在随机敌人周围环绕直到该敌人死亡
- 每秒对其他敌人造成30点接触伤害

| 项目 | 内容 |
| --- | --- |
| 类型 | 跟班 |

## 解锁与获取

- **解锁条件**：达成苍蝇王（Beelzebub）变身。 [详细教程：成就 352](/achievements/ids-301-400#achievement-352)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：里店主商店、贪婪宝箱房、宝箱房、究极隐藏房。忏悔+ 的来源可能有调整。
