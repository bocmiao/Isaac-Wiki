# 饥饿幽魂

<EntryHeader en="Hungry Soul" category="被动道具" icon="crown" code="c684" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 击杀敌人时, 33%概率生成幽灵
- 幽灵追击敌人, 造成接触伤害并在5秒后爆炸
- 角色不受该爆炸伤害

## 解锁与获取

- **解锁条件**：用游魂击败祸兽。 [详细教程：成就 461](/achievements/ids-401-500#achievement-461)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：恶魔房、贪婪恶魔房、究极隐藏房。忏悔+ 的来源可能有调整。
