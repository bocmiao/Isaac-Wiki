# 圣血吸管

<EntryHeader en="Sumptorium" category="主动道具" icon="dice" code="c713" />

<VersionBadge checked="2026-10" />

## 效果与数值

- 移除半心并创造1个血团
- 血团复制角色的泪弹
- 不同类型的心产生不同血量, 伤害和泪弹效果的血团

## 解锁与获取

- **解锁条件**：用里夏娃击败精神错乱。 [详细教程：成就 589](/achievements/ids-501-600#achievement-589)。

解锁后仍要在游戏里捡到一次，才能记入道具收藏页。

**可能出现的地方（忏悔版）**：贪婪宝箱房、宝箱房。忏悔+ 的来源可能有调整。
