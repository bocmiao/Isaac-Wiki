# 攻略库

新手路线负责带你入门，攻略库负责回答具体问题：某个结局怎么解锁、某个 Boss 怎么打、恶魔交易拿不拿。

按计划分三批上线：**首批**跟新手路线一起上线，**第二批**在主机版发售后 4 周内完成，**第三批**按大家最常看的内容决定先后。
