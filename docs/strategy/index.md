# 攻略库

新手路线负责带你入门，攻略库负责回答具体问题：某个结局怎么解锁、某个 Boss 怎么打、恶魔交易拿不拿。

10 个栏目已经全部上线。每篇文章顶部标着适用版本和校对日期，文末列出参考资料；游戏有大更新时会重新校对。
