# 机器与乞丐实用查询

<VersionBadge checked="2026-10" />

先留开路线门和回血要用的资源，剩下的再投机器。机器收费和普通受伤的规则可能不同。[原始概率表](/strategy/mechanics#乞丐与机器)保留已核对的数值，本文帮助辨认与取舍。

| 机器 / 乞丐 | 使用成本与作用 | 怎么取舍 |
| --- | --- | --- |
| 赌博机 Slot Machine | 每次 1 硬币，可能有资源或道具 | 买得到的明确提升通常优先于随机投注 |
| 预言机 Fortune Telling Machine | 每次 1 硬币，可能给魂心、卡牌、饰品等 | 不保证每次给奖励；先留商店与路线费用 |
| 献血机 Blood Donation Machine | 花生命换硬币；付血按层与角色判断 | 先留红心恢复，魂心不能一概当成不会消耗 |
| 普通捐款机 Donation Machine | 每次 1 硬币，永久里程碑与当前余额分开 | 炸机降低余额不撤销已解锁等级；[进度工具](/tools/donations)可分别记录 |
| 贪婪捐款机 Greed Donation Machine | 终局捐硬币，另有角色历史与卡住概率 | 记录实际投进去的钱，普通机不能替代；[里程碑](/strategy/greed#贪婪捐款机) |
| 补货机 Shop Restock Machine | 使用费用依实际显示，重置货物 | 准备足够购买预算再刷新，不保证出现指定道具 |
| 妈妈的梳妆台 Mom's Dressing Table | 能改变外观，也可能给奖励 | 外观变化不等于获得永久收藏道具 |
| 夹娃娃机 Crane Game | 每次 5 硬币，画面展示候选道具 | 可看到目标不等于这一投必定获胜，先比较直接购物 |
| 忏悔室 Confessional | 花生命，可有祝福与其他收益 | 生命、诅咒、交易概率分别评估，不能把付血当全局无伤 |
| 硬币乞丐 Beggar | 消耗硬币，可能给拾取物或道具 | 困难模式的前置投喂次数见机制表；拿到道具后通常离场 |
| 恶魔乞丐 Devil Beggar | 消耗生命；章节与角色影响付血 | 先把后续路线所需生命扣出来，再考虑投喂 |
| 钥匙大师 Key Master | 消耗钥匙 | 母亲路线、宝箱房、金箱子都要留预算；忏悔+ 金钥匙交互见机制表 |
| 炸弹乞丐 Bomb Bum | 消耗炸弹 | 忏悔起不要靠炸弹直接杀掉它；注意反丢的即爆炸弹 |
| 电池乞丐 Battery Bum | 消耗硬币，可能补充主动充能 | 持有有用且未充满的主动时更有价值 |
| 腐烂乞丐 Rotten Beggar | 消耗硬币，可能给虫类、腐心或道具 | 输出够用时先给治疗和路线门票留钱 |
| 猜壳乞丐 Shell Game | 每次 1 硬币，选择骷髅争取展示奖励 | 不按想要的奖品就一定猜中来做资源计划 |
| 地狱猜壳 Hell Game | 用生命而非普通硬币参与猜壳，开放条件是[成就 #608](/achievements/ids-601-641#achievement-608) | 单次扣血的当前版本细则尚未独立核实，不提供精确扣血表；生命不足时不要试投。选择奖品机制参照开发资料 |
| 在线复活机 | 在线模式给死亡队友提供复活机会 | 基础 10 硬币，之后每次加 2；先确认有死者且目标正确，见[联机](/topics/coop) |

## 解锁和使用不是同一个进度

某些机器要先完成成就才会生成。只看到机器不等于它已给出道具，给出道具也不等于所有角色都取得相同的永久强化。普通捐款机的等级由成就确认，各角色的贪婪捐款单独累计。

## 特殊角色付费前检查

游魂不能按普通角色的红心预算投生命机器；店主使用硬币生命；伯大尼不能将魂心当临时护盾；遗骸身体和灵魂的血量互不替代。无法确定一次互动结果时，先看[人物页](/characters/)及游戏当前价签，避免用普通伤害减免规则推算机器收费。

## 碰机器前按这个顺序确认

1. **现在缺什么**：输出、治疗、充能还是永久里程碑。不要把随机投注当作能立刻解决短板的保证。
2. **保留多少**：先留商店道具、治疗、母亲路线门票与下一层宝箱房所需资源，再计算可投喂数量。
3. **真正付出了什么**：每次互动看硬币 / 血条 / 钥匙实际变化；被挡掉的伤害与成功付款不能混算。
4. **有没有结束**：出现道具、机器损坏或乞丐离场时，就不必继续投。某个道具需要永久开放时先查对应成就。
5. **记录哪一类进度**：贪婪机记实际投进去的数额；普通机同时核对当前余额和永久成就，不从余额下降推断商店等级下降。

## 低血或缺钱时怎么选

- 只有很少生命时，先找能稳定恢复的心 / 硬币，暂时跳过不确定付血结果的机器。游魂与店主先看各自生命机制，不试套普通人的半心成本。
- 有明确想买的商店物品时，先保留购买钱；剩下的钱再考虑预言机、乞丐或补货。补货改变候选，不是免费得到下一件道具。
- 主动已满时，先确认自己有没有额外储存充能的道具；没有时不要把机器提供的充能重复算成备用次数。

更多案例见[生命、付血与回血](/strategy/health)。
