# 生命、付血与回血

<VersionBadge checked="2026-10" />

进房前先区分**现在能承受的伤害、能恢复的生命，以及要支付的资源**。红心、魂心、容器和永久解锁不是一回事；外观上有一整格，不等于所有角色都能按同样次数受伤。

## 先看角色能用什么

| 角色 | 生命与恢复 | 容易看错什么 |
| --- | --- | --- |
| 普通红心角色 | 红心填充已有容器，魂心 / 黑心属于临时生命 | 捡红心不增加容器，恶魔交易付掉容器后不能用普通红心直接补回 |
| [???](/characters/bluebaby) | 开局是魂心，不能按普通红心方式恢复 | 没有红心不代表交易门必开，开门仍按保护与加成计算 |
| [伯大尼](/characters/bethany) | 红心是生命，魂心 / 黑心转成主动资源 | 主动充能多不代表还有护盾生命；魂火保护也会消耗 |
| [里伯大尼](/characters/tainted-bethany) | 魂心生命和血充能分别管理 | 血充能不是血条，多余主动资源不能当作能挨的伤害 |
| [店主](/characters/keeper) | 硬币心；靠硬币恢复，第三颗还需开局强化 | 满血时把地上硬币捡光，会失去战斗中回头治疗的机会 |
| [里店主](/characters/tainted-keeper) | 两个硬币心，杀敌掉币要及时回收 | 钱也是命；不能把所有硬币都按购物预算花掉 |
| [游魂](/characters/lost)、[里游魂](/characters/tainted-lost) | 没有普通可恢复血条，保护机制分别看角色页 | 神圣屏障 / 神圣卡牌不等于获得红心容器，不能套普通人的付血流程 |
| [遗骸](/characters/forgotten) | 身体骨心和灵魂魂心各自管理 | 切换形态不等于把一套生命转换成另一套 |
| [雅各与以扫](/characters/jacob) | 两个角色分别持有生命和资源 | 当前安全站位、治疗落点与实际接触者要分别确认 |

具体开局、回复与版本差异以人物页为准。多数普通角色的上限是十二心，特殊角色另有上限。

## 三种消耗别混

1. **普通受伤**：看血条最右侧可消耗的生命、攻击的伤害和保护效果。普通主线子宫起通常增加伤害；贪婪与特殊攻击另按其规则。
2. **主动付血**：献血机、恶魔乞丐、献祭等按对应互动收费。减伤或护盾不一定能免掉机器收费，碰之前先查对应规则。
3. **恶魔交易**：价格可能是容器、魂心或金币，取决于角色与实际价签。付掉一个容器和扣掉一颗填充红心不是同一件事。

不确定费用或能否活下来时，先查[机器与乞丐](/strategy/machines)、[交易价格](/strategy/mechanics#价格)和[献祭表](/tools/sacrifice)。工具计算的概率也不是生存保证。

## 两个实用例子

- **有红心和魂心准备打 Boss**：普通伤害先消耗外侧保护时，可以保住红心保护加成；但魂心用完再扣红心就要重新按实际伤害情况算，不能把整层保护和 Boss 保护都永远勾上。
- **店主进房前生成了硬币**：当前满血时可留下能回头捡的治疗，先完成战斗再根据受伤情况回收。需要即时购物或钱有消失风险时另作取舍，快消失的硬币要及时拿。

## 金色资源与上限

- 基础硬币、炸弹、钥匙上限各 99；[深口袋](/items/c416)使硬币上限可达 999。资源满了不代表后续消耗也没有成本。
- [金心](/pickups/gold-heart)是附加奖励效果，本身不回生命；[金钥匙](/pickups/golden-key)和[金炸弹](/pickups/golden-bomb)主要服务当层，换层前完成原计划。
- [金电池](/pickups/golden-battery)有伤害风险；[金饰品](/pickups/golden-trinket)的加强按具体饰品说明看，不能全按翻倍估算。
- [永恒之心](/pickups/eternal-heart)与特殊生命不是普通半颗红心的替代物；尚未确认的消耗次序见[资料核实记录](/about-verification#pending)。
