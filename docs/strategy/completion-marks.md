# 完成标记、全角色奖励与补缺路线

<VersionBadge checked="2026-10" />

34 个角色各有十二格，共 **408 格**。每格记录普通或困难，贪婪格记录普通贪婪或极贪。**格数不是奖励数**：里角色的多格合并成一项奖励，表角色还有全困难奖励。

每个[角色独立攻略](/characters/)列有“完成标记与奖励”表：17 个表角色各 14 项、17 个里角色各 7 项，共 **357 项指定角色奖励条件**。这是角色标记奖励对照，其他累计、挑战、每日与捐款成就见[全成就](/achievements/)。

## 十二格怎么认 {#marks}

| 标记目标 | 完成地点 | 最高状态与易错点 |
| --- | --- | --- |
| 妈妈的心脏 / 它活着 | 子宫 II | 普通与困难共用一格；不要用妈妈战代替 |
| 以撒 | 教堂 | 困难完成给红标记；这是 Boss，不是玩家角色 |
| ??? | 宝箱层 | 要实际打败 ??? Boss；选 ??? 角色不等于完成此格 |
| 撒但 | 阴间 | 与超级撒但分开 |
| 羔羊 | 暗室 | 通常与撒但同一路线 |
| 超级撒但 | 宝箱 / 暗室金门后 | 准备完整钥匙或其他开门手段 |
| Boss Rush | 妈妈后的车轮战房 | 完整打完；只拿底座再传走不算 |
| 死寂 | 蓝子宫 | 与心脏分开；正常时间门通常为 30 分钟 |
| 贪婪 / 极贪 | 独立模式终点 | 同一格；普通贪婪不满足红边极贪要求 |
| 精神错乱 | 虚空 | 表现在便利贴外观变化上；仍是普通 / 困难两档 |
| 母亲 | 尸宫 II | 与妈妈、妈妈的心脏都不同 |
| 祸兽 | 家的最终战 | 只解锁里角色、只打教条都不等于完成祸兽 |

困难完成覆盖同目标的普通完成；极贪覆盖同角色普通贪婪。心脏的指定角色奖励要求困难，其他奖励是否要求困难或一整组，以对应成就条件为准。[详细入口](/guide/unlocks/endings) · [模式资格](/modes/unlock-rules)。

## 里角色为什么要打多个 Boss 才领奖励 {#combined}

| 奖励组 | 必须完成的标记 | 如何推进 |
| --- | --- | --- |
| 主线四终点 | 以撒＋???＋撒但＋羔羊 | 同一里角色，分别走全家福、底片两条分支；可分局 |
| 限时双目标 | Boss Rush＋死寂 | 同一里角色，两个都要完成；可分局 |
| 超级撒但 | 超级撒但 | 单独奖励，常开放箱子、掉落物或机器机制 |
| 极贪 | 极贪 | 普通贪婪不替代，奖励是反向塔罗牌 |
| 精神错乱 | 精神错乱 | 单独奖励 |
| 母亲 | 母亲 | 单独奖励 |
| 祸兽 | 祸兽 | 单独奖励 |

例如里以撒打过以撒、???、撒但，仍缺羔羊，就不能获得妈妈的锁。另一个里角色打羔羊也不能补进这一组。里雅各的极贪奖励同时开放反向月亮、反向太阳，两张牌共用 #542。

里角色心脏和普通贪婪没有独立奖励，但死亡证明要求的十二格困难 / 极贪仍包含它们。主线四终点、限时双目标的普通完成可以拿对应合并奖励；想避免以后补红标记，可直接用困难推进。

## 奖励、开局强化与收藏是三件事 {#reward-types}

- **开放物品**：满足条件后才加入可生成范围，不保证当前局立刻给你，也不等于收藏页已取得。例如 ??? 打以撒开放六面骰，同时让表以撒开局带它。
- **开局强化**：店主打以撒开放开局木制镍币，打撒但开放商店钥匙，打死寂开放开局硬币与第三个硬币心；不是把这些效果套给里店主。
- **新机制与合作宝宝**：超级撒但和全困难奖励中有箱子、机器、掉落物及本地合作宝宝；不能全当作普通收集页道具。
- **收藏记录**：普通道具通常还要实际取得。本地工具不能判断每件饰品、卡牌或胶囊是否拿过。

犹大的左手还有“用任意角色击败超级傲慢”途径，因此已解锁左手不证明犹大打过 ???。拉撒路已拿到困难心脏标记，也不证明满足伯大尼的“全程不触发复活”条件。离线工具会分别显示成就解锁和角色标记，因此这两项进度可能不同。

## 下一局怎么补 {#routes}

1. **先选角色，再看缺的奖励条件。** 用[只读本地工具](/tools/local-progress)查真实缺格，或在[手动清单](/tools/tracker)记录；浏览器勾选不会改变游戏存档。
2. **主线两条分支分开规划。** 全家福走教堂 → 宝箱补以撒 / ???；底片走阴间 → 暗室补撒但 / 羔羊。不要走错分支后期待同局自然切换。
3. **限时门按道具搭配决定。** 有把握可同局做 Boss Rush、死寂，再进虚空；赶不及可分局。妈咪炸弹！等特殊开门手段另按道具机制判断。
4. **金门与虚空区分版本。** 已开放虚空时，忏悔+ 打完超级撒但会给结局箱子和虚空入口，不要先碰箱子结束局。普通忏悔仍按其 50% 战后判定，不作必出承诺。[Boss 版本表](/strategy/bosses)。
5. **母亲、祸兽与极贪各自另开路线。** 回家先开对应里角色，再完成最终战；极贪先捐 500 枚开放，需打完金色二阶段。

拿到所需奖励后可继续补本局顺路目标，是否挑战额外 Boss 取决于当前道具搭配。上述是减少返工的建议，不是必须照做的固定顺序。
