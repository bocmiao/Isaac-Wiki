# 道具组合与负面联动

<VersionBadge checked="2026-10" />

组合是取舍建议，不保证任何角色都同样生效。先检查攻击形态、生命机制、主动容量与版本。[组合查询工具](/tools/synergies)。

## 硫磺火 + 妈妈的菜刀 {#combo-1}

[硫磺火](/items/c118) + [妈妈的菜刀](/items/c114)

蓄力血激光；可投掷的菜刀

菜刀优先，不吃硫磺火的射速惩罚。扔出菜刀后再射出一小串菜刀，忏悔起每把造成 2 倍伤害

**版本**：忏悔 / 忏悔+；参见单件版本说明。

**适用与风险**：本工具按已取得组件做对照，实际交互还受角色和其他道具影响。

## 追踪激光 {#combo-9}

[硫磺火](/items/c118) + [弯勺魔术](/items/c3)

硫磺火提供持续激光，弯勺魔术提供追踪。

激光可随追踪修正弯向敌人，仍需要保持与目标距离。

**版本**：忏悔 / 忏悔+；各单件差异见详情页。

**适用与风险**：兼容通常泪弹 / 激光角色；不把它当作全自动必中。

**适用与风险**：攻击方式由角色自身和其他泪弹修改共同决定。

## 爆炸免疫与吐根酊 {#combo-11}

[吐根酊](/items/c149) + [纵火狂](/items/c223)

吐根酊泪弹会爆炸，纵火狂免疫爆炸。

降低近距离自爆的风险；有红心容器时才能利用红心回复。

**版本**：忏悔 / 忏悔+；各单件差异见详情页。

**适用与风险**：游魂不能靠回血获得生命；踩脚、接触伤害不因为爆炸免疫而消失。

## 骷髅帽与爆炸泪弹 {#combo-12}

[吐根酊](/items/c149) + [寄居骷髅帽](/items/c375)

吐根酊带爆炸，寄居骷髅帽提供爆炸保护。

普通爆炸不再是主要自伤来源，但毒、地面危害和敌人接触仍需躲。

**版本**：忏悔 / 忏悔+；各单件差异见详情页。

**适用与风险**：忏悔起妈妈踩脚等不属于普通爆炸。

## 减伤与受伤充能 {#combo-13}

[圣饼](/items/c108) + [修女服](/items/c156)

圣饼减少普通伤害，修女服在受伤时补主动充能。

意外受伤的成本较低，也能获得充能；这不是建议主动撞怪。

**版本**：忏悔 / 忏悔+；各单件差异见详情页。

**适用与风险**：减伤和付血不是同一个判定，游魂不因减伤变成可扛血角色。

## 清房充能与储存 {#combo-14}

[9伏特](/items/c116) + [蓄电池](/items/c63)

9伏特改变主动充能节奏，蓄电池允许额外储存一轮充能。

便于在进入 Boss 前保留更多主动使用机会。

**版本**：忏悔 / 忏悔+；各单件差异见详情页。

**适用与风险**：不同主动的充能类型不同，不保证每个主动都能连续使用。

## 储存朋友盒充能 {#combo-15}

朋友盒复制跟班，蓄电池提供额外储存。

**版本**：忏悔 / 忏悔+；各单件差异见详情页。

**适用与风险**：莉莉丝与贪婪波次适合规划，仍需先有能参战的跟班。

## 一次蓄力多束硫磺火 {#combo-16}

[完美视力](/items/c245) + [硫磺火](/items/c118)

20/20增加同时发射数量，硫磺火改为蓄力激光。

可以扩展攻击覆盖；额外弹道和属性代价要以当前版本效果为准。

**版本**：忏悔 / 忏悔+；各单件差异见详情页。

**适用与风险**：多发泪弹修改不能一律按面板伤害乘发数估算。

## 爆炸免疫与炸弹泪弹 {#combo-17}

[胎儿博士](/items/c52) + [纵火狂](/items/c223)

胎儿博士把泪弹改为炸弹，纵火狂免疫普通爆炸。

能更安全地利用炸弹泪弹清房和开口，不能因此忽略其他伤害。

**版本**：忏悔 / 忏悔+；各单件差异见详情页。

**适用与风险**：回复仅适用于能恢复红心的角色。

## 嗝屁猫三件组件示例 {#combo-18}

[嗝屁猫](/items/c81) + [嗝屁猫的爪子](/items/c133) + [嗝屁猫的尾巴](/items/c134)

嗝屁猫、嗝屁猫的爪子、嗝屁猫的尾巴各是一件嗝屁猫组件。

取得这三种不同组件可推进嗝屁猫变身；这是一组示例，不是唯一三件配方。

**版本**：忏悔 / 忏悔+；各单件差异见详情页。

**适用与风险**：组件取得记录与本工具本局持有勾选不同；不要把同一道具重复三次当三种。

## 圣经与撒但：不要误按 {#combo-19}

[彼列之书](/items/c34) + [圣经](/items/c33)

圣经可秒杀妈妈和心脏，犹大的彼列之书用于本房间伤害提升。

到撒但战不能照搬妈妈战的圣经秒杀法；圣经会杀死使用者。

**版本**：忏悔 / 忏悔+；各单件差异见详情页。

**适用与风险**：这是主动使用风险提醒；一个主动栏通常无法同时装备两件，额外主动容量另算。

## 九条命不等于九次无损 {#combo-20}

[嗝屁猫](/items/c81) + [神圣屏障](/items/c313)

嗝屁猫复活后仅给有限红心容器，神圣屏障挡一次房间伤害。

屏障能减少复活后立刻再死的风险；不保证复活时无敌，也不弥补特殊角色复活限制。

**版本**：忏悔 / 忏悔+；各单件差异见详情页。

**适用与风险**：取舍先看角色生命机制，不能把红心容器当作魂心容器。

## 巧克力奶的蓄力取舍 {#combo-21}

[巧克力牛奶](/items/c69) + [硫磺火](/items/c118)

巧克力奶与硫磺火都涉及蓄力。

需要重新习惯蓄力时机，短蓄力不能套用普通巧克力奶泪弹的伤害预期。

**版本**：忏悔 / 忏悔+；各单件差异见详情页。

**适用与风险**：复合攻击的精确倍率不在此估算，先看两件的版本说明。

## 付血与资源预算 {#combo-22}

[小猪存钱罐](/items/c227) + [献血袋](/items/c135)

储蓄罐可在受伤时生成硬币，献血袋主动用红心交换硬币。

可以利用恢复手段把红心资源换成经济，先确保付血后能生存。

**版本**：忏悔 / 忏悔+；各单件差异见详情页。

**适用与风险**：不承诺无限循环；游魂、硬币血角色和魂心角色不能套普通红心预算。

## 追踪爆炸的贴身风险 {#combo-23}

[弯勺魔术](/items/c3) + [吐根酊](/items/c149)

弯勺魔术使弹道追踪，吐根酊的命中会爆炸。

追踪改变落点，敌人贴身时更难控制安全距离。

**版本**：忏悔 / 忏悔+；各单件差异见详情页。

**适用与风险**：没有爆炸免疫时不要把追踪当成绝对安全的增益。

## 低红心奖励与保护 {#combo-24}

[巴比伦大淫妇](/items/c122) + [神圣屏障](/items/c313)

巴比伦大淫妇在低红心状态改善输出，神圣屏障降低普通受伤概率。

能在低红心打法中增加容错；是否触发低红心效果看实际生命机制。

**版本**：忏悔 / 忏悔+；各单件差异见详情页。

**适用与风险**：没有红心的角色不等于可按普通红心角色主动付血。

## 来源与核对范围

单件机制使用本站固定 EID 快照，具体版本差异见各道具页；原有八组保留[道具取舍](/strategy/items#常见组合)的来源。新增条目以已知单件能力解释发育、操作与风险，不补未经核实的复合倍率。嗝屁猫组件依据 EID 的变身说明，圣经与撒但的风险依据[Boss 指南](/strategy/bosses)。
