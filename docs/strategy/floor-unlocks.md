# 楼层解锁与 Boss 补缺检查

<VersionBadge checked="2026-10" />

有些楼层变体要求击败对应章节的多种 Boss。只通关一次通常不够；在其他区域或 Boss Rush 击败同名 Boss，也可能计入。

## 怎么确认缺的是谁

1. 先用[本地进度工具](/tools/local-progress)检查对应成就是否已经解锁；解锁后不需要为了变体重复补这个条件。
2. 未解锁时，查看游戏图鉴的 Boss 遭遇 / 击败记录，区分见过与真正击败。
3. 用[前中期 Boss 图鉴](/bosses/)复习不会打的目标，继续可解锁的随机正常局。图鉴的章节分类是查询分组，不是官方完整必需名单。
4. 若某个目标只在已解锁变体出现，不应直接把它添成基础变体的前置，避免循环要求。

## 完整名单的核实状态

目前已确认表中的成就条件和三个排除项，完整 Boss 名单仍待补齐。因此本页能帮你确认解锁条件，暂时不能列出每个变体还缺哪一只 Boss。见[资料核实记录](/about-verification#pending)。

本地工具目前也只显示这些变体是否已解锁，不能自动列出缺少的 Boss。
