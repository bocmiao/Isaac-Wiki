# 中英译名对照

<VersionBadge checked="2026-10" />

本站的道具、饰品、卡牌、胶囊、角色和房间名，统一采用 [External Item Descriptions（EID）](https://steamcommunity.com/sharedfiles/filedetails/?id=836319872)中文版里的叫法。EID 是中文玩家最常用的道具说明模组，它的中文译者也在维护社区的忏悔+ 中文补丁，所以这些名字就是大多数玩家在游戏里看到的名字。EID 没有收录的词（楼层、部分 Boss），沿用中文社区的常用叫法。

::: info 两个例外
- **里角色**：游戏内中文叫「堕化」角色（例如堕化以撒）。中文社区更常说「里角色」，本站沿用这个叫法。
- **Boss 房**：游戏内中文叫「头目房」，Boss Rush 叫「头目车轮战」。本站正文写「Boss 房」「Boss Rush」，第一次出现时注明。
:::

在英文 wiki 或视频里看到不认识的名字，可以在这里查。
