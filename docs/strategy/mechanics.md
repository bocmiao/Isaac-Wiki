:::

本文以忏悔+ 为准，与忏悔不同处单独标出；基础内容见[房间类型入门](/guide/first-win/rooms)和[心、钱、炸弹、钥匙怎么用](/guide/first-win/pickups)。

## 恶魔房与天使房

### 出现条件

- 只在第一章第二层到第四章之间开门。第一层只有被迷宫诅咒合成 XL 层时才可能开。
- 门在打完 Boss 后出现；XL 层要打完第二个 Boss。
- 走出 Boss 房再回来，门按当前概率（已含 ×0.25 惩罚）重新判定，常会关；关了只有山羊头或圣餐能再开。**门开了直接进。**
- 用鬼牌、红箱子传送进去不算「看到门」，不降低概率。

### 开门概率

基础 1%。下面各项先相加，再乘惩罚系数，结果超过 100% 就必开。恶魔房、天使房共用这个概率。

| 来源 | 加成 |
| --- | --- |
| 整层没受红心伤害 | +99% |
| 打 Boss 时没受红心伤害 | +35% |
| 本层炸死过乞丐、腐烂乞丐、电池乞丐 | +35%；忏悔+ 起恶魔乞丐、钥匙大师也算 |
| 本层炸死过店主（Shopkeeper） | +10% |
| 启示录（拿在手上）/ 黑蜡烛 / 彼列之书（拿在手上） | +17.5% / +15% / +12.5% |
| 五芒星 | +10%，第二个 +5% |
| 撒但圣经的魂火（忏悔起） | 每个 +10%，最多 +80% |
| 腊肠（忏悔起） | +6.9% |
| 痛悔短祷（忏悔起） | 掉了红心时，+99% 变 +40%，+35% 变 +15% |
| 山羊头 / 圣餐 | 必开（圣餐必为天使房） |
| 上一层出现过恶魔房门 | ×0.25 |
| 两层前出现过 | ×0.5 |

献血机、恶魔乞丐、献血袋这类自残不算红心伤害；忏悔起，献祭房尖刺和诅咒房门也不算。XL 层没开门算两层没开，开了算一层。

::: tip 发光沙漏撤销开门
不想要这层的交易：进门后在房里用发光沙漏回溯，算作这层没开门，下一层不吃惩罚（这层概率须不到 100%）。
:::

### 恶魔还是天使

天使房有两个前提：

1. 之前某层**出现过**恶魔房门（传送进去的不算）。
2. 本局没做过恶魔交易。付血或付钱买恶魔房道具才算，游魂免费拿也算；拿黑心、开红箱子、用信用卡白拿不算。忏悔起，持有美德之书或痛悔短祷时可以无视这一条。

满足前提后，下面每项单独掷一次，任一项成功就是天使房，不能直接相加：只有基础和钥匙碎片1 时是 1−0.5×0.75=62.5%。

| 来源 | 单独判定 |
| --- | --- |
| 基础 | 50% |
| 本层向捐款机捐满 10 个硬币 | 50% |
| 钥匙碎片1、钥匙碎片2 | 各 25% |
| 本层把乞丐喂到给出道具 | 10% |
| 本层炸死恶魔乞丐（仅忏悔） | 25%；忏悔+ 改为开门概率 +35% |
| 献祭房祝福：第 3 次 / 第 5 次 / 两次都有 | 15% / 50% / 65% |
| 忏悔室祝福（忏悔起） | 每次 10%，最多 100% |
| 念珠段 | 忏悔 50%；忏悔+ 必定天使房 |
| 美德之书（忏悔起） | 12.5%，第一次交易必为天使房 |
| 圣餐 | 必定 |
| 本层把恶魔乞丐喂到给出道具 | 反向 10%，成功就强制恶魔房 |

::: info 忏悔起的天使房保底
- 本局第一扇恶魔房门出现后完全不进，下一次交易必定是天使房。
- 还没遇到过交易时，在献祭房或忏悔室得到一次祝福，本层交易必定是天使房。
:::

### 价格

| 情况 | 价格 |
| --- | --- |
| 一般 | 1 或 2 个红心容器，越强越贵 |
| 进房时没有红心容器 | 全部 3 个魂心 |
| 只剩 1 个红心容器 | 2 容器的也能拿；忏悔起改收 1 容器 + 2 魂心 |
| 有骨心（忏悔起） | 骨心算容器，至少收 1 个红心容器 |
| 角色店主、持有一磅肉（忏悔起） | 15 / 30 硬币，同样算交易 |
| ???（忏悔起） | 魂心，数量等于原价 |
| 游魂、里游魂（忏悔起） | 免费拿 1 件，其余消失 |
| 带 devilsacrifice 标签的道具（忏悔+） | 改为踩尖刺：第 1 次 50%，第 2 次必给 |

容器花光不会死，只要还剩魂心、黑心或骨心。里店主在天使房也要付硬币。

### 天使雕像与钥匙碎片

- 通关过一次暗室或宝箱后，天使房的雕像能用炸弹炸醒。乌列（Uriel）掉钥匙碎片1，加百列（Gabriel）掉钥匙碎片2，两者轮流出现。两块碎片打开暗室、宝箱开局房间的金门，通往超级撒但。
- 已有一块时，天使必定掉另一块；忏悔起同时炸醒两个也都掉。持有银丝羽毛时改掉天使房道具。
- 其他刷天使的地方：献祭房第 9、11 次；超级隐藏房的一种布局里有天使雕像，也掉碎片。

## 献祭房

每层基础生成率 1/7；进层时总血量不少于红心容器数时约 36%。

尖刺通常扣一整颗心，圣饼、巨蟹座能降到半颗；神圣屏障等挡掉伤害时不计次。装着红心的骨心不会被尖刺打碎，可以一直只付半颗红心。

| 本层第几次 | 结果 |
| --- | --- |
| 1、2 | 50% 无；50% 1 硬币 |
| 3 | 33% 无；67% 祝福 |
| 4 | 50% 无；50% 1 个箱子 |
| 5 | 33% 3 硬币；67% 更强的祝福 |
| 6 | 33% 传送到天使房（做过交易也行，本层已见过恶魔房则回恶魔房）；67% 1 个箱子 |
| 7 | 33% 天使房道具；67% 魂心。做过交易时，魂心有 50% 换成赎罪（需解锁） |
| 8 | 7 个即爆炸弹（忏悔前 6 个） |
| 9 | 乌列 |
| 10 | 50% 7 魂心；50% 30 硬币 |
| 11 | 加百列 |
| 12 起 | 50% 无；50% 传送到暗室 |

次数每层清零。召出的天使不锁门，走出去就消失。

## 商店

子宫之前每章都有，带饰品银币时子宫也有。忏悔起第一层商店不上锁；带饰品商店钥匙时都不用钥匙。基础价格见[心、钱、炸弹、钥匙怎么用](/guide/first-win/pickups)。

- **打折**：红色价签半价，道具和福袋向下取整，拾取物向上取整。
- **Steam大促**：所有用硬币买的东西半价。
- **补货**：忏悔起每补买一次涨价，最高 99。

### 商店等级

| 等级 | 0 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- |
| 捐款机累计 | 0 | 20 | 100 | 200 | 600 |
| 在售拾取物 | 0～1 | 1～2 | 2～3 | 3～4 | 4～5 |

道具始终 1～2 个。忏悔起，普通模式总是最高已解锁等级，困难模式在已解锁等级里随机。

### 贪婪

- 第二章第二层起可能占据商店，第三章第一层起可能占据隐藏房，炸不出去。先出贪婪，之后是超级贪婪，两个都遇过后本局不再出现。带着贪婪的肋骨时商店里不出现。
- 打中你会让你丢 2～4 个硬币。打赢掉 7 硬币（75%）或 Steam大促（25%）。

忏悔起出现率范围 25%～39%：

| 条件 | 出现率 |
| --- | --- |
| 基础 | 33.3% |
| 进层时硬币超过 20 个 | +1.66% |
| 上一层炸了捐款机 / 炸了店主 | +3.33% / +0.66% |
| 上一层每捐 1 硬币 | −1.66%，最多 −8.33%（离开前投 5 个就够） |

| --- | --- | --- | --- |

| 恶魔乞丐 | 红心：第四章前半颗，之后一整颗 | 胶囊、卡牌各 25%，饰品 12.5%，道具 37.5% | 2 只蜘蛛；忏悔天使判定 +25%，忏悔+ 开门 +35% |
| 钥匙大师 | 钥匙 | 65% 无，30.6% 箱子，4.4% 回形针或道具。忏悔+ 带金钥匙直接给道具 | 拾取物；忏悔+ 开门 +35% |
| 炸弹乞丐 | 炸弹 | 忏悔起：60% 无，26% 硬币，9% 心，5% 道具。忏悔+ 带金炸弹直接给道具 | 忏悔起免疫炸弹，反丢即爆炸弹 |

## 诅咒

诅咒只持续一层，会自然出现的有 6 种：

| 诅咒 | 效果 |
| --- | --- |
| 黑暗诅咒（Curse of Darkness） | 整层很暗，只有角色周围亮 |
| 迷失诅咒（Curse of the Lost） | 没有小地图，房间数上限 +4；显示地图的道具也没用 |
| 未知诅咒（Curse of the Unknown） | 不显示血量 |
| 迷宫诅咒（Curse of the Labyrinth） | 只在每章第一层；两层合成 XL 层，两个 Boss 房、两个宝箱房，算两层。第一章时两个宝箱房都不上锁 |
| 致盲诅咒（Curse of the Blind） | 道具全显示成问号，捡起才知道 |
| 混乱诅咒（Curse of the Maze） | 进门偶尔被传到别的房间 |

| 进度 | 普通 | 困难 |
| --- | --- | --- |
| 新存档 | 1/80 | 1/10 |
| 击败过妈妈 | 1/30 | 1/5 |
| 解锁 Everything Is Terrible!!!（击败妈妈的心脏 5 次） | 1/10 | 1/3 |
| 击败过以撒 | 1/5 | 1/3（忏悔前 1/2） |

被诅咒时 6 种各 1/6。抽到迷宫诅咒但本层不能出（每章第二层、子宫之后、贪婪模式），这层就没有诅咒，所以这些层的实际概率是表中的 5/6。

| 解除 | 效果 |
| --- | --- |
| 黑蜡烛 | 免疫诅咒，拿到时清掉本层诅咒（迷宫诅咒除外） |
| 朝夕符文 | 清掉本层诅咒（迷宫诅咒除外），+1 魂心 |
| 太阳（Sol） | 打完本层 Boss 后清掉诅咒（迷宫诅咒除外） |
| 忏悔室的祝福 | 移除一个诅咒 |
| XIX-太阳（忏悔起）、小夜灯 | 移除本层黑暗诅咒 |

## 隐藏房、超级隐藏房、究极隐藏房

### 隐藏房

- 通常挨着 3 或 4 个房间，两种位置机会相同。挨 2 个的少见；只挨 1 个的，只在没有 3 邻以上合法位置时出现，极少见。
- 不挨 Boss 房、超级隐藏房和另一个隐藏房。
- 入口墙前不会有坑、障碍物、尖刺或刷怪点，**每个**相邻房间都要满足，有一个不满足就换地方找。
- 大房间分段的找法：从角落贴墙走，镜头开始移动处就是分段点。窄长房只可能在尽头那面墙。

### 超级隐藏房

- 只挨一个房间，而且不是特殊房间，也不挨隐藏房。
- 它占「从起点走过去第二远」的死路（最远是 Boss 房，第三远是商店），所以常在 Boss 房附近，或在商店和 Boss 房之间。

### 究极隐藏房（忏悔起）

- 不和任何房间直接相连，只有碎裂的宝珠、秘密之书的魂火、符文碎片能在地图上标出。
- 进法：用红钥匙、水晶钥匙、红钥匙碎片、该隐的魂石开红房间，走进挨着它的红房间时自动开门；或用 XVIII-月亮？ 直接传送。
- 最常见于「透过四周红房间能连到 3 个以上普通房间」的格子，比 2 邻的格子可能性高约 11.5 倍。它四周的红房间不会连到隐藏房、超级隐藏房、诅咒房，也不会挨着 Boss 房。
- 开红房间时，选能覆盖最多候选格子的那面墙。

### 找房工具

| 用途 | 道具、卡牌、胶囊 |
| --- | --- |
| 直接打开隐藏房、超级隐藏房入口 | X光透视；我能永远看清！（胶囊，当层） |
| 地图上标出隐藏房（仍要炸） | 蓝地图、秘密之书、水晶球、思想、探窟帽、XIX-太阳、XXI-世界 |
| 传送 | XVIII-月亮 → 隐藏房；XVIII-月亮？ → 究极隐藏房 |
| 排除法 | 红钥匙不会覆盖隐藏房、超级隐藏房：本该有红门轮廓却没有的墙后面，可能就是 |
