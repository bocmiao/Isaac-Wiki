## 恶魔房与天使房

### 出现条件

- 恶魔房、天使房的门只在第 1 章第二层到第 4 章之间出现。第一层一般不开门，只有被迷宫诅咒合成 XL 层（两层合并成一层，见[诅咒](#诅咒)）时才可能开。
- 门在打完 Boss 后出现；XL 层要打完第二个 Boss。
- **想进当前交易房就当场决定。** 走出 Boss 房再回来，门会按当前概率重新判定一次。这时概率已经吃了 ×0.25 惩罚（见下表），所以常会关上。关上后只有山羊头或圣餐能再打开。若计划用忏悔起的首扇恶魔房跳过保底，应完全不进入，见[恶魔还是天使](#恶魔还是天使)。
- 用鬼牌、红箱子传送进去，不算「出现过门」，之后的开门概率不会因此吃惩罚。

### 开门概率

基础 1%。下表的加成先全部相加，再乘惩罚系数，结果超过 100% 就必开。恶魔房和天使房共用这个概率，开出来是哪一种见[恶魔还是天使](#恶魔还是天使)。

| 来源 | 加成 |
| --- | --- |
| 整层没受红心伤害 | +99% |
| 打 Boss 时没受红心伤害 | +35% |
| 本层炸死过乞丐、腐烂乞丐、电池乞丐 | +35% |
| 本层炸死过恶魔乞丐、钥匙大师（忏悔+） | +35% |
| 本层炸死过店主（Shopkeeper） | +10% |
| 启示录（拿在手上） | +17.5% |
| 黑蜡烛 | +15% |
| 彼列之书（拿在手上） | +12.5% |
| 五芒星 | +10% |
| 第二个五芒星 | 再 +5% |
| 撒但圣经的魂火（忏悔起） | 每个 +10%，最多 +80% |
| 腊肠（忏悔起） | +6.9% |
| 山羊头 | 必开 |
| 圣餐 | 必开，且必为天使房 |

持有痛悔短祷（忏悔起）时，掉了红心也不会把前两项全丢掉：「整层没受红心伤害」变为 +40%（原 +99%），「打 Boss 时没受红心伤害」变为 +15%（原 +35%）。

加成算完后，再按前几层的情况乘惩罚系数：

| 情况 | 系数 |
| --- | --- |
| 上一层出现过恶魔房门 | ×0.25 |
| 两层前出现过恶魔房门 | ×0.5 |

- 献血机、恶魔乞丐、献血袋这类自残不算红心伤害。忏悔起，献祭房尖刺和诅咒房门也不算。
- XL 层算惩罚时：没出现门，算作两层都没出现；出现了门，算作一层出现过。

::: tip 发光沙漏撤销开门
不想要这层的交易，又不想让下一层吃 ×0.25 惩罚：进门后在房里用发光沙漏退回去，这层就算没出现过门。前提是这层的开门概率不到 100%。
:::

### 恶魔还是天使

天使房有两个前提：

1. 之前某层**出现过**恶魔房门（传送进去的不算）。
2. 本局没做过恶魔交易。忏悔起，持有美德之书或痛悔短祷时可以无视这一条。
   - 算交易：付血或付钱买恶魔房道具；游魂免费拿走一件也算。
   - 不算交易：拿黑心、开红箱子、用信用卡白拿。

满足前提后，下表每一项各自单独判定一次，任一项成功就是天使房，所以不能把概率直接相加。例如只有基础 50% 和钥匙碎片1 的 25% 时，天使房概率是 1 − 0.5 × 0.75 = 62.5%。

| 来源 | 天使房概率 |
| --- | --- |
| 基础 | 50% |
| 本层向捐款机捐满 10 个硬币 | 50% |
| 持有钥匙碎片1 | 25% |
| 持有钥匙碎片2 | 25% |
| 本层把乞丐喂到给出道具 | 10% |
| 本层炸死恶魔乞丐（仅忏悔） | 25% |
| 本层献祭房第 3 次给了祝福 | 15% |
| 本层献祭房第 5 次给了祝福 | 50% |
| 本层献祭房第 3、5 次都给了祝福 | 65% |
| 忏悔室祝福（忏悔起） | 每次 10%，最多 100% |
| 念珠段（忏悔） | 50% |
| 念珠段（忏悔+） | 必定 |
| 美德之书（忏悔起） | 12.5%，本局第一次交易必为天使房 |
| 圣餐 | 必定 |

- 炸死恶魔乞丐：忏悔+ 起不再给天使房 25%，改为开门概率 +35%（见[开门概率](#开门概率)）。
- 反向判定：本层把恶魔乞丐喂到给出道具，有 10% 概率强制变成恶魔房。

::: info 忏悔起的天使房保底
- 本局第一扇恶魔房门出现后完全不进，下一次交易必定是天使房。
- 还没遇到过交易时，在献祭房或忏悔室得到一次祝福，本层交易必定是天使房。
:::

### 价格

| 情况 | 价格 |
| --- | --- |
| 一般 | 1 或 2 个红心容器，越强越贵 |
| 进房时没有红心容器 | 每件 3 个魂心 |
| 只剩 1 个红心容器，道具标 2 容器 | 忏悔前照样能拿；忏悔起改收 1 容器 + 2 魂心 |
| 有骨心（忏悔起） | 骨心算容器，但至少收 1 个红心容器 |
| 带 devilsacrifice 标签的道具（忏悔+） | 不收心，改为踩献祭尖刺：第 1 次 50% 给道具，第 2 次必给 |

下面这些角色或道具改用别的方式付：

| 角色 / 道具 | 怎么付 |
| --- | --- |
| 店主角色（忏悔起；忏悔前付硬币心容器）、持有一磅肉的任何角色 | 1 心价付 15 硬币，2 心价付 30 硬币；付硬币同样算做过恶魔交易，照样影响天使房出现率 |
| ???（Blue Baby）角色（忏悔起） | 付魂心，数量等于原价 |
| 游魂、里游魂（忏悔起） | 免费拿 1 件，其余消失 |

付完红心容器花光也不会死，只要还剩魂心、黑心或骨心。里店主在天使房也要付硬币。

### 天使雕像与钥匙碎片

- 通关过一次暗室或宝箱后，天使房里的雕像能用炸弹炸醒。乌列（Uriel）掉钥匙碎片1，加百列（Gabriel）掉钥匙碎片2，两者轮流出现。
- 两块碎片能打开暗室、宝箱开局房间的金门，门后是超级撒但。
- 已有一块碎片时，天使必定掉另一块；忏悔起同时炸醒两个天使，两块都掉。持有银丝羽毛时，天使改掉天使房道具。
- 其他能遇到这两个天使的地方：献祭房同一层第 9、11 次；超级隐藏房的一种布局里有天使雕像，炸醒后也掉碎片。

## 献祭房

献祭房每层的生成概率基础为 1/7。进层时总血量不少于红心容器数，提高到约 36%。

- 尖刺通常扣一整颗心，圣饼、巨蟹座能降到半颗。
- 神圣屏障等挡掉伤害时，这一下不计次数。
- 装着红心的骨心不会被尖刺打碎，所以可以一直只付半颗红心。

| 本层第几次 | 结果 |
| --- | --- |
| 1、2 | 50% 无；50% 1 硬币 |
| 3 | 33% 无；67% 祝福 |
| 4 | 50% 无；50% 1 个箱子 |
| 5 | 33% 3 硬币；67% 更强的祝福 |
| 6 | 33% 传送到天使房；67% 1 个箱子 |
| 7 | 33% 天使房道具；67% 魂心 |
| 8 | 7 个即爆炸弹（忏悔前 6 个） |
| 9 | 乌列 |
| 10 | 50% 7 魂心；50% 30 硬币 |
| 11 | 加百列 |
| 12 起 | 50% 无；50% 传送到暗室 |

- 第 6 次的传送：做过恶魔交易也能传到天使房；本层已经见过恶魔房的话，传回恶魔房。
- 第 7 次：做过交易时，给的魂心有 50% 换成赎罪（需解锁）。
- 次数每层清零。召出的天使不锁门，走出去就消失。

## 商店

子宫之前每章都有商店，带饰品银币时子宫也有。忏悔起，第一层的商店不上锁；带饰品商店钥匙时，所有商店都不用钥匙。基础价格见[心、钱、炸弹、钥匙怎么用](/guide/first-win/pickups)。

- **打折**：红色价签半价，道具和福袋向下取整，拾取物向上取整。
- **Steam大促**：所有用硬币买的东西半价。
- **补货（Restock）**：持有道具补货时，商店的东西买走后会立刻补上新的。忏悔起，靠补货买得越多，商品越贵，最高涨到 99 硬币。

### 商店等级

| 等级 | 0 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- |
| 捐款累计（硬币） | 0 | 20 | 100 | 200 | 600 |
| 在售拾取物 | 0～1 | 1～2 | 2～3 | 3～4 | 4～5 |

道具始终 1～2 个。忏悔起，普通模式下商店总是最高已解锁等级，困难模式在已解锁的等级里随机。

### 贪婪

- 贪婪是会占据商店或隐藏房的小头目：第 2 章第二层起可能出现在商店，第 3 章第一层起可能出现在隐藏房。碰上贪婪的商店或隐藏房算作小头目房，不能用炸弹炸开出路逃走，只能打。
- 先出贪婪，之后是超级贪婪，两个都遇过后本局不再出现。带着贪婪的肋骨时，商店里不出现贪婪。
- 被它打中会丢 2～4 个硬币。打赢后 75% 掉 7 个硬币，25% 掉 Steam大促。

忏悔起，贪婪的出现率在 25%～39% 之间，按下表计算：

| 条件 | 出现率 |
| --- | --- |
| 基础 | 33.3% |
| 进层时硬币超过 20 个 | +1.66% |
| 上一层炸了捐款机 | +3.33% |
| 上一层炸了店主 | +0.66% |
| 上一层每捐 1 硬币 | −1.66%，最多 −8.33% |

上一层离开前往捐款机投 5 个硬币，就能吃满 −8.33%。

## 诅咒

诅咒只持续一层，会自然出现的有 6 种：

| 诅咒 | 效果 |
| --- | --- |
| 黑暗诅咒（Curse of Darkness） | 整层很暗，只有角色周围亮 |
| 迷失诅咒（Curse of the Lost） | 没有小地图，房间数上限 +4；显示地图的道具也没用 |
| 未知诅咒（Curse of the Unknown） | 不显示血量 |
| 迷宫诅咒（Curse of the Labyrinth） | 只在每章第一层出现。两层合成一个 XL 层：两个 Boss 房、两个宝箱房，算两层。第 1 章时两个宝箱房都不上锁 |
| 致盲诅咒（Curse of the Blind） | 道具全显示成问号，捡起才知道 |
| 混乱诅咒（Curse of the Maze） | 进门偶尔被传到别的房间 |

每层带诅咒的概率随存档进度提高：

| 进度 | 普通 | 困难 |
| --- | --- | --- |
| 新存档 | 1/80 | 1/10 |
| 击败过妈妈 | 1/30 | 1/5 |
| 解锁 Everything Is Terrible!!!（击败妈妈的心脏 5 次） | 1/10 | 1/3 |
| 击败过以撒 | 1/5 | 1/3（忏悔前 1/2） |

抽中诅咒时，6 种各占 1/6。如果抽到迷宫诅咒而这层不能出它（每章第二层、子宫之后、贪婪模式），这层就没有诅咒。所以在这些层，实际带诅咒的概率是表中数值的 5/6。

| 解除方式 | 效果 |
| --- | --- |
| 黑蜡烛 | 免疫诅咒，拿到时清掉本层诅咒（迷宫诅咒除外） |
| 朝夕符文 | 清掉本层诅咒（迷宫诅咒除外），+1 魂心 |
| 太阳（Sol） | 打完本层 Boss 后清掉诅咒（迷宫诅咒除外） |
| 忏悔室的祝福 | 移除一个诅咒 |
| XIX-太阳（忏悔起）、小夜灯 | 移除本层黑暗诅咒 |

## 隐藏房、超级隐藏房、究极隐藏房

### 隐藏房

- 隐藏房通常和 3 或 4 个房间相邻，两种一样常见。只和 2 个房间相邻的少见。只和 1 个房间相邻的极少见，只在找不到 3 邻以上的合法位置时才出现。
- 不挨 Boss 房、超级隐藏房和另一个隐藏房。
- 入口墙前不会有坑、障碍物、尖刺或刷怪点。**每个**相邻房间都要满足这一条，有一个不满足就换地方找。
- 大房间的墙要分段找：从角落贴墙走，镜头开始移动的位置就是分段点。窄长房的隐藏房只可能在尽头那面墙后。

### 超级隐藏房

- 只挨一个房间，而且这个房间不是特殊房间，也不挨隐藏房。
- 超级隐藏房占「从起点走过去第二远」的死路（最远是 Boss 房，第三远是商店），所以常在 Boss 房附近，或在商店和 Boss 房之间。

### 究极隐藏房（忏悔起）

- 不和任何房间直接相连。只有碎裂的宝珠、秘密之书的魂火、符文碎片能在地图上标出它。
- 进法：用红钥匙、水晶钥匙、红钥匙碎片、该隐的魂石开出红房间，走进挨着究极隐藏房的红房间时自动开门；或用 XVIII-月亮？ 直接传送。
- 最常见于「透过四周红房间能连到 3 个以上普通房间」的格子，比只连到 2 个的格子可能性高约 11.5 倍。
- 它四周的红房间不会连到隐藏房、超级隐藏房、诅咒房，也不会挨着 Boss 房。
- 开红房间时，选能覆盖最多候选格子的那面墙。
