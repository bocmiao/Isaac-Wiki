# <GameIcon name="card" :size="36" style="vertical-align: -6px; margin-right: 6px" />机制详解

<VersionBadge checked="2026-10" />

先说结论：交易门开不开，最重要的是这一层别掉红心。整层不掉 +99%，打 Boss 不掉 +35%，掉魂心、黑心不算。想走天使路线，就别进本局第一扇恶魔房门，忏悔起下一次必定是天使房。献祭房踩 7 次以内是用血换小奖励，第 8 次起开始出即爆炸弹和天使 Boss。本文以忏悔+（Repentance+）为准，和忏悔（Repentance）不同的地方单独标出。房间外观、拾取物价格等基础内容见[房间类型入门](/guide/first-win/rooms)和[心、钱、炸弹、钥匙怎么用](/guide/first-win/pickups)。

## 恶魔房与天使房

### 出现条件

- 只在第一章第二层到第四章之间开门（地下室 II 到子宫 II，含对应的支线层）。第一层只有被迷宫诅咒合成 XL 层时才可能有。
- 门在打完 Boss 后出现。XL 层要打完第二个 Boss 房。
- 走出 Boss 房再回来，门按当前概率重新判定，而且已经吃了 ×0.25 的惩罚，大概率会关。关了就打不开，除非拿到山羊头或圣餐。**门开了直接进。**
- 用鬼牌、红箱子传送进去，不算「看到门」，不会降低概率。

### 开门概率

基础 1%，下面各项先相加，再乘惩罚系数，结果超过 100% 就必开。恶魔房和天使房共用这个概率。

| 来源 | 加成 |
| --- | --- |
| 整层没受红心伤害 | +99% |
| 打 Boss 时没受红心伤害 | +35% |
| 本层炸死过乞丐、腐烂乞丐或电池乞丐 | +35%（忏悔+ 起恶魔乞丐、钥匙大师也算） |
| 本层炸死过店主（Shopkeeper） | +10% |
| 启示录（拿在手上） / 黑蜡烛 / 彼列之书（拿在手上） | +17.5% / +15% / +12.5% |
| 五芒星 | +10%，第二个再 +5% |
| 撒但圣经的魂火（忏悔起） | 每个 +10%，最多 +80% |
| 腊肠（忏悔起） | +6.9% |
| 痛悔短祷（忏悔起） | 受红心伤害后，+99% 变 +40%，+35% 变 +15%，不会清零 |
| 山羊头 / 圣餐 | 必开（圣餐必为天使房） |
| 上一层出现过恶魔房门 | ×0.25 |
| 两层前出现过 | ×0.5 |

不算红心伤害的：献血机、恶魔乞丐、献血袋这类自残，忏悔起献祭房尖刺和诅咒房门的伤害也不算。XL 层没开门算两层没开，开了算一层。

例：整层不掉红心、打 Boss 不掉、炸了一个店主，1+99+35+10=145%，必开。门出现后本层概率变成 36.25%，这就是回头门会关的原因。

::: tip 发光沙漏撤销开门
不想要这一层的交易：进门后在交易房里用发光沙漏回溯，游戏当作这层没开过门，下一层不吃惩罚。前提是这层的概率本来不到 100%。
:::

### 是恶魔房还是天使房

天使房有两个前提：

1. 之前某层**出现过**恶魔房门（鬼牌、红箱子传送不算）。忏悔起，美德之书或忏悔室的祝福能让第一次交易直接是天使房。
2. 本局没做过恶魔交易。只有在恶魔房付血或付钱买道具才算；拿黑心、开红箱子、用信用卡或代金券白拿都不算。游魂免费拿也算交易。忏悔起，持有美德之书或痛悔短祷时做过交易仍能出天使房。

满足前提后，游戏对下面每一项单独掷一次，任一项成功就是天使房。概率不能直接相加：只有基础 50% 和钥匙碎片1 的 25% 时，天使房概率是 1−0.5×0.75=62.5%。

| 来源 | 单独判定 |
| --- | --- |
| 基础 | 50% |
| 本层向捐款机捐满 10 个硬币 | 50% |
| 持有钥匙碎片1、钥匙碎片2 | 各 25% |
| 本层把乞丐喂到给出道具（见下注） | 10% |
| 本层炸死恶魔乞丐（仅忏悔） | 25%。忏悔+ 删掉了这项，改成开门概率 +35% |
| 本层献祭房祝福：第 3 次 / 第 5 次 / 两次都有 | 15% / 50% / 65% |
| 本层忏悔室祝福（忏悔起） | 每次 10%，10 次到 100% |
| 念珠段 | 忏悔 50%；忏悔+ 必定天使房 |
| 美德之书（忏悔起） | 持有时 12.5%，本局第一次交易必为天使房 |
| 圣餐 | 必定 |
| 本层把恶魔乞丐喂到给出道具 | 反向判定 10%，成功就强制恶魔房 |

注：Beggar 页面写明电池乞丐、腐烂乞丐给出道具也有这 10%，忏悔+ 起钥匙大师、炸弹乞丐也算；赌博乞丐不算。

::: info 忏悔起的天使房保底
- 本局第一扇恶魔房门出现后完全不进去，下一次交易必定是天使房。中途用鬼牌去天使房不会用掉这个保底。
- 还没遇到过交易时，在献祭房或忏悔室得到一次祝福，本层的交易必定是天使房。
:::

### 价格

| 情况 | 价格 |
| --- | --- |
| 一般 | 1 或 2 个红心容器，越强越贵 |
| 进房时没有红心容器 | 全部 3 个魂心 |
| 只剩 1 个红心容器 | 2 容器的交易照样能拿；忏悔起改收 1 容器 + 2 魂心 |
| 有骨心（忏悔起） | 骨心算容器，至少收 1 个红心容器 |
| 角色店主、持有一磅肉（忏悔起） | 付硬币：15 / 30。照样算交易 |
| ???（忏悔起） | 付魂心，数量等于原价（1 或 2）。里??? 没有这个效果 |
| 游魂、里游魂、灵魂状态的里雅各（忏悔起） | 免费拿 1 件，其余消失 |
| 带 devilsacrifice 标签的道具（忏悔+） | 改为踩尖刺：第 1 次 50% 给，第 2 次必给。拿了算交易 |

容器花光不会死，只要还有魂心、黑心或骨心。天使房的道具免费，多个只能拿一个；里店主要付钱，有的 30 硬币。

### 天使雕像与钥匙碎片

- 通关一次暗室或宝箱后，天使房的雕像能用炸弹炸醒。乌列（Uriel）掉钥匙碎片1，加百列（Gabriel）掉钥匙碎片2，两个天使轮流出现。
- 两块碎片打开暗室、宝箱起始房间的金门，去打超级撒但。
- 已有一块时，天使必定掉另一块；之前打过的天使也照样掉。忏悔起，同时炸醒两个雕像，两块都会掉。
- 持有银丝羽毛时，天使改掉天使房道具，不掉碎片。
- 别处的天使：献祭房第 9、11 次；超级隐藏房的一种教堂主题布局里有天使雕像，打赢也掉碎片。

## 献祭房

每层基础生成率 1/7；进层时总血量不少于红心容器数，总计约 36%。它有 1/50 被骰子房替换，带 2 把以上钥匙时约 22%。暗室、宝箱、虚空不会自然生成。

尖刺通常扣一整颗心，圣饼、巨蟹座能降到半颗；飞行也会被扎。无敌、护盾、神圣屏障、木十字架挡住伤害时不计次。装着红心的骨心不会被尖刺打碎，可以一直只付半颗红心。

| 本层第几次 | 结果 |
| --- | --- |
| 1、2 | 50% 无；50% 1 个硬币 |
| 3 | 33% 无；67% 祝福（天使房判定） |
| 4 | 50% 无；50% 1 个随机箱子 |
| 5 | 33% 3 个硬币；67% 更强的祝福 |
| 6 | 33% 传送到天使房（做过交易也行；本层已见过恶魔房则传回恶魔房）；67% 1 个箱子 |
| 7 | 33% 1 个天使房道具；67% 1 个魂心。做过交易时，魂心有 50% 换成赎罪（需已解锁） |
| 8 | 7 个即爆炸弹（忏悔前 6 个） |
| 9 | 乌列 |
| 10 | 50% 7 个魂心；50% 30 个硬币 |
| 11 | 加百列 |
| 12 及以后 | 50% 无；50% 直接传送到暗室 |

- 次数每层清零。奖励是提前定好的，不是踩的时候才抽。忏悔起，同一层有多个献祭房时各自计数。
- 献祭房里的天使不锁门，可以直接走出去，回来就没了。
- 第 12 次起的暗室传送，没解锁底片也能用。挑战里如果终点不是暗室，就什么都不发生。

## 商店

子宫之前每章都有，带着饰品银币时子宫也有。忏悔起第一层商店不上锁；饰品商店钥匙让商店都不用钥匙。

| 商品 | 价格 |
| --- | --- |
| 红心 | 3 |
| 魂心、炸弹、钥匙、小电池、胶囊、卡牌 | 5 |
| 福袋（忏悔起） | 7 |
| 道具 | 15；忏悔起部分主动道具 10 |

- **打折**：红色价签是半价。不是整数时，道具和福袋向下取整，拾取物向上取整。
- **Steam大促**：所有用硬币买的东西半价。
- **商店积分**（饰品）：下一次购买免费，然后消失。**信用卡**：整个商店免费。
- **补货**：买走的东西会补上；忏悔起每买一次涨价，最高 99。

### 商店等级

商店按捐款机的累计捐款升级。忏悔起，普通模式总是最高已解锁等级，困难模式在已解锁等级里随机。

| 等级 | 累计捐款 | 在售 |
| --- | --- | --- |
| 0 | 0 | 0～1 个拾取物，1～2 个道具 |
| 1 | 20 | 1～2 个拾取物，1～2 个道具 |
| 2 | 100 | 2～3 个拾取物，1～2 个道具 |
| 3 | 200 | 3～4 个拾取物，1～2 个道具 |
| 4 | 600 | 4～5 个拾取物，1～2 个道具 |

捐款机的其他奖励：10 蓝地图，50 额外选择（同时解锁更多选择），150 黑蜡烛，400 红蜡烛，900 蓝蜡烛，999 怀表。

### 贪婪

- 从第二章第二层起，进商店时可能被贪婪占据；从第三章第一层起隐藏房也可能。房间算小头目房，炸不出去。
- 先出贪婪，下次换成超级贪婪；两个都打过后，本局不再出现。持有贪婪的肋骨时，商店里不会出现。
- 接触伤害一整颗心。被它打中会丢 2～4 个硬币，其中 1～3 个掉在地上。打赢掉 7 个硬币（75%）或 Steam大促（25%）。
- 忏悔起的出现率：基础 33.3%；进层时硬币超过 20 个 +1.66%；上一层炸掉捐款机 +3.33%、炸掉店主 +0.66%；上一层每捐 1 个硬币 −1.66%，最多 −8.33%。范围 25%～39%。

::: tip 压低贪婪
离开这一层前往捐款机投 5 个硬币，下一层贪婪出现率 −8.33%，这一项已到上限。进层时硬币别超过 20 个。
:::

## 乞丐与机器

忏悔起困难模式下，普通乞丐和恶魔乞丐第一次给东西至少要 6 次，之后每次至少 3 次。

| 乞丐 | 收 | 给 | 炸掉 |
| --- | --- | --- | --- |
| 乞丐 | 硬币 | 心、炸弹、钥匙各 16.6%，卡牌 25%，早餐等食物 12.6%，道具 12.6% | 掉拾取物，开门概率 +35% |
| 恶魔乞丐 | 红心：第四章前半颗，第四章起一整颗 | 胶囊、卡牌各 25%，饰品 12.5%，恶魔乞丐道具 37.5%。普通模式第 8 次必给 | 掉 2 只蜘蛛。忏悔里天使判定 +25%，忏悔+ 改为开门概率 +35% |
| 钥匙大师 | 钥匙 | 65% 无，30.6% 箱子，4.4% 回形针或道具。忏悔+ 带金钥匙会立刻给道具 | 掉拾取物；忏悔+ 开门概率 +35% |
| 炸弹乞丐 | 炸弹 | 忏悔起：60% 无，26% 1～3 硬币，9% 心，5% 道具。忏悔+ 带金炸弹会立刻给道具 | 忏悔起免疫炸弹，会回敬一堆即爆炸弹 |
| 电池乞丐 | 硬币 | 81.25% 给主动道具充 1～3 格，10% 小电池，6.25% 道具，7号电池、钮扣电池各 1.25% | 掉拾取物，开门概率 +35% |
| 腐烂乞丐 | 硬币 | 蓝苍蝇、蓝蜘蛛各 36%，腐心 12%，骨心 4%，道具 4.16% 等 | 2 只小蛆，可能有腐心，开门概率 +35% |

| 地狱赌博乞丐（Hell Game） | 血 | 猜中给黑心、2 只蓝蜘蛛、2 炸弹、2 钥匙、2～3 硬币、卡牌或恶魔房道具 | 出蜘蛛，不影响交易概率 |

| --- | --- | --- | --- |

| 献血机 | 子宫前半颗心，子宫起一整颗 | 1～2 个硬币（困难 1 个），偶尔小孩的心脏。每次 6.66% 爆炸，给血袋或献血袋 | 若干硬币或心 |
| 夹娃娃机（Crane Game，需解锁） | 5 硬币 | 每次 25% 夹出道具，给 3 次后爆炸 | 若干拾取物 |
| 忏悔室（Confessional，需解锁） | 扣血，规则同献血机 | 中奖率 30%（困难 25%）：魂心、永恒之心、移除碎心，或祝福（移除一个诅咒，本层天使判定 +10%）；小概率爆炸给天使房道具，做过交易则给赎罪 | 拾取物，不影响交易概率 |
| 捐款机 | 1 硬币 | 累计跨局，升级商店。每次 2% 幸运 +1 | 忏悔起：掉 6～14 硬币，本局不再有捐款机，下局开始从总数扣回 |
| 补货机 | 硬币 | 刷新商店全部商品并补满空位，投得越多越容易成功 | 忏悔起一炸就坏 |

捐款机忏悔起的卡住率：本层第 1 个硬币 0.15%，之后每个再 +0.15%，换层重算；一旦卡住，本局剩下的捐款机都卡住。献血机、恶魔乞丐扣的血都不影响交易概率。

## 诅咒

诅咒只持续一层。会自然出现的有 6 种：

| 诅咒 | 效果 |
| --- | --- |
| 黑暗诅咒（Curse of Darkness） | 整层很暗，只有角色周围亮。忏悔起光圈更大，圈外更黑 |
| 迷失诅咒（Curse of the Lost） | 没有小地图，房间数上限 +4。显示地图的道具也救不回来 |
| 未知诅咒（Curse of the Unknown） | 不显示血量，忏悔起连神圣屏障图标也隐藏 |
| 迷宫诅咒（Curse of the Labyrinth） | 只在每章第一层。两层合成 XL 层：两个 Boss 房、两个宝箱房，算两层 |
| 致盲诅咒（Curse of the Blind） | 所有道具显示成问号，捡起才知道是什么 |
| 混乱诅咒（Curse of the Maze） | 进门偶尔被传到别的房间；忏悔起不再震屏提示 |

另有被诅咒的诅咒（Curse of the Cursed，普通门变诅咒房门，只在 Cursed! 挑战和 CVRS ED 种子里出现）和巨人诅咒（Curse of the Giant，正常游戏里遇不到）。

| 进度 | 普通 | 困难 |
| --- | --- | --- |
| 新存档 | 1/80 | 1/10 |
| 击败过妈妈 | 1/30 | 1/5 |
| 解锁 Everything Is Terrible!!!（击败妈妈的心脏 5 次） | 1/10 | 1/3 |
| 击败过以撒 | 1/5 | 1/3（忏悔前 1/2） |

被诅咒时 6 种各 1/6。抽到迷宫诅咒但本层不能出（每章第二层、子宫之后的章节、贪婪模式），这层就没有诅咒。所以这些层实际被诅咒的概率是表中的 5/6，比如困难模式满进度是 5/18。

| 解除方法 | 效果 |
| --- | --- |
| 黑蜡烛 | 免疫诅咒，拿到时清掉本层诅咒（迷宫诅咒除外） |
| 朝夕符文 | 清掉本层诅咒（迷宫诅咒除外），+1 魂心 |
| 太阳（Sol） | 打完本层 Boss 后清掉诅咒（迷宫诅咒除外） |
| 忏悔室的祝福 | 移除一个诅咒 |
| XIX-太阳（忏悔起） | 移除本层黑暗诅咒 |
| 小夜灯 | 移除拿到那层的黑暗诅咒；以后不免疫，但光锥能大幅减轻 |

迷宫诅咒不全是坏事：第一章的 XL 层两个宝箱房都不上锁，打完第二个 Boss 还可能开交易门。

## 隐藏房、超级隐藏房、究极隐藏房

### 隐藏房

- 通常挨着 3 个或 4 个房间，两种位置被选中的机会一样。挨 2 个的少见；只挨 1 个的，只在没有 3 邻以上的合法位置时才会出现，极少见。
- 不会挨着 Boss 房、超级隐藏房或另一个隐藏房。
- 入口墙前不会有坑、障碍物、尖刺，也不会是刷怪点。**每一个**相邻房间都得满足；有一个邻居的墙中间被挡住，就换地方找。
- 炸墙正中间。大房间按单格分段：从角落贴墙走，镜头开始移动的地方就是分段点。窄长房只可能在尽头那面墙。
- 从第三章第一层起可能被贪婪占据，打赢后所有相邻入口都会打开。

### 超级隐藏房

- 只挨一个房间，而且那个房间不是特殊房间。
- 它占「从起点走过去第二远」的死路：最远的是 Boss 房，第三远是商店。所以它离起点不比商店近，常在 Boss 房附近，或在商店和 Boss 房之间。
- 不会挨着隐藏房。

### 究极隐藏房（忏悔起）

- 不和任何房间直接相连。大多数地图效果不显示它，只有碎裂的宝珠、秘密之书的魂火（美德之书）、符文碎片能标出来。
- 进法：用红钥匙（或它的魂火）、水晶钥匙、红钥匙碎片、该隐的魂石开红房间，走进挨着它的红房间时它会显形并自动开门。也可以用 XVIII-月亮？ 直接传送进去，回去的路会自动铺成红房间。
- 位置：最常见于「透过四周的红房间能连到 3 个以上普通房间」的格子，这种格子比单个 2 邻格子可能性高约 11.5 倍。它旁边的红房间不能连到隐藏房、超级隐藏房、诅咒房，也不会挨 Boss 房或窄房间的侧面。
- 开红房间时，选能同时覆盖最多候选格子的那一面。没有合法位置时，这层可能没有究极隐藏房。

### 找房工具

| 用途 | 道具、卡牌、胶囊 |
| --- | --- |
| 直接打开隐藏房和超级隐藏房的入口 | X光透视；我能永远看清！（胶囊，仅当层） |
| 提示 | 狗牙（走进相邻房间时狼嚎）；嘿，听好！（飘到入口上方） |
| 在地图上标出隐藏房（仍需炸开） | 蓝地图、秘密之书、水晶球、思想、探窟帽、XIX-太阳、XXI-世界 |
| 传送 | XVIII-月亮 → 隐藏房；XVIII-月亮？ → 究极隐藏房 |
| 排除法 | 红钥匙不能覆盖隐藏房和超级隐藏房：本该有红门轮廓却没有的墙，后面可能就是 |
