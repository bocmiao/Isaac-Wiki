# 常见敌人与地形应对

<VersionBadge checked="2026-10" />

进房先看谁会封路、哪里能站，再决定先打谁。以下是走位原则，速度和弹数会受具体敌人、精英与版本影响。[前中期 Boss](/bosses/)。

| 威胁 | 怎么观察 | 怎么打 | 常见失误 |
| --- | --- | --- | --- |
| 追逐和冲锋 | 先看追人路线、冲锋轴线和前摇 | 横向让开；让怪离开窄通道后再输出 | 沿冲锋方向退到墙角 |
| 跳跃、钻地 | 看影子、落点和露头窗口 | 先离开原位置，显露后再射击 | 看不到本体就停在原地 |
| 定点吐弹 | 看弹幕空隙、是否瞄准当前站位 | 远距离给弹幕展开空间，侧移避开瞄准线 | 距离太近，弹幕还没展开就撞上 |
| 激光 | 看抬头、面向、发光等前摇 | 在激光发出前换角度 | 等激光出现后才穿过攻击线 |
| 召唤与分裂 | 看哪只会持续增加敌人 | 先减少数量；分裂怪可集中清一个分支 | 均匀打残所有目标，让数量一起增加 |
| 配对敌人 | 面具、心脏等存在关联目标 | 先找真正可受伤的目标 | 对保护端持续输出却不换角度 |
| 蜘蛛和跳蚤 | 突然改变方向，短距离迅速接近 | 保留侧移空间，不贴怪 | 低速站桩或踩蛛网后被围 |
| 炸弹与自爆 | 引线、即爆物和尸体附近的变化 | 先避爆炸，再回来收资源 | 为了一枚钱停在爆炸中心 |

## 躲弹时也要看地面

红色大便、火堆、尖刺、敌人留下的血迹会限制路线。飞行能改变部分地形通行，但不等于免疫所有伤害或机器付血。隔坑输出时先确认敌人是否会飞、是否能跨坑攻击。

窄桥、角落和单向出口容易让走位失去选择。进入大房间时先辨认可环绕区域，不把敌人引到自己唯一的退路上。

## 练习顺序

1. 先练边后退边射击，保持移动与射击方向独立。
2. 一房只选一个最危险目标，优先减少封路敌人。
3. 能清房后，再尝试贴近提高命中率；先学不受伤，再学快。
4. 复盘时区分怪物撞击、泪弹、地面和自己爆炸，针对来源改走位。
