# 道具说明怎么读

查到一个道具，先看**它会做什么**，再看代价、解锁条件和出现地点。品质高不一定适合这一局；会改变攻击方式的道具，尤其要先读完效果。

## 先分清五种东西

| 类型 | 怎么生效 | 捡之前看什么 |
| --- | --- | --- |
| 被动道具 | 通常捡到就生效 | 是否改变泪弹、造成自伤或减少生命 |
| 主动道具 | 按主动键使用，通常需要充能 | 现在手里的主动是否要换掉，新主动要充几格电 |
| 跟班 | 跟随角色、攻击或提供其他效果 | 伤害由跟班造成，未必吃角色的全部属性加成 |
| 饰品 | 占饰品槽，持有时提供效果 | 要换掉哪件；金饰品或妈妈的盒子如何加强，按具体效果看 |
| 卡牌、符文、魂石、胶囊 | 通常用一次就消耗 | 是否需要留给传送、开门或回血；未知胶囊尽量在安全房间使用 |

默认键盘主动键是 Space，卡牌 / 胶囊键是 Q，掉落键是 Ctrl。完整操作见[按键说明](/guide/start/controls)。

## 数值和符号是什么意思

| 写法 | 读法 |
| --- | --- |
| `↑` / `↓` | 提升 / 降低后面的属性 |
| `+1` | 在对应数值上加 1 |
| `×0.5` | 乘以 0.5，也就是变为原来的一半 |
| `20% 概率` | 每次符合条件时有机会触发，连续失败也不表示下次必定成功 |
| `当前房间` | 效果范围限于这个房间，离开后按道具说明结束 |
| `射速修正` | 与普通射速加成计算方式不同；标明可突破上限时，满常规射速后仍能提升 |
| `角色伤害` / `跟班伤害` | 看清由谁造成伤害，不把两者的加成直接互换 |

例如硫磺火会把普通泪弹换成蓄力激光。看到“射速下降”先别急着放弃：还要读它一次攻击打多少次、是否适合你现有的道具。反过来，单个伤害数值高，也可能需要更长的蓄力或更近的距离。

## 充能怎么读

“4 格常规充能”通常要清四个房间补满；计时充能靠等待，特殊充能按道具自身规则。电池、充能类道具和部分房间会改变回充速度。

难房或 Boss 战里需要主动就用；传送和重置类主动则留给它们要处理的房间。离开楼层前，检查有没有要拿回的旧主动。

## 解锁、拿到和收藏是三件事

1. **解锁**：满足成就条件，让物品可以出现。
2. **拿到**：这一局真的捡起它。解锁后仍需要从对应来源找到。
3. **收藏记录**：游戏 Stats → Items 记下你拿过的收藏道具。饰品、卡牌和胶囊不按这张道具收藏表统计。

“道具池”就是某类房间或奖励可以抽到的道具名单。例如列有恶魔房，只表示它可能在那里出现。本站来源表按忏悔版资料整理，忏悔+ 可能有调整；页首效果优先列忏悔+，旧版不同之处可以展开查看。

## 什么时候先查组合

已经有爆炸泪弹、激光、菜刀或其他泪弹替换时，拿新攻击道具前先查它们如何配合。涉及付血或复活时，再看当前角色的生命规则。
