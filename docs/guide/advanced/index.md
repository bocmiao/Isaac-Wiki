# 进阶思路

<FloorTrack :current="4" compact />

能稳定打败妈妈后，继续练躲弹，也开始练**怎么选道具和路线**：要不要做恶魔交易，钥匙先开哪扇门，这局准备打哪个 Boss。

按这个顺序读：

1. [机制详解](/strategy/mechanics)：恶魔房和天使房的出现规则、献祭房、商店和乞丐、诅咒、隐藏房。先弄懂规则，后面的取舍才有依据。
2. [道具取舍与流派](/strategy/items)：道具品质怎么看，哪些恶魔房、天使房道具值得拿，常见的强力组合。
3. [表角色攻略](/strategy/characters)：17 个表角色各自的机制和打法，适合用谁去打哪个目标。
4. Boss 打法：[（一）主线终局](/strategy/bosses)——妈妈的心脏、撒但、以撒、???、羔羊、超级撒但；[（二）死寂到祸兽](/strategy/bosses-2)——死寂、精神错乱、母亲、祸兽、究极贪婪。

::: tip 先定目标再开局
每局开始前先想好这局要打哪个 Boss、补哪个完成标记，再决定恶魔交易和资源怎么花。打开[解锁清单](/tools/tracker)看看还差什么。
:::

看不懂倍率、充能或道具池，先读[道具说明怎么读](./reading-items)；名字不认识，查[中英译名对照](/strategy/glossary)。
