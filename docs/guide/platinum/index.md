# 里角色与白金神

<FloorTrack :current="5" compact />

最后一层的目标是**白金神**（Dead God，全成就）。到这里你已经打过母亲、能回「家」，主要任务是解锁 17 个里角色、完成全部挑战、补齐角色标记，再查剩余成就与道具收集。

## 标记全满后还要检查什么 {#remaining}

**死亡证明不等于白金神**。死亡证明要求 34 个角色的全套困难完成标记，贪婪列要完成极贪；白金神还要求其余成就与全部道具收集。

1. 查看游戏内 Stats → Secrets，查未完成的挑战、每日挑战、胜利圈、连续获胜和其他特殊条件。本站清单只统计角色与标记，不覆盖全部成就。
2. 查看 Stats → Items。**解锁道具不等于收集道具**：还要实际拿到道具并被收集页记录，单纯看到底座不算。
3. 按正在玩的版本核对：公开成就表列出忏悔共 637 项、忏悔+共 641 项。忏悔+的白金神条件还包含新增四项：Play Online、Win Online、Win Online Daily、Item Descriptions；不能直接套用忏悔的离线完成列表。
4. 每日与联机有独立要求。每日挑战前关闭模组和控制台；忏悔+联机流程见[联机专题](/topics/coop)，不要在中途加入的局中判断正常解锁。

这里的白金神指 Dead God；旧版 Platinum God、The Real Platinum God 等是不同成就。全部三个存档栏都达成 Dead God 也是另外一层目标，当前栏位无需先做三档。
