# 里角色与白金神

<FloorTrack :current="5" compact />

最后一层的目标是**白金神**（Dead God，全成就）。到这里你已经打过母亲、能回「家」，剩下的是三块硬骨头：17 个里角色、全部挑战、以及把每个角色的完成标记补齐。

## 现在就能用的

- [角色解锁顺序](/guide/unlocks/order)：里角色怎么解锁（到「家」用红钥匙打开衣柜），以及完成标记是什么。
- [结局一览](/guide/unlocks/endings)：回家的完整流程。
- [解锁清单](/tools/tracker)：勾选里角色、记录 34 个角色的完成标记，进度一目了然。

- [挑战模式](/strategy/challenges)：全部挑战逐个讲解。
- [贪婪模式](/strategy/greed)：贪婪与极贪打法、捐款机和相关解锁。

白金神要求解锁游戏里其余全部成就，其中很大一部分来自角色完成标记、挑战和贪婪模式。按计划，这一层的攻略会在第三批陆续补齐。
:::
