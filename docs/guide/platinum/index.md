# 里角色与白金神

<FloorTrack :current="5" compact />

最后一层的目标是**白金神**（Dead God，全成就）。到这里你已经打过母亲、能回「家」，剩下的是三块硬骨头：17 个里角色、全部挑战、以及把每个角色的完成标记补齐。

## 现在就能用的

- [角色解锁顺序](/guide/unlocks/order)：里角色怎么解锁（到「家」用红钥匙打开衣柜），以及完成标记是什么。
- [结局一览](/guide/unlocks/endings)：回家的完整流程。
- [解锁清单](/tools/tracker)：勾选里角色、记录 34 个角色的完成标记，进度一目了然。

## 三块硬骨头

1. [里角色攻略](/strategy/tainted)：17 个里角色的机制、打法和先练顺序，以及里角色完成标记的合并解锁规则。
2. [挑战模式](/strategy/challenges)：45 个挑战的总表、先做哪些，以及常卡挑战的打法。
3. [贪婪模式](/strategy/greed)：贪婪与极贪的规则和打法，贪婪捐款机的累计里程碑。

另外，[种子](/strategy/seeds)一文列出了全部特殊种子，并标明哪些会禁用成就，冲成就时别误开。

::: info 白金神要花多久
白金神要求解锁游戏里其余全部成就，其中很大一部分来自角色完成标记、挑战和贪婪模式。用[解锁清单](/tools/tracker)记下进度，一项一项补。
:::
