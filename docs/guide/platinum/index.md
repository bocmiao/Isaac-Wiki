# 里角色与白金神

<FloorTrack :current="5" compact />

最后一层的目标是**白金神**（Dead God，全成就）。到这里你已经打过母亲、能回「家」，主要任务是解锁 17 个里角色、完成全部挑战、补齐角色标记，再查剩余成就与道具收集。

- [特殊成就详细教程](/achievements/special)：每日、胜利圈、连胜、无伤与道具收集查漏。

## 标记全满后还要检查什么 {#remaining}

**死亡证明不等于白金神**。「死亡证明」成就要求 34 个角色拿满全套困难完成标记，其中贪婪模式那一格要在极贪模式下完成。白金神除此之外，还要求其余所有成就和全部道具收集。

1. 查看游戏内 Stats → Secrets，查未完成的挑战、每日挑战、胜利圈、连续获胜和其他特殊条件。[角色清单](/tools/tracker)统计角色与标记；其余进度用[全成就打勾](/achievements/#catalog)记录。
2. 查看 Stats → Items。**解锁道具不等于收集道具**：还要实际拿到道具并被收集页记录，单纯看到底座不算。
3. 按正在玩的版本核对：公开成就表列出忏悔共 637 项成就，忏悔+共 641 项。忏悔+的白金神条件多了四项新成就：Play Online、Win Online、Win Online Daily、Item Descriptions。所以忏悔+玩家不能直接照搬忏悔的离线完成列表。
4. 每日挑战和联机有各自的要求。打每日挑战前要关闭模组和控制台。忏悔+的联机流程见[联机专题](/topics/coop)；中途加入的联机局本来就不能解锁，别拿它来判断解锁是否正常。

白金神即 Dead God 成就。旧版的 Platinum God、The Real Platinum God 等是不同的成就。三个存档栏都达成 Dead God 是另一层目标，拿当前存档栏的白金神不需要先做满三个栏位。
