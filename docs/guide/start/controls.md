# 基础操作

<VersionBadge checked="2026-10" draft />

以撒的操作是「左手移动、右手射击」：移动和射击方向分开控制。先把下面几个键记熟，其他的边玩边学。

## 键盘默认按键

| 操作 | 按键 |
| --- | --- |
| 移动 | <KeyCap>W</KeyCap><KeyCap>A</KeyCap><KeyCap>S</KeyCap><KeyCap>D</KeyCap> |
| 射击 | <KeyCap>↑</KeyCap><KeyCap>↓</KeyCap><KeyCap>←</KeyCap><KeyCap>→</KeyCap> |
| 放炸弹 | <KeyCap>E</KeyCap> |
| 使用主动道具 | <KeyCap>Space</KeyCap> |
| 使用卡牌 / 药丸 | <KeyCap>Q</KeyCap> |
| 查看地图 | 按住 <KeyCap>Tab</KeyCap> |
| 快速重开 | 按住 <KeyCap>R</KeyCap> |
| 暂停 | <KeyCap>Esc</KeyCap> |

::: tip 射击方向和移动方向是独立的
可以一边往后退一边朝前射击。新手最常见的问题是追着敌人打，被撞掉血。
:::
