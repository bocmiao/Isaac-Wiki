# 基础操作

<VersionBadge checked="2026-10" />

::: tip 速览
- **左手移动、右手射击**：WASD 移动，方向键射击（[按键表](#键盘默认按键)）
- **射击方向和移动方向独立**，可以边退边朝前打（[看提示](#键盘默认按键)）
- **常用键**：炸弹 E、主动道具 Space、卡牌 / 胶囊 Q、按住 R 重开（[按键表](#键盘默认按键)）
- **手柄插上就能玩**，改键要回主菜单的 Options → Controls（[手柄](#手柄)）
:::

以撒的操作是「左手移动、右手射击」：移动和射击方向分开控制。先把下面几个键记熟，其他的边玩边学。

## 键盘默认按键

| 操作 | 按键 |
| --- | --- |
| 移动 | <KeyCap>W</KeyCap><KeyCap>A</KeyCap><KeyCap>S</KeyCap><KeyCap>D</KeyCap> |
| 射击 | <KeyCap>↑</KeyCap><KeyCap>↓</KeyCap><KeyCap>←</KeyCap><KeyCap>→</KeyCap> |
| 放炸弹 | <KeyCap>E</KeyCap> |
| 使用主动道具 | <KeyCap>Space</KeyCap> |
| 使用卡牌 / 胶囊 | <KeyCap>Q</KeyCap> |
| 查看地图 | 按住 <KeyCap>Tab</KeyCap> |
| 快速重开 | 按住 <KeyCap>R</KeyCap> |
| 暂停 | <KeyCap>Esc</KeyCap> |

::: tip 射击方向和移动方向是独立的
可以一边往后退一边朝前射击。新手最常见的问题是追着敌人打，被撞掉血。
:::

## 手柄

PC 的按键可能经过游戏 Controls 或 Steam Input 改绑。下面给出完整的操作对照与推荐布局，**先以 Controls 和 Steam Input 里显示的绑定为准**，先在安全的起始房验证一次。

| 操作 | Xbox 风格推荐布局 | 怎么确认 |
| --- | --- | --- |
| 移动 | 左摇杆 | 能分别向四个方向走 |
| 射击 | 右摇杆或十字方向键 | 不移动也能射击；松开后停止 |
| 炸弹 | LB | 起始空房向远处试放一颗，立即走开 |
| 主动道具 | A | 看主动图标和充能变化 |
| 卡牌 / 胶囊 | RB | 使用前先认清内容，不用未知胶囊测试 |
| 丢弃 / 切换口袋 | RT | 短按切换，按住丢弃饰品；角色专属动作见角色页 |
| 地图 | View / Select | 按住看地图，确认不会误用卡牌 |
| 暂停 | Menu / Start | 进入暂停后再改游戏设置 |
| 菜单确认 / 返回 | A / B | 菜单和战斗键位分别确认 |
| 在线表情 | 按下右摇杆 | 仅对应在线入口，不是默认射击动作 |
| 重开 | 用键盘按住 R，或自行绑定 | 先退出要保留的局；不列未经核对的手柄组合键 |

### 设置和排查

1. 回到**主菜单**，进入 Options → Controls，选择正在使用的控制器。不要只在对局暂停菜单寻找完整改键页。
2. 按操作逐项绑定，尤其区分 Item、Pill / Card、Bomb、Drop。PlayStation / Switch 标识可按同样的功能位置设置，别只对照字母。
3. 在安全房测试移动、射击、暂停和地图，再测试有成本的动作。不要在挑战或待解锁目标快完成时改布局。
4. 如果一个按键触发两次或方向异常，检查 Steam 游戏属性的 Controller / Steam Input 是否又套了一层不同布局。保留一种清楚的映射，重新启动后复测。
5. 忏悔+ 可在暂停选项使用 Change Controller 更换控制器。合作中先确认每个完整角色分给哪只手柄，再出门战斗。

已保存资料核对：丢弃默认右扳机、按住约 3 秒丢饰品；在线表情按下右摇杆。菜单 A 确认、B 返回、Select 地图另对照 [IsaacDocs ButtonAction](https://github.com/wofsauge/IsaacDocs/blob/e05b1fd90e33608a7a7a8dcb70a89cef908cc41a/docs/enums/ButtonAction.md)。不同设备的完整默认映射尚未在当前 Windows 客户端实测，因此采用可操作的绑定流程，不再等待主机版截图。
