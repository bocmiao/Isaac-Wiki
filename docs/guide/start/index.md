# 开局准备

<FloorTrack :current="1" compact />

开第一局之前，花 10 分钟把下面三篇看完。顺序就是推荐的阅读顺序。

1. [基础操作](./controls)：键盘和手柄的按键、几个新手最容易忽略的操作。
2. [版本与 DLC 怎么买](./versions)：现在该买哪个版本，打折时怎么买最划算。
3. [中文设置与常见问题](./chinese)：中文怎么开、成就为什么不解锁。

::: warning 第一次通关前先别装模组
打开模组可能影响成就解锁。具体规则写在[配置与模组](/topics/mods)专题里。
:::
