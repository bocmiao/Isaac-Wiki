# 学习路线

整条路线分五层，用游戏里往下走的楼层做比喻。每一层只讲当下需要知道的东西，道具和数值直接链到 [wiki](https://bindingofisaacrebirth.wiki.gg/zh/)。

| 层 | 阶段 | 读完你应该能 |
| --- | --- | --- |
| 1 · 地下室 | [开局准备](/guide/start/) | 装好游戏、调好中文和按键，知道什么时候能装模组 |
| 2 · 洞穴 | [第一次通关](/guide/first-win/) | 认识各种房间，管好心和资源，打败妈妈 |
| 3 · 深处 | [解锁主线](/guide/unlocks/) | 按顺序解锁角色和结局 |
| 4 · 子宫 | [进阶思路](/guide/advanced/) | 判断恶魔房和天使房、道具值不值得拿 |
| 5 · 暗室 | [里角色与白金神](/guide/platinum/) | 上手里角色，规划全成就 |

::: tip 不知道自己在哪一层？
还没打败过妈妈，就从第 1 层开始。已经通关过几次，可以直接打开[解锁清单](/tools/tracker)，看看还差哪些。
:::
