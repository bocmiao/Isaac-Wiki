# 角色解锁顺序

<VersionBadge checked="2026-10" />

::: tip 速览
- **先拿 6 个顺手角色**：夏娃、参孙、该隐、抹大拉、拉撒路、阿撒泻勒（[第一批](#第一批-随手就能做的-6-个)）
- **伊甸、犹大、??? 跟着主线打 Boss 自然解锁**（[第二批](#第二批-跟着主线走)）
- **其余角色卡在结局或模式上**，按表从上往下做最省事（[推荐顺序](#推荐顺序)）
- **店主靠累计捐钱**，可以和别的目标同时进行（[店主](#hidden-keeper)）
- **里角色要打过母亲、能回「家」后**，用对应表角色逐个解锁（[里角色](#tainted-unlocks)）
:::

17 个表角色各自卡在不同的条件上，按[推荐顺序](#推荐顺序)从上往下做最省事。可以先在[角色速查与练习路线](/strategy/character-roster)找到对应攻略；解锁之后，别忘了看[开局强化表](/strategy/character-roster#upgrades)，尤其是以撒、游魂和店主。

## 表角色、里角色和游戏模式 {#character-types}

忏悔 / 忏悔+ 有 **17 个表角色 + 17 个里角色，共 34 个可选角色**；雅各和以扫按一组表角色计数。

- **表角色**：选人界面的常规角色，包括需要特殊任务解锁的游魂、店主和遗骸。
- **里角色 / 堕化角色（Tainted）**：每个表角色对应一个，拥有自己的机制与完成标记。它是另一组角色，**不是普通 / 困难之外的独立游戏模式**。
- **普通 / 困难**：普通主线的难度选择。大多数角色解锁可在普通模式完成，伯大尼明确要求困难模式。
- **贪婪 / 极贪**：独立于普通主线的模式。莉莉丝与店主的获取要走贪婪相关流程；极贪标记也要在对应模式完成。

### 解锁前先确认 {#unlock-checks}

- **本文按可获得成就的正常对局操作**：不开普通固定种子、不用每日挑战、挑战或胜利圈代替角色解锁局。暂停界面出现划掉的奖杯时，先排查[成就为什么不解锁](/guide/start/chinese#成就为什么不解锁)。彩蛋种子的影响另见[种子](/strategy/seeds)。
- **看清存档栏**：角色和路线的解锁都记录在当前存档栏；换存档栏不会继承。
- **分清版本**：忏悔与忏悔+ 的存档进度也要分别确认，切 DLC 后先看选人栏和统计页，别把另一版本的解锁当成本版已有。里角色需要忏悔内容，只有重生 / 胎衣 / 胎衣+ 的版本不能用这套回家流程。

## 第一批：随手就能做的 6 个

这几个都是一局之内完成的小目标，不需要打到很深：

- **夏娃**：连续两层不捡心。获得红心容器、用 Yum Heart 回血不算捡心。
- **参孙**：连续两层不受伤。建议从第一层就开始专心躲，失败了直接重开。
- **该隐**：手里同时有 55 枚硬币，花掉了就要重新攒。
- **抹大拉**：同时有 7 个或更多红心容器。
- **拉撒路**：同时有 4 个或更多魂心，黑心也算。
- **阿撒泻勒**：同一局里做 3 次恶魔交易。

## 第二批：跟着主线走

- **伊甸**：第一次通关子宫就解锁。之后每次打败妈妈的心脏、它活着、究极贪婪或祸兽，都会得到一枚伊甸币；每开一局伊甸消耗一枚。
- **犹大**：第一次打败撒但。去阴间的方法见[结局一览](/guide/unlocks/endings)。
- **???**：妈妈的心脏累计打 10 次。这一步同时开放蓝子宫和死寂。

## 贪婪模式：莉莉丝和店主

- **莉莉丝**：用阿撒泻勒在贪婪模式打败究极贪婪。
- **店主**：向打完究极贪婪后出现的贪婪捐款机累计捐 1000 枚，完整步骤见[店主：贪婪捐款机](#hidden-keeper)。

## 隐藏角色与特殊解锁 {#hidden}

“隐藏角色”是玩家对特殊解锁角色的常用称呼，不是额外的一组人数。最容易漏的是下面三位，它们已包含在 17 个表角色里；对应的里版本仍要用本人回家单独解锁。

| 角色 | 关键前置 | 本次要做的事 | 常见误区 |
| --- | --- | --- | --- |
| [游魂](#hidden-lost) | 以撒击败羔羊，解锁寻人启事 | 带着寻人启事在献祭房内死亡 | 解锁饰品不代表已拿到饰品；自带屏障是另一个解锁 |
| [店主](#hidden-keeper) | 能通关贪婪模式并给终点捐款机捐钱 | 当前存档累计捐到 1000 枚 | 普通商店捐款机不计入，角色口袋里的钱也不算 |
| [遗骸](#hidden-forgotten) | 已击败过羔羊，准备暗室路线 | 首层限时 → 铲子碎片 → Boss Rush → 暗室挖坟 | 光有铲子碎片或打完 Boss Rush 都还没解锁 |

### 游魂：寻人启事与献祭房 {#hidden-lost}

1. 先用**以撒**打败暗室里的羔羊，解锁饰品寻人启事（Missing Poster）。
2. 另开可解锁的正常局，实际找到并携带寻人启事。饰品被解锁只表示进入可出现范围，不会直接送到开局。
3. 找献祭房，确认进入房间时仍带着该饰品，在这个房间内死亡。
   - 房间里任何死法都算；被传送离开后在外面死亡不算。
   - 连续踩献祭尖刺可能触发传送，接近后段奖励时先考虑如何在房间内完成死亡，别无意识一直踩。
4. 触发解锁后以游魂复活，可以继续这局；后续选人时也能选择游魂。

**不要把解锁角色与神圣屏障混为一谈**：屏障要向贪婪捐款机累计捐 879 枚硬币才有。当前忏悔版本也不使用重生初版那套多角色连续死亡的旧解锁法。

### 店主：贪婪捐款机 {#hidden-keeper}

1. 开贪婪模式，用自己能稳定通关的角色打败究极贪婪。
2. 留钱给 Boss 战后出现的**贪婪捐款机**，实际投进去的硬币才计入。
3. 跨局、跨角色累计到 1000 枚时解锁店主。中途 500 枚开放极贪模式，879 枚给游魂开局屏障。
4. 捐款机卡住就结束本次捐款，之后换角色或另开一局继续；不是一局必须存够 1000 枚。单角色的卡机风险分别记录，换角色捐款有助于推进总额。

普通商店的捐款机与它不是同一个计数。解锁店主后，先用店主击败以撒（Boss）拿木制镍币，再争取死寂解锁第 3 个硬币心，见[开局强化表](/strategy/character-roster#upgrades)。

## 第三批：要打第 6 章

- **亚玻伦**：打败超级撒但。金门的条件和钥匙碎片的拿法见[结局一览](/guide/unlocks/endings)。

## 第四批：多步任务

### 遗骸：铲子任务全流程 {#hidden-forgotten}

前提是已经打败过一次羔羊。推荐先解锁底片，准备好常规阴间 → 暗室路线，再用阿撒泻勒等首层清房快的角色尝试：

1. 非种子局，在 1 分钟内打败第一层的 Boss，听到妈妈的提示后回到本层起始房间，放炸弹炸出铲子碎片（Broken Shovel）。
   - 计时按本局开始算，不是进 Boss 房才开始。
   - 推荐先用没有迷宫诅咒的首层练流程。
2. 拿着它时妈妈的脚会不定时踩你。好处是 Boss Rush 的时间限制取消了，但必须打完 Boss Rush 才能去下一层。
3. 打完 Boss Rush 得到另一半，拼成妈妈的铲子（Mom's Shovel）。铲子碎片阶段的踩脚压力到这里结束，但任务还没完成。
4. 拿着铲子时，教堂的光柱不会出现，只能走阴间。所以要在妈妈那里拿底片（需要已解锁），打完撒但碰箱子进暗室。
5. 暗室里有一间坟墓房，站在中间的土堆上用铲子。等灵魂升到屏幕顶端再离开房间，否则可能不解锁。

::: warning 铲子任务中途检查
首层是否达成限时、有没有炸弹炸起始房、主动栏里是否还带着铲子、妈妈处有没有拿底片，是最容易漏的四项。铲子主动的暂时保护不等于永久停止踩脚；不要拿到其他主动就忘记把任务道具带走。
:::

### 伯大尼：困难模式与不死要求

**伯大尼**：用拉撒路开困难模式，打败妈妈的心脏或它活着，全程一次都不能死，包括不能触发拉撒路自带的复活；这局不要按每层主动死亡换属性的打法玩。

## 最后：雅各和以扫

用任意角色打败母亲。这条路要先把死寂打 3 次，再在一局里集齐两块菜刀碎片，具体见[结局一览](/guide/unlocks/endings)。打败母亲还会开放回「家」的路，里角色就从这里开始。

## 里角色怎么解锁 {#tainted-unlocks}

每个表角色都有一个对应的里角色（Tainted，游戏内中文叫「堕化」），**必须逐个解锁**。解锁一个不会开放全部里角色。先解锁目标表角色，再用它本人完成下面的流程；普通难度就可以做，不要求困难标记，也不要求击败祸兽。

### 到家之前：完整准备流程 {#tainted-route}

1. **先开放回家路线**：累计击败死寂 3 次，开放隐藏路线；走尸宫击败一次母亲，开放深处 II 的奇怪的门。完整母亲路线见[结局一览](/guide/unlocks/endings)。母亲和妈妈是不同 Boss，打普通妈妈不能代替。
2. **选目标表角色开新局**：例如要里游魂就选游魂，要里店主就选店主；不是选任意角色到家后再挑目标。
3. **提前留下钥匙材料**：在捡爸爸的便条前，往一间宝箱房或 Boss 房里丢一个饰品，记住楼层与房间。第一次到家保证有红钥匙，之后推荐每次都提前留饰品，避免依赖随机掉落。
4. **在深处 II 准备传送**：炸开带标记的特殊头骨，取得 0-愚者（The Fool），保留到妈妈战后。也可用能离开妈妈房的其他可靠传送手段。
5. **击败妈妈，拿全家福或底片**：用传送回本层起始房，带着刚拿的道具打开奇怪的门；开门会消耗它。别选错向下走普通子宫，也别提前把传送卡用掉。
6. **进入特殊陵墓 II，捡爸爸的便条**：这次进入上行（Ascent）流程，沿各层起始房的光柱向上回走；先前丢在宝箱房 / Boss 房的饰品会变成红钥匙碎片。
7. **回程领取红钥匙碎片**：到之前留饰品的同一间房拿碎片，保留到家。饰品带在身上不会自动变成碎片；到家后再丢饰品也来不及补这个准备步骤。
8. **地下室 I 通过光柱到家**：先去开里角色的隐藏房，再决定是否睡觉触发教条与祸兽路线。

### 到家之后：开门、接触、确认 {#tainted-door}

1. 第一次到家，打开妈妈卧室的箱子，必定拿到红钥匙（Red Key），同时永久解锁这个道具；第二次以后箱子不保证再给。
2. 回到**妈妈卧室前的走廊**，在**左侧墙**对应位置使用红钥匙或红钥匙碎片（Cracked Key）。开的是隐藏房入口，不是普通卧室箱子。
3. 进入隐藏房，接触正在里面的里角色。接触并出现解锁提示才算完成，单纯开门不够。
4. 回到选人界面，键盘 <KeyCap>E</KeyCap>、手柄 <KeyCap>RB</KeyCap> 切换到里角色列表，确认对应角色已可选。达到条件后这局再失败也不影响解锁。

已拥有该隐的魂石（Soul of Cain）时，它也能用于开启这间隐藏房；新手优先按留饰品 → 红钥匙碎片的方案准备，不必依赖这块魂石。

### 到家了却没解锁：按这张表排查

| 情况 | 原因与处理 |
| --- | --- |
| 卧室箱子没有红钥匙 | 只有首次保证获得；以后要提前留饰品，回程带红钥匙碎片 |
| 留了饰品却找不到碎片 | 确认是在捡便条前丢进宝箱房 / Boss 房，回程去同层同房领取；身上带着不算 |
| 只打过妈妈，深处 II 没有奇怪的门 | 还没击败隐藏路线终点的母亲 |
| 拿不到想要的里角色 | 本局必须使用对应表角色，不是任意角色都能解锁任意里角色 |
| 门开了但选人里仍锁着 | 还要进去接触角色，并确认本局没有禁用解锁的奖杯标记 |
| 以为要再打祸兽才算 | 接触角色即完成，祸兽是后续独立目标 |
| 找不到“里模式”开关 | 在选人界面切换角色列表，再选择普通 / 困难或贪婪模式；没有独立的里角色难度 |

## 变身与 NPC 不用另找解锁任务 {#character-forms}

下面几种身份常被误认为遗漏的隐藏可选角色，它们不额外增加选人栏的 34 个名额：

| 名称 | 如何出现 | 与可选角色的关系 |
| --- | --- | --- |
| 犹大之影 / 黑犹大（Dark Judas） | 持有犹大的影子（Judas' Shadow）后死亡复活 | 复活形态，不是额外一位表角色，也不等于里犹大 |
| 复活的拉撒路（Lazarus Risen） | 表拉撒路触发自带复活 | 同一个角色的复活形态，不等于里拉撒路 |
| 遗骸之魂（The Soul） | 使用遗骸的切换能力 | 表遗骸的另一种形态；里遗骸也有自己的灵魂与身体玩法 |
| 里以扫（Dark Esau） | 使用里雅各时追逐他的角色 | 里雅各的机制组成，不是另一个可选里角色 |

## 完成标记是什么

角色选择界面上的便利贴记录这个角色完成了哪些目标，每个角色 12 项：

妈妈的心脏 / 它活着、以撒、撒但、???、羔羊、超级撒但、Boss Rush、死寂、究极贪婪、精神错乱、母亲、祸兽。

- 普通模式完成是实心黑色，困难模式完成是红色描边。困难模式完成会同时算作普通模式完成。
- 究极贪婪这一格区分贪婪模式和极贪模式。
- 精神错乱不画标记，而是让便利贴变得破破烂烂，困难模式还会带血。
- 里角色也有自己的一套完成标记。其中 Boss Rush 和死寂合起来解锁一样东西，以撒、???、撒但、羔羊四个合起来再解锁一样。

清单里的普通 / 困难是同一格的两个状态；贪婪列的困难状态指极贪模式。全困难标记与死亡证明的条件见[角色速查的标记说明](/strategy/character-roster#marks)。
