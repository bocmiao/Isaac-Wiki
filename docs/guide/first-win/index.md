这一层的目标只有一个：**打败妈妈**。下面四篇按顺序读，边玩边练房间判断、资源分配和走位。

1. [新手前 10 局该注意什么](./first-runs)：一份开局清单，先养成几个好习惯。
2. [房间类型入门](./rooms)：每种房间里有什么、进去要付出什么、该不该进。
3. [心、钱、炸弹、钥匙怎么用](./pickups)：各种心的区别，资源该花在哪。
4. [第一次打妈妈](./mom)：妈妈在哪、怎么躲、打完之后会发生什么。

::: tip 死了不要紧
以撒每一局都是随机的，死掉就重开。前几局的目标是熟悉房间和操作，不是一次通关。
:::
