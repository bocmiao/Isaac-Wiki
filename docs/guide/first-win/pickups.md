# 心、钱、炸弹、钥匙怎么用

<VersionBadge checked="2026-10" />

::: tip 速览
- **受伤先扣血条最右边的魂心、黑心**，最后才扣红心（[扣血顺序](#受伤时先扣哪颗)）
- **硬币主要花在商店**，道具一般 15 个（[价目](#硬币)）
- **炸弹先留着**炸隐藏房和带 X 记号的石头（[用途](#炸弹)）
- **钥匙先留给宝箱房和商店**，普通主线地下室 I 这两间通常不用钥匙（[钥匙](#钥匙)）
- **基础硬币、炸弹、钥匙上限各 99；[深口袋](/items/c416)可使硬币上限达到 999**（[资源管理](#新手资源管理)）
:::

## 心：你的血量

普通角色通常最多有 12 颗心的血条；魂心、骨心和特殊角色不能一概任意组合。店主、游魂、伯大尼等的生命限制与[特殊角色生命规则](/strategy/health)分别说明。

| 心 | 作用 |
| --- | --- |
| 心之容器（Heart Container，也叫红心容器） | 红心的「格子」。道具、Health Up 胶囊能加，恶魔房交易会扣 |
| 红心、半颗红心（Red Heart） | 补进心之容器。红心不能超过容器数量，多补的直接浪费 |
| 魂心（Soul Heart） | 蓝色的心，接在血条末尾。没有容器，掉了就没了 |
| 黑心（Black Heart） | 和魂心一样。被扣完时，对房间里所有敌人造成 40 点伤害 |
| 永恒之心（Eternal Heart） | 总是半颗。带到下一层，或同一层吃到第二个，就变成一个新的红心容器。伤害消耗时机需要结合血条组成与版本判断，不能当作额外半颗普通红心 |
| 双红心（Double Heart） | 一次补两颗红心 |

下面几种要先解锁，刚入门可能还见不到：

- **骨心（Bone Heart）**：一个骨头做的容器，可以装红心。装着红心时，要挨三下扣半颗心的攻击才碎；如果每下扣一整颗心，挨两下就碎。碎了就没了。
- **腐心（Rotten Heart）**：占一个红心容器，但每颗只抵半颗心。每清一个房间，每颗腐心最多生出 2 只蓝苍蝇帮你打怪。
- **金心（Gold Heart）**：一圈金边套在最后一颗心上，本身不加血。那颗心掉了时会爆出 3～8 个硬币。

## 受伤时先扣哪颗

血条从左到右是：红心（含空容器）和腐心，后面接魂心、黑心、骨心（按拿到的先后排）。普通受伤从最右边往左扣，有两排时先扣下面那排。所以一般是：

1. 先扣最右边的魂心、黑心或骨心；骨心里装着红心时，先扣里面的血，再碎骨头。
2. 再扣腐心。
3. 最后才扣红心。

永恒之心是特殊附加效果，不直接套用红心或魂心的扣除顺序。不同血条组成的扣除时机尚未独立实测，保守打法是尽量避免受伤并带到下层；不要拿半颗白心预算“还能挨一下”。

扣多少：前三章（地下室、洞穴、深处）大多数攻击只扣半颗心，从第四章子宫开始变成一整颗。自己的炸弹炸到自己，扣一整颗。

::: warning 献血机这类东西先扣红心
献血机（Blood Donation Machine）、恶魔乞丐（Devil Beggar）这类主动扣血的东西，会先把红心扣光，再扣魂心。献血机在子宫之前每次扣半颗心。
:::

::: tip 掉魂心不影响恶魔房
恶魔房出现率只看你有没有被扣过红心。被扣魂心、黑心、骨心、腐心、永恒之心都不算，献血机这类自己主动扣的血也不算。详见[房间类型入门](/guide/first-win/rooms)。
:::

## 硬币

普通硬币（Penny）算 1 枚，五分币（Nickel）算 5 枚，一角币（Dime）算 10 枚。解锁后还会见到幸运币（Lucky Penny，捡到 +1 运气）和粘地镍币（Sticky Nickel，粘在地上，要用爆炸炸松才能捡）。

| 花在哪 | 价钱 | 备注 |
| --- | --- | --- |
| 商店（Shop） | 见下表 | 红色价签半价 |
| 乞丐（Beggar） | 碰一下捐一次 | 可能给心、炸弹、钥匙、卡牌，偶尔给道具，给了道具就消失 |
| 赌博机（Slot Machine）、预言机（Fortune Telling Machine） | 每次 1 枚 | — |
| 夹娃娃机（Crane Game） | 每次 5 枚 | 解锁后会出现在赌博房 |
| 赌博房（Arcade）的门 | 1 枚 | — |
| 捐款机（Donation Machine） | 每次 1 枚 | 累计数会跨局保存，攒够了能升级商店、解锁新东西 |

### 商店价目

| 商品 | 价钱 |
| --- | --- |
| 红心 | 3 枚 |
| 魂心、炸弹、钥匙、小电池（Lil' Battery）、胶囊、卡牌 | 各 5 枚 |
| 福袋（Grab Bag） | 7 枚 |
| 道具 | 15 枚（部分主动道具 10 枚） |

红色价签的商品半价。

## 炸弹

按 <KeyCap>E</KeyCap> 放炸弹。炸到敌人造成 100 点伤害，炸到自己扣一整颗心。用途：

- **炸隐藏房**：站在墙正中间炸。找法见[房间类型入门](/guide/first-win/rooms)。
- **炸石头**：标记石头（Tinted Rock，带 X 记号的石头）炸开会掉 1～2 个奖励，最常见的是魂心，也可能是钥匙、炸弹或金箱子（Locked Chest）。炸普通石头有小概率露出通往夹层（Crawl Space）的活板门。
- **炸开门**：房间里还有怪时，炸开普通的门就能先跑出去。
- **开石箱子（Stone Chest）**：灰色、像石头的箱子，只能用爆炸打开。
- **炸机器和乞丐**：赌博机、乞丐被炸掉会掉一些拾取物；商店店主（Shopkeeper）也能炸，可能有奖励。

拾取物和箱子会被爆炸推开，小心别把它们炸进尖刺或坑里。

炸弹拾取物有几种：

| 拾取物 | 效果 |
| --- | --- |
| 双炸弹 | 给 2 个 |
| 金炸弹 | 这一层放炸弹不消耗数量 |
| 即爆炸弹（Troll Bomb） | 捡不起来，出现时已经点着，炸到你扣一整颗心，看到就跑开 |

## 钥匙

| 用在哪 | 要几把 |
| --- | --- |
| 宝箱房、商店 | 第 1 层免费，之后各 1 把 |
| 图书馆（Library） | 1 把 |
| 金箱子 | 1 把。没钥匙时碰它只会把它推走 |
| 钥匙块（Key Block） | 1 把 |
| 宝库（Vault）、骰子房（Dice Room） | 2 把 |

金钥匙（Golden Key）不加钥匙数，但这一层用钥匙都不再消耗。充能钥匙（Charged Key）捡到时还会顺便给主动道具充电。

## 新手资源管理

基础硬币、炸弹、钥匙上限各 99；[深口袋](/items/c416)可使硬币上限达到 999。

1. **第一层尽量别花钥匙。** 宝箱房和商店都是免费的，把钥匙带到第二层。
2. **每层先给宝箱房留 1 把钥匙。** 金箱子、钥匙块、图书馆往后排。
3. **炸弹别拿来炸普通小怪。** 每层至少留 1～2 个找隐藏房和超级隐藏房。
4. **进每章第二层前留 5 个硬币。** 离开上一层时有 5 个以上硬币，第二层才可能出赌博房。
5. **别炸捐款机。** 从忏悔（Repentance）起，炸掉捐款机后，这局就不会再出现捐款机，炸出来的钱还会从累计数里扣掉。
6. **满血进新层。** 进层时总血量不少于心之容器数，这层才可能有挑战房，献祭房也更容易出现。
7. **局末用不掉的硬币**，可以投进商店的捐款机。

更多变体见[拾取物与宝箱图鉴](/pickups/)，付机器前看[机器与乞丐](/strategy/machines)。
