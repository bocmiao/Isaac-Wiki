# 心、钱、炸弹、钥匙怎么用

<VersionBadge checked="2026-10" />

先记住四句话：受伤时先扣血条最右边的魂心、黑心，最后才扣红心；硬币主要花在商店；炸弹先留着炸隐藏房和带 X 记号的石头；钥匙先留给宝箱房和商店（第一层这两间不用钥匙）。硬币、炸弹、钥匙各最多存 99 个。

## 心：你的血量

血条最多放 12 颗心，各种心可以任意组合。

| 心 | 作用 |
| --- | --- |
| 红心、半颗红心（Red Heart） | 补进心之容器。红心不能超过容器数量，多补的直接浪费 |
| 心之容器（Heart Container） | 红心的「格子」。道具、Health Up 药丸能加，恶魔房交易会扣 |
| 魂心（Soul Heart） | 蓝色的心，接在血条末尾。没有容器，掉了就没了 |
| 黑心（Black Heart） | 和魂心一样；扣完时对房间里所有敌人造成 40 点伤害 |
| 永恒之心（Eternal Heart） | 总是半颗。带到下一层，或同一层吃到第二个，就变成一个新的红心容器；第一次受到红心伤害就会消失 |
| 双红心（Double Heart） | 一次补两颗红心 |

下面几种要先解锁，刚入门可能还见不到：

- **骨心（Bone Heart）**：一个骨头做的容器，可以装红心。装着血时要挨三下才碎（遇到一下扣一整颗的攻击是两下），碎了就没了。
- **腐心（Rotten Heart）**：占一个红心容器，但每颗只抵半颗心。每清一个房间，每颗腐心最多生出 2 只蓝苍蝇帮你打怪。
- **金心（Gold Heart）**：一圈金边套在最后一颗心上，本身不加血。那颗心掉了时会爆出 3～8 个硬币。

## 受伤时先扣哪颗

血条从左到右是：红心（含空容器）和腐心，后面接魂心、黑心、骨心（按拿到的先后排）。普通受伤从最右边往左扣，有两排时先扣下面那排。所以一般是：

1. 先扣最右边的魂心、黑心或骨心；骨心里装着红心时，先扣里面的血，再碎骨头。
2. 再扣腐心。
3. 最后才扣红心。

永恒之心比较特殊：第一次受到红心伤害就没了。

扣多少：前三章（地下室、洞穴、深处）大多数攻击只扣半颗心，从第四章子宫开始变成一整颗。自己的炸弹炸到自己，扣一整颗。

::: warning 献血机会先扣红心
献血机（Blood Donation Machine）、恶魔乞丐（Devil Beggar）这类主动扣血的东西，会先把红心扣光，再扣魂心。献血机在子宫之前每次扣半颗心。
:::

::: tip 掉魂心不影响恶魔房
恶魔房出现率只看你掉没掉红心。掉魂心、黑心、骨心、腐心、永恒之心都不算；献血机这类自己扣的血也不算。详见[房间类型入门](/guide/first-win/rooms)。
:::

## 硬币

普通硬币（Penny）值 1，五分币（Nickel）值 5，一角币（Dime）值 10。解锁后还会见到幸运币（Lucky Penny，捡到 +1 运气）和粘地镍币（Sticky Nickel，粘在地上，要用爆炸炸松才能捡）。

| 花在哪 | 价钱 |
| --- | --- |
| 商店（Shop） | 红心 3；魂心、炸弹、钥匙、小电池（Lil' Battery）、药丸、卡牌各 5；福袋（Grab Bag）7；道具 15，部分主动道具 10。红色价签半价 |
| 乞丐（Beggar） | 碰一下捐一次硬币。可能给心、炸弹、钥匙、卡牌，偶尔给道具，给了道具就消失 |
| 老虎机（Slot Machine）、算命机（Fortune Telling Machine） | 每次 1 个 |
| 抓娃娃机（Crane Game） | 每次 5 个，解锁后会出现在赌场 |
| 赌场（Arcade）的门 | 1 个 |
| 捐款机（Donation Machine） | 每次 1 个。累计数会跨局保存，攒够了能升级商店、解锁新东西 |

## 炸弹

按 <KeyCap>E</KeyCap> 放炸弹。炸到敌人造成 100 点伤害，炸到自己扣一整颗心。用途：

- **炸隐藏房**：站在墙正中间炸。找法见[房间类型入门](/guide/first-win/rooms)。
- **炸石头**：带 X 记号的石头（Tinted Rock）炸开会掉 1～2 个奖励，最常见的是魂心，也可能是钥匙、炸弹或金箱子（Locked Chest）。炸普通石头有小概率露出通往爬行空间（Crawl Space）的活板门。
- **炸开门**：房间里还有怪时，炸开普通的门就能先跑出去。
- **开石箱子（Stone Chest）**：灰色、像石头的箱子，只能用爆炸打开。
- **炸机器和乞丐**：老虎机、乞丐被炸掉会掉一些拾取物；商店店主（Shopkeeper）也能炸，可能有奖励。

拾取物和箱子会被爆炸推开，小心别把它们炸进尖刺或坑里。

炸弹拾取物有几种：双炸弹给 2 个；金炸弹让你这一层放炸弹不消耗数量；坑人炸弹（Troll Bomb）捡不起来，出现时已经点着，会炸你一整颗心，看到就跑开。

## 钥匙

| 用在哪 | 要几把 |
| --- | --- |
| 宝箱房、商店 | 第 1 层免费，之后各 1 把 |
| 图书馆（Library） | 1 把 |
| 金箱子 | 1 把。没钥匙时碰它只会把它推走 |
| 钥匙块（Key Block） | 1 把 |
| 金库（Vault）、骰子房（Dice Room） | 2 把 |

金钥匙（Golden Key）不加钥匙数，但这一层用钥匙都不再消耗。充能钥匙（Charged Key）捡到时还会顺便给主动道具充电。

## 新手资源管理

1. **第一层尽量别花钥匙。** 宝箱房和商店都是免费的，把钥匙带到第二层。
2. **每层先给宝箱房留 1 把钥匙。** 金箱子、钥匙块、图书馆往后排。
3. **炸弹别拿来炸普通小怪。** 每层至少留 1～2 个找隐藏房和超级隐藏房。
4. **进每章第二层前留 5 个硬币。** 离开上一层时有 5 个以上硬币，第二层才可能出赌场。
5. **别炸捐款机。** 在 Repentance 里炸掉它，这局之后就不会再出捐款机，炸出来的钱还会从累计数里扣掉。
6. **满血进新层。** 进层时总血量不少于心之容器数，这层才可能有挑战房，献祭房也更容易出现。
7. **局末用不掉的硬币**，可以投进商店的捐款机。
