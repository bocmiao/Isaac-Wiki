# 第一次打妈妈

<VersionBadge checked="2026-10" />

::: tip 速览
- **看到影子就走开**：开场第一脚固定踩房间正中（[四种攻击](#她的四种攻击)）
- **别贴着门站**：手和眼睛都从四面墙的门里伸进来（[四种攻击](#她的四种攻击)）
- **一直保持移动**：她总朝你当前的位置踩（[打法](#打法建议)）
- **小怪只清挡路的**：妈妈一死，小怪跟着死（[打法](#打法建议)）
- **第一次打赢直接播结局**，同时解锁子宫等一大批内容（[打赢以后](#打赢以后会发生什么)）
:::

妈妈（Mom）固定在深处 II（Depths II），也就是一路往下走的第 6 层。第一次打赢后这一局就此结束，同时解锁第 4 章子宫等一大批内容。

## 她在哪一层

- 第 1 到第 3 章每章两层：地下室（Basement）、洞穴（Caves）、深处（Depths）。深处 II 的 Boss 永远是妈妈，不会随机换成别的。
- 妈妈的房间四面墙正中各有一扇门，她的攻击大多从这些门里来。
- 打起来就别想从门溜走：能从里面打开 Boss 房门的道具，对妈妈都无效。所以进门前先把这一层的宝箱房和商店逛完。
- 以后解锁隐藏路线，还会遇到更强的妈妈：一次连踩三脚，眼睛会射激光。新手暂时不用管。

## 她的四种攻击

她不会整个出现在房间里：脚从头顶踩下来，手和眼睛从四面墙的门里伸进来，还会从门口放小怪。

| 攻击 | 怎么看出来 | 怎么应对 |
| --- | --- | --- |
| 踩脚 | 你所在的位置出现一个越来越大的影子，同时听到她的哼声 | 马上走出影子。开场第一脚固定踩房间正中，开局别站中间 |
| 伸手 | 你靠近某扇门时，手从那扇门伸出来 | 别贴着门站 |
| 伸眼睛 | 眼睛从门里探出来，本身不攻击 | 别撞上去 |
| 放小怪 | 门口伸出一块肉，冒出一只怪，场上最多同时 3 只 | 挡路的先清掉 |

被她碰到一次扣整整一颗心。忏悔版（Repentance）里，踩下来的脚算接触伤害，以前能防爆炸的道具挡不住。踩脚也会砸碎障碍物、伤到附近的小怪。

## 打法建议

1. 进门前尽量多攒血。每下都是一颗心，只有 3 颗心的以撒，被碰 3 下就没了。
2. 开场离房间正中远一点。
3. 平时站在离门有点距离的地方，小步来回走。她总是朝你当前的位置踩，停在原地最容易被踩中。
4. 小怪别恋战。妈妈一死，她放的小怪会跟着死（Globin 会留下一滩肉泥），所以只清挡路的，把火力留给妈妈。
5. 不认识的胶囊别在这场里吃，吃到麻痹会 2 秒动不了。也别用「II-女祭司」（The High Priestess）卡：打妈妈时它会踩你自己，扣一颗心（走开可以躲掉）。
6. 有主动道具就按 <KeyCap>Space</KeyCap> 用掉，打 Boss 正是用它的时候。

::: tip 圣经可以秒杀妈妈
主动道具圣经（The Bible）在妈妈战里使用，会直接杀死她，对妈妈的心脏和它活着也一样。用这种方法打赢还会解锁一个新道具。圣经可能出现在商店、天使房和图书馆里。但千万别对撒但用，那会直接杀死你自己。
:::

## 打赢以后会发生什么

**第一次打败妈妈**，游戏直接播放结局动画（Epilogue）和制作人员名单，这一局结束。就算用时在 20 分钟内，第一次也不会开 Boss Rush（游戏内叫头目车轮战）。同时解锁：

| 解锁 | 说明 |
| --- | --- |
| 子宫（Womb） | 第 4 章。以后再打败妈妈，就能继续往下走 |
| 天启骑士（The Harbingers） | 饥荒、瘟疫、战争、死亡四骑士开始作为 Boss 出现 |
| 新道具 | Cube of Meat 和 Ball of Bandages |
| 挑战 | 一批新挑战 |
| 道具说明 | 忏悔+（Repentance+）专属，可以在设置里打开 |

另外，之后每层被诅咒的几率会变高：普通模式从 1/80 升到 1/30。

**以后再打败妈妈**：

- 房间的四扇门全部消失，只能从活板门往下走，进入子宫。
- 她会掉一个随机 Boss 道具。等你以后解锁了全家福（The Polaroid）和底片（The Negative），就改成这两个里选一个。
- 20 分钟内打败她，会多出一扇通往 Boss Rush 的门。
- 从子宫开始没有宝箱房和商店，而且受到的任何伤害都按一整颗心算。

::: info 什么时候能装模组
打败妈妈之前，开着模组玩是解锁不了成就的；打败一次之后就没有这个限制了。想装模组，至少先打败一次妈妈。
:::

## 妈妈的心脏和它活着

子宫 II（第 8 层）的固定 Boss 是妈妈的心脏（Mom's Heart）。

- 前几个阶段，它会升到画面上方变成无敌，一边放弹幕一边召唤小怪；小怪清光它才会降下来挨打。
- 血越少心跳越快、弹幕越快，最后阶段会放四道旋转的激光。所有弹幕都扣一整颗心，心脏本身不撞人。
- 打败后出现一个大箱子，碰它进入结局。前 11 次打败它，每次都是一个新结局：第 1 次解锁伊甸，第 10 次解锁 ???，第 11 次之后，它被它活着（It Lives!）永久取代。
- 它活着的打法和妈妈的心脏一样，只是召唤的怪不同。打败它之后可以继续往下，去阴间（Sheol）或教堂（Cathedral）。
- 解锁它活着之前，想越过妈妈的心脏，只能靠打完后刚好开出的恶魔房（里面有通往阴间的活板门）或天使房（里面有通往教堂的光柱）。
