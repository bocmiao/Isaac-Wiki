# 新手前 10 局该注意什么

<VersionBadge checked="2026-10" />

::: tip 速览
- **先用以撒**：唯一一开始就能用的角色，属性平均（[角色](#先用以撒)）
- **每层先找宝箱房**把道具拿到手，第一层不用钥匙（[流程](#每一层的固定流程)）
- **想拿这层交易房奖励，开门就进**；若想争取下次必出天使房，首扇恶魔门要完全不进（[规则](#恶魔房和天使房)）
- **不认识的胶囊**，清完房间、没有敌人时再吃（[胶囊](#胶囊-药丸-值得吃-但挑时候)）
- **死了就按住 R 重开**，前 10 局的主线是稳定打败妈妈（[解锁](#最早的解锁从哪来)）
:::

前 10 局先熟悉流程，练习稳定打到妈妈。下面按单人普通难度、随机开局讲。

## 先用以撒

以撒（Isaac）是唯一一开始就能用的角色：3 个红心容器（血条上的心格，见[心的种类](/guide/first-win/pickups)）、1 个炸弹，属性平均，最适合熟悉游戏。其他角色要达成条件才解锁，下面几个前几局就可能顺手拿到：

| 角色 | 解锁条件 |
| --- | --- |
| 抹大拉 | 同时拥有 7 个或更多红心容器 |
| 该隐 | 同时持有 55 个硬币 |
| 夏娃 | 连续 2 层不捡任何心 |
| 参孙 | 连续 2 层不受伤 |
| 拉撒路 | 同时拥有 4 个或更多魂心（Soul Heart，蓝色的临时心） |
| 阿撒泻勒 | 一局里做 3 次恶魔交易 |

完整顺序见[角色解锁顺序](/guide/unlocks/order)。

## 每一层的固定流程

1. 进新的一层，先按住 <KeyCap>Tab</KeyCap> 看地图。
2. 先找宝箱房（Treasure Room），它的门框是金色的。从地下室 I 到深处 II，每层都一定有一个。第一层的宝箱房不用钥匙，第二层开始要花 1 把钥匙。
3. 再看商店（Shop）。第一层的商店不上锁，之后要钥匙。钥匙不够时先开宝箱房，那里的道具不要钱。
   - 价格：道具 15 枚硬币，红心 3 枚，魂心、炸弹、钥匙、胶囊、卡牌各 5 枚。
   - 从洞穴 II 起，进商店偶尔会变成和贪婪（Greed）打一场小 Boss 战。
4. 去打 Boss。赢了会掉一个道具和一些心，房间里出现通往下一层的活板门。
5. 如果打完 Boss 多出一扇门，那是恶魔房或天使房，见下一节。

::: warning 子宫以后没有宝箱房和商店
从第 4 章子宫（Womb）开始，通常没有普通宝箱房和商店。主要购物放在前三章；剩余钥匙还可开箱，不用为了花光资源乱用。详见[心、钱、炸弹、钥匙怎么用](/guide/first-win/pickups)。
:::

## 恶魔房和天使房

打完 Boss 后，房间里有几率多出一扇门，通往恶魔房或天使房。第一层不会出现这扇门（被迷宫诅咒合成大层时例外），子宫之后也不会出现。

| | 恶魔房（Devil Room） | 天使房（Angel Room） |
| --- | --- | --- |
| 怎么拿道具 | 用红心容器换，一般每件 1 或 2 个 | 免费，但只能拿一个，拿了其余的会消失 |
| 没有红心容器时 | 改为扣 3 个魂心 | 不涉及 |
| 出现前提 | 无 | 之前某层出现过恶魔房的门，且这局没做过恶魔交易 |

几条规则一定要记住：

- 只要在恶魔房里花血买过一次道具，这一局就不会再自然出现天使房。拿恶魔房里的黑心、开红箱子不算交易。
- 整层都没被扣过红心，开门的几率会大幅提高。只在 Boss 战里没被扣红心，也有加成。被扣魂心不影响几率。
- 想拿这层奖励就及时进门。离开 Boss 房再回来，门可能已经关了。
- 从忏悔版（Repentance）起：一局里第一次出现的恶魔房门如果你完全没进去，下一次开出来的必定是天使房。

::: warning 别把自己换死
红心容器全换光时，只要还有魂心或黑心就不会死；什么都不剩就会死。以撒只有 3 个红心容器，买要 2 个红心容器的交易前先算清楚。
:::

## 胶囊（药丸）：值得吃，但挑时候

- 胶囊（Pills）就是很多人说的药丸。每局开始时，每种颜色的胶囊随机对应一种效果，整局不变。没吃过的显示为“???”，吃过一次，同颜色的就都认得了。
- 胶囊既有好效果也有坏效果。想识别本局的颜色，最好等房间清完、有余血时再试。
- 坏效果里有直接降属性的（血量上限、射程、射速、移速、幸运），也有让你 2 秒不能动、不能射的麻痹（Paralysis）。所以不认识的胶囊，清完房间再按 <KeyCap>Q</KeyCap>。
- 有两个保底：
  - 扣血的胶囊：你只剩 1 颗心或更少时，会变成回满血。
  - 降血量上限的胶囊：你只有 1 个或更少红心容器时，会变成加血量上限。

## 卡牌：一次性的

卡牌和符文（Cards and Runes）都是一次性的，和胶囊共用一个格子，同样按 <KeyCap>Q</KeyCap> 使用。先认识这三张：

| 卡牌 | 效果 |
| --- | --- |
| XIX-太阳（The Sun） | 回满血，对房间里所有敌人造成 100 点伤害，显示本层地图，去掉黑暗诅咒 |
| 鬼牌（Joker） | 直接传送到恶魔房或天使房 |
| XVI-塔（The Tower） | 在房间中央附近放 6 个即爆炸弹（Troll Bomb），用之前先站远 |

## 诅咒：只影响这一层

每进一层都有几率被诅咒，换层就消失。普通模式下，还没打败妈妈时每层被诅咒的几率只有 1/80，打败妈妈后升到 1/30。

| 诅咒 | 效果 |
| --- | --- |
| 黑暗诅咒（Curse of Darkness） | 整层变暗，只有以撒身边亮 |
| 迷失诅咒（Curse of the Lost） | 看不到地图 |
| 迷宫诅咒（Curse of the Labyrinth） | 一章的两层合成一个大层，有两个 Boss 房和两个宝箱房，算作两层 |
| 混乱诅咒（Curse of the Maze） | 进门时偶尔被传到别的房间 |
| 未知诅咒（Curse of the Unknown） | 看不到自己的血量 |
| 致盲诅咒（Curse of the Blind） | 道具显示成问号，捡起来才知道是什么 |

黑暗诅咒可以靠调高设置里的亮度（Gamma）缓解。

## 道具：两个通用思路

- **主动道具**按 <KeyCap>Space</KeyCap> 使用，多数用完要靠清房间或等待回充。难房里该用就用；传送、重置类主动要留给指定地点。通常只能带一个，捡新的时旧的会留在底座上，还能换回来。
- **被动道具**捡起来就生效，数量不限，效果一般持续到这局结束。所以宝箱房里的道具，通常直接拿。

忏悔+（Repentance+）里，第一次打败妈妈后，设置里会多出“道具说明”选项：靠近你拿过至少一次的道具，就会弹出它的作用。

## 死了不要紧

死了就按住 <KeyCap>R</KeyCap> 重开。每一局的地图和道具都由随机种子决定，所以每局都不一样，死了只是重新抽一次。解锁是记在存档里的，一局没了不影响它。

注意：手动输入种子的局不能解锁成就，想解锁东西就别填种子。

## 最早的解锁从哪来

| 做到什么 | 解锁 |
| --- | --- |
| 通关第 1 章（地下室） | 一个新道具 |
| 通关第 2 章（洞穴） | 一个新道具 |
| 打败妈妈 | 第 4 章子宫、天启骑士（The Harbingers）、新道具和几个挑战 |
| 打败妈妈的心脏 | 前 11 次每次解锁一个新结局，第 1 次还解锁伊甸 |

所以前 10 局的主线很简单：稳定打到深处 II，打败妈妈。打法见[第一次打妈妈](/guide/first-win/mom)，进度可以记在[解锁清单](/tools/tracker)里。
