## #601 · Mega Chest {#achievement-601}

**条件**：用里以撒击败超级撒但。

**分类**：角色标记。**加入版本**：忏悔；该标签不表示沿用旧版条件。

**解锁步骤**：

1. 在选人菜单选择里以撒，确认当前局允许解锁。角色机制与开局配置见[里以撒攻略](/strategy/tainted#isaac)。
2. 规划宝箱层或暗室路线；同局击败两位天使拿齐钥匙碎片，或准备爸爸的钥匙等替代开门手段，打开起始房金门并击败超级撒但。
3. 本条未额外写困难要求时，普通模式也可解锁；为全困难标记规划可直接用困难。极贪奖励必须选择极贪。
4. 路线、机制与操作细节见[对应攻略](/guide/unlocks/endings)。

[原条目与奖励说明](https://bindingofisaacrebirth.wiki.gg/wiki/Chests#Mega_Chest) · [成就表原文](https://bindingofisaacrebirth.wiki.gg/wiki/Achievements)
