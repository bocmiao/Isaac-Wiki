## 通用规则：做之前先确认 {#rules}

- 正常目标在可解锁的局中做；手动普通种子、挑战模式、每日挑战、胜利圈有各自限制。划掉的奖杯说明本局不能正常解锁，详见[成就排查](/guide/start/chinese#成就为什么不解锁)。
- 初始存档先不开模组、不开控制台，在正常局击败妈妈。每日挑战要求关闭模组与控制台并重启；忏悔+官方在线联机还须按联机规则处理。
- **挑战开放与挑战完成奖励是两项**。名字叫某个挑战的成就通常让它在菜单可选；奖励道具需另外完成挑战并拿奖杯。
- **解锁道具与收集道具是两件事**。解锁只是让道具有机会出现，Dead God 还要检查物品收集页。
- **普通 / 困难**：条件没写困难的，普通模式也能解锁；但要冲死亡证明就直接用困难，免得返工。极贪奖励必须选极贪模式。
- 标记奖励指定角色，不能拿别人的完成代替。里角色“主线四 Boss”和“Boss Rush + 死寂”需同一角色补齐，可以分局完成。
- “加入版本”表示这个秘密最早属于哪个 DLC，不表示现在仍用当年的解锁条件；本系列已单独处理已核对的忏悔与忏悔+差异。

## 推荐推进顺序 {#roadmap}

1. **主线前置**：妈妈 → 心脏累计 11 次 → 教堂 / 阴间 → 全家福 / 底片。同期解锁易上手角色、商店升级和关键挑战奖励。
2. **稳定路线**：开放死寂与虚空，击败死寂 3 次后走母亲路线；母亲后走上行回家，逐个开里角色。
3. **角色标记**：表 / 里角色各十二格，主线用困难，另开极贪。先做 D6、游魂屏障、店主续航等关键开局强化，再补难角色。
4. **挑战与累计**：完成全部 45 个挑战；普通和贪婪捐款分开推进，补石头、机器、床、变身、单局收集等特殊条件。
5. **每日与联机**：每日参与 31 次、获胜 7 次与连胜 5 次是三个不同目标，可以提前并行安排。忏悔+新增在线三项另计。
6. **收集与收尾**：角色满标记解锁死亡证明，再补剩余秘密与实际道具收集；检查 Dead God。单档达成不要求先把其他两档也全部完成。

路线参照[角色解锁](/guide/unlocks/order)、[结局与入口](/guide/unlocks/endings)、[角色标记](/strategy/character-roster#marks)，特殊目标见[详细解锁教程](/achievements/special)。[角色清单](/tools/tracker)目前统计角色与标记，**不会自动读取游戏存档，也不是 641 项全成就完成率**。
