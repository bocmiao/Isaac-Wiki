## 通用规则：做之前先确认 {#rules}

- 大部分成就要在能解锁的普通局里做。手动输入种子的局、挑战模式、每日挑战、胜利圈各有限制。
- 钥匙数量下方出现划掉的奖杯图标，说明这局解锁不了东西，详见[成就排查](/guide/start/chinese#成就为什么不解锁)。
- 新存档先不开模组、不开控制台，在正常局里打败妈妈（Mom，第 3 章的 Boss）。
- 每日挑战要求关掉模组与控制台并重启。忏悔+ 的官方在线联机另有规则，见[联机专题](/topics/coop)。
- **开放挑战和完成挑战的奖励是两个成就**。以挑战名命名的成就，通常只是让这个挑战在菜单里能选；挑战的奖励道具，要另外打通这个挑战、拿到奖杯才给。
- **解锁道具与收集道具是两件事**。解锁只是让道具有机会出现。Dead God（白金神，全成就）还要求物品收集页上的道具都实际捡到过。
- **普通 / 困难**：条件没写困难的，普通模式也能解锁。但如果要拿死亡证明（全部角色满标记的奖励），直接用困难，免得返工。
- **极贪**：极贪模式的奖励必须选极贪模式。
- 标记奖励只认指定角色，别的角色打出的标记不算。
- 里角色的“主线四 Boss”和“Boss Rush（限时连打 Boss 的房间）+ 死寂”这两组标记，要由同一个角色补齐，可以分几局完成。
- “加入版本”只表示这个秘密最早来自哪个 DLC，不代表现在还用当年的解锁条件。忏悔和忏悔+ 条件不同的地方，各条目里已单独写明。

## 推荐推进顺序 {#roadmap}

1. **主线前置**：打败妈妈 → 累计打败妈妈的心 11 次 → 教堂 / 阴间 → 全家福（The Polaroid）/ 底片（The Negative）。这期间顺便解锁易上手的角色、商店升级和关键挑战奖励。
2. **稳定路线**：开放死寂与虚空。打败死寂 3 次后，走母亲路线。打完母亲后，走上行回家，逐个开里角色。
3. **角色标记**：表角色、里角色各有 12 个完成标记，主线终点用困难打，极贪模式另外打。先解锁 D6、游魂的神圣屏障、店主续航等关键开局强化，再补难的角色。
4. **挑战与累计**：完成全部 45 个挑战。普通模式和贪婪模式的捐款分开累计。再补石头、机器、床、变身、单局收集等特殊条件。
5. **每日与联机**：每日挑战参加 31 次、获胜 7 次、连胜 5 次是三个不同的成就，可以提前同时推进。忏悔+ 新增的三个在线成就另算。
6. **收集与收尾**：全角色满标记解锁死亡证明，再补剩下的秘密和道具收集，最后检查 Dead God。Dead God 只看当前存档，不要求另外两个存档也完成。

路线参照[角色解锁](/guide/unlocks/order)、[结局与入口](/guide/unlocks/endings)、[角色标记](/strategy/character-roster#marks)，特殊目标见[详细解锁教程](/achievements/special)。[角色清单](/tools/tracker)目前统计角色与标记，**不会自动读取游戏存档，也不是 641 项全成就完成率**。
