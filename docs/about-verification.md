## 更新和复核步骤

1. 先保存原始出处与版本，再改 `data/` 源稿；独立生成页不直接改。
2. 跑各生成脚本与 `python3 scripts/check-generated.py`，确保页面、索引与离线数据一致。
3. 跑 `npm test`、`python3 scripts/check-content.py`、生产构建、`python3 scripts/check-built-links.py`。
4. 新的规则差异需要回到相关条目验证，不能只改一个概述页。
