# 献祭房 {#sacrifice}

## 进入与计数

进门免费，中央尖刺每次有效献祭通常扣 1 心；部分减伤与特殊角色机制改变实际消耗。被神圣屏障挡掉的伤害不计次数。次数按本层累计，下层重置。

| 本层次数 | 常规奖励 / 风险 |
| --- | --- |
| 1、2 | 各 50% 给 1 硬币 |
| 3 | 67% 得祝福 |
| 4 | 50% 给箱子 |
| 5 | 33% 给 3 硬币，67% 得祝福 |
| 6 | 33% 传送天使房，67% 给箱子；当前交易状态有例外 |
| 7 | 33% 给天使池道具，67% 给魂心；已交易等情形有特殊分支 |
| 8 | 忏悔起生成 7 个即爆炸弹，立刻躲开 |
| 9 | 召唤乌列，可取得钥匙碎片 |
| 10 | 50% 给 7 魂心，50% 给 30 硬币 |
| 11 | 召唤加百列，可取得另一钥匙碎片 |
| 12 及以后 | 每次 50% 传送暗室，50% 无事发生 |

## 打法

先数好可用的红心、魂心和主动回血次数，每次停下来确认次数和奖励。第 8 次不要站在中央等炸弹；天使出现后先停献祭处理战斗。第 12 次起可能直接离开本层去暗室，母亲、死寂或回家路线不要误踩。价格、交易状态例外与祝福判定以[机制原表](/strategy/mechanics#献祭房)为准，也可用[奖励查询](/tools/sacrifice)。
