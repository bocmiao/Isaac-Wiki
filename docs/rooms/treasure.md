# 宝箱房 {#treasure}

<EntryHeader en="Treasure Room" category="基础与发育" icon="crown" />

<VersionBadge checked="2026-10" />

## 进入

金色门框，地图通常是王冠。正常主线前三章一般生成，第一层通常不耗钥匙，之后一般耗 1 把。挑战限制、角色和特殊种子能改变生成。子宫及更深主线通常没有常规宝箱房；贪婪模式的两间宝箱房另见[贪婪楼层](/strategy/floors#greed-floors)。

## 奖励

通常是宝箱房池道具。遇到两个底座，先看是否属于选择组，不能默认两件都能拿。忏悔替代路线常有一个可见道具和一个问号道具，取其中一个后另一个消失。

## 取舍

想稳健发育就优先留钥匙进宝箱房；问号不是品质更高的保证。为星象房跳过宝箱房是主动放弃眼前道具来赌后续机会，跳过指的是不进入，不能进门看完再算跳过。祸兽上行可以回访先前没拿的底座，见[上行准备](/floors/ascent)。
