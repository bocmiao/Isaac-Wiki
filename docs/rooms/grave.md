# 遗骸坟墓房

<EntryHeader en="Forgotten Grave" category="路线与特殊区域" icon="map" />

<VersionBadge checked="2026-10" />

暗室的土堆布局，需要完整妈妈的铲子及前置任务来解锁遗骸。

## 进入与机制

先击败过羔羊，再开始遗骸的铲子任务：首层限时击败 Boss，拿铲子碎片，带着它完成 Boss Rush 得到完整妈妈的铲子。

## 推进与注意事项

之后去暗室找到带土堆的房间，在土堆上使用完整铲子并确认解锁。只有铲子碎片、只打完 Boss Rush 或只抵达暗室，都不算完成任务。

遗骸与遗骸之魂是同一个角色的两种形态，不需要各找一间坟墓解锁；详细时间要求与路线准备按完整教程执行。
