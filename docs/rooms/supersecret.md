# 超级隐藏房 {#supersecret}

<EntryHeader en="Super Secret Room" category="隐藏与交易" icon="bomb" />

<VersionBadge checked="2026-10" />

## 找法与进入

通常只接触一个普通房间，位于地图外围尽头，常靠近 Boss 支路；不按普通隐藏房“被多个房围住”的方法找。入口同样不能被障碍物堵住，通常炸墙开启。

## 奖励与取舍

布局可能集中给红心、魂心、箱子或特殊物体。它更适合在缺补给时寻找，不保证是道具房；用最后一颗炸弹盲炸多个远端墙，往往不如先炸明确的标记石头。
