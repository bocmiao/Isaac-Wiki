# 干净卧室 {#clean-bedroom}

<EntryHeader en="Isaac&#x27;s Room" category="特殊奖励" icon="heart" />

<VersionBadge checked="2026-10" />

## 进入与内容

常见木板封门，通常要炸两次；房内有床和地毯。睡床可回满可恢复的红心，没有红心容器的常规情形改给 3 魂心；特殊角色与合作模式的回复按角色机制处理。

## 额外收益

炸开干净卧室地毯会露出夹层入口，可以下去探索并爬梯回来。先比较两颗炸弹的成本和回血收益，再开门；需要夹层时另外留炸地毯的炸弹。
