# 蓝钥匙房 {#blue}

<EntryHeader en="Blue Room" category="路线与特殊区域" icon="key" />

<VersionBadge checked="2026-10" />

## 触发

携带饰品蓝钥匙开相应上锁门时，先进入一间蓝子宫风格的战斗房，清完后再进入原目标房，以额外战斗替代钥匙消耗。

## 区别与打法

这是道具插入的中间房，**不是已经到达死寂所在的蓝子宫楼层**，也不会因此给死寂标记。省钥匙但要付出战斗和时间成本，低血、赶限时门时先考虑是否值得绕这一战；不能据此无条件打开双锁门、超级撒但门等所有特殊门。
