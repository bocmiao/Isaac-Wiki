# 天使房 {#angel}

<EntryHeader en="Angel Room" category="隐藏与交易" icon="soul" />

<VersionBadge checked="2026-10" />

## 出现

与恶魔房共用开门机会，再决定房间种类。忏悔起，**本局第一次出现的恶魔房完全不进入**，下一次成功生成常规交易门会是天使房；不是下一层必开门。天使加成的多次独立判定不能直接相加，想算本层概率用[概率工具](/tools/deal-chance)。

## 奖励与操作

通常给免费的天使池道具；多个底座可能是多选一，也可能布局允许拿更多，要按选择组处理。炸天使雕像可召唤天使，击败后获得相应钥匙碎片，为超级撒但开门。

## 取舍

免费道具也不等于必须打天使；血少、没炸弹、当前不走超级撒但时可以拿奖励就走。想集齐钥匙碎片则要提前留炸弹。献祭传送进来的天使房与正常交易门不完全共用出现规则。
