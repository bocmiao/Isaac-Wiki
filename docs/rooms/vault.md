# 宝库 {#vault}

<EntryHeader en="Chest Room / Vault" category="资源与挑战" icon="chest" />

<VersionBadge checked="2026-10" />

## 进入与收益

通常双钥匙门，一次消耗 2 把钥匙；里面常有多个箱子与拾取物。里面的金箱子还要另外用钥匙开。

## 取舍

先保留宝箱房与目标路线门的钥匙，再决定宝库。没有额外钥匙时，可能开门后仍打不开金箱子；箱子里也未必是道具。
