# 诅咒房 {#curse}

<EntryHeader en="Curse Room" category="资源与挑战" icon="heart" />

<VersionBadge checked="2026-10" />

## 进入

尖刺门，默认进门与出门分别造成一次伤害，先算进出两次后还剩多少血。飞行通常免进门伤害，但出门仍会受伤；神圣屏障、短暂无敌、传送和隐藏房侧门可以改变实际消耗。**飞行不等于免费往返**。

## 内容与风险

可能有红箱子、道具、拾取物或敌人。红箱子可能给魂心、蜘蛛、即爆炸弹，或把人传走；开箱后先观察，别站着等爆炸。忏悔起尖刺门伤害不扣恶魔房概率，但里面被普通敌人打掉红心仍按正常规则计算。

## 取舍

有稳定免伤、传送或充足补血时收益更合算。只剩一点血时不能把未开的箱子当作确定的回血来源。先看是否有隐藏房侧门，再考虑付血穿门。
