# 肮脏卧室 {#dirty-bedroom}

<EntryHeader en="Barren Room" category="特殊奖励" icon="heart" />

<VersionBadge checked="2026-10" />

## 识别与收益

是脏乱的卧室布局，木板门与床的基本用途相同。关键区别是地毯下通常为**通向下一层的活板门**，不是干净卧室的夹层。

## 使用

可以睡床回血后继续本层，也可以从地毯下出口提前走。要拿本层 Boss 奖励、交易门、刀片或完成目标时，不要把这个出口当成一定该进的奖励；先把本层必须做的事完成。
