# 小头目房 {#miniboss}

<EntryHeader en="Miniboss Room" category="基础与发育" icon="skull" />

<VersionBadge checked="2026-10" />

## 内容

常见七宗罪及其超级版本；商店里碰到贪婪是商店被占据的情形，不等于所有小头目都只出在商店。门和地图图标可能随布局变化。

## 奖励

可给对应敌人的道具、饰品或拾取物，不能保证每次给底座道具，也不替代本层正式 Boss 的出口。

## 打法

先认出敌人的攻击方式。例如贪婪的横向硬币弹不要迎面跑，愤怒的炸弹不要堵在角落。把这类房当一次独立战斗，血少时不要为了潜在奖励多探索危险支路。
