# 贪婪出口房 {#greed-exit}

<EntryHeader en="Greed Exit" category="路线与特殊区域" icon="coin" />

<VersionBadge checked="2026-10" />

## 用途

贪婪 / 极贪模式的下楼连接房。规定战斗完成后入口才正常开放，不提供普通主线 Boss 房那样的常规底座奖励。

## 怎么用

下楼前回商店买关键道具，拿完两间宝箱房和交易房奖励，确认钱与血量。可选噩梦波关系到本层交易房；已经能下楼不表示所有可选奖励都拿了。详见[贪婪模式波次](/strategy/greed#波次与按钮)。
