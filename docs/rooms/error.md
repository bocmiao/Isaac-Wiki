# 错误房 {#error}

<EntryHeader en="I AM ERROR Room" category="路线与特殊区域" icon="dice" />

<VersionBadge checked="2026-10" />

## 进入

不能靠普通地图炸墙寻找；特殊传送可能到达。传送 2.0 在满足探索条件后可将这里作为最后目标，直接使用一次不保证到错误房。

## 内容与出口

可有道具、拾取物、机器与奇特布局。常规出口通常让你进入下一层，没有连接原地图的普通门，进入前要把本层关键目标做好。

## 取舍

探索完全部房再谋取额外奖励比较合算。没拿刀片、没开路线门或还需返回妈妈房时，不要把错误房传送当成免费绕路。
