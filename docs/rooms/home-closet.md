# Home 隐藏衣柜

<EntryHeader en="Home Closet" category="路线与特殊区域" icon="key" />

<VersionBadge checked="2026-10" />

妈妈卧室前走廊左侧墙后的隐藏房，接触对应里角色才能解锁。

## 进入与机制

先走奇怪的门、爸爸的便条与上行路线到家，再在妈妈卧室前走廊左侧墙的对应位置使用红钥匙或红钥匙碎片等开门。

## 推进与注意事项

第一次到家打开妈妈卧室箱子保证给红钥匙；以后优先提前留饰品，上行取红钥匙碎片。该隐的魂石也是可用方式，不必依赖随机拿到它。

开门后进隐藏衣柜，接触里面的对应里角色并确认解锁提示。只是到家、只是开门、或者用其他表角色到家，都不能代替目标角色的解锁。先做完衣柜，再睡床触发终局战。
