# 隐藏房 {#secret}

<EntryHeader en="Secret Room" category="隐藏与交易" icon="bomb" />

<VersionBadge checked="2026-10" />

## 找法

常在同时接触多个房间的空格，通常不邻 Boss 房。候选入口在相邻房的墙中间，所有相邻房的对应入口都不能被坑、石头等阻挡。地图看起来“被围住”但入口堵住的格子，应先排除。大房间按占据的小格检查。

## 进入与奖励

用炸弹炸对应墙面，或使用开门、显示入口、传送等效果。里面可有钱、炸弹、机器、店主、怪或隐藏房池底座，不保证必出道具。

## 用途

从隐藏房炸开通向上锁商店、宝箱房的墙可以省钥匙；通向诅咒房的墙可以避开尖刺门。探到后检查所有相邻房，别只拿完奖励就走。详细排除规则见[隐藏房机制](/strategy/mechanics#隐藏房、超级隐藏房、究极隐藏房)。
