# 究极隐藏房 {#ultrasecret}

<EntryHeader en="Ultra Secret Room" category="隐藏与交易" icon="key" />

<VersionBadge checked="2026-10" />

## 出现与进入

忏悔新增，位于正常地图外，需通过红钥匙、红钥匙碎片、该隐魂石等开红房拓路，或用逆位月亮直接传送。普通炸弹不能从正常房的墙上炸出它；普通地图显示效果也不必然标出它。

## 奖励

忏悔现行机制使用究极隐藏房池，以红色主题道具为主。红色外观并不等于效果适合当前组合，还是要查道具说明。

## 找法

优先考虑地图外能接触多个潜在红房的空格，按红房连接规则逐步排除；正常隐藏房、超级隐藏房和诅咒房等会限制红房连接。红钥匙充能有限，别把每面外墙都当作同等概率。完整规则见[红房与究极隐藏房机制](/strategy/mechanics#究极隐藏房-忏悔起)。
