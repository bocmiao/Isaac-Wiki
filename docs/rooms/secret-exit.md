# 替代章节入口房 {#secret-exit}

<EntryHeader en="Secret Exit" category="路线与特殊区域" icon="key" />

<VersionBadge checked="2026-10" />

## 开启前提

击败死寂 3 次解锁[秘密出口（成就 407）](/achievements/ids-401-500#achievement-407)，Boss 房旁才会正常出现母亲路线入口。它是路线连接房，不是隐藏房，不按普通隐藏房炸墙逻辑寻找。

| 前往 | 入口位置 | 常规开门代价 |
| --- | --- | --- |
| 下水道 / 污水渠 | 地下室 I 或 II 的 Boss 房旁 | 1 钥匙 |
| 矿洞 / 灰坑 | 洞穴 I 或下水道 / 污水渠 II 的 Boss 房旁 | 2 炸弹 |
| 陵墓 / 炼狱 | 深处 I 或矿洞 / 灰坑 II 的 Boss 房旁 | 总计 2 心伤害，角色机制有例外 |

## 路线决策

要母亲就提前保留钥匙、炸弹与生命，并在 II 层做好两块刀片。入口花费是开门代价，不保证接下来的楼层安全；刀片也不是一开门就自动送。各层出口与刀片步骤见[母亲替代路线](/strategy/floors#alt-path)。
