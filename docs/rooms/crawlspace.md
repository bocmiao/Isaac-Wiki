# 夹层 {#crawlspace}

<EntryHeader en="Crawl Space / Dungeon" category="特殊奖励" icon="rock" />

<VersionBadge checked="2026-10" />

## 出现与进入

炸岩石等可能露出带梯子的入口；我们需要深入一层！、铲子等开洞效果也受地形和道具规则影响，不是每次开洞都保证夹层。干净卧室地毯下是另一个来源。

## 内容

进入后变为横版小区域，可以有底座、拾取物、敌人和侧向通道。普通夹层能从梯子回原房，不等同于下层活板门。

## 打法

先看梯子与平台位置再移动；飞行、泪弹在横版区域的操作感不同。发现侧向通道可能通往黑市，别以为每个夹层必带黑市或道具。
