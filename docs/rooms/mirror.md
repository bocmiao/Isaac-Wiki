# 镜面世界

<EntryHeader en="Mirror World" category="路线与特殊区域" icon="map" />

<VersionBadge checked="2026-10" />

下水道 / 污水渠 II 的特殊区域，临时游魂进入镜子后取得刀片 1。

## 进入与机制

先在下水道 / 污水渠 II 找到白火和镜子，触碰白火进入临时游魂状态，再穿镜子。刀片 1 在镜面宝箱房，拿到后原路穿镜子返回。

## 推进与注意事项

临时游魂的神圣屏障与游魂开局强化有关，不能假定未完成强化也能安全挨一下。镜面 Boss 是可选额外奖励，母亲路线不要求击败它。

进门先观察危险物与敌人，刀片到手就优先安全返回；不要为多拿一个可选奖励把整条路线断掉，也不要打碎镜子后再计划返回。
