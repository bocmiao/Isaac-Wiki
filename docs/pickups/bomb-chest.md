# 石箱子

<VersionBadge checked="2026-10" />

需要爆炸打开。

## 怎么用

先摆好位置再放炸弹，避免把内容炸到坑或尖刺上。

## 要注意什么

不要把里面的资源连同下一颗爆炸推到坑里或尖刺上。

::: details 用控制台生成它

```text
spawn 5.51.1
```

这条命令会把它放在地上，不会解锁对应成就。 [打开命令生成器](/tools/console-generator?pickup=bomb-chest) · [开启控制台](/topics/debug-console)。
