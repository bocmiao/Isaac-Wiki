# 金电池

<VersionBadge checked="2026-10" />

提供充能收益，但拾取伴随伤害风险。

## 怎么用

先确认当前生命和保护状态，再决定充能是否值得冒受伤风险。

## 要注意什么

游魂类角色尤其要小心，不要只看到主动缺电就碰它；完整扣血例外仍待核实。

## 解锁条件

先完成[成就 #615](/achievements/ids-601-641#achievement-615)，之后才可能出现。
