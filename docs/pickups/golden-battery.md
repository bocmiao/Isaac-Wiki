# 金电池

<VersionBadge checked="2026-10" />

提供充能收益，但拾取伴随伤害风险。

## 获取与使用

先确认生命够用；游魂类角色不能只看充能收益就直接碰。

## 操作顺序

1. 先确认当前生命和保护状态，再权衡充能是否值得承担伤害风险。

## 限制与特殊角色

游魂类角色不能只看主动缺电就直接拾取；不提供未经当前版本核实的完整扣血例外。

## 永久解锁

先满足[成就 #615](/achievements/ids-601-641#achievement-615)；解锁后才可能在对应来源生成，不保证这一局掉落。

## 控制台练习

```text
spawn 5.90.4
```

只生成地上实体，不会证明自然获取、永久解锁或收藏条件已经满足。 [打开命令生成器](/tools/console-generator?pickup=golden-battery)，开启控制台见[控制台教程](/topics/debug-console)。

编号对照 [PickupVariant](https://github.com/wofsauge/IsaacDocs/blob/e05b1fd90e33608a7a7a8dcb70a89cef908cc41a/docs/enums/PickupVariant.md) 与 [BatterySubType](https://github.com/wofsauge/IsaacDocs/blob/e05b1fd90e33608a7a7a8dcb70a89cef908cc41a/docs/enums/BatterySubType.md)；枚举不证明开启成本与掉率。
