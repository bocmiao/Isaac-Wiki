# 黑心

<VersionBadge checked="2026-10" />

类似魂心，耗尽对应黑心时有清房伤害效果。

## 怎么用

捡来保护红心；耗尽它时的清场伤害可以补输出，但不值得故意挨打触发。

## 要注意什么

它不一定能杀光所有敌人，也不会额外结算一次清房奖励。
