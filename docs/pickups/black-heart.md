# 黑心

<VersionBadge checked="2026-10" />

类似魂心，耗尽对应黑心时有清房伤害效果。

## 获取与使用

不要为触发清屏故意受伤；该效果与普通清房奖励不是同一件事。

## 操作顺序

1. 先清场，再捡作临时保护；失去黑心的伤害效果只作额外收益。

## 限制与特殊角色

黑心被消耗的清房伤害不等于所有敌人一定死亡，更不是一次额外清房奖励。
