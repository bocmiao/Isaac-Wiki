# 小电池与其他电池

<VersionBadge checked="2026-10" />

给主动道具补充充能，不等于得到电池类收藏道具。

## 怎么用

先确认主动的充能方式和是否已满；额外储存、过充由道具决定。

## 要注意什么

拾取电池与获得蓄电池、9 伏特等收藏道具不同，不会自动获得它们的被动效果。

::: details 用控制台生成它

```text
spawn 5.90.1
```

这条命令会把它放在地上，不会解锁对应成就。 [打开命令生成器](/tools/console-generator?pickup=battery) · [开启控制台](/topics/debug-console)。
