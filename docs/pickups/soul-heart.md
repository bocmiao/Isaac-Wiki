# 魂心

<VersionBadge checked="2026-10" />

独立临时生命，消耗后没有空容器可恢复。

## 获取与使用

保护红心并减少交易概率损失；无法储存魂心的角色按自身机制转化。

## 操作顺序

1. 普通红心角色可以把魂心留作红心外侧保护；进入危险房前再决定是否拾取。

## 限制与特殊角色

伯大尼将魂心当充能资源，不能按增加生命计算；店主也不能套魂心角色的血条。
