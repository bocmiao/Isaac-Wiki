# 魂心

<VersionBadge checked="2026-10" />

独立临时生命，消耗后没有空容器可恢复。

## 怎么用

普通红心角色可把它放在红心外侧，保护红心并减少交易概率损失。进入危险房间前可以先捡。

## 要注意什么

伯大尼把魂心转为主动充能，店主也不能用魂心回血；先看角色规则。
