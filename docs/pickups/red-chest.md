# 红箱子

<VersionBadge checked="2026-10" />

可有道具、心、传送或危险内容。

## 获取与使用

保留落点与退路；蜘蛛或炸弹出现时先躲，不站在箱子中心。

## 操作顺序

1. 先清场并留退路，开箱后看到蜘蛛或炸弹立即移动。

## 限制与特殊角色

传送可能改变当前位置；有路线物品待拿时先完成本层事项。
