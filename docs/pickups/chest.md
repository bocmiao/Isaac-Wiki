# 普通箱子

<VersionBadge checked="2026-10" />

通常碰触即可打开，可能是奖励也可能有危险内容。

## 获取与使用

清场后开，别把开箱当作必定回血或一定出道具。

## 操作顺序

1. 先清场，在有退路的位置触碰；开后再观察具体内容。

## 限制与特殊角色

普通箱子也可能有危险内容；不要把开箱当成保证回血或一定出收藏道具。

## 控制台练习

```text
spawn 5.50.1
```

只生成地上实体，不会证明自然获取、永久解锁或收藏条件已经满足。 [打开命令生成器](/tools/console-generator?pickup=chest)，开启控制台见[控制台教程](/topics/debug-console)。
