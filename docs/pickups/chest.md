# 普通箱子

<VersionBadge checked="2026-10" />

通常碰触即可打开，可能是奖励也可能有危险内容。

## 怎么用

清场后开，别把开箱当作必定回血或一定出道具。

## 要注意什么

普通箱子也可能有危险内容；不要把开箱当成保证回血或一定出收藏道具。
