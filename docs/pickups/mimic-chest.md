# 伪装刺箱

<VersionBadge checked="2026-10" />

外观容易与普通箱子混淆，接近时可露出尖刺。

## 获取与使用

观察变化后再决定是否开，不在低血或游魂局莽撞触碰。

## 操作顺序

1. 接近前观察外观和尖刺变化，确认后按刺箱预算处理。

## 限制与特殊角色

不要把普通箱子的安全触碰经验照搬到外观相似的箱子。
