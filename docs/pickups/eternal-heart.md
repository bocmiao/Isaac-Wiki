# 永恒之心

<VersionBadge checked="2026-10" />

半颗白心，取得另一半或带到下一层可增加红心容器。

## 怎么用

能安全下楼时尽量保住；同层取得第二半或下层结算后再看容器变化。

## 要注意什么

白心的扣除顺序与血条组成有关，目前仍待核实；尽量保到下层，不要靠它赌最后一下伤害。
