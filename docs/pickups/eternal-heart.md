# 永恒之心

<VersionBadge checked="2026-10" />

半颗白心，取得另一半或带到下一层可增加红心容器。

## 获取与使用

优先保住到下层；伤害消耗次序依血条组成与版本，见生命机制说明。

## 操作顺序

1. 能安全下楼时尽量保住；同层取得第二半或下层结算后再看容器变化。

## 限制与特殊角色

不同生命组成的伤害消耗顺序仍待核实，不把半颗白心算成能稳定挨一次攻击。

## 控制台练习

```text
spawn 5.10.4
```

只生成地上实体，不会证明自然获取、永久解锁或收藏条件已经满足。 [打开命令生成器](/tools/console-generator?pickup=eternal-heart)，开启控制台见[控制台教程](/topics/debug-console)。
