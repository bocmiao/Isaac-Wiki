# 炸弹与双炸弹

<VersionBadge checked="2026-10" />

补炸弹资源，用于战斗、开口与破坏障碍。

## 获取与使用

不要站在爆炸范围里等开墙；优先隐藏入口、标记石头和路线门。

## 操作顺序

1. 先留刀片路线、隐藏房和明显标记石头，再考虑用炸弹补 Boss 输出。

## 限制与特殊角色

生成或放置炸弹不是爆炸免疫；自己的爆炸也可能造成伤害。

## 控制台练习

```text
spawn 5.40.1
```
