# 炸弹与双炸弹

<VersionBadge checked="2026-10" />

补炸弹资源，用于战斗、开口与破坏障碍。

## 怎么用

先留刀片路线、隐藏房和明显标记石头，再考虑用炸弹补 Boss 输出。

## 要注意什么

生成或放置炸弹不是爆炸免疫；自己的爆炸也可能造成伤害。

::: details 用控制台生成它

```text
spawn 5.40.1
```

这条命令会把它放在地上，不会解锁对应成就。 [打开命令生成器](/tools/console-generator?pickup=bomb) · [开启控制台](/topics/debug-console)。
