# 刺箱子

<VersionBadge checked="2026-10" />

碰触开箱有受伤成本。

## 怎么用

清场后，先算开箱扣血后的生命。血少时可以留下，等回血再开。

## 要注意什么

飞行不会免掉刺箱的接触伤害；游魂等角色要另外看护盾与无敌效果。
