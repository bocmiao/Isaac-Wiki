# 腐心

<VersionBadge checked="2026-10" />

与红心容器有关，清房能产生蓝苍蝇。

## 怎么用

清房产生的蓝苍蝇能补伤害。准备献血或献祭前，先确认当前实际生命够不够。

## 要注意什么

腐心显示占一整格，但可承受的伤害与普通整颗红心不同。

## 解锁条件

先完成[成就 #411](/achievements/ids-401-500#achievement-411)，之后才可能出现。
