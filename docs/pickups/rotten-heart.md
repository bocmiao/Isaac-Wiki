# 腐心

<VersionBadge checked="2026-10" />

与红心容器有关，清房能产生蓝苍蝇。

## 获取与使用

不能将外观一整格当成普通完整红心的受伤次数；付血前先看有效生命。

## 操作顺序

1. 用腐心前先比较后续付血与治疗需求，清房收益属于辅助输出。

## 限制与特殊角色

一整格外观不代表与普通整颗红心相同的受伤预算。

## 永久解锁

先满足[成就 #411](/achievements/ids-401-500#achievement-411)；解锁后才可能在对应来源生成，不保证这一局掉落。

## 控制台练习

```text
spawn 5.10.12
```

只生成地上实体，不会证明自然获取、永久解锁或收藏条件已经满足。 [打开命令生成器](/tools/console-generator?pickup=rotten-heart)，开启控制台见[控制台教程](/topics/debug-console)。

编号对照 [PickupVariant](https://github.com/wofsauge/IsaacDocs/blob/e05b1fd90e33608a7a7a8dcb70a89cef908cc41a/docs/enums/PickupVariant.md) 与 [HeartSubType](https://github.com/wofsauge/IsaacDocs/blob/e05b1fd90e33608a7a7a8dcb70a89cef908cc41a/docs/enums/HeartSubType.md)；枚举不证明开启成本与掉率。
