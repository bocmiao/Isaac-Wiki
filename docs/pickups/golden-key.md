# 金钥匙

<VersionBadge checked="2026-10" />

当层普通用钥匙时不扣库存，换层不保留该层效果。

## 怎么用

当层优先开需要的锁，特殊机器的互动另看其规则。

## 要注意什么

效果只持续这一层；钥匙乞丐等特殊互动另有规则，使用前先查。

::: details 用控制台生成它

```text
spawn 5.30.2
```

这条命令会把它放在地上，不会解锁对应成就。 [打开命令生成器](/tools/console-generator?pickup=golden-key) · [开启控制台](/topics/debug-console)。
