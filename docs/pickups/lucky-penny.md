# 幸运币

<VersionBadge checked="2026-10" />

硬币同时提供运气提升。

## 怎么用

运气不自动提高所有随机事件概率，先看具体道具的判定。

## 要注意什么

运气只影响部分随机判定；房间、机器和各道具是否受它影响，要看对应规则。

## 解锁条件

先完成[成就 #242](/achievements/ids-201-300#achievement-242)，之后才可能出现。
