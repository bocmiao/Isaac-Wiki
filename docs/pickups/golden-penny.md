# 金硬币

<VersionBadge checked="2026-10" />

拾取后可重新出现在附近，直到这一枚的连续奖励结束。

## 怎么用

清场后再连续追捡，注意新位置是否靠近尖刺或坑；奖励结束后会消失。

## 要注意什么

不能无限捡；附近有敌人时先保命。

## 解锁条件

先完成[成就 #613](/achievements/ids-601-641#achievement-613)，之后才可能出现。

::: details 用控制台生成它

```text
spawn 5.20.7
```
