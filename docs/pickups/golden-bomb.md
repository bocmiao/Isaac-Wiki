# 金炸弹

<VersionBadge checked="2026-10" />

当层放普通炸弹不消耗库存。

## 怎么用

当层使用仍会造成爆炸危险，不等于免疫自己的炸弹。

## 要注意什么

无限库存消耗不等于免疫爆炸，换层也不会保留当层效果。

## 解锁条件

先完成[成就 #226](/achievements/ids-201-300#achievement-226)，之后才可能出现。
