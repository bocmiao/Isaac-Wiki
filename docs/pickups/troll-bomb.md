# 即爆炸弹

<VersionBadge checked="2026-10" />

无法拾取为库存，出现后会自行爆炸。

## 获取与使用

看到引线就先避开，箱子和机器也可能生成这种危险奖励。

## 操作顺序

1. 看到引线先后退，开箱或机器付出后也要观察是否出现危险炸弹。

## 限制与特殊角色

这种炸弹无法捡进普通库存，不为了看清奖励停在爆炸中心。

## 控制台练习

```text
spawn 5.40.3
```

只生成地上实体，不会证明自然获取、永久解锁或收藏条件已经满足。 即爆炸弹会爆炸，先准备安全距离。 [打开命令生成器](/tools/console-generator?pickup=troll-bomb)，开启控制台见[控制台教程](/topics/debug-console)。
