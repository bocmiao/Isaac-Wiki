# 即爆炸弹

<VersionBadge checked="2026-10" />

无法拾取为库存，出现后会自行爆炸。

## 怎么用

看到引线就先避开，箱子和机器也可能生成这种危险奖励。

## 要注意什么

这种炸弹无法捡进普通库存，不为了看清奖励停在爆炸中心。

::: details 用控制台生成它

```text
spawn 5.40.3
```

这条命令会把它放在地上，不会解锁对应成就。 即爆炸弹会爆炸，先准备安全距离。 [打开命令生成器](/tools/console-generator?pickup=troll-bomb) · [开启控制台](/topics/debug-console)。
