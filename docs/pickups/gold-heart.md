# 金心

<VersionBadge checked="2026-10" />

附在生命上的奖励效果，不自行增加可承受伤害。

## 获取与使用

金边不是额外一颗血，不能拿它预算献祭或恶魔交易。

## 操作顺序

1. 先认清金边附着的生命，再决定是否继续献祭或交易。

## 限制与特殊角色

拾取金心本身没有补回一颗生命，不能用它凑够开门付血。

## 永久解锁

先满足[成就 #224](/achievements/ids-201-300#achievement-224)；解锁后才可能在对应来源生成，不保证这一局掉落。

## 控制台练习

```text
spawn 5.10.7
```

只生成地上实体，不会证明自然获取、永久解锁或收藏条件已经满足。 [打开命令生成器](/tools/console-generator?pickup=gold-heart)，开启控制台见[控制台教程](/topics/debug-console)。

编号对照 [PickupVariant](https://github.com/wofsauge/IsaacDocs/blob/e05b1fd90e33608a7a7a8dcb70a89cef908cc41a/docs/enums/PickupVariant.md) 与 [HeartSubType](https://github.com/wofsauge/IsaacDocs/blob/e05b1fd90e33608a7a7a8dcb70a89cef908cc41a/docs/enums/HeartSubType.md)；枚举不证明开启成本与掉率。
