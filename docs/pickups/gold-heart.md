# 金心

<VersionBadge checked="2026-10" />

附在生命上的奖励效果，不自行增加可承受伤害。

## 怎么用

它附在已有生命上，不能拿来补血或凑开门所需的生命。

## 要注意什么

金边是奖励效果，角色不会因此多一颗心。

## 解锁条件

先完成[成就 #224](/achievements/ids-201-300#achievement-224)，之后才可能出现。

::: details 用控制台生成它

```text
spawn 5.10.7
```

这条命令会把它放在地上，不会解锁对应成就。 [打开命令生成器](/tools/console-generator?pickup=gold-heart) · [开启控制台](/topics/debug-console)。
