# 鬼箱子

<VersionBadge checked="2026-10" />

靠近时可能遭遇幽灵敌人的攻击。

## 怎么用

辨认后保持移动，先处理敌人，再考虑内容。

## 要注意什么

名称像宝箱不等于可以安全站桩；不要在低血时忽略幽灵攻击。

## 解锁条件

先完成[成就 #611](/achievements/ids-601-641#achievement-611)，之后才可能出现。

::: details 用控制台生成它

```text
spawn 5.58.1
```
