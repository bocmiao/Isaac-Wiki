# 红心

<VersionBadge checked="2026-10" />

填充已有红心容器，不会单凭拾取增加容器。

## 怎么用

有空红心格时可以捡来回血。能回头拿时，也可留给献血、献祭或诅咒房之后。

## 要注意什么

满红心时不会增加容器；???、游魂等角色的生命规则不同。

::: details 用控制台生成它

```text
spawn 5.10.1
```
