# 充能钥匙

<VersionBadge checked="2026-10" />

提供钥匙资源，也能给主动道具充能。

## 怎么用

主动已满时，若本来就要使用可先用再捡，让钥匙和充能都产生收益。

## 要注意什么

主动已满又不能储存额外充能时，会浪费充能部分，但仍可得到钥匙。

## 解锁条件

先完成[成就 #333](/achievements/ids-301-400#achievement-333)，之后才可能出现。
