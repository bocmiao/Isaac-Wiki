# 金饰品

<VersionBadge checked="2026-10" />

许多饰品的效果会加强，但并非全都简单翻倍。

## 怎么用

按饰品详情查看金色版本差异；同名普通形态不能直接替代。

## 要注意什么

并非所有饰品都简单翻倍；解锁金饰品也不等于饰品已经有逐项收藏记录。

## 解锁条件

先完成[成就 #617](/achievements/ids-601-641#achievement-617)，之后才可能出现。
