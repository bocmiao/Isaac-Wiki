# 钥匙与双钥匙

<VersionBadge checked="2026-10" />

普通钥匙开锁，双钥匙提供两把资源。

## 怎么用

开宝箱房和商店前，先保留母亲路线或其他双锁入口所需数量。

## 要注意什么

双钥匙是一次补两把；双钥匙门通常仍需两把，不是捡过双钥匙就永久免费。

::: details 用控制台生成它

```text
spawn 5.30.1
```

这条命令会把它放在地上，不会解锁对应成就。 [打开命令生成器](/tools/console-generator?pickup=key) · [开启控制台](/topics/debug-console)。
