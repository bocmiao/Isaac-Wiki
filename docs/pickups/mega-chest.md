# 巨型宝箱

<VersionBadge checked="2026-10" />

通常要投入多把钥匙才能打开。

## 怎么用

给下一层留好钥匙，剩余的再用来开；钥匙不够时可以先留下。

## 要注意什么

可能要花多把钥匙，具体次数分布尚未核实。

## 解锁条件

先完成[成就 #601](/achievements/ids-601-641#achievement-601)，之后才可能出现。

::: details 用控制台生成它

```text

```
