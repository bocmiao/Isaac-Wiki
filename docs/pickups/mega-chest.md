# 巨型宝箱

<VersionBadge checked="2026-10" />

通常需要多次付钥匙才能开启，不能按一次一把预算。

## 获取与使用

有足够备用钥匙再尝试，别花光下一层开门资源。

## 操作顺序

1. 先给下一层开门留钥匙，再尝试多次开启。

## 限制与特殊角色

不写未经核实的钥匙次数分布；尚未开成时别把内容当已获得。

## 永久解锁

先满足[成就 #601](/achievements/ids-601-641#achievement-601)；解锁后才可能在对应来源生成，不保证这一局掉落。

## 控制台练习

```text
spawn 5.57.1
```

只生成地上实体，不会证明自然获取、永久解锁或收藏条件已经满足。 [打开命令生成器](/tools/console-generator?pickup=mega-chest)，开启控制台见[控制台教程](/topics/debug-console)。

编号对照 [PickupVariant](https://github.com/wofsauge/IsaacDocs/blob/e05b1fd90e33608a7a7a8dcb70a89cef908cc41a/docs/enums/PickupVariant.md) 与 [ChestSubType](https://github.com/wofsauge/IsaacDocs/blob/e05b1fd90e33608a7a7a8dcb70a89cef908cc41a/docs/enums/ChestSubType.md)；枚举不证明开启成本与掉率。
