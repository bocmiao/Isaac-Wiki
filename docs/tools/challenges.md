# 挑战进度清单

<VersionBadge checked="2026-10" />

45 个挑战一页看完，完成一个勾一个。输入纯数字或 `#编号` 精确查某项，也能按名称、角色、奖励、终点、开放条件和“蒙眼”等规则找。「显示」可以只看没完成的。攻略页的“记录本挑战进度”会直接带入对应编号，搜索链接可分享。

**勾选的意思是已经通关并拿到奖杯**，不是挑战已经在菜单里开放。

<ChallengeChecklist />

## 注意

- 进度只存在这个浏览器里，不会读取游戏存档。换电脑或清浏览器数据前先「导出」。
- 「导入」默认合并已完成项，也可选择替换整份清单；文件不对时原进度不变。不同存档栏建议分别导出保存。
- 第 45 个挑战 DELETE THIS 在游戏菜单里本来就不显示名字，不是漏了。

每项“查看打法”直接打开对应独立攻略；完整入口见[45 个挑战图鉴](/challenges/)。每日挑战、胜利圈等规则见[模式总览](/modes/)。

数据来源：[挑战模式 · 全部挑战总表](/strategy/challenges#全部挑战总表)。
