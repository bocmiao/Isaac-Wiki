# 挑战进度清单

<VersionBadge checked="2026-10" />

45 个挑战一页看完，完成一个勾一个。搜索框能按编号、名称、角色、奖励找，「显示」可以只看没完成的。

**勾选的意思是已经通关并拿到奖杯**，不是挑战已经在菜单里开放。

<ChallengeChecklist />

## 注意

- 进度只存在这个浏览器里，不会读取游戏存档。换电脑或清浏览器数据前先「导出」。
- 「导入」会替换这个清单的进度；文件不对时原进度不变。不同存档栏建议分别导出保存。
- 第 45 个挑战 DELETE THIS 在游戏菜单里本来就不显示名字，不是漏了。
