# 恶魔房 / 天使房概率计算器

<VersionBadge checked="2026-10" />

算这一层打完 Boss 后出现交易门的概率，以及门开了是天使房还是恶魔房。适用单人忏悔 / 忏悔+ 的普通主线。

**怎么用**：按这一层的实际情况勾选条件，结果固定在屏幕底部，勾一项变一次。

<DealCalculator />

## 结果怎么看 {#如何读结果}

- **出现交易门**：各项加成先相加，再乘「最近出现过交易门」的惩罚，超过 100% 按 100% 算。例如 1 + 99 + 35 = 135%，上一层见过门时是 135% × 0.25 = 33.75%（不是先封顶 100% 再乘）。
- **门开后是天使房的比例**：每个来源单独掷一次，任一项成功就是天使房，所以不能直接相加。只有基础 50% 和钥匙碎片1 的 25% 时，是 1 − 0.5 × 0.75 = 62.5%。
- **最终天使房 / 恶魔房** = 出现交易门 × 各自比例，两者加起来等于出现交易门的概率。

## 注意

- 贪婪模式噩梦波、鬼牌传送、红箱子传送不按这套概率算。
- 「首扇恶魔门完全没进」的保底只能用一次；已经用掉了就别再选这一项。
- 本层恶魔乞丐给了道具、同时又满足天使保底时，资料没写哪个优先，工具不给这种组合的最终数字。
- 献血机等自残算不算红心伤害、XL 层怎么算惩罚、发光沙漏撤销开门，见[机制详解](/strategy/mechanics#恶魔房与天使房)，按游戏里的实际情况勾选。
