# 恶魔房 / 天使房概率计算器

<VersionBadge checked="2026-10" />

用于单人忏悔 / 忏悔+普通主线交易门。规则逐项来自[开门概率](/strategy/mechanics#开门概率)和[恶魔还是天使](/strategy/mechanics#恶魔还是天使)。贪婪噩梦波、鬼牌传送与特殊强制房间不按这套普通开门概率计算。

## 如何读结果

- 加成先求和，再乘最近出现过交易门的惩罚，最后限制为 0–100%。例如 `1 + 99 + 35 = 135%`，上一层见过门时是 `135 × 0.25 = 33.75%`，不能先封顶为100%再乘。
- 天使普通判定为 `1 − ∏(1 − p)`；只有基础50%和钥匙碎片1的25%时是62.5%。它是**开门后选择天使的比例**，不是最终开天使门概率。
- 最终天使概率 = 开门概率 × 天使比例；最终恶魔概率 = 开门概率 × 恶魔比例。两者相加等于开门概率。
- 首扇恶魔门完全没进的保底要尚未消费；已经开过保底天使后不继续选择这个状态。未见交易门的祝福保底与美德之书首次规则单独处理。
- 恶魔乞丐给道具的反向判定，与天使强制保底同时存在时，原表没有明确优先级；工具会标注这一组合，避免生成未经核对的最终数值。
- 红心自残的例外、XL层历史计数、沙漏回溯等请先对照机制文章，按游戏实际状态填写。它不是自动读取 HUD 的计算器。
