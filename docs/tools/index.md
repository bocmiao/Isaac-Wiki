# 实用工具

<VersionBadge checked="2026-10" />

| 工具 | 能做什么 | 数据来源 |
| --- | --- | --- |
| [角色解锁清单](/tools/tracker) | 34 个角色与十二格标记进度 | 角色攻略与完成标记 |
| [恶魔 / 天使房概率计算器](/tools/deal-chance) | 开门加成、历史惩罚、独立天使判定与最终概率 | 机制详解的两张概率表 |
| [献祭房奖励查询](/tools/sacrifice) | 查第1–12次及以后奖励 | 机制详解的献祭房表 |
| [挑战进度清单](/tools/challenges) | 45 个挑战的规则、前置、奖励与完成记录 | 全部挑战总表 |
| [捐款机进度](/tools/donations) | 贪婪与普通机里程碑、角色累计及已知卡住档位 | 贪婪攻略、成就数据与商店等级表 |
| [道具组合查询](/tools/synergies) | 8 组已核对联动、中文 / 英文 / ID 搜索、本局持有筛选 | 道具攻略的常见组合表 |
| [主线路线规划](/tools/routes) | 11 条目标路线、永久前置和本局步骤记录 | 结局一览与前置条件 |
| [控制台命令生成器](/tools/console-generator) | 按道具、角色、楼层和 debug 编号生成命令清单 | 控制台指南与已核对道具编号 |

挑战、捐款、道具持有与路线记录只存在当前浏览器，不读取游戏存档、不在设备间自动同步。各有独立导入导出，互不覆盖，也不覆盖角色清单。换设备或清浏览器数据前先导出；请勿直接拿角色清单文件导入另一个工具。

后续可以考虑每日目标记录，并继续按资料扩充道具组合库。
