# 实用工具

<VersionBadge checked="2026-10" />

| 工具 | 什么时候用 |
| --- | --- |
| [本地存档进度对照](/tools/local-progress) | 读自己的存档，找未解锁、未收集和未完成的内容；可下载后断网使用 |
| [全成就打勾](/achievements/#catalog) | 查成就条件，记录完成进度，筛选还没做的成就 |
| [道具速查](/tools/items) | 查道具、饰品、卡牌和胶囊的效果与获取方式 |
| [角色解锁清单](/tools/tracker) | 记录 34 个角色的解锁与十二格完成标记 |
| [恶魔 / 天使房概率计算器](/tools/deal-chance) | 算这一层打完 Boss 后开门的概率，以及会是哪种房间 |
| [献祭房奖励查询](/tools/sacrifice) | 查这一层第几次踩尖刺会给什么奖励 |
| [挑战进度清单](/tools/challenges) | 查 45 个挑战的规则与打法，勾选已经拿到奖杯的挑战 |
| [捐款机进度](/tools/donations) | 记录两台捐款机的数字，查下个奖励和卡住概率 |
| [道具组合查询](/tools/synergies) | 查 22 组道具组合的效果、副作用，以及还缺哪件 |
| [主线路线规划](/tools/routes) | 选本局目标，查前置条件和沿途要做的事 |
| [控制台命令生成器](/tools/console-generator) | 选物品、角色或楼层，生成可复制进游戏的命令 |

除本地存档工具外，各清单都靠你手动记录，保存在当前浏览器里。换设备或清浏览器数据前先导出备份，导入时使用同一工具的文件。

各工具的详细用法和资料出处见对应页面。
