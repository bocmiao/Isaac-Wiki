# 工具

边玩边用的小工具。进度都只存在你自己的浏览器里，不用注册；换设备或清理浏览器前，记得用工具里的「导出」备份。

| 工具 | 用来做什么 |
| --- | --- |
| [角色解锁清单](/tools/tracker) | 勾选解锁的角色，点格子记录 34 个角色的完成标记（十二格） |
| [全成就打勾](/achievements/#catalog) | 641 项成就逐项打勾，看完成进度，筛出还没做的 |
| [道具速查](/tools/items) | 按中文名、英文名或 ID 查道具、饰品、卡牌、胶囊，跳到 wiki |

::: tip 怎么搭配用
冲白金神时：先用**角色解锁清单**补标记，再用**全成就打勾**筛「只看未完成」，查到不认识的道具用**道具速查**。
:::
