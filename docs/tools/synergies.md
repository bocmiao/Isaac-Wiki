# 道具组合查询

<VersionBadge checked="2026-10" />

输入中文、英文、道具 ID 或效果关键词，查已收录联动。展开持有清单，勾选本局道具后可筛选“已有两件”或“还差一件”。清单会留在当前浏览器，换局请清空；支持独立导入导出。

<SynergyFinder />

## 收录范围

当前完整收录[道具攻略的常见组合表](/strategy/items#常见组合)中的 8 组，保留原文效果和限制；不是全部道具之间的组合数据库。未收录的关系显示无结果，不判断无效，也不按品质推算伤害。道具编号来自与控制台生成器共用的 `item-links.json`。

达摩克里斯之剑采用被动道具编号 **656**，不使用旧主动版本的 577。神圣屏障挡住伤害不会启动掉剑判定，但挡不住真正落下的剑；查询中保留了这一限制。硫磺火和菜刀的两倍伤害说明仅按原表的忏悔版本描述。

持有清单不读取游戏状态。导入会替换此工具的持有道具，其他工具记录不受影响。浏览器拒绝保存时会显示提示，仍可导出备份。
