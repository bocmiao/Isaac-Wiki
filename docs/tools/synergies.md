# 道具组合查询

<VersionBadge checked="2026-10" />

查站内收录的道具组合：多件组件、主动预算与负面风险会怎样改变取舍。可以按中文名、英文名、道具 ID 或效果关键词搜。

**本局用法**：展开「勾选本局已有道具」，勾上你拿到的，再把持有状态选成「已有部分」，就能看到还差哪件能凑成组合。新开一局时点「清空持有」。
