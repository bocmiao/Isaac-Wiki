# 道具组合查询

<VersionBadge checked="2026-10" />

查两件或多件道具放在一起会有什么效果、还缺哪件，以及有什么副作用。可以按中文名、英文名、道具 ID 或效果关键词搜。

**本局用法**：展开「勾选本局已有道具」，勾上你拿到的，再把持有状态选成「已有部分」，就能看到还差哪件能凑成组合。新开一局时点「清空持有」。

## 收录范围

- 目前收录 22 组，包括[八组常见组合](/strategy/items#常见组合)，以及[攻击替换、主动充能和变身组件](/strategy/synergies)，不是全部道具的组合库。搜不到不代表两件道具没有联动。
- 达摩克里斯之剑用底座上那件的编号 577。神圣屏障挡下的伤害不会触发掉剑，但挡不住真正落下来的剑。
- 硫磺火 + 妈妈的菜刀的 2 倍伤害说明来自忏悔版本。
- 勾选只存在这个浏览器里，不读取游戏；导入只替换这个工具的勾选。
