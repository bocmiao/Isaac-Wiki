本清单只记角色和标记。查其他成就用[全成就清单](/achievements/)，查道具收藏用[本地存档对照](/tools/local-progress)。

完成标记表中的角色名直接进入该角色的奖励对照。四终点合并、Boss Rush＋死寂、困难 / 极贪与开局强化的区别见[完成标记与补缺路线](/strategy/completion-marks)。需要核对真实存档时用[本地进度对照](/tools/local-progress)。

导入默认合并进度，保留已解锁角色和已完成的困难标记；选择“替换”才会覆盖整份清单。格式有误时保留原记录。从本地工具导入，请选它的“导出角色与标记 JSON”。
