# 贪婪与普通捐款机进度

<VersionBadge checked="2026-10" />

记录两台捐款机的累计数，看下一个奖励还差多少枚。

**第一次用先校正**：在下面「校正已有存档」里填上游戏中机器现在显示的数字；全新存档填 0。之后每次捐完，填这次实际投进去的枚数。

## 数据与边界

- **两个数字别弄混**：机器的总累计决定解锁到哪一步；某个角色自己历史上捐了多少，决定这个角色在贪婪捐款机上卡住的概率。两者没法互相推算。
- 贪婪和极贪共用一台机器的总累计。
- 卡住概率：贪婪模式里 127～168、174～199 枚这两段资料没列，工具显示「未列出」，不瞎补。极贪模式 0～54 枚不会卡，55 枚起最高 1%。
- 显示的卡住概率是投下一枚时的概率，不是「这一批都能投进去」的概率。
- 贪婪捐款机到 1000 枚解锁店主，机器会爆炸。
- 普通捐款机被炸会让显示的数字下降，但已经拿到的解锁不会丢。困难模式的商店不保证每层都是最高等级。
