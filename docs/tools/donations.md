# 贪婪与普通捐款机进度

<VersionBadge checked="2026-10" />

首次使用先按目标存档校正累计数；全新存档填写0。机器**总累计**决定里程碑，该角色的**历史累计**决定贪婪卡住档位，两者不能互相推算。只记录实际被机器接收的硬币，不是原本打算捐的金额。

<DonationTracker />

## 数据与边界

- 贪婪里程碑和卡住档位来自[贪婪捐款机](/strategy/greed#贪婪捐款机)及[卡住与爆炸](/strategy/greed#卡住与爆炸)。贪婪与极贪共用总累计；角色历史分开填写。
- 普通贪婪的127–168、174–199枚档位在原文省略，工具显示资料未列出，不补概率。极贪按原表0–54枚为0%，55枚起封顶1%。
- 1000枚解锁店主并使贪婪机爆炸；工具不会假定可以再往这个总累计加钱。某次记录填错可用校正输入恢复。
- 普通机的10个成就里程碑从 `data/achievement-source.json` 的普通 Donate 条件提取，与贪婪机分开；商店等级阈值来自[商店等级](/strategy/mechanics#商店等级)。
- 普通机数字因炸机下降不代表撤销永久解锁；工具显示当前数字是否达到阈值，不据此断定已有成就丢失。困难模式商店也不保证每层使用最高已解锁等级。
- 卡住概率是原表当前档位值，不是整批捐款全部成功的概率；工具不计算未经核对的整批模型。
