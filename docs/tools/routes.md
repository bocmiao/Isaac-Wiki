# 主线路线规划

<VersionBadge checked="2026-10" />

选一个想打的结局，工具告诉你存档还缺哪些前置条件，以及这一局要按什么顺序走。

**怎么用**

1. 「本局目标」选你想打的 Boss。
2. 在「永久解锁条件」里勾上存档已经做到的（比如心脏打过 11 次）。
3. 还缺的前置会显示在下面；这一局每走完一步就勾一步。

<RoutePlanner />

## 注意 {#怎样使用}

- 「永久解锁条件」记的是存档，「本局步骤」记的是这一局，两者不会互相影响。新开一局点「清空当前路线步骤」，存档条件不会被清掉。
- 超级撒但可以走宝箱或暗室，选哪边就检查哪边需要的照片和金门条件。这个选择刷新页面后会回到宝箱。
- 撒但、以撒按「它活着」之后的稳定走法检查。打心脏阶段也可能通过恶魔房或天使房提前去，显示「还需确认」不等于去不了。
- 普通主线和贪婪模式是两套规划，一局里不能随意切换。
- 不判断你的血量和输出够不够，具体打法看攻略原文。

## 收录范围 {#规则与边界}

11 条路线：撒但、以撒、???、羔羊、超级撒但、死寂、精神错乱、母亲、祸兽、贪婪、极贪。母亲路线包括下水道镜子、矿洞矿车、陵墓肉门、尸宫；回家路线包括全家福 / 底片、爸爸的便条和上行。出口是否出现仍取决于当前版本和本局条件。
