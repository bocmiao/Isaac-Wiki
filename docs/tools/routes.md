# 主线路线规划

<VersionBadge checked="2026-10" />

选择本局目标，按存档勾选永久解锁条件，再逐项核对本局入口与资源。普通局分支和贪婪模式分开规划，不能在一局中随意切换。路线步骤、永久条件与当前目标会保存在本浏览器，也可导入导出。

<RoutePlanner />

## 怎样使用

- 永久条件表示存档已解锁；本局步骤表示这一局已经完成，两者不会自动互相增加。
- 换目标会显示该路线自己的步骤记录；新开一局请点“清空当前路线步骤”。清空不会删除永久解锁记录。
- 超级撒但可选宝箱或暗室分支，工具会同时检查对应照片和金门条件。所选分支仅用于当前页面判断，刷新后默认宝箱。
- 撒但、以撒按它活着后的稳定入口检查条件；心脏阶段仍可能通过恶魔房或天使房提前进入，不能把“尚未确认”理解成绝对不能去。

## 规则与边界

11 条目标路线依据[结局一览与前置条件](/guide/unlocks/endings)：撒但、以撒、???、羔羊、超级撒但、死寂、精神错乱、母亲、祸兽、贪婪与极贪。母亲路线完整保留下水道镜面、矿车、陵墓肉门和尸宫步骤；回家路线保留愚者、照片、爸爸的便条与上行。

资源扣费采用攻略里的常规值，不代替特殊角色的存活判断，也不计算速度是否足够。虚空出口、超级撒但结局等版本差异保留说明；攻略标为待核实的出口细节不作必出承诺。详细打法与参考链接请进入原攻略。

此记录不读取存档，也不会修改游戏。导入会替换此工具的全部路线记录，其他进度工具不受影响。
