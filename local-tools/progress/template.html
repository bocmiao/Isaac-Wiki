Windows Steam《忏悔+》存档在哪里？

通常先找 Steam 的 userdata 目录；Steam 不一定安装在 C 盘。每个账号的数字文件夹分别查看：

Steam\userdata\<账号数字目录>\250900\remote\rep+persistentgamedata1.dat
Steam\userdata\<账号数字目录>\250900\remote\rep+persistentgamedata2.dat
Steam\userdata\<账号数字目录>\250900\remote\rep+persistentgamedata3.dat

其他存档位置可在“文档\My Games\Binding of Isaac Repentance+”检查。带日期的文件通常是备份，读取后请看文件名和修改时间。不要选本局的 gamestate、日志或 options.ini。

尚未选择存档。下载这个 HTML 后，用 Edge / Chrome 双击打开即可离线使用。

“已解锁”表示满足永久前置，“已收集”表示该存档收藏记录中取得过。工具不能判断每个饰品、卡牌或胶囊是否拿过，只显示它们的解锁前置。隐藏形态也不计入普通收集清单。

各类 JSON 分别导入网站对应的进度工具；成就 JSON 用于“全成就打勾”。条件、效果和收集对照可离线查看，打开完整站内教程需要联网。更换存档栏请重新选择文件。

支持忏悔 / 忏悔+ 的已知存档格式。遇到新格式、损坏文件或缺少记录时，会提示无法判断；Steam 账号成就不会替代当前存档进度。首次读取请与游戏 Stats / Secrets / Items 对照。
